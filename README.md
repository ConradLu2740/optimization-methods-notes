# 最优化方法与应用 · 学习资料

浙江工业大学《最优化方法与应用》课程的备考资料整理。包含三册复习材料、6 套模拟卷、8 道专项练题、23 题简答库，以及 15 个知识点讲解动画。

教材：陈宝林《最优化理论与算法》第 2 版（清华大学出版社，2005.10）。
覆盖章节：CH1–CH3（线性规划与单纯形法）、CH7–CH10 至 10.4（最优性条件、算法、一维搜索、使用导数的方法）、CH12（可行方向法）、CH13（惩罚函数法）。

## 怎么用

**从零开始**：先读 [docs/第三册-课件知识点与解析.md](docs/第三册-课件知识点与解析.md) 建立分章框架，再按 [docs/第一册-课件例题精讲.md](docs/第一册-课件例题精讲.md) 的 ★ 清单手推例题。

**考前速扫**：[docs/考前30分钟速扫版.md](docs/考前30分钟速扫版.md)，或看同名 PDF（`pdf/考前30分钟速扫版.pdf`）。

**刷题**：`exams/` 六套模拟卷按 120 分/140 分钟出，题型与真实考试一致（简答 + 计算大题 + 开放题）。`practice/` 是逐方法专项练题，共 8 道（KKT 二阶充分条件、外点罚函数、大M法、内点罚函数、0.618 一维搜索、Zoutendijk + Rosen 求方向、单纯形纯表、单纯形退化与循环），每题带答案锚点、预埋坑和复验记录。

**背简答**：[docs/简答题-全考点题库与答案-2026-11-22.md](docs/简答题-全考点题库与答案-2026-11-22.md)，23 题覆盖概念对比、凸性判别、定理、最优性条件、算法思想优缺点。遮答案自测可用同目录的自测版。

**看动画**：`animations/README.md` 有 15 个动画的清单和各自核心内容，MP4 在 `animations/renders/`。

三份考点总览（`docs/考点-知识点-例题答案-套路-总表.md`、`docs/考前总览-全考点套路例题解答-2026-11-21.md`、`docs/考前30分钟速扫版.md`）内容有重叠：前两份是完整版，速扫版是考前最后一晚看的压缩版。

## 数值都复验过

所有例题、模拟卷、练题的答案数字都由 `scripts/` 下的 Python 脚本复算过，不是手推一遍就落盘：

- 精确分数：`fractions.Fraction` 全程有理数运算，单纯形表逐格打印（`bigM_lib.py`、`verify_review_lp.py`、`verify_exam_bigM.py`）
- 符号计算：SymPy 解驻点方程、求极限、算 Hessian 特征值（`verify_penalty_in.py`、`verify_exam_v6.py`、`verify_kkt_disk.py`）
- 独立交叉：顶点枚举、消元法、scipy/HiGHS/SLSQP 多起点数值最小化，与符号解对拍（`cross_scipy.py`、`verify_simplex_pure.py`、`verify_zout_rosen.py`）

复验不是走过场：两阶段法例 1 的复算当场抓出过 4 处检验数笔误，Beale 循环例复跑时发现脚本混用 int/float 导致显示 0.0/−0.0。
