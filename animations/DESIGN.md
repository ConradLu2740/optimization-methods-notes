# DESIGN.md — 《最优化方法与应用》知识点动画系列

## Style Prompt

深色"数字黑板"：把考前复习的板书搬进屏幕。背景是深蓝墨色，内容像荧光笔写在黑板上——重点数字用琥珀色高亮，可行域用绿色，约束用蓝色，不可行/淘汰用红色。排版克制，表格是主角，动画只做一件事：让"哪一格在变、为什么变"看得见。整体气质是课堂讲义，不是产品发布。

## Colors

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| ground | #0E1526 | 全局背景（所有场景一致） |
| panel | #17233F | 表格/卡片底板 |
| ink | #E9EEF8 | 主文字 |
| muted | #8FA3C8 | 次要文字、坐标轴、注释 |
| accent | #FFC53D | 当前焦点：入基变量、主元、当前迭代点 |
| feasible | #3ECF8E | 可行域、可行方向、正确 |
| constraint | #5AA9FF | 约束线、等式、结构元素 |
| danger | #FF6B6B | 出局、不可行、负乘子 |

## Typography

- 中文标题/正文：`ZCOOL XiaoWei`（宋体气质，像讲义印刷体）
- 数字/表格/公式：`IBM Plex Mono`（等宽，tabular-nums，分数和 σ 行对齐）
- 权重对比：标题 400（ZCOOL 只有一重，靠字号和颜色分层），正文 350，数据 500

## Motion

- 能量级：Medium（讲解向）。主转场 = 横向 push slide，0.4s power3.inOut；关联场景之间用 blur crossfade 0.45s
- 入场全部 gsap.from，同一场景内 ease 至少三种（power3.out / power2.out / expo.out / back.out）
- 迭代动画节奏：高亮（0.3s）→ 停顿（0.4s）→ 换数（0.25s）→ 停顿，让学习者跟得上
- 装饰：细网格 + 低透明度幽灵多边形缓慢漂移

## What NOT to Do

- 不用渐变文字、不用紫蓝渐变、不用纯黑 #000 或纯白 #fff
- 不给每张卡加左侧亮色竖条
- 不做全屏线性渐变（H.264 色带）
- 表格数字不用比例数字（必须 tabular-nums，否则 σ 行列不齐）
- 不堆emoji当装饰；动画里出现的符号（σ、θ、λ）就是内容本身
