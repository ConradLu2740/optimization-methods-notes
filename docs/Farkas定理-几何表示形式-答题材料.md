## 一、先把定理陈述对（三种形式，考场写哪种）

### 形式 A（PPT 定理 2.11 原版，首选）

设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0，cᵀx > 0 有解的充要条件是：Aᵀy = c，y ≥ 0 无解。

### 形式 B（二择一形式，教材/LP 经典版）

设 A∈R^{m×n}，b∈R^m，则以下两个论断**有且只有一个**成立：

1. 存在 x∈R^n，使得 Ax = b，且 x ≥ 0；
2. 存在 y∈R^m，使得 Aᵀy ≥ 0，且 bᵀy < 0。

### 形式 C（置换定理 2.11′，画图最好用）

c 是 A 的行向量的凸锥组合（c ∈ cone A）⇔ 对任意满足 Ax ≤ 0 的向量 x∈R^n，都有 cᵀx ≤ 0。

⚠️ 三种形式是同一个定理的换写：B 是 LP 经典版（把 ≤ 写成 =、非负约束挪到 x 上）；C 是"锥"语言，**最适合画图**。考场建议：先写 A（PPT 原版），紧接一句"等价地（置换定理）c∈coneA 当且仅当……"，然后画图。

## 二、几何表示形式（核心，画图部分）

### 2.1 图里有什么

记 **S = cone A = {Aᵀy : y ≥ 0}**，即由 A 的**行向量** a₁,…,a_m 经非负组合张成的**凸锥**（二维平面里就是两条射线夹成的角形，顶点在原点）。

c 与 S 的关系**二择一**，有且只有一种发生：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | c 是行向量的非负组合（∃y≥0: Aᵀy=c）⇒ 系统 II 有解 | c 落在锥内，任何满足 Ax≤0 的方向 x 都与 c 成钝角/直角（cᵀx≤0），不存在 cᵀx>0 的方向 |
| c ∉ S | 系统 I 有解（Ax≤0, cᵀx>0），Aᵀy=c, y≥0 无解 | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0（即 Ax≤0）且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

### 2.2 考场 30 秒画法

1. 画两条从原点 O 出发的射线 a₁、a₂，夹角区域涂阴影表示凸锥 S（标上行向量名）
2. 画左右两个小图：**左图** c 点在锥内；**右图** c 点在锥外
3. 右图补一条**过原点 O 的虚线** H（分离超平面）+ 法向量箭头 x，标上 a₁ᵀx ≤ 0、a₂ᵀx ≤ 0、cᵀx > 0
4. 每个小图旁边写一句结论（照抄 2.1 表格第二列）

### 2.3 为什么分离超平面一定过原点（会被追问的点）

凸锥对非负数乘封闭：z∈S ⇒ tz∈S 对任意 t ≥ 0。所以 S 沿每条母线无限延伸，任何不经过原点的直线都会被某个足够大的 tz 穿过去，分不开。因此分离超平面必须**过原点**，图里 H 一定要画成穿过 O 的直线。

## 三、证明骨架（PPT 口径，让证就按这个写）

**必要性**（由 Ax≤0, cᵀx>0 有解，证 Aᵀy=c, y≥0 无解）——反证法：

设存在 y ≥ 0 使 Aᵀy = c　(1)。由条件取 x̄ 使 Ax̄ ≤ 0 且 cᵀx̄ > 0。将 (1) 式两端转置并右乘 x̄，得

> yᵀAx̄ = cᵀx̄　(2)

由于 y ≥ 0、Ax̄ ≤ 0，故 yᵀAx̄ ≤ 0，从而由 (2) 得 cᵀx̄ ≤ 0，与 cᵀx̄ > 0 矛盾。

**充分性**（由 Aᵀy=c, y≥0 无解，证 Ax≤0, cᵀx>0 有解）：

令 S = {z | z = Aᵀy, y ≥ 0}，则 S 为闭凸集。由假设 c ∉ S，根据**定理 2.7（严格分离）**，存在非零向量 x 及数 ε > 0，使对每一点 z ∈ S 成立

> xᵀc ≥ ε + xᵀz

于是：

- 令 z = 0（0 ∈ S），得 xᵀc > 0；
- 令 z = Aᵀy（y ≥ 0 任意），则 xᵀAᵀy < xᵀc 对一切 y ≥ 0 成立；左边关于 y 线性、y 的分量可任意大，故必有 xᵀAᵀ ≤ 0，即 **Ax ≤ 0**；
- 合并即得所求的 x。

（关键依赖就两点：S 是闭凸集 + Th2.7 严格分离——这也是第二节画法的理论根据，写在证明开头点一句即可。）

## 四、考场可直接抄的答题模板（约 400 字）

> **Farkas 定理**（定理 2.11）：设 A 为 m×n 矩阵，c 为 n 维向量，则 Ax ≤ 0、cᵀx > 0 有解的充要条件是 Aᵀy = c、y ≥ 0 无解。等价地（置换定理 2.11′）：c 是 A 的行向量的凸锥组合，当且仅当对任意满足 Ax ≤ 0 的 x 都有 cᵀx ≤ 0。
>
> **几何表示**：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥，则 c 与 S 的关系二择一。若 c ∈ S，则 c 可表为行向量的非负组合，此时任何满足 Ax ≤ 0 的方向 x 都与 c 成钝角或直角（cᵀx ≤ 0），故不存在使 cᵀx > 0 的方向；若 c ∉ S，由于 S 是闭凸锥且对非负数乘封闭，根据凸集严格分离定理，存在**过原点**的超平面 H: xᵀz = 0 将 c 与 S 分开，其法向量 x 满足 aᵢᵀx ≤ 0（即 Ax ≤ 0）且 cᵀx > 0。两种情形有且只有一个发生，此即 Farkas 定理的几何表示（如图所示）。
>
> **意义**：Farkas 定理与 Gordan 定理作为凸集分离定理的应用，在最优化理论中非常有用，是判断线性系统"有无可行方向"的基本工具。

## 五、易错点 / 捞分点

1. **"有且只有一个成立"**别写成"至少一个"——二择一形式是**排他**的，这是定理的魂
2. S 必须画成**锥**（从原点发出的射线束），不是半平面、不是线段——因为是 y ≥ 0 的非负组合
3. 分离超平面**过原点**（见 2.3），不过原点分不开无界锥
4. 系统别叫混：形式 A 中系统 I = {Ax ≤ 0, cᵀx > 0}，系统 II = {Aᵀy = c, y ≥ 0}
5. 意义句可用 PPT 原话："作为凸集分离定理的应用……在最优化理论中是很有用的"（s028）
6. **Gordan 定理（2.12）同源**，顺手记：Ax < 0 有解 ⇔ 不存在非零向量 y ≥ 0 使 Aᵀy = 0；证明同样是"必要性反证转置右乘 + 充分性构造 S₁∩S₂=∅ 用分离定理"的套路（s033–s036）
7. 💡 Farkas 正是 **LP 对偶定理的证明工具**（第 4 章内容）。对偶虽按不考准备，但若卷子上意外出现，至少能拿"用 Farkas 引理证明强对偶"的思路分——知道这层联系即可，不用展开
