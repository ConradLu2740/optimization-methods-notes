# 我是怎么学、怎么复习、怎么备考的

《最优化方法与应用》备考复盘（2026-11-08 定稿）。写给同样在啃这门课的人：哪些动作真的有用，哪些只是自我感觉良好。

## 一、学一个新方法，怎么才算真会

**1. 固定闭环：讨论 → 手写 → 核对 → 落盘。** 合上书先写一遍，再对答案。差异处才是真要学的地方。写到中途的方法（比如 DFP 算到 H₂、FR 算到 β₁），下一轮按"和第一轮完全相同"的口径续做。

**2. 数值一律机器复验。** 落盘的例题数值全部用精确分数 + Python 复算。复验不是走过场：两阶段法例 1 的复算当场抓出 4 处检验数笔误。验证类题目另做 KKT 残差与可行域抽样。

**3. 看不懂的理论，翻译成做题动作。** 说"二阶充分条件看不懂"时，有效的回应不是再堆理论，而是给别名（"临界锥 = 一阶判不了生死的嫌疑人名单"）+ 几何图 + 机械步骤。同一道题给三条路线并配选路表，而不是只教一条。

**4. 公式备好推导层。** 被连追三轮的问题（解释比值 → r 怎么求 → 有没有公式）落点是内核：等距 + 旧点复用，所以区间长度倒着长。讲新公式前先把推导层备好。

**5. 计算层和表述层分开学。** 每个方法带"命名与术语"小节：考场写哪个名、答哪个式。FR 要答的是 β = ‖g_{k+1}‖²/‖g_k‖² 那个式子；DFP 的 H_k 叫拟牛顿矩阵；Fibonacci 的 r_k 不用解、查表直读。

**6. 防错网和直观图前置。** 自检口诀先行（两点等距、系数和 = 1），易错点清单先行，抽象主题配直观图。

**7. 机器复验要留下"考场版"。** AI 不在场时靠什么兜底？已经转化成考场自检的只有两处：0.618 自检三件套（等距 / 系数和 = 1 / 旧点在新区间）和单纯形表四步自检（基变量列须为单位向量、基解 = b 列）。可以继续转化的：KKT 解出乘子后代回原式验残差、FR 抽验相邻梯度正交与方向共轭、DFP 每步验 H 对称、二阶题先数临界锥再决定动不动 Hessian。

## 二、复习：怎么排、怎么检索、怎么分档

**1. 材料按考场动作拆，不按章节拆。** 三册分别对应"刷题手推 / 背简答 / 精读与考前速记"。用时按动作取册，不按目录翻。

**2. 清单 ≠ 练习。** 设计层（★ 标记、必考手推清单、带具体参数值的 checklist）很容易建，但执行层的数据约等于零。判定标准应该是**带日期与对错结果的提取记录**：哪天、闭卷、哪题、对错、用时。没有这个记录，"清单建好了"只是幻觉。

**3. 多层压缩。** 全量解析 → 公式卡（考前一夜只看这一页）→ 一句话储备（考前扫一遍）。低优先级内容只占一行。

**4. 顺序看规定档，分值只当弱依据。** 老师口头点名 > 无署名考点清单里的"20 分"。同一份清单在反面清单里是坑源，在排序里就只能当参考。

**5. 掌握状态如实分三档。** A 档 = 手写回传 + 逐项核对一致；B 档 = 讲解到推导层 + 自评"懂了"，无手写回传；C 档 = 代写或未做。**自评"懂了"最多值 B 档**，要靠自测小问或手写回传才能升 A。

**6. 考场迁移缺一层：从没练过"题与题之间"。** 时间预算都停在单题层。考场第一动作是"拿到题 → 识别是两阶段还是大 M、是 FR 还是 DFP"，这个动作从来没被练过。要补：混卷限时连做，每题记录"识别方法耗时 + 总用时"，错配（把 FR 题当 DFP 做）单独复盘。

## 三、备考：范围怎么定、材料怎么组织

**范围三条铁律**：① 只认任课老师本人（课堂口头 / 讲义）这一权威源，参考其他老师得来的信息显式标来源、尽早澄清；信息分"规定 vs 判断"两档，老师口头是规定、最高优先级，自己的推断是判断、不得冒充。② "没材料 ⇒ 不考"要跟材料状态挂钩，材料一到就重估。③ 定稿前先问"资料是否发全"，用确认关账。

**范围变更的同步流程**：先改总索引再动分册，两份索引当场都改到位、含理由和日期。漏改一份，后续就会按旧范围答错。

**材料组织**：逐章对照表带页码与考否状态；每道例题带精确出处；每册开头声明定位并互链；背诵内容写成"可直抄模板"并标字数与时间预算，骨架固定 + 机制段可替换，防考场换算法；易错点按"别写反""别漏"这类防错动作写；教材与课程口径冲突时以讲义为准。

**真题维度整体缺席。** 上面三条铁律解决了"考什么知识点"，材料组织解决了"怎么背"，但很容易一句都不提往年真题、样卷、题型结构。而题型结构直接决定设计是否现实：纯计算卷的话，300–500 字直抄模板的预算就得往下调。这是考前信息收集里性价比最高的一块。

## 四、和 AI 协作：谁写由我的原话决定

五种模式：

- **"教我 X"**（讲解模式）：先对齐定理编号、记号、例题再讲，结构走"地图 → 几何 → 代数 → 例题 → 考试口径"，配直观图 + 小数值例手走 + 结尾留小问让我接手。
- **"把题目给我"**：只给题面，不带过程不带提示。保住产生式学习。
- **"你先自己求 / 我也写一下"**：AI 先解、与我的版本对照，互相验证、暴露差异。
- **"你写一下"**（纯代写）：解完精确分数 + Python 复验后落盘，但文中注明"代写、未复推"。兜底模式，成本最低，但不冒充掌握。
- **停笔"不写了，你参考 XX 文档补充"**：按我的口径补全剩余步骤，写进我指名的那份文档，不自动全链路搬。

有效的根源：考试是我自己考，我要亲手练。配套一条汇报纪律：说"已改"之前必须确认编辑真的成功，拿不准就说"还没改"。

## 五、踩过的坑

1. **二手资料当权威。** 混合来源的考点清单让"对偶要考"误导了整整两天，才被拍板推翻。
2. **用"没材料"推"不考"。** 被当天新发的讲义推翻。判断必须挂钩材料状态。
3. **合并 / 转写 / 复算必有笔误。** 旧稿 Beale 例 x4 系数 1/4 实为 1/2、单纯形例 1 的 x4 = 3 实为 1；手写笔记 Fibonacci 分母下标、∇²ₓₓL 符号两处。凡转写来的内容逐条重核；发现旧错不静默覆盖，留勘误记录。
4. **手写 / 口述的不确定信息直接采信。** 一行字被误读成另一个考点；过期日期被当成考试日期。存疑就挂账，别猜。
5. **没读材料就下覆盖结论。** "本册到牛顿法为止"被核对推翻——阻尼牛顿、修正牛顿都在同一份 PDF 里。下覆盖结论前先抽文本或渲染核对。
6. **虚报完成比不汇报更糟。** 汇报"已同步"而编辑实际未执行；声称写入的记忆实际未落盘。这两类事故比"还没做"伤害大得多。
