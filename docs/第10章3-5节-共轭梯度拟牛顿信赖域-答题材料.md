## 〇、四种无约束方法一张表（简答题"比较各方法"直接套）

| 方法 | 方向 | 每步计算量 | 收敛速度 | 终止性 | 主要缺点 |
|---|---|---|---|---|---|
| 最速下降法 10.1 | d = −∇f | 最低（一个梯度） | **线性**，且靠近极值点锯齿严重、很慢 | 无 | 太慢 |
| 牛顿法 10.2 | d = −∇²f⁻¹∇f | 最高（Hessian + 求逆） | **二次** | 有限步（二次函数一步到位） | Hessian 难算、可能不正定、初点要近 |

| **共轭梯度 10.3** | d = −g + βd_prev | **低**（只存几个向量） | 二次（正定二次函数） | **≤ n 步** | 对非二次函数要重启 |
| **拟牛顿 10.4** | d = −H_k g（H_k ≈ ∇²f⁻¹） | 中（一次一维搜索 + 秩2更新） | **超线性** | **≤ n 步**（二次终止） | 需存 n×n 矩阵 |

# 10.3 共轭梯度法

## 一、几何出发点（PPT 开篇原话）

二次函数等值面上一点的法向量：**梯度向量必须与等值面的切向量垂直**，即**梯度向量在某点处就是该点等值面的法向量**。

最速下降法的问题是：相邻两次搜索方向**正交**（g_{k+1}ᵀg_k = 0），在拉长了的等值面上来回锯齿。共轭方向法改为让相邻方向**关于 A 共轭**（A-正交），从而 n 步走完。

## 二、基本概念与两条定理

**定义 10.3.1**：设 A 是 n×n **对称**矩阵，若 Rⁿ 中两个方向 d⁽¹⁾、d⁽²⁾ 满足

    (d⁽¹⁾)ᵀ A d⁽²⁾ = 0                （10.3.1）

则称这两个方向**关于 A 共轭**（或称关于 A 正交）。若 d⁽¹⁾,…,d⁽ᵏ⁾ 两两关于 A 共轭，即

    (d⁽ⁱ⁾)ᵀAd⁽ʲ⁾ = 0,  i ≠ j ,  i,j = 1,…,k      （10.3.2）

则称这组方向是 **A 共轭的**，或称它们为 A 的 k 个共轭方向。

**定理 10.3.1**：设 A 是 n 阶**对称正定**矩阵，d⁽¹⁾,…,d⁽ᵏ⁾ 是 k 个 A 共轭的非零向量，则这个向量组**线性无关**。

**定理 10.3.2（扩张子空间定理）⭐全章最重要**：设有函数

    f(x) = ½ xᵀAx + bᵀx + c

其中 A 是 n 阶对称正定矩阵，d⁽¹⁾,…,d⁽ᵏ⁾ 是 A 共轭的非零向量。以任意的 x⁽¹⁾ ∈ Rⁿ 为初始点，依次沿 d⁽¹⁾,…,d⁽ᵏ⁾ 进行一维搜索，得到点列 x⁽¹⁾,…,x⁽ᵏ⁺¹⁾，则 **x⁽ᵏ⁺¹⁾ 是函数 f(x) 在线性流形 x⁽¹⁾ + Γκ 上的唯一极小点**。特别地，当 **k = n** 时，x⁽ᵏ⁺¹⁾ 是 f(x) 在 Rⁿ 上的唯一极小点。其中

    Γκ = { x⁽¹⁾ + Σ_{i=1..k} λᵢd⁽ⁱ⁾ ,  λᵢ ∈ (−∞, +∞) }

是 d⁽¹⁾,…,d⁽ᵏ⁾ 生成的子空间。

**推论**：在 Th10.3.2 的条件下，**g_{k+1}ᵀd⁽ʲ⁾ = 0, ∀j ≤ k**。当 k = n 时必有 **g_{n+1} = 0**，从而 x⁽ⁿ⁺¹⁾ 是 f 在 Rⁿ 上的唯一极小点。

> 💡 **你可能还需要考虑**：扩张子空间定理是"共轭梯度法 ≤ n 步终止"的唯一理论依据。简答题若问"为什么共轭梯度法有二次终止性"，答案就是：沿 n 个 A 共轭方向一维搜索后，搜索子空间扩张到整个 Rⁿ，由 Th10.3.2 即得全局最优。

## 三、算法 1：共轭方向法（3 步）

1. **初始化**：给定初始点 x⁽⁰⁾ ∈ Rⁿ，计算 ∇f(x⁽⁰⁾)，给定一个搜索方向 d⁽⁰⁾ ≠ 0 使 ∇f(x⁽⁰⁾)ᵀd⁽⁰⁾ < 0；置 k = 0；
2. **线搜索**：求解一维极小化问题 min_{α∈R} f(xᵏ + αdᵏ)；令 xᵏ⁺¹ = xᵏ + αᵏdᵏ，若 ∇f(xᵏ⁺¹) = 0 或 k = n，停止；否则转步 3；
3. **计算共轭方向**：计算一个非零方向 dᵏ⁺¹ ∈ Rⁿ，使 (dᵏ⁺¹)ᵀGd⁽ʲ⁾ = 0（∀j = 0,1,…,k）；置 k+1 → k，转步 2。

## 四、Fletcher-Reeves (FR) 共轭梯度法 ⭐必考

一般迭代格式：已知 x⁽ᵏ⁾ 和 d⁽ᵏ⁾，则

    x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏ d⁽ᵏ⁾                （10.3.14）

其中 λᵏ 满足 f(x⁽ᵏ⁺¹⁾) = min f(x⁽ᵏ⁾ + λd⁽ᵏ⁾)。

**推导步长 λᵏ（10.3.17）**——考场可能要推：

记 φ(λ) = f(x⁽ᵏ⁾ + λd⁽ᵏ⁾)，令 φ′(λ) = ∇f(x⁽ᵏ⁺¹⁾)ᵀd⁽ᵏ⁾ = 0（10.3.15），即 (Ax⁽ᵏ⁺¹⁾+b)ᵀd⁽ᵏ⁾ = 0。代入 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾+λᵏd⁽ᵏ⁾：

    (gᵏ + λᵏAd⁽ᵏ⁾)ᵀd⁽ᵏ⁾ = 0              （10.3.16）
    ⟹  λᵏ = − gᵏᵀd⁽ᵏ⁾ / (d⁽ᵏ⁾ᵀ A d⁽ᵏ⁾)        （10.3.17）

**构造下一方向（10.3.18–10.3.19）**：

    d⁽ᵏ⁺¹⁾ = −g_{k+1} + βᵏd⁽ᵏ⁾              （10.3.18）

上式两端左乘 (d⁽ᵏ⁾)ᵀA 并令其为 0（保证 A-共轭）：

    (d⁽ᵏ⁾)ᵀA d⁽ᵏ⁺¹⁾ = −(d⁽ᵏ⁾)ᵀA g_{k+1} + βᵏ(d⁽ᵏ⁾)ᵀA d⁽ᵏ⁾ = 0
    ⟹  βᵏ = (d⁽ᵏ⁾)ᵀA g_{k+1} / (d⁽ᵏ⁾)ᵀA d⁽ᵏ⁾       （10.3.19）

**在第一个搜索方向取负梯度的前提下，重复使用 10.3.14、10.3.17–3.19 就能伴随计算点的增加，构造出一组搜索方向。**

### 定理 10.3.3 ⭐（FR 的有限步终止）

对于正定二次函数（10.3.12），具有**精确一维搜索**的 Fletcher-Reeves 法在 **m ≤ n 次一维搜索后即终止**，并且对所有 i（1 ≤ i ≤ m）下列关系成立：

1. (d⁽ⁱ⁾)ᵀA d⁽ʲ⁾ = 0，j = 1,2,…,i−1
2. gᵢᵀg_j = 0，j = 1,2,…,i−1；且 **gᵢᵀd⁽ⁱ⁾ = −gᵢᵀgᵢ**（蕴涵 d⁽ⁱ⁾ ≠ 0）
3. （梯度逐次正交）

**注意（PPT 原文，简答可考）**：**初始搜索方向选择最速下降方向十分重要**。如果选择别的方向作为初始方向，其余方向均按 FR 方法构造，则极小化正定二次函数时，这样构造出来的一组方向**并不能保证共轭性**。

### 定理 10.3.4 ⭐（β 的省算公式）

对于正定二次函数，FR 法中因子 βᵢ 具有下述表达式

    βᵢ = ‖g_{i+1}‖² / ‖gᵢ‖²        （i ≥ 1, gᵢ ≠ 0）    （10.3.24）

即**不作矩阵运算**就能求出 βᵢ——这是 FR 法实用的关键。

### FR 算法（对二次凸函数）5 步 —— 默写级

1. 给定初点 x⁽¹⁾，置 k = 1；
2. 计算 gᵏ = ∇f(x⁽ᵏ⁾)。若 **gᵏ = 0，停止计算，得点 x\* = x⁽ᵏ⁾**；否则进行下一步；
3. 构造搜索方向：令 **d⁽ᵏ⁾ = −gᵏ + βᵏ⁻¹d⁽ᵏ⁻¹⁾**，其中当 k = 1 时 βᵏ⁻¹ = 0，当 k > 1 时按公式（10.3.24）计算 βᵏ⁻¹；
4. 令 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾，其中按公式（10.3.17）计算步长 λᵏ；
5. 若 **k = n**，则停止计算，得点 x\* = x⁽ᵏ⁺¹⁾；否则置 k = k+1，转 2。

## 五、用于一般函数的共轭梯度法（非线性）

一般迭代格式（10.3.3.1）：

    x_{k+1} = xᵏ + αᵏdᵏ
    d_{k+1} = −g_{k+1} + βᵏdᵏ ,  k = 0,1,…

其中初始方向 **d₀ = −g₀**，步长 αᵏ 由一维搜索得到，βᵏ 的计算公式通常有 5 种：

| 编号 | 名称 | 公式 |
|---|---|---|
| 1 | **Fletcher-Reeves (FR)** | βᵏ = (g_{k+1}ᵀg_{k+1}) / (gᵏᵀgᵏ) |
| 2 | **PRP (Polak-Ribière-Polyak)** | βᵏ = g_{k+1}ᵀ(g_{k+1} − gᵏ) / (gᵏᵀgᵏ) |
| 3 | **SW (Sorenson-Wolfe)** | βᵏ = g_{k+1}ᵀ(g_{k+1} − gᵏ) / [ dᵏᵀ(g_{k+1} − gᵏ) ] |
| 4 | **Daniel** | βᵏ = [dᵏᵀ∇²f(x_{k+1})g_{k+1}] / [dᵏᵀ∇²f(x_{k+1})dᵏ] |
| 5 | **Dixon** | βᵏ = −(g_{k+1}ᵀg_{k+1}) / (dᵏᵀgᵏ) |

**带重启的 FR 算法**（用于一般函数，5 步）：给定初始点 x⁽¹⁾，允许误差 ε>0，置 y⁽¹⁾=x⁽¹⁾、d⁽¹⁾=−∇f(y⁽¹⁾)、k=j=1；
2. 若 ‖∇f(y⁽ʲ⁾)‖ < ε 则停止，否则作一维搜索求 λʲ 使 f(y⁽ʲ⁾+λʲd⁽ʲ⁾) = min，令 y⁽ʲ⁺¹⁾ = y⁽ʲ⁾ + λʲd⁽ʲ⁾；
3. 如果 j < n 转步 4，否则转步 5；
4. 令 d⁽ʲ⁺¹⁾ = −∇f(y⁽ʲ⁺¹⁾) + βʲd⁽ʲ⁾，其中 βʲ = ‖∇f(y⁽ʲ⁺¹⁾)‖²/‖∇f(y⁽ʲ⁾)‖²，置 j=j+1 转步 2；
5. 令 x⁽ᵏ⁺¹⁾ = y⁽ⁿ⁺¹⁾，y⁽¹⁾ = x⁽ᵏ⁺¹⁾，d⁽¹⁾ = −∇f(y⁽¹⁾)，置 j=1、k=k+1，转步 2。

### 收敛性定理 ⭐

假设函数 f: Rⁿ → R **有下界**，梯度 ∇f(x) **Lipschitz 连续**。在 FR 共轭梯度法中，步长参数 αᵏ 由**精确线搜索**确定，并且满足**充分下降条件（Armijo 条件）**：

    f(xᵏ + λᵏdᵏ) ≤ f(xᵏ) + c₁λᵏ∇f(xᵏ)ᵀdᵏ

若 ∀k ≥ 0, gᵏ ≠ 0，则

    **liminf_{k→+∞} ‖gᵏ‖ = 0**

### 共轭梯度法的特点（6 条，PPT 原文，简答直接抄）

1. 对凸函数**全局收敛**（下降算法）；
2. 计算公式简单，**不用求 Hessian 矩阵或者逆矩阵**，计算量小、存储量小，每步迭代只需存储若干向量，**适用于大规模问题**；
3. 具有**二次收敛性**（对于正定二次函数，至多 n 次迭代可达最优解）；
4. **收敛速率不坏于最速下降法**；如果初始方向不用负梯度方向，则其收敛速率是**线性收敛**的；
5. 是目前求解无约束优化问题**最常用的方法之一**；
6. 共轭梯度法有多种求解形式，不同的求解公式对于正定二次函数是等价的，对非正定二次函数有不同的效果。

## 六、⭐ 例 10.3.2（PPT 原题，考试可能直接搬）

    min f(x) = x1² + 2x2² ,  初始点 x⁽¹⁾ = (5, 5)ᵀ
    ∇f(x) = (2x1, 4x2)ᵀ

**k = 1**：

    d⁽¹⁾ = −g⁽¹⁾ = (−10, −20)ᵀ
    x⁽²⁾ = x⁽¹⁾ + λ1d⁽¹⁾ = (5 − 10λ1, 5 − 20λ1)ᵀ
    φ(λ1) = f(x⁽²⁾) = (5 − 10λ1)² + 2(5 − 20λ1)²
    由 φ′(λ1) = 0  ⟹  λ1 = 5/18 ,  x⁽²⁾ = (20/9, −5/9)ᵀ

**k = 2**：

    g⁽²⁾ = (40/9, −20/9)ᵀ
    β1 = ‖g⁽²⁾‖² / ‖g⁽¹⁾‖² = [ (40/9)² + (−20/9)² ] / (10² + 20²) = (2000/81)/500 = **4/81**
    d⁽²⁾ = −g⁽²⁾ + β1d⁽¹⁾ = (−40/9, 20/9)ᵀ + (4/81)(−10, −20)ᵀ = (−400/81, 100/81)ᵀ = (100/81)(−4, 1)ᵀ

从 x⁽²⁾ 出发沿 d⁽²⁾ 作一维搜索：

    x⁽³⁾ = x⁽²⁾ + λ2d⁽²⁾ ,  由 φ′(λ2) = 0 得 λ2 = **9/20**
    x⁽³⁾ = (20/9, −5/9)ᵀ + (9/20)·(100/81)(−4, 1)ᵀ = (20/9, −5/9)ᵀ + (5/9)(−4, 1)ᵀ = **(0, 0)ᵀ**

g⁽³⁾ = (0, 0)ᵀ，已达到极小点 **x\* = (0, 0)ᵀ**。**两步终止（n = 2）**，正是 Th10.3.3 的体现。

# 10.4 拟牛顿法

## 一、基本思想（简答题标准答案）

牛顿法成功的关键在于利用了 **Hessian 矩阵提供的曲率信息**，而计算 Hessian 矩阵工作量大，并且有的目标函数的 Hessian 矩阵很难计算，甚至不好求出。**拟牛顿法就是利用目标函数值 f 和一阶导数 g 的信息，构造出目标函数的曲率近似，而不需要明显形成 Hessian 矩阵，同时具有收敛速度快的优点。**

阻尼牛顿法的迭代公式：

    x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾                  （10.4.1）
    d⁽ᵏ⁾ = −∇²f(x⁽ᵏ⁾)⁻¹ ∇f(x⁽ᵏ⁾)             （10.4.2）

目标：构造 H^{k+1} 近似 ∇²f(x⁽ᵏ⁺¹⁾)⁻¹。

## 二、拟牛顿条件（割线方程）⭐

设在第 k 次迭代后得点 x⁽ᵏ⁺¹⁾，将 f(x) 在 x⁽ᵏ⁺¹⁾ 附近 Taylor 展开：

    f(x) ≈ f(x⁽ᵏ⁺¹⁾) + ∇f(x⁽ᵏ⁺¹⁾)ᵀ(x − x⁽ᵏ⁺¹⁾) + ½(x − x⁽ᵏ⁺¹⁾)ᵀ∇²f(x⁽ᵏ⁺¹⁾)(x − x⁽ᵏ⁺¹⁾)

于是在 x⁽ᵏ⁺¹⁾ 附近

    g(x) = ∇f(x) ≈ ∇f(x⁽ᵏ⁺¹⁾) + ∇²f(x⁽ᵏ⁺¹⁾)(x − x⁽ᵏ⁺¹⁾)      （10.4.3）

令 x = x⁽ᵏ⁾，并记

    p⁽ᵏ⁾ = x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾                    （10.4.4）
    q⁽ᵏ⁾ = ∇f(x⁽ᵏ⁺¹⁾) − ∇f(x⁽ᵏ⁾) = g_{k+1} − gᵏ   （10.4.5）

则

    q⁽ᵏ⁾ ≈ ∇²f(x⁽ᵏ⁺¹⁾) p⁽ᵏ⁾                （10.4.6）
    p⁽ᵏ⁾ ≈ ∇²f(x⁽ᵏ⁺¹⁾)⁻¹ q⁽ᵏ⁾              （10.4.7）

于是计算出 p⁽ᵏ⁾ 和 q⁽ᵏ⁾ 后，可根据（10.4.7）估计 x⁽ᵏ⁺¹⁾ 处 Hessian 矩阵的逆。令 H^{k+1} 取代牛顿法中的 Hessian 逆，则 H^{k+1} 满足

    **p⁽ᵏ⁾ = H^{k+1} q⁽ᵏ⁾**                    （10.4.8）

（10.4.8）称为**拟牛顿条件（方程）**，也称为**割线方程**。

**构造策略**：当 ∇²f(x⁽ᵏ⁾) 是 n 阶对称正定矩阵时，满足拟牛顿条件的 H^{k+1} 也应是 n 阶对称矩阵。一般做法是：**H₁ 取为任意 n 阶对称正定矩阵（如单位阵 I）**，然后通过修正 Hᵏ 给出 H^{k+1}：

    H^{k+1} = Hᵏ + ΔHᵏ                        （10.4.9）

ΔHᵏ 称为**校正矩阵**。

## 三、三种校正公式 ⭐

**对称秩 1 校正**（10.4.14）：

    H^{k+1} = Hᵏ + (p⁽ᵏ⁾ − Hᵏq⁽ᵏ⁾)(p⁽ᵏ⁾ − Hᵏq⁽ᵏ⁾)ᵀ / [ q⁽ᵏ⁾ᵀ(p⁽ᵏ⁾ − Hᵏq⁽ᵏ⁾) ]

**秩 2 校正 —— DFP 公式**（10.4.18）：

    H^{k+1} = Hᵏ + p⁽ᵏ⁾p⁽ᵏ⁾ᵀ/(p⁽ᵏ⁾ᵀq⁽ᵏ⁾) − Hᵏq⁽ᵏ⁾q⁽ᵏ⁾ᵀHᵏ/(q⁽ᵏ⁾ᵀHᵏq⁽ᵏ⁾)

DFP 算法是 **Davidon（1959）**提出的，后来 **Fletcher 和 Powell（1963）** 作了改进，形成 Davidon-Fletcher-Powell 算法。它是**第一个被提出的拟 Newton 法**，也是无约束最优化问题的最有效的算法之一，已被广泛采用。

**BFGS 公式**：若用不含二阶导数的矩阵 B_{k+1} 近似 Hessian ∇²f(x⁽ᵏ⁺¹⁾)，则由（10.4.6）得另一种形式的拟牛顿条件

    q⁽ᵏ⁾ = B_{k+1}p⁽ᵏ⁾                        （10.4.31）

修正公式（10.4.32）：

    B_{k+1} = Bᵏ + q⁽ᵏ⁾q⁽ᵏ⁾ᵀ/(q⁽ᵏ⁾ᵀp⁽ᵏ⁾) − Bᵏp⁽ᵏ⁾p⁽ᵏ⁾ᵀBᵏ/(p⁽ᵏ⁾ᵀBᵏp⁽ᵏ⁾)

设 B_{k+1} 可逆，则 p⁽ᵏ⁾ = B_{k+1}⁻¹q⁽ᵏ⁾，令 **H_{k+1} = B_{k+1}⁻¹**（10.4.34）。利用 **Sherman-Morrison 公式**可得关于 H 的 BFGS 公式（10.4.35）：

    H_{k+1}^{BFGS} = Hᵏ + (1 + q⁽ᵏ⁾ᵀHᵏq⁽ᵏ⁾/(p⁽ᵏ⁾ᵀq⁽ᵏ⁾)) · p⁽ᵏ⁾p⁽ᵏ⁾ᵀ/(p⁽ᵏ⁾ᵀq⁽ᵏ⁾)
                        − [ p⁽ᵏ⁾q⁽ᵏ⁾ᵀHᵏ + Hᵏq⁽ᵏ⁾p⁽ᵏ⁾ᵀ ] / (p⁽ᵏ⁾ᵀq⁽ᵏ⁾)

上述公式由 **Broyden, Fletcher, Goldfarb, Shanno（1970）** 给出。

**Broyden 簇**：DFP 和 BFGS 公式都有由 p⁽ᵏ⁾ 和 Hᵏq⁽ᵏ⁾ 构成的**对称秩 2 校正**，故此两公式的加权组合仍具有相同的形式：

    H_{k+1}^φ = (1 − φ)H_{k+1}^{DFP} + φH_{k+1}^{BFGS}        （10.4.36）

## 四、DFP 算法 7 步 —— 默写级

1. 给定初始点 x⁽¹⁾ ∈ Eⁿ，允许误差 ε > 0；
2. 置 **H₁ = Iₙ**，计算出 x⁽¹⁾ 处的梯度 g₁ = ∇f(x⁽¹⁾)，置 k = 1；
3. 令 **d⁽ᵏ⁾ = −Hᵏgᵏ**；
4. 从 x⁽ᵏ⁾ 出发沿 d⁽ᵏ⁾ 进行一维搜索，求 λᵏ 使 f(x⁽ᵏ⁾+λᵏd⁽ᵏ⁾) = min_{λ≥0}；令 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾；
5. 检验收敛准则：若 ‖∇f(x⁽ᵏ⁺¹⁾)‖ ≤ ε，停止，得 x\* = x⁽ᵏ⁺¹⁾；否则转 6；
6. 若 k = n，则令 x⁽¹⁾ = x⁽ᵏ⁺¹⁾，转 2；否则转 7；
7. 令 g_{k+1} = ∇f(x⁽ᵏ⁺¹⁾)，p⁽ᵏ⁾ = x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾，q⁽ᵏ⁾ = g_{k+1} − gᵏ，由公式（10.4.18）计算 H^{k+1}，置 k = k+1，转 3。

## 五、⭐ 例 1（PPT 原题，第一步已算好，考场接着做）

    min f = 2x1² + x2² − 4x1 + 2
    x⁽¹⁾ = (2, 1)ᵀ ,  H₁ = [1 0; 0 1]
    g = ( 4(x1 − 1), 2x2 )ᵀ

**第 1 次迭代**：

    g₁ = (4, 2)ᵀ
    d⁽¹⁾ = −H₁g₁ = (−4, −2)ᵀ
    一维搜索 min f(x⁽¹⁾ + λd⁽¹⁾), λ ≥ 0  ⟹  λ1 = 5/18
    x⁽²⁾ = (2, 1)ᵀ + (5/18)(−4, −2)ᵀ = (8/9, 4/9)ᵀ
    g₂ = ( 4(8/9 − 1), 2·4/9 )ᵀ = (−4/9, 8/9)ᵀ

第 2 次迭代继续：p⁽¹⁾ = x⁽²⁾−x⁽¹⁾ = (−10/9, −5/9)ᵀ，q⁽¹⁾ = g₂−g₁ = (−40/9, 2/9)ᵀ，代入（10.4.18）算 H²，再 d⁽²⁾ = −H²g₂ 继续一维搜索。**n = 2，按 Th10.4.2 至多两步到位。**

## 六、DFP 的两条收敛性定理 ⭐

**定理 10.4.1**：若 gᵢ ≠ 0, i = 1,…,n，则 DFP 方法构造的矩阵 Hᵢ (i = 1,…,n) 为**对称正定矩阵**。

**证明骨架（归纳法，PPT 用 5 页，考场写关键三步即可）**：
1. H₁ 给定对称正定；设 H_j 对称正定，证 H_{j+1}。**对称性显然**（DFP 公式三项都对称）。
2. 正定性：对任意非零 y ∈ Eⁿ，

       yᵀH_{j+1}y = yᵀH_jy + (yᵀp⁽ʲ⁾)²/(p⁽ʲ⁾ᵀq⁽ʲ⁾) − (yᵀH_jq⁽ʲ⁾)²/(q⁽ʲ⁾ᵀH_jq⁽ʲ⁾)     （10.4.19）

3. H_j 对称正定 ⟹ ∃可逆 u_j 使 **H_j = u_jᵀu_j**。令 p̄ = u_jy, q̄ = u_jq⁽ʲ⁾，则 yᵀH_jy = p̄ᵀp̄，yᵀH_jq⁽ʲ⁾ = p̄ᵀq̄，q⁽ʲ⁾ᵀH_jq⁽ʲ⁾ = q̄ᵀq̄，代入得

       yᵀH_{j+1}y = (yᵀp⁽ʲ⁾)²/(p⁽ʲ⁾ᵀq⁽ʲ⁾) + [ (p̄ᵀp̄)(q̄ᵀq̄) − (p̄ᵀq̄)² ] / (q̄ᵀq̄)    （10.4.21）

4. 由 **Schwartz 不等式**，(p̄ᵀp̄)(q̄ᵀq̄) − (p̄ᵀq̄)² > 0（10.4.22）；
5. 由一维搜索及方向定义，

       p⁽ʲ⁾ᵀq⁽ʲ⁾ = λ_jd⁽ʲ⁾ᵀ(g_{j+1} − g_j) = −λ_jd⁽ʲ⁾ᵀg_j = −λ_j(−H_jg_j)ᵀg_j = λ_j g_jᵀH_jg_j > 0   （10.4.23）

   （λ_j > 0, g_j ≠ 0, H_j 正定）⟹ (yᵀp⁽ʲ⁾)²/(p⁽ʲ⁾ᵀq⁽ʲ⁾) ≥ 0（10.4.24）；
6. 最后证（10.4.22）与（10.4.24）**不同时为 0**：若（10.4.22）= 0 则 p̄ ∥ q̄，即 p = βq (β≠0)，从而 y = βp⁽ʲ⁾ ⟹ (yᵀp⁽ʲ⁾)²/(p⁽ʲ⁾ᵀq⁽ʲ⁾) > 0。矛盾。
7. 综上 **yᵀH_{j+1}y > 0**。∎

**定理 10.4.2**：设用 DFP 方法求解 min f(x) = ½xᵀAx + bᵀx + c，其中 A 为 n 阶对称正定矩阵。取初点 x⁽¹⁾，令 H₁ 为 n 阶对称正定矩阵，则成立：

1. **p⁽ⁱ⁾ᵀA p⁽ʲ⁾ = 0**，1 ≤ i < j ≤ k        （10.4.25）　← 搜索方向是 A 共轭的
2. **H_{k+1}A p⁽ⁱ⁾ = p⁽ⁱ⁾**，1 ≤ i ≤ k        （10.4.26）

**推论**：在 Th10.4.2 的条件下，必有 **H_{n+1} = A⁻¹**。

**三条结论（PPT 原文，直接背）**：
- DFP 方法中构造出来的搜索方向是**一组 A 共轭方向**；
- DFP 方法具有**二次终止性**；
- 若 f 是 Eⁿ 上的二次连续可微实函数，对任意的 x̂ ∈ Eⁿ，存在常数 m > 0，使得当 x ∈ C(x̂) = {x | f(x) ≤ f(x̂)}, y ∈ Eⁿ 时有 m‖y‖² ≤ yᵀ∇²f(x)y，则 DFP 方法产生的序列 {x⁽ᵏ⁾} **或终止于或收敛于 f 在 Eⁿ 上的唯一极小点**。

**定理 10.4.3**：设 min f(x) = ½xᵀAx + bᵀx + c，A 为 n 阶对称正定矩阵。则对于 **Broyden 方法**同样成立：1. p⁽ⁱ⁾ᵀAp⁽ʲ⁾ = 0；2. H_{k+1}Ap⁽ⁱ⁾ = p⁽ⁱ⁾。

    min x1² + 3x2² ,  x⁽¹⁾ = (1, −1)ᵀ ,  H₁ = [2 1; 1 1]

# 10.5 信赖域方法

## 一、基本思想（简答题标准答案）

考虑无约束问题 min f(x), x ∈ Rⁿ（10.5.1）。将 f(x) 在给定点 x⁽ᵏ⁾ 展开，取二次近似：

    f(x) ≈ f(x⁽ᵏ⁾) + ∇f(x⁽ᵏ⁾)ᵀ(x − x⁽ᵏ⁾) + ½(x − x⁽ᵏ⁾)ᵀ∇²f(x⁽ᵏ⁾)(x − x⁽ᵏ⁾)

记 **d = x − x⁽ᵏ⁾**，得到**二次模型**

    ϕ_k(d) = f(x⁽ᵏ⁾) + ∇f(x⁽ᵏ⁾)ᵀd + ½dᵀ∇²f(x⁽ᵏ⁾)d        （10.5.2）

为了在 x⁽ᵏ⁾ 附近用 ϕ_k(d) 近似 f(x⁽ᵏ⁾ + d)，**限定 d 的取值**，令 ‖d‖ ≤ r_k，r_k 是给定的常数，称为**信赖域半径**。

## 二、子问题与其最优性条件

将求函数的极小点归结为解一系列子问题：

    min  ϕ_k(d) = f(x⁽ᵏ⁾) + ∇f(x⁽ᵏ⁾)ᵀd + ½dᵀ∇²f(x⁽ᵏ⁾)d
    s.t.  ‖d‖ ≤ r_k                                    （10.5.3）

若 d⁽ᵏ⁾ 是（10.5.3）的最优解，则存在乘子 **ŵ ≥ 0**，使

    ∇²f(x⁽ᵏ⁾)d⁽ᵏ⁾ + ∇f(x⁽ᵏ⁾) + ŵ(d⁽ᵏ⁾ᵀd⁽ᵏ⁾)^{-1/2} d⁽ᵏ⁾ = 0
    ŵ( ‖d⁽ᵏ⁾‖ − r_k ) = 0
    ‖d⁽ᵏ⁾‖ ≤ r_k

## 三、ρk：实际下降量与预测下降量之比 ⭐

求出 d⁽ᵏ⁾ 后，x⁽ᵏ⁾+d⁽ᵏ⁾ 能否作为近似解，还要根据用 ϕ_k(d) 逼近 f(x) 是否成功来确定。若**函数值实际下降量与预测下降量之比**

    ρk = [ f(x⁽ᵏ⁾) − f(x⁽ᵏ⁾ + d⁽ᵏ⁾) ] / [ f(x⁽ᵏ⁾) − ϕ_k(d⁽ᵏ⁾) ]      （10.5.7）

**太小**，就认为不成功，后继点仍然取 x⁽ᵏ⁾；若 **ρk 比较大**，则逼近成功，令 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + d⁽ᵏ⁾。

## 四、信赖域算法 6 步 —— 默写级

1. 给定可行点 x⁽¹⁾、信赖域半径 r₁、参数 **0 < μ < η < 1**（一般取 **μ = 0.25, η = 0.75**）及精度要求 ε，置 k := 1；
2. 计算 f(x⁽ᵏ⁾)、∇f(x⁽ᵏ⁾)。若 ‖∇f(x⁽ᵏ⁾)‖ ≤ ε，则停止计算，得解 x\* = x⁽ᵏ⁾；否则计算 ∇²f(x⁽ᵏ⁾)；
3. 求解子问题（10.5.3）得最优解 d⁽ᵏ⁾，计算 ρk；
4. 如果 **ρk ≤ μ**，令 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾；如果 **ρk > μ**，令 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + d⁽ᵏ⁾；
5. 修改 r_k：如果 ρk ≤ μ，令 **r_{k+1} = 0.5r_k**；如果 μ < ρk < η，令 **r_{k+1} = r_k**；如果 ρk ≥ η，令 **r_{k+1} = 2r_k**；
6. 置 k := k+1，转步骤 2。

> 记法口诀：**差就缩（减半）、好就涨（加倍）、不好不坏保持不变**。

## 五、⭐ 例 10.5.1（PPT 原题）

    min f(x) = x1⁴ + x1² + x2² − 4x2 + 5
    初始点 x⁽¹⁾ = (0, 0)ᵀ ,  r1 = 1 ,  μ = 0.25 ,  η = 0.75

**第 1 次迭代**：

    f(x⁽¹⁾) = 5 ,  ∇f(x⁽¹⁾) = (0, −4)ᵀ ,  ∇²f(x⁽¹⁾) = [2 0; 0 2]

解子问题：

    min ϕ1(d) = 5 − 4d2 + d1² + d2²    s.t.  d1² + d2² ≤ 1

得到子问题的 K-T 点（也是最优解）

    d⁽¹⁾ = (d1, d2)ᵀ = **(0, 1)ᵀ**

    f(x⁽¹⁾ + d⁽¹⁾) = 2 ,   ϕ1(d⁽¹⁾) = 2
    ρ1 = (5 − 2)/(5 − 2) = **1 > η**   ⟹ 逼近成功

令 **x⁽²⁾ = x⁽¹⁾ + d⁽¹⁾ = (0, 1)ᵀ**，**r₂ = 2r₁ = 2**。

**第 2 次迭代**：

    f(x⁽²⁾) = 2 ,  ∇f(x⁽²⁾) = (0, −2)ᵀ ,  ∇²f(x⁽²⁾) = [2 0; 0 2]

解子问题：

    min ϕ2(d) = 2 − 2d2 + d1² + d2²    s.t.  ‖d‖ ≤ 2

（后续迭代 PPT 未逐字给出完整数值，考场按同一套路：解带球约束的二次规划 → 算 ρ₂ → 定 x⁽³⁾ 与 r₃。）

# 附：可直抄答题模板

### 模板 A：共轭梯度法的思想与优点（约 220 字）

> 共轭梯度法利用 A 共轭方向构造搜索方向。设 A 是对称正定矩阵，若两个方向满足 (d⁽¹⁾)ᵀAd⁽²⁾=0 则称其关于 A 共轭。由扩张子空间定理，从任一点出发依次沿 k 个 A 共轭方向作一维搜索，所得点是 f 在 x⁽¹⁾+Γκ 上的唯一极小点，k=n 时即为 Rⁿ 上的唯一极小点，因此共轭梯度法具有二次终止性，至多 n 步迭代可达最优解。Fletcher-Reeves 法取初始方向为负梯度，以后用 d⁽ᵏ⁺¹⁾=−g_{k+1}+βᵏd⁽ᵏ⁾ 构造共轭方向，其中 βᵏ=‖g_{k+1}‖²/‖gᵏ‖²，步长 λᵏ=−gᵏᵀd⁽ᵏ⁾/(d⁽ᵏ⁾ᵀAd⁽ᵏ⁾)。该法公式简单，不需计算 Hessian 矩阵或其逆矩阵，计算量和存储量小，每步只需存储若干向量，适用于大规模问题，且收敛速率不坏于最速下降法。

### 模板 B：拟牛顿法的思想（约 200 字）

> 牛顿法成功的关键在于利用了 Hessian 矩阵提供的曲率信息，但计算 Hessian 工作量大且有时难以计算。拟牛顿法利用目标函数值 f 和一阶导数 g 的信息构造曲率近似，不明显形成 Hessian 矩阵。其核心是拟牛顿条件（割线方程）p⁽ᵏ⁾=H^{k+1}q⁽ᵏ⁾，其中 p⁽ᵏ⁾=x⁽ᵏ⁺¹⁾−x⁽ᵏ⁾，q⁽ᵏ⁾=g_{k+1}−gᵏ。构造时取 H₁ 为对称正定矩阵（如单位阵），再通过校正矩阵修正：H^{k+1}=Hᵏ+ΔHᵏ。典型校正有对称秩 1 校正、DFP 秩 2 校正与 BFGS 校正，DFP 与 BFGS 的加权组合构成 Broyden 簇。拟牛顿法构造的方向是 A 共轭方向，具有二次终止性，且在一定条件下收敛于唯一极小点，是目前最有效的无约束优化算法之一。

### 模板 C：信赖域方法的思想（约 180 字）

> 信赖域方法在每步迭代点 x⁽ᵏ⁾ 处用二次模型 ϕ_k(d)=f(x⁽ᵏ⁾)+∇f(x⁽ᵏ⁾)ᵀd+½dᵀ∇²f(x⁽ᵏ⁾)d 近似目标函数。由于二次模型只在 x⁽ᵏ⁾ 附近可靠，故限定步长 d 落在以 r_k 为半径的信赖域内，通过解子问题 min ϕ_k(d) s.t. ‖d‖≤r_k 得到试探步 d⁽ᵏ⁾。该步能否被接受由实际下降量与预测下降量之比 ρk 判断：ρk 较大则接受并可能扩大信赖域（r_{k+1}=2r_k），ρk 很小则拒绝该步、保留原迭代点并缩小信赖域（r_{k+1}=0.5r_k），一般取 μ=0.25、η=0.75。该方法不要求 Hessian 正定，全局收敛性好。

# 易错点清单（考前扫一遍）

1. **共轭 ≠ 正交**：(d⁽¹⁾)ᵀAd⁽²⁾=0 是关于 **A** 共轭，不是 d⁽¹⁾ᵀd⁽²⁾=0。
2. **FR 的 β 有两个式子**：一般形式（10.3.19）βᵏ=d⁽ᵏ⁾ᵀAg_{k+1}/(d⁽ᵏ⁾ᵀAd⁽ᵏ⁾)；正定二次函数可化简为（10.3.24）βᵢ=‖g_{i+1}‖²/‖gᵢ‖²。**考试给正定二次函数时用后者**。
3. **FR 初始方向必须是负梯度**，否则不保证共轭性（Th10.3.3 后面的"注意"）。
4. **共轭梯度的二次终止是"≤ n 次一维搜索后终止"**，不是"一次"。
5. **拟牛顿条件的方向别写反**：p⁽ᵏ⁾ = H^{k+1}q⁽ᵏ⁾（H 近似 Hessian 的**逆**，所以 p 在左）。
6. **DFP 与 BFGS 的差别**：DFP 校正 H（近似 ∇²f⁻¹），BFGS 先校正 B（近似 ∇²f）再取逆（用 Sherman-Morrison）。
7. **H_{n+1} = A⁻¹ 是 DFP 的推论**，前提是正定二次函数 + H₁ 对称正定。
8. **信赖域 ρk 的分子分母方向**：分子是**实际**下降 f(x⁽ᵏ⁾)−f(x⁽ᵏ⁾+d⁽ᵏ⁾)，分母是**预测**下降 f(x⁽ᵏ⁾)−ϕ_k(d⁽ᵏ⁾)。
9. **半径调整倍数**：0.5（缩）、1（不变）、2（涨），阈值 μ=0.25、η=0.75。
10. **例 10.3.2 的 λ1 = 5/18 是精确一维搜索的结果**，考试若让重算，按 φ′(λ)=0 求，不要用黄金分割之类。
