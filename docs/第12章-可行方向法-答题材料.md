## 〇、先记住这一章的骨架

可行方向法是**把无约束下降算法搬到约束情形**：无约束问题是"找下降方向 → 一维搜索"，约束问题只多一个要求——**方向必须可行**。

    x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏ d⁽ᵏ⁾        （和无约束完全同一个迭代格式）

于是每一轮只回答两个问题：

1. **方向**：在 x⁽ᵏ⁾ 的可行方向中，找一个使 f 下降的 d⁽ᵏ⁾；
2. **步长**：沿 d⁽ᵏ⁾ 一维搜索，但**不能跳出可行域**（λ ≤ λmax）。

Zoutendijk 法把这两个问题都化成 **LP** 解；Rosen 梯度投影法用**投影矩阵**直接算出方向，不解 LP。

---

## 一、核心概念：可行方向

**定义**：设 x̂ 是可行点，d 是非零向量。若存在 δ > 0，使得对每个 λ ∈ (0, δ)，x̂ + λd 仍是可行点，则称 d 为 x̂ 处的**可行方向**。

> 考场写法：定义题就写"∃δ>0, ∀λ∈(0,δ): x̂+λd ∈ S"。别忘了 **d ≠ 0** 和 **λ 要能连续取一小段**（不是只取一个点）。

## 二、线性约束：Zoutendijk 可行方向法

问题（12.1.1）：

    min f(x)   s.t.  Ax ≥ b,  Ex = e
    f 可微；A 为 m×n，E 为 l×n；x∈Rⁿ

把约束按在 x̂ 处是否起作用拆开（**这一步是全书最常用的技巧，后面 Rosen 法还要用**）：

    A1 x̂ = b1   （起作用）      A2 x̂ > b2   （不起作用）

### Th12.1.1　可行方向的充要条件 ⭐必考

x̂ 为可行解，且 A1x̂=b1、A2x̂>b2，则**非零向量 d 为 x̂ 处可行方向的充要条件是**

    A1 d ≥ 0 ,  E d = 0

**证明骨架（必要 + 充分，各四行，考场能拿满）**

*必要性*：d 是可行方向 ⇒ ∃δ≥0，对每个 λ∈(0,δ) 有

    A(x̂+λd) ≥ b  ⟺  [ b1 + λA1d ;  A2x̂ + λA2d ] ≥ [ b1 ; b2 ]

第二式因 A2x̂ > b2，λ 小时自动成立；第一式要求 λA1d ≥ 0，而 **λ > 0**，故 **A1d ≥ 0**。
又 E(x̂+λd)=e 且 Ex̂=e ⟹ Ed=0。

*充分性*：设 A1d≥0、Ed=0。

1. 由 A2x̂ > b2，存在正数 δ 使 ∀λ∈[0,δ) 有 A2(x̂+λd) ≥ b2；
2. 由 A1d≥0 且 A1x̂=b1，得 A1(x̂+λd) = b1 + λA1d ≥ b1；
3. 由 Ed=0 且 Ex̂=e，得 E(x̂+λd)=e。

三式合并即 A(x̂+λd)≥b、E(x̂+λd)=e ⟹ x̂+λd 可行。

**推论（下降可行方向）**：若 d 同时满足

    ∇f(x̂)ᵀd < 0 ,  A1d ≥ 0 ,  Ed = 0

则 d 是 x̂ 处的**下降可行方向**。

### 怎么找方向？化成 LP（12.1.10）

    min  ∇f(x)ᵀ d
    s.t.  A1 d ≥ 0
          E d = 0
          −1 ≤ d_j ≤ 1 ,  j = 1,…,n

三个关键观察（简答题常考）：

- **d = 0 必是可行解** ⟹ 目标函数最优值 **≤ 0**；
- 最优值 **< 0** ⟹ 拿到下降可行方向；最优值 **= 0** ⟹ x 就是 KKT 点；
- 加 −1≤d_j≤1 是为了让 LP 有界（否则目标可以趋于 −∞）。

### Th12.1.2　KKT 的判别 ⭐必考，证明用 Farkas

x 为问题（12.1.1）的 KKT 点 **⇔** LP（12.1.10）的目标函数最优值为 **0**。

**证明骨架**：

1. x 为 KKT 点 ⟺ ∃w≥0 和 v，使 **∇f(x) − A1ᵀw − Eᵀv = 0**（12.1.11）。
2. 令 **v = p − q，p,q ≥ 0**（把自由变量拆成两个非负变量之差），则（12.1.11）写成

       (−A1ᵀ, −Eᵀ, Eᵀ)(w, p, q)ᵀ = −∇f(x) ,   (w,p,q)ᵀ ≥ 0        （12.1.12）

3. 由 **Farkas 定理**，该方程组有解的充要条件是

       (−A1ᵀ, −Eᵀ, Eᵀ)ᵀd ≤ 0 ,  −∇f(x)ᵀd > 0  无解             （12.1.13）

4. 展开即：**∇f(x)ᵀd < 0, A1d ≥ 0, Ed = 0 无解**，这正是 LP（12.1.10）最优值为 0。∎

> 💡 **你可能还需要考虑**：这一章的证明两次用到**择一定理**——线性约束用 **Farkas**，非线性约束用 **Gordan**。如果卷子上让"证明 x 是 KKT / F-J 点"，标准答案几乎一定走这两条路，务必能把"无解 ⟺ 存在非负组合"这一步写出来。

### 步长怎么定？λmax（12.1.22–24）

一维搜索问题（12.1.15）先化简：Ed⁽ᵏ⁾=0 使等式约束多余；起作用约束 A1(x⁽ᵏ⁾+λd⁽ᵏ⁾)≥b1 因 A1d⁽ᵏ⁾≥0 自动成立。最后只剩

    min f(x⁽ᵏ⁾ + λd⁽ᵏ⁾)   s.t.  0 ≤ λ ≤ λmax            （12.1.25）

令

    b̂ = b2 − A2 x⁽ᵏ⁾        （12.1.22）   ← 由 A2x⁽ᵏ⁾ > b2 知 b̂ < 0
    d̂ = A2 d⁽ᵏ⁾             （12.1.23）

则约束 λd̂ ≥ b̂、λ ≥ 0 给出

    λmax = min { b̂i / d̂i : d̂i < 0 }   （d̂ ≥ 0 时 λmax = ∞）   （12.1.24）

**记法**：λmax = min{−b̂i/d̂i, d̂i<0}。考场算错九成是**符号**：b̂ 是负的，只有 d̂i<0 时 b̂i/d̂i 才是正的。

### 初始可行点从哪来？辅助 LP（12.1.26）

    min  Σξi + Σηi
    s.t.  Ax + ξ ≥ b ,  Ex + η = e ,  ξ ≥ 0, η ≥ 0

若最优解为 (x*, ξ*, η*) = (x*, 0, 0)，则 **x* 就是（12.1.1）的一个可行解**。

### Zoutendijk 算法（线性约束）6 步 —— 默写级

1. 给定初始可行点 x⁽¹⁾，置 k=1；
2. 在 x⁽ᵏ⁾ 处分解 A、b 为 (A1,A2)ᵀ 和 (b1,b2)ᵀ，使 A1x⁽ᵏ⁾=b1、A2x⁽ᵏ⁾>b2；
3. 解 LP：min ∇f(x⁽ᵏ⁾)ᵀd s.t. A1d≥0, Ed=0, −1≤d_j≤1，得最优解 d⁽ᵏ⁾；
4. 若 ∇f(x⁽ᵏ⁾)ᵀd⁽ᵏ⁾ = 0，**停止，x⁽ᵏ⁾ 为 KKT 点**；否则转 5；
5. 用（12.1.22）–（12.1.24）算 λmax，在 [0, λmax] 上一维搜索得 λᵏ，令 x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾+λᵏd⁽ᵏ⁾；
6. 置 k:=k+1，转 2。

### ⭐ 例题（PPT 原题，考试可能直接搬）

    min f = x1² + x2² − 2x1 − 4x2 + 6
    s.t.  −2x1 + x2 + 1 ≥ 0
          −x1 − x2 + 2 ≥ 0
          x1 ≥ 0 ,  x2 ≥ 0
    初点 x⁽¹⁾ = (0, 0)ᵀ

**第一次迭代全过程**：

1. ∇f(x) = (2x1−2, 2x2−4)ᵀ ⟹ **∇f(x⁽¹⁾) = (−2, −4)ᵀ**
2. 在 x⁽¹⁾=(0,0) 处起作用的是 x1≥0、x2≥0，故

       A1 = [1 0; 0 1] ,  b1 = (0,0)ᵀ
       A2 = [−2 1; −1 −1] ,  b2 = (−1, −2)ᵀ

3. 解方向 LP：

       min −2d1 − 4d2   s.t.  d1 ≥ 0 , d2 ≥ 0 , −1 ≤ d_j ≤ 1

   单纯形法得 **d⁽¹⁾ = (1, 1)ᵀ**
4. 算步长上限：

       d̂ = A2d⁽¹⁾ = [−2 1; −1 −1](1,1)ᵀ = (−1, −2)ᵀ
       b̂ = b2 − A2x⁽¹⁾ = (−1,−2)ᵀ − (0,0)ᵀ = (−1, −2)ᵀ
       λmax = min{ −1/−1 , −2/−2 } = **1**
5. 一维搜索：x = x⁽¹⁾ + λd⁽¹⁾ = (λ, λ)ᵀ

       f = λ² + λ² − 2λ − 4λ + 6 = **2λ² − 6λ + 6** ,  0 ≤ λ ≤ 1
       无约束极小点在 λ = 1.5，被 λmax=1 截断 ⟹ **λ1 = 1**
       x⁽²⁾ = x⁽¹⁾ + λ1d⁽¹⁾ = **(1, 1)ᵀ**
6. 重复迭代，最后得 **x\*** = (1/2, 3/2)ᵀ。

**练习题**（PPT 42 页，只问方向不问全过程）：

    min x1² + 2x2² + 3x3² + x1x2 − 2x1x3 + x2x3 − 4x1 − 6x2
    s.t. x1 + 2x2 + x3 ≤ 4 ,  x1,x2,x3 ≥ 0
    求 x⁽¹⁾ = (0,0,0)ᵀ 处的可行下降方向

提示：先把 ≤ 化成 ≥（−x1−2x2−x3+4 ≥ 0）；在原点处该约束取值 4 > 0 **不起作用**，起作用的仅 x1,x2,x3 ≥ 0 三个，A1 = I₃。∇f⁽¹⁾ = (−4,−6,0)ᵀ，解 LP min −4d1−6d2 s.t. 0≤dⱼ≤1 得 **d⁽¹⁾ = (1,1,0)ᵀ**（d3 任取 [0,1] 均最优，取 0），最优值 −10 < 0。（2026-11-10 复核修正：旧稿"四个约束全部取等号、A1 为 4×3"有误。）

## 三、非线性约束：Zoutendijk 法（12.1.2）

问题（12.1.27）：min f(x) s.t. gᵢ(x) ≥ 0, i=1,…,m。记 **I = { i | gᵢ(x) = 0 }**（起作用约束下标集）。

### Th12.1.3　下降可行方向的充分条件

f、gᵢ (i∈I) 在 x 可微，gᵢ (i∉I) 连续，若

    ∇f(x)ᵀd < 0 ,   ∇gᵢ(x)ᵀd > 0  (i ∈ I)

则 d 是 x 处的**下降可行方向**。

**证明骨架**：

- i ∉ I：gᵢ(x) > 0 且连续 ⟹ λ 充分小有 gᵢ(x+λd) ≥ 0；
- i ∈ I：gᵢ(x)=0 且可微，由一阶展开

      gᵢ(x+λd) = gᵢ(x) + λ∇gᵢ(x)ᵀd + λ‖d‖α(x,λd) = λ[∇gᵢ(x)ᵀd + ‖d‖α(x,λd)]

  其中 λ→0 时 α(x,λd)→0；因 ∇gᵢ(x)ᵀd > 0，λ 充分小时右端 > 0 ⟹ gᵢ(x+λd) > 0；
- 合起来 gᵢ(x+λd) ≥ 0 (i=1..m) ⟹ d 可行；又 ∇fᵀd<0 ⟹ d 下降。∎

### 找方向：LP（12.1.31）

    min  z
    s.t.  ∇f(x)ᵀd − z ≤ 0
          ∇gᵢ(x)ᵀd + z ≥ 0 ,  i ∈ I
          −1 ≤ d_j ≤ 1 ,  j = 1,…,n

判据：**z\*** < 0 ⟹ d\*** 是下降可行方向；**z\*** = 0 ⟹ x 是 Fritz John 点。

### Th12.1.4　Fritz John 点的判别 ⭐证明用 Gordan

x 是问题（12.1.27）的 **Fritz John 点** ⟺ LP（12.1.31）的最优目标函数值为 0。

**证明骨架**：最优值为 0 ⟺ 不等式组

    ∇f(x)ᵀd < 0 ,  −∇gᵢ(x)ᵀd < 0  (i ∈ I)        （12.1.33）

**无解**。由 **Gordan 定理**，其无解的充要条件是：**存在不全为 0 的数 w₀≥0、wᵢ≥0 (i∈I)，使**

    w₀∇f(x) − Σ_{i∈I} wᵢ∇gᵢ(x) = 0

这正是 Fritz John 条件的定义（w₀ 可以 > 0，这是 F-J 比 KKT 弱的原因）。∎

> 💡 **F-J vs KKT**：KKT 要求 w₀ 可归一化为 1（即 ∇f = Σuᵢ∇gᵢ，u≥0）；F-J 允许 w₀>0（即 w₀∇f = Σwᵢ∇gᵢ）。所以 KKT ⟹ F-J，反过来要加约束规范。**线性约束情形 Th12.1.2 拿到的是 KKT，非线性约束情形 Th12.1.4 只拿到 F-J**，这个差别简答题可能问。

### 步长

    min f(x⁽ᵏ⁾ + λd⁽ᵏ⁾)  s.t.  0 ≤ λ ≤ λmax
    λmax = sup { λ | gᵢ(x⁽ᵏ⁾ + λd⁽ᵏ⁾) ≥ 0 , i = 1,…,m }      （12.1.35）

（非线性时没有闭式，要么解析求要么试算。）

### 算法（非线性约束）4 步

1. 给定初始可行点 x⁽¹⁾，置 k=1；
2. 令 I = {i | gᵢ(x⁽ᵏ⁾)=0}，解 LP（12.1.31）得 (zᵏ, d⁽ᵏ⁾)。若 **zᵏ=0，停止，x⁽ᵏ⁾ 为 Fritz John 点**；否则转 3；
3. 解一维搜索 min f(x⁽ᵏ⁾+λd⁽ᵏ⁾) s.t. 0≤λ≤λmax，得 λᵏ；
4. x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾+λᵏd⁽ᵏ⁾，k:=k+1，转 2。

## 四、Zoutendijk 的收敛性缺陷与修正（12.1.3 / 12.1.4）⭐简答题高危区

### 算法映射的合成

Zoutendijk 算法映射 **A = M ∘ D**：

- **D（方向映射）**：给定可行点 x，解 LP（12.1.10）得下降可行方向 d，得到 (x,d) ∈ D(x)。D 是 Rⁿ → Rⁿ×Rⁿ 的映射；
- **M（一维搜索映射）**：给定 x 和 d，解 min f(x+λd) s.t. x+λd∈S, λ≥0，得最优解 y ∈ M(x,d)。M 是 Rⁿ×Rⁿ → Rⁿ 的映射。

**关键结论：D 和 M 不一定是闭映射** ⟹ 迭代序列可能不收敛于 K-T 点。

### Wolfe (1972) 反例 ⭐必考（会讲就要会复述）

    min  −2x1 − x2
    s.t.  −x1 − x2 + 2 ≥ 0 ,  x1 ≥ 0 ,  x2 ≥ 0

取序列 **x⁽ᵏ⁾ = (0, 2 − 1/k)ᵀ**。在序列中每一点只有 **x1 ≥ 0** 起作用，故方向 LP 为

    min −2d1 − d2   s.t.  0 ≤ d1 ≤ 1 , −1 ≤ d2 ≤ 1     ⟹  d⁽ᵏ⁾ = (1, 1)ᵀ

序列的极限点 **x̂ = (0, 2)ᵀ**，在此点起作用约束变成两个：−x1−x2+2≥0 和 x1≥0，方向 LP 变成

    min −2d1 − d2   s.t.  −d1 − d2 ≥ 0 , 0 ≤ d1 ≤ 1 , −1 ≤ d2 ≤ 1     ⟹  d̂ = (1, −1)ᵀ

于是 D(x̂) = { (x̂, d̂) }，但当 x⁽ᵏ⁾→x̂ 时 (x⁽ᵏ⁾, d⁽ᵏ⁾) → (x̂, (1,1)ᵀ) **∉** D(x̂)。**故 D 在 x̂ 处不是闭映射**，收敛性无法保证。

### Topkis-Veinott 修正（12.1.4）

把求方向的 LP 右端从 0 改成 **−gᵢ(x)**：

    min  z
    s.t.  ∇f(x)ᵀd − z ≤ 0
          ∇gᵢ(x)ᵀd + z ≥ −gᵢ(x) ,  i = 1,…,m        （注意是全部 m 个，不分起不起作用）
          −1 ≤ d_j ≤ 1 ,  j = 1,…,n

其余（一维搜索、步长 λmax）与原算法相同。

**Th12.1.5**：设 f、gᵢ (i=1,…,m) 连续可微，则 Topkis-Veinott 算法产生的序列 {x⁽ᵏ⁾} 的**任一聚点都是 Fritz John 点**。

> 一句话记：**原 Zoutendijk 只承诺"要么给方向、要么给 F-J 点"，且映射不闭可能不收敛；T-V 修正把 −gᵢ(x) 放进 LP，保证了聚点必是 F-J 点。**

## 五、Rosen 梯度投影法（12.2）

### 基本思想（简答题标准答案）

用**积极约束系数矩阵的行向量生成一个法向量子空间**，把目标函数的**负梯度方向正交投影到该法向子空间的正交补**中，获得一个使目标函数下降的可行方向；然后从当前迭代点出发，沿该可行方向一维搜索，寻找新的改进点，直到得到 KKT 点。

**好处**：不用解 LP，一次投影就出方向，计算量小。

### 投影矩阵（定义 + 性质，可能考小题）

- **定义**：P ∈ R^{n×n}，若 P² = P 称 P 为**投影算子矩阵**；若还有 PᵀP = P 称**正交投影算子矩阵**。
- **值空间 / 零空间**：R(P) = {Px | x∈Rⁿ}，N(P) = {(I−P)x | x∈Rⁿ}。
- **例**：P = [1 1; 0 0]，则 P²=P，R(P) = {x=(x1,x2) | x2=0}，N(P) = {x | x1+x2=0}。
- **常用公式**（A 行满秩）：

      P_R(Aᵀ) = Aᵀ(AAᵀ)⁻¹A        （Rⁿ → R(Aᵀ) 的正交投影）
      P_N(A)  = I − Aᵀ(AAᵀ)⁻¹A    （Rⁿ → N(A) 的正交投影）

- **命题**（3 条）：

  1. 投影矩阵的特征根**或为 0 或为 1**；
  2. P 是（正交）投影矩阵 **⟺** I−P 是（正交）投影矩阵；
  3. 正交投影矩阵的 R(P) 与 N(P) 是**互补且正交**的线性子空间。

### 记号

在 x 处 A1x=b1、A2x>b2，记积极约束系数矩阵

    M = [ A1 ; E ]     （行满秩）
    P_N(M) = I − Mᵀ(MMᵀ)⁻¹M

### Th12.2.1

若 **d = −P_N(M)∇f(x) ≠ 0**，则 d 是问题（12.1.1）的一个**下降的可行方向**。

### Th12.2.2 ⭐（KKT 判别 + 删行技巧）

设 **w = (MMᵀ)⁻¹M∇f(x) = (uᵀ, vᵀ)ᵀ**（u、v 分别对应 A1 和 E 的分量），且 P_N(M)∇f(x) = 0，则：

1. **u ≥ 0 ⟹ x 为问题的 KKT 点**。
   *证明*：P_N(M)∇f(x)=0 ⟹ 0 = (I − Mᵀ(MMᵀ)⁻¹M)∇f(x) = ∇f(x) − A1ᵀu − Eᵀv，这正是 **K-T 条件**。∎
2. **u ≱ 0 时**（不妨设 u_{i0} < 0）：从 M 中**删去 u_{i0} 对应的行**得子矩阵 M̂，则

       d̂ = −P_N(M̂)∇f(x) = −(I − M̂ᵀ(M̂M̂ᵀ)⁻¹M̂)∇f(x)

   仍是问题的**下降可行方向**。
   *证明要点*：反证 P̂∇f(x)=0，则 ∇f(x) − M̂ᵀŴ = 0；又 ∇f(x) − MᵀW = 0 且 A1ᵀu+Eᵀv = M̂ᵀŴ + u_{i0}rⱼᵀ，两式相减得 0 = M̂ᵀ(W−Ŵ) + u_{i0}rⱼᵀ，右端是 M 行向量的线性组合且至少一个系数 u_{i0}≠0 ⟹ M 行向量线性相关，与 M 行满秩矛盾。再由 P̂ 半正定得 ∇f(x)ᵀd̂ = −‖P̂∇f(x)‖² < 0（下降）；且 M̂d̂=0、rⱼᵀd̂ = −u_{i0}rⱼᵀP̂rⱼ ≥ 0，合起 A1d̂≥0、Ed̂=0（可行）。∎

### Rosen 梯度投影算法 4 步

1. **初始化**：初始点 x₀，置 k=0；
2. **计算投影向量**：确定积极约束指标集 A(xᵏ) = I(xᵏ) ∪ E(xᵏ) 与积极约束系数矩阵 M = (aᵢ | i∈A(xᵏ))ᵀ，计算 dᵏ = −P_N(M)∇f(xᵏ)。若 dᵏ = 0 转步 3，否则转步 4；
3. **收敛性检验**：计算 w = (MMᵀ)⁻¹M∇f(xᵏ)，令 uᵀ = (wᵢ | i∈I(xᵏ))、vᵀ = (wⱼ | j∈E(xᵏ))。若 **u ≥ 0，则 xᵏ 为 KKT 点，Stop**；否则取 i₀ = argmin λᵢ，从 M 中**删去 i₀ 对应行**得 M̃，重算 dᵏ = −P_N(M̃)∇f(xᵏ)，转步 4；
4. **迭代改进**：解一维优化问题（12.1.25）得最优步长 αᵏ，置 x_{k+1} = xᵏ + αᵏdᵏ，转步 2；若一维搜索最优解无界，算法停止。

### 练习题（PPT 52 页）

    min x1² + x2² + 2x2 + 5
    s.t.  x1 − 2x2 ≥ 0 ,  x1 ≥ 0 ,  x2 ≥ 0
    求 x⁽¹⁾ = (2, 0)ᵀ 处的可行下降方向

**解（2026-11-10 精确分数复验；旧提示误把 x1−2x2≥0 当起作用，已修正）**：在 (2,0) 处 x1−2x2 = 2 > 0 **不起作用**，x1≥0 也不起作用，唯一起作用的是 x2≥0 ⟹ M = [0 1]。

    MMᵀ = [1]，P_N(M) = I − Mᵀ(MMᵀ)⁻¹M = [1 0; 0 0]
    ∇f(2,0) = (2x1, 2x2+2)ᵀ = (4,2)ᵀ
    d = −P_N(M)∇f = (−4, 0)ᵀ ≠ 0

检验：∇fᵀd = −16 < 0（下降），Md = 0（可行，沿 x2=0 这面墙滑动）。**d⁽¹⁾ = (−4,0)ᵀ**。

**续走一步（顺带演示 d=0 分支）**：不起作用约束给 λmax：x1−2x2 = 2−4λ ≥ 0、x1 = 2−4λ ≥ 0 ⟹ λmax = 1/2；φ(λ) = (2−4λ)² + 5，φ′(λ) = 32λ−16 = 0 ⟹ λ₁ = 1/2 ⟹ x⁽²⁾ = (0,0)ᵀ。
在 (0,0) 三个约束全起作用，取极大无关行组 M = [0 1; 1 −2]（x1≥0 的梯度 (1,0) = (1,−2)+2·(0,1) 可被线性表出，舍）。M 为满秩方阵 ⟹ P_N(M) = 0 ⟹ d = 0，转收敛性检验：w = (MMᵀ)⁻¹M∇f = (2,0)ᵀ（对应行 x2≥0、x1−2x2≥0），u ≥ 0 ⟹ **(0,0) 是 KKT 点，停**。与 KKT 定义核对：∇f = (0,2)ᵀ = 0·(1,−2)ᵀ + 2·(0,1)ᵀ ✓。

## 六、可直抄答题模板

### 模板 A：什么是可行方向法（约 200 字）

> 可行方向法是求解约束非线性规划的一类直接方法，其思想与求解无约束问题的下降算法一致：从问题的可行点出发，在该点的**可行方向**中寻找使目标函数下降的方向，然后沿该方向进行一维搜索，得到一个新的可行点，迭代直至满足最优性条件。迭代格式为 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾。每一轮需解决两个问题：一是确定**下降可行方向**，二是确定**步长** λᵏ，步长须同时保证迭代点的可行性与目标函数值尽可能减小，故步长上限受可行域约束（λ ≤ λmax）。典型代表有 Zoutendijk 可行方向法与 Rosen 梯度投影法。

### 模板 B：Zoutendijk 法怎么做（约 250 字）

> Zoutendijk 法把确定搜索方向归结为求解一个线性规划。设当前点 x⁽ᵏ⁾ 处起作用约束为 A1x⁽ᵏ⁾=b1，不起作用约束为 A2x⁽ᵏ⁾>b2，则下降可行方向由 LP：min ∇f(x⁽ᵏ⁾)ᵀd s.t. A1d≥0, Ed=0, −1≤d_j≤1 确定。由于 d=0 是该 LP 的可行解，目标最优值必不大于 0；若最优值小于 0，则得下降可行方向，若等于 0，则由 Farkas 定理可证 x⁽ᵏ⁾ 为 KKT 点。求得方向后，步长由 λmax = min{b̂i/d̂i : d̂i<0}（其中 b̂=b2−A2x⁽ᵏ⁾, d̂=A2d⁽ᵏ⁾）限定，在 [0, λmax] 上作一维搜索。若问题没有现成可行点，可先解辅助 LP min Σξi+Σηi s.t. Ax+ξ≥b, Ex+η=e, ξ,η≥0 求初始可行解。

### 模板 C：Rosen 梯度投影法的思想（约 180 字）

> Rosen 梯度投影法用积极约束系数矩阵的行向量生成一个法向量子空间，将目标函数的负梯度方向正交投影到该法向子空间的正交补中，获得一个使目标函数下降的可行方向；然后从当前迭代点出发，沿该可行方向一维搜索，寻找新的改进点，直到得到约束优化问题的 KKT 点。设 M=[A1;E] 行满秩，P_N(M)=I−Mᵀ(MMᵀ)⁻¹M，若 d=−P_N(M)∇f(x)≠0 即为下降可行方向；若 d=0，则计算 w=(MMᵀ)⁻¹M∇f(x)=(uᵀ,vᵀ)ᵀ，当 u≥0 时 x 为 KKT 点，否则从 M 中删去 u 的负分量对应行后重新投影。该方法避免了解线性规划，计算量小。

### 模板 D：Zoutendijk 法为什么不收敛 / T-V 修正（约 150 字）

> Zoutendijk 算法映射是方向映射 D 与一维搜索映射 M 的合成，而 D 和 M 不一定是闭映射，因此迭代序列可能不收敛于 K-T 点，Wolfe 于 1972 年给出了反例。Topkis 和 Veinott 的修正把求方向的线性规划右端由 0 改为 −gᵢ(x)，使得算法产生的序列的任一聚点都是 Fritz John 点，从而改善了收敛性。

## 七、易错点清单（考前扫一遍）

1. **A1/A2 分解要看当前点**：同一条约束在不同迭代点可能在起作用/不起作用之间切换，每轮都要重分解。
2. **λmax 的符号**：b̂ = b2 − A2x⁽ᵏ⁾ 是**负**的（因为 A2x⁽ᵏ⁾ > b2）；λmax 只对 d̂i < 0 的分量取 min。
3. **−1≤d_j≤1 不能漏**：漏了 LP 无界，且考场写 LP 时它是得分点。
4. **Th12.1.2 的方向别反**：它是充要命题，但考场证明通常只写"KKT ⟹ 无下降方向 ⟹ LP 最优值 0"这一侧。
5. **F-J 与 KKT 的区别**：F-J 多一个 w₀≥0；线性约束情形 Th12.1.2 拿到的是 KKT，非线性情形 Th12.1.4 只拿到 F-J。
6. **Rosen 法删行后要重算投影**：d̂ = −P_N(M̂)∇f(x)，不是简单把某个分量置零。
7. **P²=P 与 PᵀP=P 的区别**：只有后者才是正交投影，才有 R(P)⊥N(P)。
