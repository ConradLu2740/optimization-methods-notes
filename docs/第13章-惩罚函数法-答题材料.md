## 〇、一章导览：先建立对比，再记细节

问题（13.1.1）：

    min f(x)   s.t.  gᵢ(x) ≥ 0, i = 1,…,m
                  h_j(x) = 0, j = 1,…,l

可行域 D = { x | gᵢ(x) ≥ 0, h_j(x) = 0 }。

**基本思想**：构造辅助函数 F，把约束问题转化为**无约束**问题。最朴素的想法是

    F(x) = f(x),  x ∈ D ;   F(x) = +∞,  x ∉ D

二者解等价，但**这个 F 性态极坏，无法用有效的无约束优化算法求解**（PPT 例题：min x1+x2 s.t. x1+x2=2，最优解 (1,1)ᵀ，理想罚函数在直线外全是 +∞）。所以**构造辅助函数极为重要**——罚函数法是**序列无约束极小化方法（SUMT）**的典型代表。

**两类方法的对比表**（简答题高频，直接背）：

| | 外点罚函数法（13.1） | 内点罚函数法 / 障碍函数法（13.2） |
|---|---|---|
| 辅助函数 | F(x,μ) = f(x) + μP(x)，μ **很大** | F(x,μ) = f(x) + μB(x)，μ **很小** |
| 迭代点位置 | 从**可行域外部**逼近解，允许不可行 | 从**可行域内部**逼近解，始终保持可行 |
| 适用问题 | 等式 + 不等式均可 | **只有不等式约束** gᵢ(x) ≥ 0 |
| 初始点 | 任意（不必可行） | 必须是**严格内点** x⁽⁰⁾ ∈ int S |
| μ 的变化 | μk **递增** → ∞（罚得越来越重） | μk **递减** → 0（墙越筑越低） |
| 罚项在可行域上 | P(x) = 0 | B(x) 在边界 → ∞ |
| 迭代终止判据 | μkP(x⁽ᵏ⁾) < ε | μkB(x⁽ᵏ⁾) < ε |
| 收敛结论 | 聚点是最优解（Th13.1.3） | 子列极限是最优解（Th13.2.1） |

**经济解释**（PPT 原话，简答可抄）：把目标函数看为**价格**，约束条件看为某种"规定"的范围，则问题可描述为**在规定的范围内买价格最低的东西**。若同时制定超范围购买的高"罚款"政策，则**总代价 = 价格 + 罚款**。当罚款高到一定程度时，用最小总代价所买到的东西总在规定的范围内，于是约束问题转化成为无约束问题。为达此目的，可**逐次加大罚款**求极小。

**图形解释**：min u = f(x) s.t. x ∈ S。令 u = f(x)（x∈S）而 u* = 加大（x∉S），使 u* 的无约束极小点成为 u 的约束极小点。

## 一、外点罚函数法（13.1）

### 1.1 辅助函数的三种写法

**等式约束问题**（13.1.2）：min f(x) s.t. h_j(x) = 0

    F1(x, μ) = f(x) + μ Σ_{j=1..l} h_j(x)²          （13.1.3）

**不等式约束问题**（13.1.5）：min f(x) s.t. gᵢ(x) ≥ 0

    F2(x, μ) = f(x) + μ Σ_{i=1..m} ( max{0, −gᵢ(x)} )²     （13.1.6）

> 注意 max{0, −gᵢ(x)}：**只在违反约束时才有惩罚**（gᵢ<0 时 −gᵢ>0）；可行时该项为 0。

**一般形式**（13.1.1）：

    F(x, μ) = f(x) + μ P(x)                    （13.1.8）
    P(x) = Σ_{i=1..m} φ(gᵢ(x)) + Σ_{j=1..l} ψ(h_j(x))     （13.1.9）

连续函数 φ 和 ψ 满足：

    φ(y) = 0, y ≥ 0 ;  φ(y) > 0, y < 0
    ψ(y) = 0, y = 0 ;  ψ(y) > 0, y ≠ 0

**典型取法**：

    φ = ( max{0, −gᵢ(x)} )^α ,   ψ = | h_j(x) |^β        （α ≥ 1, β ≥ 1）

### 1.2 ⭐ 例题一（等式约束，解析求极限）

    min f(x1, x2) = x1² + x2²   s.t.  x1 + x2 − 2 = 0

最优解 x\* = (1, 1)ᵀ。令

    P(x) = (x1 + x2 − 2)²
    罚函数 F(x, σ) = x1² + x2² + σ(x1 + x2 − 2)²

令一阶导数为 0：

    ∂F/∂x1 = 2x1 + 2σ(x1 + x2 − 2) = 0
    ∂F/∂x2 = 2x2 + 2σ(x1 + x2 − 2) = 0

两式相减 ⟹ x1 = x2，代回 ⟹

    x1 = x2 = 2σ / (2σ + 1)

当 **σ → +∞** 时 (x1(σ), x2(σ))ᵀ → (x1\*, x2\*)ᵀ = **(1, 1)ᵀ**。
即**无约束问题最优解的极限为原问题最优解**——这就是外点法的全部理论依据。

### 1.3 ⭐ 例题二（不等式约束，分段求导）

    例1   min f(x) = x²   s.t.  g(x) = −x − 1 ≥ 0

可行域 D = (−∞, −1]，最优解 **x\* = −1**。

    P(x) = [ max{0, −g(x)} ]² = { 0,          x ≤ −1
                                 { (−x−1)²,   x > −1

令 F(x, μ) = f(x) + μP(x)，则

    ∂F/∂x = { 2x,                  x ≤ −1
            { 2x − 2σ(−x − 1),     x > −1

min F(x, σ) 的解为

    x(σ) = −σ / (1 + σ)   ⟹  x(μ) = −σ/(1+σ) → **−1** = x\*,  σ → +∞

### 1.4 罚因子怎么选？SUMT

**罚因子的选取非常重要**。一般策略：取一趋向无穷大的**严格递增正数列 {μk}**，从某个 μ1 开始，对每个 k 求解

    min  f(x) + μk P(x)                  （13.1.13）

从而得到一个极小点的序列 {x_{μk}}。在适当条件下，此序列收敛于约束问题的最优解。这套方法称为**序列无约束极小化方法（SUMT, Sequential Unconstrained Minimization Technique）**。

### 1.5 外点法算法（3 步，默写级）

1. 给定初点 x⁽⁰⁾、初始罚因子 μ1、放大系数 c > 1、允许误差 ε > 0，置 k = 1；
2. 以 x⁽ᵏ⁻¹⁾ 为初点，解无约束问题 min f(x) + μkP(x)，得极小点 x⁽ᵏ⁾；
3. 若 **μkP(x⁽ᵏ⁾) < ε**，停止，得点 x⁽ᵏ⁾；否则令 μ_{k+1} = cμk，置 k = k+1，转 2。

### 1.6 ⭐ 收敛性（三条，引理 13.1.1 是证明核心）

**引理 13.1.1**：设 0 < μk < μ_{k+1}，x⁽ᵏ⁾ 和 x⁽ᵏ⁺¹⁾ 分别为取罚因子 μk 和 μ_{k+1} 时无约束问题的**全局极小点**，则

    1. F(x⁽ᵏ⁾, μk) ≤ F(x⁽ᵏ⁺¹⁾, μ_{k+1})
    2. P(x⁽ᵏ⁾) ≥ P(x⁽ᵏ⁺¹⁾)
    3. f(x⁽ᵏ⁾) ≤ f(x⁽ᵏ⁺¹⁾)

**证明骨架**：
- 证 1：x⁽ᵏ⁾ 是 F(·,μk) 的全局极小点，且 μk < μ_{k+1}，于是

      F(x⁽ᵏ⁾, μk) = f(x⁽ᵏ⁾) + μkP(x⁽ᵏ⁾) ≤ f(x⁽ᵏ⁺¹⁾) + μkP(x⁽ᵏ⁺¹⁾) ≤ f(x⁽ᵏ⁺¹⁾) + μ_{k+1}P(x⁽ᵏ⁺¹⁾) = F(x⁽ᵏ⁺¹⁾, μ_{k+1})

- 证 2：两个极小点给出两个不等式

      f(x⁽ᵏ⁾) + μkP(x⁽ᵏ⁾) ≤ f(x⁽ᵏ⁺¹⁾) + μkP(x⁽ᵏ⁺¹⁾)        （13.1.14）
      f(x⁽ᵏ⁺¹⁾) + μ_{k+1}P(x⁽ᵏ⁺¹⁾) ≤ f(x⁽ᵏ⁾) + μ_{k+1}P(x⁽ᵏ⁾)   （13.1.15）

  两式相加整理得

      (μ_{k+1} − μk)P(x⁽ᵏ⁾) ≥ (μ_{k+1} − μk)P(x⁽ᵏ⁺¹⁾)          （13.1.16）

  由 μ_{k+1} > μk 即得 P(x⁽ᵏ⁾) ≥ P(x⁽ᵏ⁺¹⁾)。
- 证 3：由（13.1.14）加上已证的（13.1.17）即得 f(x⁽ᵏ⁾) ≤ f(x⁽ᵏ⁺¹⁾)。∎

**推论（背下来，简答常用）**：若迭代不终止，则 **{f(x⁽ᵏ⁾)} 和 {F(x⁽ᵏ⁾, μk)} 为非减序列，{P(x⁽ᵏ⁾)} 为非增序列**。

**引理 13.1.2**：设 x\* 是问题（13.1.1）的最优解，且对任意 μk > 0，F(x, μk) 存在全局极小点 x⁽ᵏ⁾，则对每一个 k

    f(x\*) ≥ F(x⁽ᵏ⁾, μk) ≥ f(x⁽ᵏ⁾)                    （13.1.19）

*证明*：右端——μkP(x⁽ᵏ⁾) ≥ 0 ⟹ F(x⁽ᵏ⁾, μk) = f(x⁽ᵏ⁾) + μkP(x⁽ᵏ⁾) ≥ f(x⁽ᵏ⁾)；左端——x\* 可行 ⟹ P(x\*) = 0，且 x⁽ᵏ⁾ 是全局极小点 ⟹ f(x\*) = f(x\*) + μkP(x\*) ≥ f(x⁽ᵏ⁾) + μkP(x⁽ᵏ⁾) = F(x⁽ᵏ⁾, μk)。∎

**Th13.1.3**（外点法收敛性）：设问题（13.1.1）的可行域非空，且 ∃ε > 0 使集合

    S_ε = { x | gᵢ(x) ≥ −ε, i = 1,…,m ;  h_j(x) ≤ ε, j = 1,…,l }      （13.1.22）

是**紧集**；又设 {μk} 是趋向 ∞ 的严格递增正数列，且对每个 k，问题（13.1.13）存在全局最优解 x⁽ᵏ⁾。则 {x⁽ᵏ⁾} 存在一个收敛子序列 {x⁽ᵏʲ⁾}，并且任何这样的收敛子序列的**极限都是问题（13.1.1）的最优解**。

### 1.7 练习题（PPT 23 页，两题）

    1）min 1.5x1² + x2² + 0.5x3² − x1x2 − x2x3 + x1 + x2 + x3
       s.t. x1 + 2x2 + x3 − 4 = 0

    2）min x1² + x2²
       s.t. 2x1 + x2 − 2 ≤ 0 ,  x2 ≥ 1
       并用最优性条件说明 (0,1) 是否为局部极小点

> 第 2 题的第二问是**跨章综合**：先写 KKT / F-J 条件再判断。(0,1) 处两个约束：2x1+x2−2 = −1 < 0（不起作用）、x2−1 = 0（起作用）。f 的梯度 (0, 2)，起作用约束梯度 (0,1)。F-J：w₀(0,2) − w(0,1) = 0 需 w₀ = w/2，取 w₀=w=0 之外的非零解存在（w₀=1, w=2 时 (0,2)−2(0,1)=0）⟹ 是 F-J 点；KKT 需 u≥0 使 (0,2) = u(0,1) ⟹ u = 2 ≥ 0 ⟹ **是 KKT 点**。二阶还需看投影到起作用约束切空间上的 Hessian（此处切空间就是 x1 轴，Hessian = [[2,0],[0,2]] 在 x1 方向为 2 > 0）⟹ **是局部极小点**。

## 二、内点罚函数法（13.2）—— 障碍函数法

### 2.1 基本思想

内点法产生的点列**从可行域的内部逼近问题的解**，因此只适用于**不等式约束问题**（13.2.1）：

    min f(x)   s.t.  gᵢ(x) ≥ 0, i = 1,…,m

记可行域 S = {x | gᵢ(x) ≥ 0}，**严格可行域** S₀ = {x | gᵢ(x) > 0}。

构造辅助（光滑）函数 F_μ：该函数在 S₀ 以外的取值为无穷大，且当点 x 从 S₀ 趋于 S 的边界时，函数值趋于无穷大。这样无约束问题 min F_μ = F(x, μ) 的解一定在 S₀ 内。

> 形象说法（PPT 原话）：辅助函数 F(x, μ) **在 S 的边界筑起了一道很高的墙**，把无约束问题的解挡住了可行域 S 的内部。因此内点法也称为**障碍函数法**。

定义障碍函数：

    F(x, μ) = f(x) + μ B(x)                    （13.2.3）

其中 B(x) 连续，当 x 趋向可行域边界时 B(x) → ∞；**μ 是很小的正数**。于是 x 趋向边界时 F(x,μ) → ∞；否则由于 μ 很小，F(x,μ) 近似 f(x)。通过解 min F(x,μ) s.t. x ∈ int S（13.2.4）得到原问题的近似解。

### 2.2 两种最重要的形式 ⭐

    B(x) = Σ_{i=1..m}  1 / gᵢ(x)              （13.2.5）   ← 倒数和（倒数障碍函数）
    B(x) = − Σ_{i=1..m} log gᵢ(x)             （13.2.6）   ← 负对数和（对数障碍函数）

> 对数形式更常用（光滑性更好、数值性质更稳）；两种都要求 gᵢ(x) > 0，即 x 必须是**严格内点**。

### 2.3 内点法算法（3 步，默写级）

1. 给定初始**内点** x⁽⁰⁾ ∈ int S、允许误差 ε > 0、初始参数 μ1、缩小系数 β ∈ (0,1)，置 k = 1；
2. 以 x⁽ᵏ⁻¹⁾ 为初点，解无约束问题 min f(x) + μkB(x)，得极小点 x⁽ᵏ⁾；
3. 若 **μkB(x⁽ᵏ⁾) < ε**，停止，得点 x⁽ᵏ⁾；否则令 μ_{k+1} = **βμk**，置 k = k+1，转 2。

> 和外点法对照记：外点 μ_{k+1} = cμk（c>1，放大）；内点 μ_{k+1} = βμk（β∈(0,1)，缩小）。

### 2.4 ⭐ 例 13.2.1（PPT 原题，解析求解）

    min  (1/12)(x1 + 1)³ + x2
    s.t.  x1 − 1 ≥ 0 ,  x2 ≥ 0

定义障碍函数

    F(x, μk) = (1/12)(x1+1)³ + x2 + μk( 1/(x1−1) + 1/x2 )

用解析法求解 min F(x, μk) s.t. x ∈ S。令一阶导数为 0：

    ∂F/∂x1 = (1/4)(x1+1)² − μk/(x1−1)² = 0
    ∂F/∂x2 = 1 − μk/x2² = 0

解得

    x = (x1, x2) = ( 1 + 2√μk ,  μk )

当 **μk → 0** 时，x_{μk} → x\* = **(1, 0)**，x\* 是问题的最优解。

### 2.5 收敛性

**Th13.2.1**：设在问题（13.2.1）中，可行域内部 int S 非空且存在最优解；又设对每一个 μk，由（13.2.3）定义的 F(x, μk) 在 int S 内存在极小点，并且内点法产生的全局极小点序列 {x⁽ᵏ⁾} 存在子列收敛到 x̄，则 **x̄ 是问题（13.2.1）的最优解**。

### 2.6 练习题（PPT 32 页）

    min (x + 1)²   s.t.  x ≥ 0

提示：B(x) = 1/x，F(x,μ) = (x+1)² + μ/x，∂F/∂x = 2(x+1) − μ/x² = 0。x\* = 0（边界上），内点法只能从右侧逼近。

## 三、可直抄答题模板

### 模板 A：罚函数法的基本思想（约 200 字）

> 罚函数法通过构造辅助函数，把原来的约束问题转化为求极小化辅助函数的无约束问题。其经济解释是：把目标函数看作价格，约束条件看作规定的范围，若同时制定超范围购买的高"罚款"政策，则总代价 = 价格 + 罚款；当罚款高到一定程度时，用最小总代价所买到的东西总在规定的范围内，于是约束问题转化为无约束问题。根据迭代点从可行域外部还是内部逼近解，分为外点罚函数法和内点罚函数法（障碍函数法）。前者适用于等式和不等式约束，初始点可任意；后者只适用于不等式约束，要求初始点为严格内点。这类方法统称为序列无约束极小化方法（SUMT）。

### 模板 B：外点法与内点法的对比（约 250 字，表格可直接画）

> 外点罚函数法构造辅助函数 F(x,μ) = f(x) + μP(x)，其中 μ 是很大的正数，P(x) 在可行域内部为 0、在外部大于 0，典型形式为 P(x) = Σ(max{0,−gᵢ(x)})² + Σh_j(x)²。它从可行域外部逼近解，允许迭代点不可行，适用于等式和不等式约束，罚因子取递增数列 μ_{k+1}=cμk（c>1），当 μk→∞ 时无约束问题的解趋于原问题的解。内点罚函数法构造 F(x,μ) = f(x) + μB(x)，其中 μ 是很小的正数，B(x) 在可行域边界趋于无穷大（如 Σ1/gᵢ(x) 或 −Σlog gᵢ(x)），在边界筑起一道高墙把解挡在可行域内部；它要求初始点为严格内点，只适用于不等式约束，罚因子取递减数列 μ_{k+1}=βμk（β∈(0,1)）。

### 模板 C：为什么外点法能收敛（约 150 字）

> 设 {μk} 严格递增且趋于无穷，x⁽ᵏ⁾ 为对应无约束问题的全局极小点。由引理可知 F(x⁽ᵏ⁾,μk) 与 f(x⁽ᵏ⁾) 非减、P(x⁽ᵏ⁾) 非增，即随着罚因子加大，迭代点的不可行程度单调下降；又由 f(x\*) ≥ F(x⁽ᵏ⁾,μk) ≥ f(x⁽ᵏ⁾) 可知 f(x⁽ᵏ⁾) 不会低于最优值。若存在 ε>0 使 S_ε 为紧集，则 {x⁽ᵏ⁾} 有收敛子列，且任一收敛子列的极限都是原问题的最优解。

## 四、易错点清单（考前扫一遍）

1. **μ 的趋势别反**：外点 μ **大且递增 → ∞**；内点 μ **小且递减 → 0**。
2. **内点法不能处理等式约束**（边界墙只对不等式有意义）；等式约束必须用外点法。
3. **内点法初始点必须是严格内点**（gᵢ(x⁽⁰⁾) > 0 全部严格成立），否则 1/gᵢ 或 log gᵢ 无定义。
4. **max{0, −gᵢ(x)} 的方向**：惩罚的是**违反** gᵢ ≥ 0 的部分，可行时不罚。
5. **判据是 μkP(x⁽ᵏ⁾) < ε，不是 P(x⁽ᵏ⁾) < ε**（要乘上罚因子）。
6. **Th13.1.3 要 S_ε 紧**：这是收敛性的前提条件，考场写结论时别漏。
7. **引理 13.1.1 要求"全局"极小点**：只说局部极小点推不出单调性。
8. **例 13.2.1 的答案是参数化的**：x = (1+2√μk, μk)，要写出"当 μk→0 时趋于 (1,0)"这个极限过程，只写参数式不得分。
