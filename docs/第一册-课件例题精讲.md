## §3.1 单纯形方法原理（表格形式）

**例1**（s015–s023）

    min z = x1 + 5x2 − 2x3
    s.t. x1+x2+x3 ≤ 4 ;  x1 ≤ 2 ;  x3 ≤ 3 ;  3x2+x3 ≤ 6 ;  x ≥ 0

→ 标准化引入松弛变量 x4–x7；**最优解 x1=0, x2=0, x3=3，z* = −6**（四个松弛变量依次为 1, 2, 0, 3，即 BFS 向量 (0,0,3,1,2,0,3)）。
> ⚠️ 《考试范围与例题清单.md》此处记的 y'=(0,0,3,3,2,0,3) 把 x4 误记成 3 —— 复算：x4 = 4−(x1+x2+x3) = 1。以复算为准。

**例2**（s029–s031）

    max z = 3x1 + 4x2 − x3 + 2x4
    s.t. x1+x2+x3+x4 ≤ 25 ;  x1+2x2+x3+2x4 ≤ 36 ;  x ≥ 0

→ 化为 min z′ = −3x1−4x2+x3−2x4，引入松弛 x5, x6；**最优解 (14, 11, 0, 0, 0, 0)，max z = 86**

**例3（课堂练习）**（s032–s035）

    max z = 2x1 + 3x2 + x3
    s.t. x1+3x2+x3 ≤ 15 ;  2x1+3x2−x3 ≤ 18 ;  x1−x2+x3 ≤ 3 ;  x ≥ 0

→ **最优解 (5, 3, 1, 0, 0, 0)，max z = 20**

## §3.2 两阶段法与大 M 法 ★★（20 分题出处处；两阶段法老师点名必考）

**例1（两阶段法）**（s042–s047）★必须会手推

    min z = 5x1 + 21x3
    s.t. x1 − x2 + 6x3 ≥ 2 ;  x1 + x2 + 2x3 ≥ 1 ;  x ≥ 0

**完整手推（五张表 + 每步行变换，2026-11-08 按精确分数逐行复算）**：

**第 0 步 标准化**：≥ 约束减过剩变量：x1−x2+6x3−**x4** = 2、x1+x2+2x3−**x5** = 1。

**表 P1-1**（第一阶段，min w = a1+a2，初始基 (a1,a2)，w = 3）

| 基 | b | x1 | x2 | x3 | x4 | x5 | a1 | a2 |
|---|---|---|---|---|---|---|---|---|
| a1 | 2 | 1 | −1 | **6** | −1 | 0 | 1 | 0 |
| a2 | 1 | 1 | 1 | 2 | 0 | −1 | 0 | 1 |
| σ | | −2 | 0 | **−8** | 1 | 1 | 0 | 0 |

σ₃=−8 最负 ⇒ x3 入基；比值 min{2/6, 1/2} = 1/3 ⇒ a1 出基。

**变换①**（主元 = 第1行×第3列 = 6）：
- 主行 ÷ 6：`[1/6, −1/6, 1, −1/6, 0, 1/6, 0 | 1/3]`
- a2 行 − 2×新主行：`[2/3, 4/3, 0, 1/3, −1, −1/3, 1 | 1/3]`

**表 P1-2**（基 (x3,a2)，c_B=(0,1)，w = 1/3）

| 基 | b | x1 | x2 | x3 | x4 | x5 | a1 | a2 |
|---|---|---|---|---|---|---|---|---|
| x3 | 1/3 | 1/6 | −1/6 | 1 | −1/6 | 0 | 1/6 | 0 |
| a2 | 1/3 | 2/3 | **4/3** | 0 | 1/3 | −1 | −1/3 | 1 |
| σ | | −2/3 | **−4/3** | 0 | −1/3 | 1 | 4/3 | 0 |

（σ 重算：σ_j = c_j − 1×(a2 行)_j）σ₂=−4/3 最负 ⇒ x2 入基；比值 (1/3)/(4/3) = 1/4 ⇒ a2 出基。

**变换②**（主元 = 第2行×第2列 = 4/3）：
- 主行 × 3/4：`[1/2, 1, 0, 1/4, −3/4, −1/4, 3/4 | 1/4]`
- x3 行 − (−1/6)×新主行 = x3 行 + (1/6)×新主行：`[1/4, 0, 1, −1/8, −1/8, 1/8, 1/8 | 3/8]`

**表 P1-3**（基 (x3,x2)，c_B=(0,0)，w = 0）

| 基 | b | x1 | x2 | x3 | x4 | x5 | a1 | a2 |
|---|---|---|---|---|---|---|---|---|
| x3 | 3/8 | 1/4 | 0 | 1 | −1/8 | −1/8 | 1/8 | 1/8 |
| x2 | 1/4 | 1/2 | 1 | 0 | 1/4 | −3/4 | −1/4 | 3/4 |
| σ | | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

c_B = (0,0) ⇒ σ ≡ c，人工变量列 σ=1。**w\* = 0，人工变量全部离基** ⇒ 过渡判据满足，进入第二阶段。

**表 P2-1**（第二阶段：删 a1/a2 两列，目标换回 min z = 5x1+21x3，c_B=(21,0)，z = 63/8）

| 基 | b | x1 | x2 | x3 | x4 | x5 |
|---|---|---|---|---|---|---|
| x3 | 3/8 | **1/4** | 0 | 1 | −1/8 | −1/8 |
| x2 | 1/4 | 1/2 | 1 | 0 | 1/4 | −3/4 |
| σ | | **−1/4** | 0 | 0 | 21/8 | 21/8 |

（σ 重算：σ_j = c_j − 21×(x3 行)_j）σ₁=−1/4 最负 ⇒ x1 入基；比值 min{(3/8)/(1/4), (1/4)/(1/2)} = min{3/2, 1/2} = 1/2 ⇒ x2 出基。

**变换③**（主元 = 第2行×第1列 = 1/2）：
- 主行 × 2：`[1, 2, 0, 1/2, −3/2 | 1/2]`
- x3 行 − (1/4)×新主行：`[0, −1/2, 1, −1/4, 1/4 | 1/4]`

**表 P2-2**（基 (x3,x1)，c_B=(21,5)，z = 31/4）

| 基 | b | x1 | x2 | x3 | x4 | x5 |
|---|---|---|---|---|---|---|
| x3 | 1/4 | 0 | −1/2 | 1 | −1/4 | 1/4 |
| x1 | 1/2 | 1 | 2 | 0 | 1/2 | −3/2 |
| σ | | 0 | **1/2** | 0 | **11/4** | 9/4 |

（σ 重算：σ_j = c_j − [21×(x3 行)_j + 5×(x1 行)_j]）σ 全 ≥ 0 ⇒ **最优**。

**结论**：**x\* = (1/2, 0, 1/4, 0, 0)ᵀ，z\* = 5(1/2)+21(1/4) = 31/4**（两约束同时取等）。

> ⚠️ 2026-11-08 修正记录：① 旧稿 σ₄=7/2 → 实为 **11/4**；② 旧稿 P1-1 σ₄=2 → 实为 **1**（0−[1·(−1)+1·0]）；③ 旧稿 P1-2 σ_a1=1/3 → 实为 **4/3**（1−(−1/3)）；④ P2-2 表中 x1 行 x₂ 系数 = **2**（x1 = 1/2−2x2−x4/2+3x5/2）、x3 行 x₂ 系数 = **−1/2**。以上均经 Python 精确分数逐行复算 + 三维顶点枚举独立复核（四个可行顶点 10、63/8、21/2、31/4）。

**例9.2.1（0.618 法）** ★必须会手推

    min f(x) = 2x² − x − 1 ,  初始区间 [−1, 1] ,  精度 L ≤ 0.16

**完整手推**（真实极小点 x*=0.25）：
- 第 1 轮：λ₁ = −1+0.382×2 = −0.236，λ₂ = −1+0.618×2 = 0.236。f(λ₁) = −0.6526 > f(λ₂) = −1.1246 ⇒ 区间缩为 **[−0.236, 1]**（长 1.236）；
- 第 2 轮：复用 λ₂ 作新 λ₁，新 λ₂ = −0.236+0.618×1.236 = 0.5278。f(0.236)=−1.1246 ≤ f(0.5278)=−0.9706 ⇒ 区间缩为 **[−0.236, 0.5278]**（长 0.764）；
- 第 3 轮：新 λ₁ = −0.236+0.382×0.764 = 0.0558。f(0.0558)=−1.0496 > f(0.236)=−1.1246 ⇒ 区间缩为 **[0.0558, 0.5278]**（长 0.472）；
- 第 4 轮：新 λ₂ = 0.0558+0.618×0.472 = 0.3475。f(0.236) ≤ f(0.3475)=−1.1059 ⇒ 区间缩为 **[0.0558, 0.3475]**（长 0.292）；
- 第 5 轮：新 λ₁ = 0.0558+0.382×0.292 = 0.1672。f(0.1672)=−1.1113 > f(0.236)=−1.1246 ⇒ 区间缩为 **[0.1672, 0.3475]**（长 0.180）；
- 第 6 轮：新 λ₂ = 0.1672+0.618×0.180 = 0.2786。f(0.236) ≤ f(0.2786)=−1.1234 ⇒ 区间缩为 **[0.1672, 0.2786]**（长 0.111 ≤ 0.16，停止）；
- 取区间中点 ≈ 0.223 作为极小点估计（真实 0.25）。

## 第 13 章　惩罚函数法 —— (13).pdf，32 页

**例（理想罚函数反例）**（p7）

    min x1²+x2²   s.t. x1+x2−2 = 0

x*=(1,1)ᵀ；理想罚函数 F 在直线外全为 +∞，**性态极坏，无法用有效的无约束优化算法求解** ⇒ 引出罚函数的构造。

**例（外点·等式）** ★必须会手推（p13）

    min x1²+x2²   s.t. x1+x2−2 = 0

令 P(x)=(x1+x2−2)²，F=x1²+x2²+σ(x1+x2−2)²。令 ∂F/∂x1=2x1+2σ(x1+x2−2)=0、∂F/∂x2=0，两式相减得 x1=x2，代回得 **x1=x2=2σ/(2σ+1) → (1,1)**（σ→∞）。

**例1（外点·不等式）** ★（p14）

    min x²   s.t. g(x) = −x−1 ≥ 0     （D=(−∞,−1]，x*=−1）

P(x)=[max{0,−g(x)}]²，分段求导得 **x(σ) = −σ/(1+σ) → −1**。

**练习题**（p23）：① min 1.5x1²+x2²+0.5x3²−x1x2−x2x3+x1+x2+x3 s.t. x1+2x2+x3−4=0；② min x1²+x2² s.t. 2x1+x2−2≤0, x2≥1，并用最优性条件说明 (0,1) 是否为局部极小点。
> ② 答案：(0,1) 处 g2=x2−1=0 起作用、g1=2−2x1−x2=1>0 不起作用；∇f=(0,2)=2·(0,1) ⇒ 乘子 u=2≥0，**是 KKT 点**；又 x2≥1 ⇒ f=x1²+x2²≥1=f(0,1) ⇒ **也是全局最优**。

**例13.2.1（内点）** ★必须会手推（p29–30）

    min (x1+1)³/12 + x2   s.t. x1−1 ≥ 0 ,  x2 ≥ 0

F=(x1+1)³/12+x2+μk(1/(x1−1)+1/x2)。∂F/∂x1=(x1+1)²/4−μk/(x1−1)²=0、∂F/∂x2=1−μk/x2²=0 ⟹ **x=(1+2√μk, μk) → (1,0)**（μk→0）。

**练习题（内点）**（p32）：min (x+1)² s.t. x≥0（B(x)=1/x，∂F/∂x=2(x+1)−μ/x²=0；x*=0 在边界，只能从右侧逼近）。
