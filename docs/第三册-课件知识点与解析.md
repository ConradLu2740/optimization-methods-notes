# 第一部分　分章知识点与解析

## 第 1 章　引言

**知识点**
- **非线性规划（NLP）一般形式**：min f(x)，s.t. g_i(x) ≥ 0（i=1..m）、h_j(x) = 0（j=1..l）；可行域 D = {x | 约束全满足}。
- **最优解 / 局部最优解**：x* 是全局最小点指 f(x*) ≤ f(x) 对所有可行 x 成立；x* 是局部最小点指存在邻域，使 f(x*) ≤ f(x) 对所有邻域内可行 x 成立。（Df 1.1 / 1.2）
- **运筹学方法论**：模型 → 理论 → 算法。
- **发展史**：17 世纪牛顿（极值优化、Lagrangian）→ 1847 年 Cauchy 最速下降法 → 1930s 康托诺维奇 LP → 1947 年 Dantzig 单纯形 → 1950s Bellman 动态规划 / KKT → 1980s 现代优化算法。
- **三个建模例子**（CH1-1，可能考建模）：**食谱问题**（选牛奶鸡蛋满足维生素下限、成本最小）、**运输问题**（m 产地 n 销地，产销平衡/不平衡）、**选址问题**（开放哪些设施 + 放在哪 + 顾客怎么分，最大总利润）。

**解析与提示**：本章不考计算，考"能说出 NLP 三要素（决策变量、目标函数、约束条件）"和建模思路。答题时先设变量、再写目标、最后写约束，三步走。

## 第 2 章　线性规划的基本性质

**知识点**
- **标准形式**：min z = c 转置乘 x，s.t. Ax = b，x ≥ 0。约束是不等式时引入**松弛变量**（≤ 加非负松弛、≥ 减非负松弛/加人工变量）。
- **图解法**：画可行域 → 找极点 → 平移目标函数等值线。食谱例：min 3x+2.5y，s.t. 2x+4y ≥ 40、3x+2y ≥ 50、x,y ≥ 0；极点 (0,25)、(15,2.5)、(20,0)，最优解 (15,2.5)，z*=51.25。
- **Th2.2**：LP 的可行域是**凸集**（凸集的有限交）。
- **Th2.3**：若 LP 有最优解，则**最优解可在极点达到**。★考点第 4 条
- **Def2.6**：在标准形式中取定基 B（m 个线性无关列），令非基变量为 0 解出基变量得**基本解**；若基本解可行则称**基本可行解（BFS）**。基变量为 0 的基本可行解称为**退化的**。
- **Th2.4**：**极点集 ≡ BFS 集**。★考点第 5 条
- **Th2.5**：若可行域非空，则至少存在一个 BFS。

**解析与提示**：考点第 5 条"初始基本可行解与极点的关系、求极点"的标准答法：① 说明极点与 BFS 一一对应（Th2.4）；② 求极点 = 从约束矩阵中选 m 个线性无关列作基、解方程组、检验非负；③ 两阶段法第一阶段找初始 BFS 就是"用人工变量构造一个起点"。

## 第 3 章　单纯形方法 ★★（20 分，多写点会捞；两阶段法老师点名必考）

**知识点**
- **3.1 原理与表格形式**：从一个 BFS 出发，计算检验数 σ_j = c_j − c_B 转置乘 B⁻¹A_j；
  - 所有 σ_j ≤ 0（min 问题）⇒ 当前 BFS 最优；
  - 否则选 σ_j > 0 中最大的（或最左边）对应的非基变量**入基**；
  - 用**最小比值规则** min{b_i / a_ij : a_ij > 0} 定**出基**变量，保证可行性；
  - 换基后目标值严格下降，转下一步。
- **Th3.4**：相容且非退化时算法有限步终止。
- **3.2 两阶段法（老师点名必考）**：对 ≥ 或 = 约束，减去过剩变量后加**人工变量**，构造仅含人工变量的初始基；
  - **第一阶段**：min 所有人造变量之和 w。若 w*=0 得原问题一个 BFS，转第二阶段；若 w*>0 则原问题不可行；
  - **第二阶段**：从第一阶段最终表删去人工变量列，以原目标函数继续单纯形迭代。
- **大 M 法**：把人造变量以极大罚金 M 放进原目标（min 问题加 M·人工变量），一次迭代同时处理。M 是符号常数，不进数值表。
- **单人工变量技巧**：等式约束两端乘 −1 后，可以只引入一个人工变量。
- **3.3 退化情形**：比值计算出现并列 ⇒ 可能循环。两种解法：**摄动法**（"选最左边的正检验数对应的非基变量入基"）与 **Bland 规则**（入基取最小下标正检验数、出基取最小下标并列者）。
- **3.4 修正单纯形法**：不维护全表，只维护 B⁻¹ 与相关向量；**逆的乘积形式**用初等矩阵连乘更新 B⁻¹，减少计算量。

**解析与提示**：考场写单纯形表要写全五列（基变量、c_B、b、θ、检验数/目标行），步骤文字要写"选入基变量→算比值→定出基→旋转变换→检验最优性"。20 分的题，表格占 12 分、文字占 8 分，别只画表不写话。

## 第 7 章　最优性条件 ★★（KKT 必考）

**7.1 无约束极值条件**
- **Th7.1.1（下降条件）**：f 在 x* 可微，若存在 d ≠ 0 使 ∇f(x*) 转置乘 d < 0，则存在 δ>0，对任意 λ∈(0,δ) 有 f(x*+λd) < f(x*)。（证明：一阶展开 f(x*+λd)=f(x*)+λ∇f(x*)ᵀd+λ‖d‖α，α→0）
- **Th7.1.2-3（必要条件）**：x* 局部极小，则（1）f 可微时 **∇f(x*)=0**；（2）f 二次可微时 ∇f(x*)=0 且 **Hessian 半正定**。（证明思路：反证取 d=−∇f(x*)；二阶展开令 λ→0 得 dᵀH(x*)d ≥ 0）
- **定义**：∇f(x*)=0 的点叫**驻点/平稳点**；既非极大也非极小的驻点叫**鞍点**。
- **Th7.1.4（二阶充分条件）**：∇f(x*)=0 且 H(x*) **正定** ⇒ x* 是（严格）局部极小点。
- **Th7.1.5（凸函数充要条件）**：f 可微凸，则 x* 全局最小 **当且仅当** ∇f(x*)=0。

**7.2 约束极值条件**
- **Def7.2.1 下降方向**：∃δ>0，使 ∀λ∈(0,δ) 有 f(x*+λd)<f(x*)。可微时 ∇f(x*)ᵀd<0 即为下降方向；所有下降方向构成 F₀ = {d | ∇f(x*)ᵀd < 0}。
- **Def7.2.2 可行方向**：x ∈ clS，d≠0，若 ∃δ>0 使 ∀λ∈(0,δ) 有 x+λd ∈ S。所有可行方向构成**可行方向锥** D。
- **Th7.2.1（几何形式一阶必要条件）**：x* 局部极小 ⇒ **F₀(x*) ∩ D = ∅**。（反证：取 d∈F₀∩D，则沿 d 小步既下降又可行，矛盾）
- **Def7.2.3 正则点**：在 x 处起作用约束的梯度 {∇g_i(x) (i∈I), ∇h_j(x)} **线性无关**，则 x 为正则点（约束规格）。
- **Def7.2.4 / Th7.2.6**：切平面 T(x) = {d | ∇h_j(x)ᵀd = 0}（等式约束梯度线性无关时）。
- **Th7.2.7（几何形式）**：正则点且局部最优 ⇒ F₀ ∩ G₀ ∩ H₀ = ∅，其中 G₀={d | ∇g_i(x)ᵀd > 0 (i∈I)}、H₀={d | ∇h_j(x)ᵀd=0}。
- **Th7.2.8（Fritz John 条件）**：x 局部最优 ⇒ ∃不全为零的 w₀≥0、w_i≥0 (i∈I)、v_j ∈ R，使

      w₀∇f(x) − Σ_{i∈I} w_i ∇g_i(x) − Σ_j v_j ∇h_j(x) = 0

  证明路线：Th7.2.7 得不等式组无解 → 构造两集合 S1、S2 不相交 → **凸集分离定理**得 p → 记分量即得。（PPT 用 8 页讲这个证明，考场写"由凸集分离定理"即可）
- **Lagrange 函数**：L(x, w, v) = f(x) − Σ w_i g_i(x) − Σ v_j h_j(x)。
- **Th7.2.9（KKT 条件）**：x 为正则点且局部最优 ⇒ ∃w_i≥0 (i∈I)、v_j，使 ∇f(x) − Σ w_i∇g_i(x) − Σ v_j∇h_j(x) = 0（即 F-J 中 **w₀ > 0 可归一化为 1**）。
- **Th7.2.10（凸规划充分条件）**：f、g_i 可微凸、h_j 线性（或仿射）时，**KKT 点即全局最优解**。
- **二阶条件**：在起作用约束的切空间上考查 Lagrange 函数的 Hessian；二阶充分条件要求 d 转置乘 ∇²ₓL d > 0 对所有可行方向 d 成立。

**解析与提示**：① 求 KKT 的标准流程：列 L → 对 x、w、v 求导置零 → 补 w_i g_i(x)=0（互补松弛）→ 解方程组 → 验 w≥0。② 选择题问"哪个点不是 KKT 点"，算完乘子有负的直接淘汰。③ F-J 与 KKT 的差别就在 w₀：KKT 要求 w₀>0，F-J 允许 w₀=0（此时一阶条件不含 f 的信息，判不了）。

## 第 8 章　算法

**知识点**
- **Df8.1.1 算法映射**：算法 A 是空间 X 上的**点到集映射**，每点 x∈X 指定一个子集 A(x)⊂X；给初始点 x₁，生成点列 x_{k+1} ∈ A(x_k)。
- **解集合 Ω 的六种常用类型**：① 全体局部最优解；② {x∈S | f(x) ≤ b}（b 为可接受目标值）；③ {x∈S | f(x) < LB+ε}（LB 为最优值下界）；④ {x∈S | f(x) − f(x̂) < ε}；⑤ 全体 KKT 点；⑥ 全体 F-J 点。
- **Df8.1.2 下降函数**：α 连续，且 x∉Ω、y∈A(x) 时 α(y)<α(x)，x∈Ω 时 α(y)≤α(x)。解 NLP 时通常取 **∇f(x) 或 f(x)** 作下降函数。
- **迭代算法一般格式**：给定 x⁽⁰⁾ →（i）定可行下降方向 p⁽ᵏ⁾；（ii）定步长 α_k>0 使 f(x⁽ᵏ⁾+α_k p⁽ᵏ⁾)<f(x⁽ᵏ⁾)；（iii）x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾+α_k p⁽ᵏ⁾；（iv）检验终止准则。沿 p⁽ᵏ⁾ 求步长的过程叫**一维搜索/线性搜索**。
- **收敛性**：有限步得最优解，或点列极限点是最优解 ⇒ **收敛**；只有初值充分接近才收敛 ⇒ **局部收敛**；任意初值都收敛 ⇒ **全局收敛**。
- **Df8.2.1 收敛速度**：lim ‖x⁽ᵏ⁺¹⁾−x*‖/‖x⁽ᵏ⁾−x*‖ = β。0<β<1 **线性收敛**（β 为收敛比）；β=0 **超线性收敛**；β=1 **次线性收敛**；更一般地 lim ‖x⁽ᵏ⁺¹⁾−x*‖/‖x⁽ᵏ⁾−x*‖^p = β>0 为 **p 阶收敛**。
- **例1**（PPT）：min x² s.t. x ≥ 1，最优解 x*=1。点到点映射 A(x)=(x+1)/2，从 x₁=4 生成 4, 2.5, 1.75, 1.375, … 收敛到 1；点到集版本 A(x)=[1,(x+1)/2] 或 [(x+1)/2,1]。

**解析与提示**：本章是"证明算法收敛"的工具章。标准套路：把算法写成合成映射 A = M∘D → 用 Th9.1.1 证 M 闭、D 连续 ⇒ A 闭 → 找下降函数 α → 点列含于紧集 ⇒ 由收敛定理得收敛。最速下降法、牛顿法的收敛性证明全是这个模板。

## 第 9 章　一维搜索

**知识点**
- **Df9.1.1 算法映射**：M(x,d) = { y | y = x+λd，λ 使 f(x+λd) = min_{λ≥0} f(x+λd) }。
- **Th9.1.1（闭性）**：f 连续、d≠0，则 M 在 (x,d) 处是**闭映射**。（证明：设 (x⁽ᵏ⁾,d⁽ᵏ⁾)→(x,d)、y⁽ᵏ⁾→y，由 y⁽ᵏ⁾=x⁽ᵏ⁾+λᵏd⁽ᵏ⁾ 解出 λᵏ=(y⁽ᵏ⁾−x⁽ᵏ⁾)/d⁽ᵏ⁾ → λ，再用 f 连续取极限）
- **Df9.2.1 单峰函数**：[a,b] 上 ∃极小点 x*，对 ∀x⁽¹⁾<x⁽²⁾∈[a,b]，当 x⁽²⁾≤x* 时 f(x⁽¹⁾)>f(x⁽²⁾)，当 x*≤x⁽¹⁾ 时 f(x⁽¹⁾)<f(x⁽²⁾)。等价定义：f 在 [a,α*] 严格递减、在 [α*,b] 严格递增。
- **Th9.2.1**：单峰函数中取两点 x⁽¹⁾<x⁽²⁾，若 f(x⁽¹⁾)>f(x⁽²⁾) 则极小点在 [x⁽¹⁾,b]；若 f(x⁽¹⁾)≤f(x⁽²⁾) 则极小点在 [a,x⁽²⁾]。**一次比较砍掉一段区间**。
- **缩减率** τ^(k−1) = (b^(k−1)−a^(k−1))/(b^(k)−a^(k))，越小效率越高。
- **试探法**：0.618 法（黄金分割，每次保留 0.618 倍区间，可复用已算点）、Fibonacci 法（按 Fibonacci 数列取点，区间长度比趋于黄金比）。
- **函数逼近法**：用二次/三次插值近似 f，取近似函数的极小点。
  - **牛顿法**：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − f′(x⁽ᵏ⁾)/f″(x⁽ᵏ⁾)（式 3.2）；**Th3.1**：f 有三阶连续导数、f′(x*)=0、f″(x*)≠0、初点充分接近，则牛顿法**至少 2 阶收敛**。
  - **割线法**：用差商代替二阶导数，只需函数值不需导数。

**解析与提示**：0.618 与 Fibonacci 的考题就是"迭代两次得新区间"，按公式一步步算别跳步。注意 0.618 法第一个试点取在 a+0.382(b−a) 与 a+0.618(b−a)，之后每轮只有一个新点。

## 第 10 章　使用导数的最优化方法

### 10.1 最速下降法
- 方向导数 D(x,d) = ∇f(x) 转置乘 d。求下降最快方向归结为 min ∇f(x)ᵀd s.t. ‖d‖≤1（式 10.1.3）。由 **Schwartz 不等式** ∇f(x)ᵀd ≥ −‖∇f(x)‖，故

      d = − ∇f(x) / ‖∇f(x)‖        （10.1.5）

  即**负梯度方向为最速下降方向**。
- 迭代格式：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾，d⁽ᵏ⁾ = −∇f(x⁽ᵏ⁾)，λᵏ 由一维搜索确定（10.1.6）。
- **收敛性**：设 f 连续可微、{x⁽ᵏ⁾} 含于紧集，则每个聚点 x̂ 满足 ∇f(x̂)=0。证明：A = M∘D，Th9.1.1 证 M 闭、D 连续 ⇒ A 闭；f 是下降函数。
- **收敛比**：x* 局部极小、Hessian 最小特征值 a>0、最大特征值 A，则 {f(x⁽ᵏ⁾)} 以不大于 **((A−a)/(A+a))²** 的收敛比线性收敛于 f(x*)。令 r=A/a 为**条件数**，r 越小收敛越快、越大越慢。
- **锯齿现象**：相邻迭代点的梯度互相正交，在拉长的等值面上来回"之字形"，越靠近极值点越慢。

### 10.2 牛顿法
- **迭代格式**（10.2.2）：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − ∇²f(x⁽ᵏ⁾)⁻¹ ∇f(x⁽ᵏ⁾)。由 Taylor 二阶展开令 ∇φ(x)=0 得。
- **另一种理解**：取 A = G_k = ∇²f(x⁽ᵏ⁾)，牛顿方向是**椭球范数意义下的最速下降方向**（式 10.2.5）。
- **Th10.2.1（局部收敛性）**：f 二次可微、∇f(x*)=0、∇²f(x⁽ᵏ⁾)⁻¹ 存在、初点充分接近（存在 k₁k₂<1 使 Hessian 逆有界且梯度误差有界），则牛顿法产生的序列收敛于 x*。
- **二次终止性**：对**严格二次凸函数，迭代一次即得极小点**。
- **优缺点**：优点——G* 正定且初点合适时二阶收敛、对正定二次函数一步到位；缺点——多数问题不是全局收敛、每步要算 Hessian、要解线性方程组 G_k p = −g_k（可能奇异/病态/非正定，p_k 可能不是下降方向）、可能收敛到鞍点或极大点。
- **阻尼牛顿法**：在牛顿方向上再加一维搜索，x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾，d⁽ᵏ⁾ 为牛顿方向，λᵏ 由一维搜索定。**反例**（PPT）：min x1⁴+x1x2+(1+x2)²，初点 (0,0)ᵀ，∇f=(0,2)ᵀ，∇²f=[[0,1],[1,2]]，牛顿方向 d⁽¹⁾=(−2,0)ᵀ，但一维搜索 φ(λ)=16λ⁴+1 得 λ₁=0，**产生不了新点**——因为该点 Hessian 非正定。
- **修正牛顿法（10.2.3）**：Hessian 非正定时构造对称正定 G_k 取代它，解 G_k d⁽ᵏ⁾ = −∇f(x⁽ᵏ⁾)，得 d⁽ᵏ⁾ = −G_k⁻¹∇f(x⁽ᵏ⁾)，再沿该方向一维搜索。构造例：G_k = ∇²f(x⁽ᵏ⁾) + ε_k I（ε_k 适当正数）。算法中记 B_k = G_k + E_k，E_k 为修正矩阵（G_k 正定时取 0）。

## 第 12 章　可行方向法

详见专项材料《第12章-可行方向法-答题材料.md》。必背骨架：
- **可行方向**：∃δ>0，∀λ∈(0,δ) 有 x̂+λd 可行（d≠0）。
- **Th12.1.1**：线性约束下，d 为可行方向的充要条件是 **A1d ≥ 0、Ed = 0**（A1 起作用、A2 不起作用）。
- **方向 LP**（12.1.10）：min ∇f(x)ᵀd s.t. A1d≥0, Ed=0, −1≤d_j≤1。d=0 可行 ⇒ 最优值≤0；<0 得下降可行方向，=0 则 x 是 KKT 点。
- **Th12.1.2**：x 为 KKT 点 ⇔ LP 最优值为 0（证明用 **Farkas 定理**，令 v=p−q）。
- **步长上限**：b̂=b2−A2x⁽ᵏ⁾、d̂=A2d⁽ᵏ⁾，λmax = min{b̂i/d̂i : d̂i<0}（12.1.24）。
- **Th12.1.4**：非线性约束下 z*=0 ⇒ x 是 **Fritz John 点**（证明用 **Gordan 定理**）。
- **收敛性缺陷**：算法映射 A=M∘D，D、M 未必闭 ⇒ 可能不收敛（Wolfe 1972 反例）；**Topkis-Veinott 修正**把 LP 右端改为 −g_i(x)，Th12.1.5 保证聚点是 F-J 点。
- **Rosen 梯度投影**：M=[A1;E] 行满秩，P_N(M)=I−Mᵀ(MMᵀ)⁻¹M；d=−P_N(M)∇f(x)≠0 为下降可行方向；w=(MMᵀ)⁻¹M∇f(x)=(uᵀ,vᵀ)ᵀ，**u≥0 ⇔ KKT**，u 有负分量则删对应行再投影。

## 第 13 章　惩罚函数法

详见专项材料《第13章-惩罚函数法-答题材料.md》。必背骨架：
- **思想**：构造辅助函数把约束问题化为无约束问题；**总代价 = 价格 + 罚款**（经济解释）。
- **外点法**：F(x,μ)=f(x)+μP(x)，μ 很大且递增至 ∞；等式罚项 Σh_j(x)²、不等式罚项 Σ(max{0,−g_i(x)})²；迭代点可从可行域外逼近；适用于等式+不等式。
- **内点法（障碍函数法）**：F(x,μ)=f(x)+μB(x)，μ 很小且递减至 0；B(x)=Σ1/g_i(x) 或 −Σlog g_i(x)；**只适用于不等式约束**，初始点必须是严格内点。

## 2.1 Farkas 定理的几何表示形式（必考第 1 条，且要画图）

**定理 2.11（Farkas 定理）**　设 A 为 m×n 矩阵，c 为 n 维向量，则

    Ax <= 0 ,  c 转置乘 x > 0  有解   <=>   A 转置乘 y = c ,  y >= 0  无解

**定理 2.11′（置换定理）**　c 是 A 的行向量的凸锥组合，即

    c 属于 cone(A)   <=>   对任意满足 Ax <= 0 的 x，有 c 转置乘 x <= 0

**经典择一形式**　设 A 为 m×n 矩阵、b 为 m 维向量，以下两个论断**有且只有一个**成立：

1. 存在 x 使 Ax = b 且 x >= 0
2. 存在 y 使 A 转置乘 y >= 0 且 b 转置乘 y < 0

**定理 2.12（Gordan 定理）**　Ax < 0 有解，当且仅当不存在非零向量 y >= 0 使 A 转置乘 y = 0

**几何表示（画图题就画这个）**：取 A 的两个行向量 a1、a2，它们张成一个锥 C = cone{a1, a2}。对向量 c 只有两种情况：
- **c 在锥内**：则 c 可写成 a1、a2 的非负组合，即存在 y≥0 使 A 转置乘 y = c；此时任何满足 Ax ≤ 0 的 x 都给出 c 转置乘 x ≤ 0，所以 c 转置乘 x > 0 有解不成立；
- **c 在锥外**：则由凸集分离定理（Th2.7 / 推论 2.2），存在一条**过原点的分离超平面** {x | c 转置乘 x = 0}，使得 Ax ≤ 0 的半平面在它的一侧且 c 转置乘 x > 0 有解；此时 A 转置乘 y = c、y ≥ 0 无解。

**证明路线**（PPT s029–s031 已给）：凸集分离定理 Th2.7，先证必要性（c 转置乘 x > 0 有解，则 A 转置乘 y = c 无解），再证充分性。

| 什么是可行方向法 | 从可行点出发，在可行方向中找使目标下降的方向，沿方向一维搜索得新可行点，迭代至 KKT 点 |

## 3.1 公式卡（考前一夜只看这一页）

**最优性条件**
- 无约束一阶必要：∇f(x*)=0；二阶必要：H(x*) 半正定；二阶充分：H(x*) 正定；凸函数：∇f(x*)=0 充要
- 下降方向：∇f(x*)ᵀd < 0；可行方向：∃δ>0, ∀λ∈(0,δ) x+λd 可行
- F-J：w₀∇f − Σwᵢ∇gᵢ − Σvⱼ∇hⱼ = 0（w₀, wᵢ ≥ 0 不全为零）
- KKT：∇f − Σwᵢ∇gᵢ − Σvⱼ∇hⱼ = 0（wᵢ ≥ 0）+ 互补松弛 wᵢgᵢ(x)=0；正则点 + 凸规划 ⇒ KKT 即全局最优
- Lagrange：L = f − Σwᵢgᵢ − Σvⱼhⱼ

**线性规划与单纯形**
- 检验数 σⱼ = cⱼ − c_BᵀB⁻¹Aⱼ；入基取 σⱼ>0（min），出基用最小比值 min{bᵢ/aᵢⱼ : aᵢⱼ>0}
- 两阶段法：第一阶段 min 人工变量之和，w*=0 才转第二阶段
- 大 M 法：目标加 M·(人工变量之和)，M 为符号常数
- 退化处理：摄动法 / Bland 规则

**一维搜索**
- 0.618：λ₁=a+0.382(b−a)、λ₂=a+0.618(b−a)；f(λ₁)>f(λ₂) ⇒ 取 [λ₁,b]，否则取 [a,λ₂]
- 牛顿法（一元）：x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾−f′(x⁽ᵏ⁾)/f″(x⁽ᵏ⁾)，至少 2 阶收敛

**第 10 章**
- 最速下降方向：d = −∇f/‖∇f‖；收敛比 ((A−a)/(A+a))²，条件数 r=A/a 越小越快
- 牛顿方向：d = −∇²f⁻¹∇f；严格二次凸函数一步到位
- 修正牛顿：G_k = ∇²f + ε_k I，解 G_k d = −∇f
- 共轭：(d⁽ⁱ⁾)ᵀAd⁽ʲ⁾=0；FR：λ=−gᵏᵀd/(dᵀAd)、β=‖g_{k+1}‖²/‖gᵏ‖²
- 拟牛顿条件：p = Hq（p=x⁽ᵏ⁺¹⁾−x⁽ᵏ⁾, q=g_{k+1}−gᵏ）；DFP：H+ppᵀ/(pᵀq) − HqqᵀH/(qᵀHq)
- 信赖域：ρ_k = [f(x⁽ᵏ⁾)−f(x⁽ᵏ⁾+d⁽ᵏ⁾)]/[f(x⁽ᵏ⁾)−ϕ_k(d⁽ᵏ⁾)]；ρ≤μ 减半、μ<ρ<η 不变、ρ≥η 加倍

**第 12 章**
- 可行方向充要条件（线性约束）：A1d ≥ 0, Ed = 0
- λmax = min{b̂ᵢ/d̂ᵢ : d̂ᵢ<0}，b̂=b2−A2x⁽ᵏ⁾, d̂=A2d⁽ᵏ⁾
- Rosen：P_N(M)=I−Mᵀ(MMᵀ)⁻¹M，d=−P_N(M)∇f(x)，u≥0 ⇔ KKT

**第 13 章**
- 外点：F=f+μP，等式罚 Σh²、不等式罚 Σ(max{0,−g})²，μ↑∞
- 内点：F=f+μB，B=Σ1/g 或 −Σlog g，μ↓0，只要不等式约束
- 判据：μP(x⁽ᵏ⁾)<ε（外）/ μB(x⁽ᵏ⁾)<ε（内）

## 3.2 易错点 Top 15

1. **Kuhn-Tucker 乘子符号**：min f s.t. g≥0 时乘子 w ≥ 0；写成 g≤0 形式时符号要跟着变。
2. **互补松弛别漏**：KKT 必须写 wᵢgᵢ(x)=0，不起作用的约束乘子为 0。
3. **F-J 与 KKT 混淆**：F-J 允许 w₀=0；题目没给正则条件时只能得 F-J。
4. **最速下降方向的单位化**：d=−∇f/‖∇f‖ 是单位向量，直接写 −∇f 在"变化率最小"的推导里不严谨。
5. **牛顿法不一定下降**：Hessian 非正定时牛顿方向可能不是下降方向，必须配阻尼或修正。
6. **共轭梯度的初始方向**：必须是负梯度，否则 FR 构造的方向组不保证共轭。
7. **β 的两个式子用错场合**：正定二次函数用 ‖g_{k+1}‖²/‖gᵢ‖²，一般函数才用 dᵀAg 形式。
8. **拟牛顿条件 p、q 别写反**：p 在等式左边（p=Hq），p 是位移、q 是梯度差。
9. **信赖域 ρ_k 分子分母**：分子是实际下降，分母是预测下降；ρ≤μ 是**拒绝**该步。
10. **信赖域半径调整倍数**：0.5（缩）、1（不变）、2（涨），阈值 μ=0.25、η=0.75。
11. **λmax 的符号**：b̂ 为负，只对 d̂ᵢ<0 的分量取 min。
12. **内点法不能解等式约束**，且初始点必须严格可行。
13. **罚因子趋势别反**：外点 μ 递增到 ∞，内点 μ 递减到 0。
14. **两阶段法第一阶段 w*>0 ⇒ 原问题不可行**，不是"继续迭代"。
15. **简答题写"全局最优"要加限定**：现代优化算法只在概率意义/可接受精度内给出满意解。
