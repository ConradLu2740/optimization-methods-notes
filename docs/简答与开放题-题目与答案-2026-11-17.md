## 简答题

### Q1 局部最优解与全局最优解

**题目**：给出局部最优解与全局最优解的定义，说明两者关系；什么条件下局部最优就是全局最优？

**参考答案**：
全局最优解是对**整个可行域** S 而言的：x\* ∈ S 且对一切 x ∈ S 都有 f(x\*) ≤ f(x)；局部最优解只要求**存在一个邻域** N(x\*)，使得在该邻域与可行域的交集 N(x\*)∩S 内 f(x\*) 最小。两者关系：**全局最优必是局部最优，局部最优未必是全局最优**（可行域内可能存在多个局部极小）。但在**凸规划**（目标函数为凸函数 + 可行域为凸集）中，局部最优解就是全局最优解。算法层面：传统优化方法基于局部搜索，一般只能保证收敛到局部最优解或 KKT 点；现代优化方法面向全局优化，用随机搜索跳出局部极小，但无最优性保证，给出的是可接受精度内的满意解。

**易错点**：① 定义必须写"存在邻域"，不能写"比附近的点好"；② "局部=全局"的前提是凸规划（目标+可行域都要凸），只说"凸函数"不完整。

### Q2 线性规划与非线性规划的区别

**题目**：什么是线性规划？什么是非线性规划？它们的区别有哪些？

**参考答案**：
按**目标函数与约束函数的类型**划分：目标函数和所有约束函数都是线性（仿射）函数的优化问题是线性规划（LP）；目标或约束中**至少有一个是非线性函数**的，是非线性规划（NLP）。区别有四：① **可行域**——LP 的可行域是凸多面体（线性约束的交集，Th2.2），NLP 的可行域一般不是凸集；② **最优解位置**——LP 若有最优解，**必可在极点（基本可行解）达到**（Th2.3、Th2.4），NLP 的最优解可在可行域内部或边界任何位置，用 KKT 条件刻画；③ **局部与全局**——LP 是凸规划，局部最优即全局最优，NLP 一般不成立；④ **算法**——LP 用单纯形法、两阶段法、大 M 法，NLP 用最速下降、牛顿、共轭梯度、拟牛顿、可行方向法、罚函数法等迭代下降算法。

**易错点**：① 判别看"有没有非线性项"：x₁x₂、x₁²、sin x 都使问题成为 NLP，约束 x ≥ 0 是线性的；② "最优解在极点"只对 LP 成立，且前提是"有最优解"（无界/无可行解时谈不上）。

### Q3 对偶函数

**题目**：什么是对偶函数？它有哪些性质？

**参考答案**（按课程 Lagrange 口径）：
对约束优化问题 min f(x)，s.t. gᵢ(x) ≥ 0，hⱼ(x) = 0，先构造 **Lagrange 函数** L(x, u, v) = f(x) − Σuᵢgᵢ(x) − Σvⱼhⱼ(x)（uᵢ ≥ 0）。**对偶函数**定义为 θ(u, v) = inf_x L(x, u, v)，即固定乘子后对 x 取下确界。核心性质：① **θ 是凹函数**——L 对 (u,v) 是仿射的，一族仿射函数的逐点下确界是凹的；② **弱对偶性**——当 u ≥ 0 时，对任意可行 x 有 L(x,u,v) ≤ f(x)，故 θ(u,v) ≤ f\*，即对偶函数值给出原问题最优值的**下界**。对偶问题就是 max θ(u,v)，s.t. u ≥ 0；若原问题是凸规划且满足约束规格，则强对偶成立，原、对偶最优值相等，KKT 点处乘子即对偶最优解。

**易错点**：① 符号口径跟课程走：L = f − Σug − Σvh、g ≥ 0、u ≥ 0；② 对偶函数是**凹**函数，对偶问题是**极大化**；③ inf 不一定 attain，写"下确界"严谨；④ 弱对偶不需要凸性，强对偶才需要凸 + 约束规格。

### Q4 凸集与凸函数的关系

**题目**：凸集与凸函数分别如何定义？二者有什么关系？

**参考答案**：
凸集是**集合**的性质：集合 C 中任意两点的连线段仍在 C 内，即 λx + (1−λ)y ∈ C（λ ∈ [0,1]）；凸函数是**函数**的性质，且定义域必须是凸集：f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)。核心桥梁是**上镜图**：f 是凸函数 **当且仅当** 其上镜图 epi f = {(x, t) | f(x) ≤ t} 是凸集（充要）。其次，凸函数的**水平集** {x | f(x) ≤ α} 都是凸集，但反过来不成立（水平集全凸只说明拟凸，不能推出凸函数）。运算性质：凸集之交仍是凸集；凸函数的非负加权和仍是凸函数。优化意义：凸集上凸函数的**局部极小点就是全局极小点**；目标凸 + 可行域凸才是凸规划，此时 KKT 点即全局最优解。

**易错点**：① 上镜图凸是**充要**条件，水平集凸只是**必要**条件——最常考的辨析点；② 凸函数定义里"定义域为凸集"不能漏；③ 可行域凸 ≠ 凸规划。

### Q5 现代优化算法与传统优化算法的区别与联系

**题目**：现代优化算法与传统优化算法有什么区别和联系？（开放题也考这问，答法相同）

**参考答案（差别 5 条 + 联系 4 条骨架）**：
**差别**：① **搜索性质**——传统算法本质上是**局部搜索**，依赖初值、沿下降方向迭代且是确定性的；现代算法（GA/SA/TS/DE）是**全局随机搜索**，种群/温度驱动探索，同一初值不同随机数结果不同。② **函数要求**——传统算法要求目标**至少一阶连续可微**，常需梯度甚至 Hessian；现代算法只需目标值/适应度可计算，**不要求可导**，可处理不可微、离散、含噪问题。③ **最优性保证**——传统算法有 KKT、F-J 条件与收敛性定理，最优性可严格判定；现代算法**无最优性证明**，只在概率意义上收敛到全局最优附近。④ **适用问题**——传统算法适合凸或光滑的小规模问题，对 NP-hard 无能为力；现代算法面向 **NP-hard 的全局优化与组合优化**。⑤ **计算代价**——传统算法单次迭代快、精度高；现代算法需大量函数评价、参数敏感。
**联系**：① 同一问题模型、同一迭代骨架（产生候选解 → 评价 → 更新 → 停机；传统算法每步也写成 x_{k+1}=x_k+λₖdᵏ）；② 共用同一套最优化理论（凸性、下降方向、KKT/F-J、罚函数法——GA/SA 处理约束用的就是罚函数法）；③ 互补融合：现代算法全局探索 + 传统算法局部精修（memetic 算法、Multi-Start）；④ 跳出局部最优的机制同源（单纯形法摄动/Bland 规则 ↔ SA 概率接受劣解、TS 禁忌表）。

**易错点**：① 别把现代算法说成"保证找到全局最优"——是概率意义/近似；② 联系 4 条最容易漏，开放题必须写；③ 答题口径按 CH1-2 PPT：传统 = 局部搜索 + 至少一阶可微 + 确定性。

### Q6 用定义验证凸集

**题目**：用定义验证 S = {(x₁, x₂) | x₂ ≥ |x₁|} 是凸集。

**参考答案**：
任取 x⁽¹⁾=(a₁,a₂)、x⁽²⁾=(b₁,b₂) ∈ S，任取 λ∈[0,1]，令 x = λx⁽¹⁾+(1−λ)x⁽²⁾，则 x₁ = λa₁+(1−λ)b₁，x₂ = λa₂+(1−λ)b₂。由 x⁽¹⁾、x⁽²⁾ ∈ S 知 a₂ ≥ |a₁|、b₂ ≥ |b₁|，于是

x₂ = λa₂+(1−λ)b₂ ≥ λ|a₁|+(1−λ)|b₁| ≥ |λa₁+(1−λ)b₁| = |x₁|

（第二步用绝对值函数的凸性 |λa+(1−λ)b| ≤ λ|a|+(1−λ)|b|。）故 x₂ ≥ |x₁|，即 x ∈ S。由定义 S 为凸集。∎
几何意义：S 是 |x₁| 的上镜图，|x₁| 是凸函数，凸函数的上镜图必为凸集。

**易错点**：别漏 λ|a₁|+(1−λ)|b₁| ≥ |λa₁+(1−λ)b₁| 这步——凸性来自这里，只写等号会错。

### Q7 凸函数的判别与凸性保持

**题目**：判断 f(x₁,x₂) = x₁² − 2x₁x₂ + x₂² + x₁ + x₂ 是否为凸函数；并证明两凸函数之和仍为凸函数。

**参考答案**：
**(1) 是凸函数，但不是严格凸函数。** Hessian 法最快：∇f = (2x₁−2x₂+1, −2x₁+2x₂+1)，∇²f = [[2,−2],[−2,2]]，特征值 0 与 4（迹 4、行列式 0）均非负 ⇒ ∇²f 半正定 ⇒ f 凸；因存在零特征值，非严格凸。（备选：f = (x₁−x₂)² + x₁ + x₂，平方项半正定 + 线性项既凸又凹，和仍凸。）
**(2) 证明**：任取 x, y 与 λ∈[0,1]，由凸函数定义
f₁(λx+(1−λ)y) ≤ λf₁(x)+(1−λ)f₁(y)，f₂(λx+(1−λ)y) ≤ λf₂(x)+(1−λ)f₂(y)，
两式相加得 (f₁+f₂)(λx+(1−λ)y) ≤ λ(f₁+f₂)(x)+(1−λ)(f₁+f₂)(y)，故 f₁+f₂ 为凸函数。∎
升级：凸函数的非负线性组合仍凸；可微时 ∇²(f₁+f₂)=∇²f₁+∇²f₂，半正定之和仍半正定。

**易错点**：半正定要说明"有零特征值 ⇒ 凸但非严格凸"；凸函数三路线（定义/一阶 f(y) ≥ f(x)+∇f(x)ᵀ(y−x)/二阶 Hessian 半正定）考哪个写哪个，Hessian 最快。

### Q8 Farkas 定理的几何表示（画图题）

**题目**：从几何角度绘图解释 Farkas 定理。

**参考答案**：
定理（二择一形式）：设 A ∈ R^{m×n}，b ∈ R^m，则以下两式**有且仅有一个成立**：(i) ∃x，Ax = b，x ≥ 0；(ii) ∃y，Aᵀy ≤ 0，bᵀy > 0。
几何解释：记 A 的列向量为 a₁,…,aₙ，锥 C(A) = {Ax : x ≥ 0} = cone{a₁,…,aₙ} 为列向量生成的有限锥（二维下即两向量张成的楔形区域）。
- **情形 1（b 在锥内）**：b ∈ C(A)，b 可表成列向量的非负组合，(i) 成立；
- **情形 2（b 在锥外）**：由凸集分离定理，存在过原点的超平面把 b 与 C(A) 严格分离。设法向量为 y，则 y 与 C(A) 中每个向量内积 ≤ 0，即 aᵢᵀy ≤ 0 ⇒ **Aᵀy ≤ 0**；b 在法向所指一侧 ⇒ **bᵀy > 0**，(ii) 成立。
两情形互斥（同时成立则 bᵀy = xᵀAᵀy ≤ 0，矛盾），故二择一。
**30 秒画图**：① 画原点 O；② 从 O 画两条生成向量 a₁、a₂，夹角区域涂阴影为 C(A)；③ b 在阴影内 → 标 b = α₁a₁+α₂a₂（α ≥ 0）；④ b 在阴影外 → 过 O 画分离直线（法向 y 箭头指向 b），标 y 与 a₁、a₂ 夹角钝角（Aᵀy ≤ 0）、与 b 夹角锐角（bᵀy > 0）。

**易错点**：分离超平面**过原点**（C(A) 是锥）；两种情形都要会画。

### Q9 最速下降法与牛顿法的优缺点

**题目**：比较最速下降方向与牛顿下降方向；两种方法各有什么优缺点？牛顿法的缺点如何解决？

**参考答案**：
方向：最速下降方向 d = −∇f（函数下降最快的方向）；牛顿方向 d = −H⁻¹∇f（解 Hd = −∇f）。
**最速下降法**：优点——概念简单，每步只需算梯度，计算量与存储量小；不需要 Hessian；每步局部下降最快。缺点——**收敛慢**，靠近极小点时出现"锯齿形"（zig-zag）现象，相邻两步方向近似正交；线性收敛，收敛比依赖 Hessian 条件数；只有一阶信息，不利用曲率。
**牛顿法**：优点——利用二阶信息，极小点附近**二阶（二次）收敛**；对正定二次函数理论上**一步到达极小点**；无锯齿现象。缺点——每步要算 Hessian 并解线性方程组，n 大时 O(n³) 昂贵；**Hessian 可能非正定甚至奇异**，此时方向可能不是下降方向；只有局部收敛性，初值远时可能发散；要求二阶可微。
**补救**（配表格写）：Hessian 非正定/奇异 → **阻尼牛顿法**（牛顿方向 + 一维搜索 Armijo 保证下降）或**修正牛顿法**（Hessian 修正为 Gₖ 使其正定）；算 Hessian 太贵 → **拟牛顿法**（DFP/BFGS 用梯度差近似 Hessian）或**共轭梯度法**（只用梯度、避免锯齿）；远处不稳 → 线搜索限制步长；要求二阶可微 → 改一阶方法。

**易错点**：考场速记——牛顿法两大毛病"贵"（Hessian + 解方程组）和"娇气"（不正定、局部收敛）；两条药方：阻尼/修正保方向，拟牛顿/共轭省二阶计算。

### Q10 概念储备（防概念小题）

**题目**：智能优化是什么？/（运输问题、LP 对偶的一句话）

**参考答案（各一句话）**：
- **智能优化（现代优化算法）**：面向 NP-hard 全局优化问题的随机搜索方法（GA、SA、TS、DE、蚁群等），不依赖梯度、无最优性保证，在可接受时间和精度内给出满意解。
- **运输问题**：一类特殊的线性规划——把供应地的物资运到需求地，在产销平衡约束下最小化总运费，可用单纯形法或专门的表上作业法求解。（老师课上仅举过一例，整章不考。）
- **LP 对偶**：每个线性规划都伴随一个对偶问题，原问题的约束对应新变量（对偶变量/影子价格），强对偶时两者最优值相等。（第 4 章整章不考，只需知道概念。）

### Q11 介绍一种现代优化算法，并说明与传统优化算法的区别与联系

**参考答案（以遗传算法 GA 为例，约 500 字）**：
遗传算法（GA）是 20 世纪 80 年代初兴起的现代优化算法，模拟生物进化过程：把问题的解编码为"染色体"（二进制串/实数向量），用目标函数值定义**适应度**，模拟"适者生存、优胜劣汰"，以种群为单位在解空间随机全局搜索。流程：**编码 → 初始化种群 → 适应度评价 → 选择（轮盘赌/锦标赛）→ 交叉（交换部分基因产生新解）→ 变异（小概率翻转基因位维持多样性）→ 新一代**，直至适应度收敛或达到代数上限；带约束时用罚函数处理。
与传统优化算法的差别（5 条，同 Q5）：搜索范围（局部确定性 vs 全局随机）、函数要求（至少一阶可微 vs 只需函数值可算）、最优性保证（KKT/收敛定理 vs 无保证、概率意义）、适用问题（凸/光滑小规模 vs NP-hard）、计算代价（单次迭代快精度高 vs 大量评价、参数敏感）。
联系（4 条，同 Q5）：同一迭代骨架（x_{k+1}=x_k+λₖdᵏ 与"选择-交叉-变异"同为候选解生成机制）；共用凸性、下降方向、KKT、罚函数等理论工具；可互补融合（GA 全局探索 + 传统法局部精修）；跳出局部最优机制同源（摄动/Bland ↔ 概率接受劣解/禁忌表）。
收尾：现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力。

**易错点**：写"确定全局最优解"必须补"概率意义上/近似"；联系部分别写"完全不同"。

### Q12 凸/非凸优化算法对比 + 全局优化算法原理

**参考答案**：
**两种凸优化算法**：① 最速下降法（Cauchy 1847）：x_{k+1}=x_k+λₖ(−∇f(xₖ))，每步沿负梯度做一维搜索，凸问题上收敛到全局最优；② 阻尼牛顿法/修正牛顿法：解 Hₖd=−∇f 得牛顿方向，配一维搜索（阻尼）或 Hessian 非正定时修正为 Gₖ（修正牛顿），凸问题且 H 正定时二次收敛。（也可写共轭梯度、DFP/BFGS、单纯形法，任选其二。）
**两种非凸优化算法**：① 遗传算法（GA）：模拟自然选择，维护解的种群，通过选择、交叉、变异进化；② 模拟退火（SA）：模拟固体退火，以 Metropolis 准则概率性接受劣解，温度递减控制扰动。（也可写禁忌搜索 TS、差分进化 DE、蚁群 ACS、Multi-Start。）
**对比表**：

| | 凸优化算法（传统） | 非凸优化算法（现代） |
|---|---|---|
| 最优性 | 局部最优=全局最优，有收敛性定理 | 无最优性保证，可能陷局部最优 |
| 依赖信息 | 梯度/Hessian，要求至少一阶可微 | 只用目标函数值，不要求可微 |
| 搜索方式 | 单点确定性迭代，结果可复现 | 种群/邻域随机搜索，概率意义收敛 |
| 输出 | 精确最优解（或任意精度近似） | 可接受精度内的**满意解** |
| 适用问题 | 凸问题（LP、凸二次规划等） | NP-hard 的全局优化问题 |

**相似之处 4 条**：① 框架同源——都是"从一个点/一群点出发，反复产生新解并择优保留"的迭代改进；② 目标一致——都追求目标函数值更小，可用同一停止准则；③ 共同两大组件——新解产生机制（下降方向 vs 邻域扰动/交叉变异）+ 接受准则（线搜索/Armijo vs 适应度/Metropolis）；④ 可互相结合——现代算法常内嵌传统局部搜索（memetic = GA + 最速下降），Multi-Start = 传统算法 + 随机重启。
**全局优化原理（以 GA 为例）**：种群并行维护多个候选解，交叉重组"积木块"、变异提供随机扰动，三者共同维持全局搜索能力，不易像单点爬山那样卡在局部最优；代价是不保证找到全局最优，给的是概率意义上的满意解。深层原因：NP-hard 问题在有限时间内严格求出全局最优**既不可能也不现实**，只能在可接受时间和精度内求满意解（PPT p12 口径）。

**易错点**：相似处按"框架同源（x_{k+1}=x_k+λₖdᵏ）+ 目标一致 + 接受准则 + 可混合"四条写，别写"完全不同"。
