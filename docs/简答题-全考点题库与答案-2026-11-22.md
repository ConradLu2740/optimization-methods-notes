## A 组　概念对比（五组必考组）

### Q1 局部最优解与全局最优解 🟡

**题**：给出局部最优解与全局最优解的定义，说明两者关系；什么条件下局部最优就是全局最优？

**答**：全局最优解是对**整个可行域** S 而言的：x* ∈ S，且对一切 x ∈ S 都有 f(x*) ≤ f(x)。局部最优解只要求**存在一个邻域** N(x*)，使得在 N(x*)∩S 内 f(x*) 最小（CH1-1 定义 1.1/1.2）。两者关系：**全局最优必是局部最优，局部最优未必是全局最优**（可行域内可有多个局部极小）。但在**凸规划**（目标函数为凸函数 + 可行域为凸集）中，局部最优解就是全局最优解。算法层面：传统方法基于局部搜索，一般只能保证收敛到局部最优解或 KKT 点；现代方法面向全局优化，用随机搜索跳出局部极小，但无最优性保证，给的是可接受精度内的满意解。

**易错点**：定义必须写"存在邻域"，不能写"比附近的点好"；"局部 = 全局"的前提是凸规划（目标+可行域都要凸），只说"凸函数"不完整；别说现代算法"保证找到全局最优"。

### Q2 线性规划与非线性规划的区别 🟡

**题**：什么是线性规划？什么是非线性规划？它们的区别有哪些？

**答**：按**目标函数与约束函数的类型**划分：目标函数和所有约束函数都是线性（仿射）函数的是线性规划（LP）；目标或约束中**至少有一个非线性函数**的是非线性规划（NLP）。区别有四：① **可行域**——LP 的可行域是凸多面体（线性约束的交，Th2.2），NLP 的可行域一般不是凸集；② **最优解位置**——LP 若有最优解，**必可在极点（基本可行解）达到**（Th2.3、Th2.4），NLP 的最优解可在可行域内部或边界任何位置，用 KKT 条件刻画；③ **局部与全局**——LP 是凸规划，局部最优即全局最优，NLP 一般不成立；④ **算法**——LP 用单纯形法、两阶段法、大 M 法，NLP 用最速下降、牛顿、共轭梯度、拟牛顿、可行方向法、罚函数法等迭代下降算法。

**易错点**：判别看"有没有非线性项"：x₁x₂、x₁²、sin x 都使问题成为 NLP，约束 x ≥ 0 是线性的；"最优解在极点"只对 LP 成立，且前提是"有最优解"（无界/无可行解时谈不上）。

### Q3 对偶函数 🟡【补充：讲义未展开，按 Lagrange 对偶口径准备】

**题**：什么是对偶函数？它有哪些性质？

**答**：对约束优化问题 min f(x)，s.t. gᵢ(x) ≥ 0，hⱼ(x) = 0，先构造 **Lagrange 函数** L(x, u, v) = f(x) − Σuᵢgᵢ(x) − Σvⱼhⱼ(x)（uᵢ ≥ 0）。**对偶函数**定义为 θ(u, v) = inf_x L(x, u, v)，即固定乘子后对 x 取下确界。核心性质：① **θ 是凹函数**——L 对 (u, v) 是仿射的，一族仿射函数的逐点下确界是凹的；② **弱对偶性**——当 u ≥ 0 时，对任意可行 x 有 L(x, u, v) ≤ f(x)，故 θ(u, v) ≤ f*，即对偶函数值给出原问题最优值的**下界**。对偶问题就是 max θ(u, v)，s.t. u ≥ 0；若原问题是凸规划且满足约束规格，则强对偶成立，原、对偶最优值相等，KKT 点处乘子即对偶最优解。

**易错点**：符号口径跟课程走：L = f − Σug − Σvh、g ≥ 0、u ≥ 0；θ 是**凹**函数，对偶问题是**极大化**；inf 不一定 attain，写"下确界"严谨；弱对偶不需要凸性，强对偶才需要凸 + 约束规格。

### Q4 凸集与凸函数的关系 🟡

**题**：凸集与凸函数分别如何定义？二者有什么关系？

**答**：凸集是**集合**的性质：集合 C 中任意两点的连线段仍在 C 内，即 λx + (1−λ)y ∈ C（λ ∈ [0,1]）。凸函数是**函数**的性质，且定义域必须是凸集：f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)。核心桥梁是**上镜图**：f 是凸函数**当且仅当**其上镜图 epi f = {(x, t) | f(x) ≤ t} 是凸集（充要）。其次，凸函数的**水平集** {x | f(x) ≤ α} 都是凸集，但反过来不成立（水平集全凸只说明拟凸，不能推出凸函数）。运算性质：凸集之交仍是凸集；凸函数的非负加权和仍是凸函数。优化意义：凸集上凸函数的**局部极小点就是全局极小点**；目标凸 + 可行域凸才是凸规划，此时 KKT 点即全局最优解。

**易错点**：上镜图凸是**充要**条件，水平集凸只是**必要**条件，这是最常考的辨析点；凸函数定义里"定义域为凸集"不能漏；可行域凸 ≠ 凸规划。

### Q5 现代优化算法与传统优化算法的区别与联系 🟡（开放题也考这问，答法相同）

**题**：现代优化算法与传统优化算法有什么区别和联系？

**答**：**差别 5 条**：① **搜索性质**——传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；现代算法（GA/SA/TS/DE）是全局随机搜索，种群/温度驱动探索。② **函数要求**——传统算法要求目标至少一阶连续可微，常需梯度甚至 Hessian；现代算法只需目标值可计算，不要求可导，可处理不可微、离散、含噪问题。③ **最优性保证**——传统算法有 KKT、F-J 条件与收敛性定理；现代算法无最优性证明，只在概率意义上收敛到全局最优附近。④ **适用问题**——传统算法适合凸或光滑的小规模问题，对 NP-hard 无能为力；现代算法面向 NP-hard 的全局优化与组合优化。⑤ **计算代价**——传统算法单次迭代快、精度高；现代算法需大量函数评价、参数敏感。
**联系 4 条**：① 同一问题模型、同一迭代骨架（产生候选解 → 评价 → 更新 → 停机；传统算法每步也写成 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λₖd⁽ᵏ⁾）；② 共用同一套最优化理论（凸性、下降方向、KKT/F-J、罚函数法——GA/SA 处理约束用的就是罚函数法）；③ 互补融合：现代算法全局探索 + 传统算法局部精修（memetic 算法、Multi-Start）；④ 跳出局部最优的机制同源（单纯形法摄动/Bland 规则 ↔ SA 概率接受劣解、TS 禁忌表）。

**易错点**：别把现代算法说成"保证找到全局最优"，是概率意义/近似；联系 4 条最容易漏，开放题必须写；答题口径按 CH1-2 PPT：传统 = 局部搜索 + 至少一阶可微 + 确定性。

## B 组　凸性判别

### Q6 用定义验证凸集 🟡

**题**：用定义验证 S = {(x₁, x₂) | x₂ ≥ |x₁|} 是凸集。

**答**：任取 x⁽¹⁾ = (a₁, a₂)、x⁽²⁾ = (b₁, b₂) ∈ S，任取 λ ∈ [0,1]，令 x = λx⁽¹⁾ + (1−λ)x⁽²⁾，则 x₁ = λa₁ + (1−λ)b₁，x₂ = λa₂ + (1−λ)b₂。由 x⁽¹⁾、x⁽²⁾ ∈ S 知 a₂ ≥ |a₁|、b₂ ≥ |b₁|，于是

x₂ = λa₂ + (1−λ)b₂ ≥ λ|a₁| + (1−λ)|b₁| ≥ |λa₁ + (1−λ)b₁| = |x₁|

（第二步用绝对值函数的凸性 |λa + (1−λ)b| ≤ λ|a| + (1−λ)|b|。）故 x₂ ≥ |x₁|，即 x ∈ S，由定义 S 为凸集。∎
几何意义：S 是 |x₁| 的上镜图，|x₁| 是凸函数，凸函数的上镜图必为凸集。

**易错点**：别漏 λ|a₁| + (1−λ)|b₁| ≥ |λa₁ + (1−λ)b₁| 这步，凸性来自这里，只写等号会错。

### Q7 凸函数的判别与凸性保持 🟡

**题**：判断 f(x₁, x₂) = x₁² − 2x₁x₂ + x₂² + x₁ + x₂ 是否为凸函数；并证明两凸函数之和仍为凸函数。

**答**：**(1) 是凸函数，但不是严格凸函数。** Hessian 法最快：∇f = (2x₁ − 2x₂ + 1, −2x₁ + 2x₂ + 1)，∇²f = [[2, −2], [−2, 2]]，迹 4、行列式 0，特征值 0 与 4 均非负 ⇒ ∇²f 半正定 ⇒ f 凸；因存在零特征值，非严格凸。（备选：f = (x₁−x₂)² + x₁ + x₂，平方项半正定 + 线性项既凸又凹，和仍凸。）
**(2) 证明**：任取 x, y 与 λ ∈ [0,1]，由凸函数定义

f₁(λx + (1−λ)y) ≤ λf₁(x) + (1−λ)f₁(y)，　f₂(λx + (1−λ)y) ≤ λf₂(x) + (1−λ)f₂(y)，

两式相加得 (f₁+f₂)(λx + (1−λ)y) ≤ λ(f₁+f₂)(x) + (1−λ)(f₁+f₂)(y)，故 f₁+f₂ 为凸函数。∎
推广：凸函数的非负线性组合仍凸；可微时 ∇²(f₁+f₂) = ∇²f₁ + ∇²f₂，半正定之和仍半正定。

**易错点**：半正定要说明"有零特征值 ⇒ 凸但非严格凸"；凸函数三路线（定义 / 一阶 f(y) ≥ f(x) + ∇f(x)ᵀ(y−x) / 二阶 Hessian 半正定）考哪个写哪个，Hessian 最快。

## C 组　定理

### Q8 Farkas 定理的几何表示（画图题）🔵 考点清单第 1 条 + 必考.md 点名"画图"

**题**：从几何角度绘图解释 Farkas 定理。

**答**：定理（二择一形式）：设 A ∈ R^{m×n}，b ∈ R^m，则以下两式**有且仅有一个成立**：(i) ∃x，Ax = b，x ≥ 0；(ii) ∃y，Aᵀy ≤ 0，bᵀy > 0。
几何解释：记 A 的列向量为 a₁, …, aₙ，锥 C(A) = {Ax : x ≥ 0} = cone{a₁, …, aₙ} 为列向量生成的有限锥（二维下即两向量张成的楔形区域）。
- **情形 1（b 在锥内）**：b ∈ C(A)，b 可表成列向量的非负组合，(i) 成立；
- **情形 2（b 在锥外）**：由凸集分离定理，存在过原点的超平面把 b 与 C(A) 严格分离。设法向量为 y，则 y 与 C(A) 中每个向量内积 ≤ 0，即 aᵢᵀy ≤ 0 ⇒ **Aᵀy ≤ 0**；b 在法向所指一侧 ⇒ **bᵀy > 0**，(ii) 成立。
两情形互斥（同时成立则 bᵀy = xᵀAᵀy ≤ 0，矛盾），故二择一。
**30 秒画图**：① 画原点 O；② 从 O 画两条生成向量 a₁、a₂，夹角区域涂阴影为 C(A)；③ b 在阴影内 → 标 b = α₁a₁ + α₂a₂（α ≥ 0）；④ b 在阴影外 → 过 O 画分离直线（法向 y 箭头指向 b），标 y 与 a₁、a₂ 夹角钝角（Aᵀy ≤ 0）、与 b 夹角锐角（bᵀy > 0）。

**易错点**：分离超平面**过原点**（C(A) 是锥）；两种情形都要会画。

### Q9 多面体表示定理、极点与 BFS 的关系、LP 最优解为什么在极点 🔵 考点清单第 2、4、5 条

**题**：叙述多面体表示定理；说明极点与基本可行解的关系；线性规划的最优解为什么可以在极点达到？

**答**：**多面体表示定理**：有界多面体等于它的**极点的凸组合**；无界多面体等于极点的凸组合**加上**极方向的非负组合。
**极点与 BFS**：标准形中取定基 B（m 个线性无关列），令非基变量为 0、解出基变量得**基本解**；基本解可行则称**基本可行解（BFS）**，其中基变量取 0 的称为退化的。**极点集 ≡ BFS 集**（Th2.4），一一对应。
**LP 最优在极点的依据**：可行域是凸集（Th2.2）；若最优解不在极点，说明还能沿可行方向继续改进，与最优性矛盾；由多面体表示定理，可行域任一点可表为极点的凸组合，而目标是线性的，故最优值必在某个极点达到（Th2.3：LP 若有最优解，最优解可在极点达到）。
**应用**：求极点 = 从约束矩阵选 m 个线性无关列作基、解方程组、检验非负；两阶段法第一阶段找初始 BFS，本质就是"用人工变量构造一个极点起点"。

**易错点**：Th2.3 的前提是"LP 有最优解"（无界/无可行解时谈不上）；退化 BFS 仍与极点一一对应，别以为退化就破坏对应。

## D 组　最优性条件（KKT 必考）

### Q10 KKT 条件 🟡

**题**：叙述约束优化问题的 KKT 条件；凸规划下有什么结论？

**答**：问题 min f(x)，s.t. gᵢ(x) ≥ 0（i = 1…m），hⱼ(x) = 0（j = 1…l）。设 x* 可行，构造 Lagrange 函数 L(x, w, v) = f(x) − Σwᵢgᵢ(x) − Σvⱼhⱼ(x)。x* 为 **KKT 点**指存在乘子 w、v 使：① ∇ₓL(x*) = 0，即 ∇f(x*) − Σwᵢ∇gᵢ(x*) − Σvⱼ∇hⱼ(x*) = 0；② **wᵢ ≥ 0**；③ **互补松弛** wᵢgᵢ(x*) = 0；④ x* 本身可行（gᵢ(x*) ≥ 0、hⱼ(x*) = 0）。乘子含义：wᵢ > 0 表示第 i 个不等式约束起作用；wᵢ = 0 表示该约束不起作用（弱起作用也满足 KKT）。
凸规划（f 凸、gᵢ 凹、hⱼ 线性）+ 正则点/约束规格时，**KKT 点即全局最优解**，一阶条件既必要又充分。

**易错点**：乘子符号和 ∇²ₓₓL 的**减号**别写反；KKT 一般只是必要条件，充分性要靠凸性或二阶条件；算出的乘子有负的直接答"不是 KKT 点"。

### Q11 F-J 条件与 KKT 的关系、约束规格 🟡

**题**：叙述 Fritz John 条件；它与 KKT 条件有什么关系？什么情况下 F-J 点就是 KKT 点？

**答**：**F-J 条件**：x* 可行，存在不全为零的非负向量 w₀, w₁, …, wₘ, v₁, …, vₗ，使

w₀∇f(x*) − Σwᵢ∇gᵢ(x*) − Σvⱼ∇hⱼ(x*) = 0。

**与 KKT 的关系**：KKT 条件就是 w₀ > 0 的情形（两端除以 w₀ 即得 KKT 形式）；F-J 允许 w₀ = 0，此时一阶条件里**不含 f 的信息**，可能把极大点也判成"最优"，判别力弱于 KKT。
**约束规格的作用**：当 x* 处起作用约束的梯度线性无关（LICQ）等约束规格成立时，可证 w₀ > 0，F-J 点就是 KKT 点；约束规格不成立时（如 ∇f(x*) 与 ∇gᵢ(x*) 线性相关），一阶条件判不了，需要引入二阶条件。

**易错点**：F-J 与 KKT 的唯一差别就在 w₀ 能否为 0；课件例题里"验证 F-J 成立"常出现在 ∇f、∇g 相关的点，这时要点明约束规格失败、KKT 判不了。

### Q12 局部极小点的二阶充分条件 🟡

**题**：设 x* 是 KKT 点，如何用二阶条件判断它是否为严格局部极小点？

**答**：设 x* 处起作用的不等式约束集 I = {i | gᵢ(x*) = 0}、等式约束为 hⱼ(x*) = 0。定义**临界锥**

C = {d | ∇gᵢ(x*)ᵀd = 0（i ∈ I），∇hⱼ(x*)ᵀd = 0}。

若对一切 d ∈ C、d ≠ 0 都有 **dᵀ∇²ₓₓL(x*)d > 0**，则 x* 是**严格局部极小点**。其中

∇²ₓₓL = ∇²f − Σwᵢ∇²gᵢ − Σvⱼ∇²hⱼ（**减号**，别写反）。

直观理解：临界锥是"嫌疑人名单"——只在这批方向上检查目标函数 + 起作用约束的曲率是否够正。凸规划不需要二阶条件（一阶即充分）。

**易错点**：二阶项只对**起作用**的约束求和；∇²ₓₓL 符号写反整题崩；KKT 过了 ≠ 就是极小点，必须再过二阶这一关。

## E 组　算法思想与优缺点

### Q13 最速下降法与牛顿法的优缺点 🟡

**题**：比较最速下降方向与牛顿下降方向；两种方法各有什么优缺点？牛顿法的缺点如何解决？

**答**：方向：最速下降方向 d = −∇f（函数下降最快的方向）；牛顿方向 d = −H⁻¹∇f（解 Hd = −∇f）。
**最速下降法**：优点——概念简单，每步只需算梯度，计算量与存储量小，不需要 Hessian，每步局部下降最快。缺点——**收敛慢**，靠近极小点时出现"锯齿形"（zig-zag）现象，相邻两步方向近似正交；线性收敛，收敛比依赖 Hessian 条件数；只有一阶信息，不利用曲率。
**牛顿法**：优点——利用二阶信息，极小点附近**二阶（二次）收敛**；对正定二次函数理论上**一步到达极小点**；无锯齿现象。缺点——每步要算 Hessian 并解线性方程组，n 大时 O(n³) 昂贵；**Hessian 可能非正定甚至奇异**，此时方向可能不是下降方向；只有局部收敛性，初值远时可能发散；要求二阶可微。
**补救**：Hessian 非正定/奇异 → **阻尼牛顿法**（牛顿方向 + 一维搜索保证下降）或**修正牛顿法**（Hessian 修正为 Gₖ 使其正定）；算 Hessian 太贵 → **拟牛顿法**（DFP/BFGS 用梯度差近似 Hessian）或**共轭梯度法**（只用梯度、避免锯齿）；远处不稳 → 线搜索限制步长；要求二阶可微 → 改一阶方法。

**易错点**：考场速记——牛顿法两大毛病"贵"（Hessian + 解方程组）和"娇气"（不正定、局部收敛）；两条药方：阻尼/修正保方向，拟牛顿/共轭省二阶计算。

### Q14 共轭梯度法（FR）的特点 🟡 老师点名必考

**题**：共轭梯度法有哪些特点？（或：为什么共轭梯度法既不用 Hessian 又避免了锯齿现象？）

**答**（课件 PPT 原文 6 条）：① 对凸函数**全局收敛**（下降算法）；② 计算公式简单，**不用求 Hessian 矩阵或逆矩阵**，计算量小、存储量小，每步只需存储若干向量，**适用于大规模问题**；③ 具有**二次终止性**：对正定二次函数至多 n 次迭代可达最优解（Th10.3.3）；④ **收敛速率不坏于最速下降法**（若初始方向不用负梯度，则为线性收敛）；⑤ 是目前求解无约束优化问题**最常用的方法之一**；⑥ 有多种求解形式，不同公式对正定二次函数等价，对非正定二次函数效果不同。
核心公式：d⁽ᵏ⁺¹⁾ = −gₖ₊₁ + βₖd⁽ᵏ⁾，FR 取 βₖ = ‖gₖ₊₁‖²/‖gₖ‖²（Th10.3.4）；理论上沿 k 个共轭方向一维搜索得线性流形上唯一极小点，k = n 即全局最优（Th10.3.2）。

**易错点**：特点 6 条是课件原文，简答直接抄；FR 初始方向必须是 −∇f；二次终止的前提是"正定二次函数"。

### Q15 拟牛顿法的思想与拟牛顿条件 🟡 老师点名必考

**题**：拟牛顿法的基本思想是什么？什么是拟牛顿条件？DFP 校正怎么做？

**答**：**思想**：牛顿法每步都要算 Hessian 并解方程组，代价高；拟牛顿法**只用目标函数值和一阶梯度的信息**构造 Hessian 逆的近似矩阵 Hₖ，搜索方向 d⁽ᵏ⁾ = −Hₖgₖ，不必显式形成 Hessian。
**拟牛顿条件（割线方程）**：要求相邻两步的位移 pₖ = x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾ 与梯度差 qₖ = gₖ₊₁ − gₖ 满足 **Hₖ₊₁qₖ = pₖ**（近似 Hessian 逆在该方向上的作用与真实二阶信息一致）。
**DFP 秩 2 校正**：Hₖ₊₁ = Hₖ + pₖpₖᵀ/(pₖᵀqₖ) − (Hₖqₖ)(Hₖqₖ)ᵀ/(qₖᵀHₖqₖ)，初值 H₁ = I。性质：Hₖ 保持对称正定（Th10.4.1）；具有共轭性，对正定二次函数二次终止（Th10.4.2），n 步后 H_{n+1} = A⁻¹。BFGS 是另一种秩 2 校正，同样保持对称正定。

**易错点**：方向是 **−Hₖgₖ** 不是 −gₖ；p（位移）、q（梯度差）别写反；H₁ 默认取 I；拟牛顿条件是 p = Hq 的方向别背反。

### Q16 两阶段法与大 M 法的思想 🔵（20 分计算题的简答版）

**题**：两阶段法和大 M 法各自的基本思想是什么？它们怎么处理"找初始基本可行解"这个难题？

**答**：**共同难题**：≥ 约束或等式约束减过剩变量后没有现成的初始 BFS，需要引入**人工变量**造一个。
**两阶段法**：加人工变量后分两个阶段。**第一阶段**构造辅助目标 min w = Σaᵢ（人工变量之和），用单纯形法求解；若 **w* = 0**，人工变量全部出基，得到原问题的一个 BFS，转入**第二阶段**：删去人工变量列、换回原目标 c、**检验数全部重算**，继续单纯形迭代；若 **w* > 0**，说明原问题无可行解，停止。
**大 M 法**：不换目标，直接在原目标上加惩罚项 M·Σaᵢ（M 是很大的正数，作为符号常数不进表）：只要原问题有可行解，优化过程必然把人工变量压出基；检验数先比 M 的系数、再比常数项。
**共同点**：都把"找初始可行解"化成解一个辅助 LP；人工变量一旦出基就该删列，不允许再进基。

**易错点**：第一阶段判据句必须写"w* = 0"；第二阶段 σ 要**全重算**（照抄旧值是最常见错误）；大 M 的 M 是符号常数，比较检验数时先看 M 系数。

### Q17 惩罚函数法的基本思想、外点法与内点法对比 🟡

**题**：惩罚函数法的基本思想是什么？外点罚函数法与内点罚函数法有什么区别？

**答**：**基本思想**：构造辅助函数把约束问题化为无约束问题；经济解释是"总代价 = 价格 + 罚款"——违反约束就付罚款，罚得越狠越贴近可行域。
**外点罚函数法**：F(x, μ) = f(x) + μP(x)，等式罚项 Σhⱼ(x)²、不等式罚项 Σ(max{0, −gᵢ(x)})²，从可行域**外部**逼近（迭代点允许不可行），罚因子序列 μₖ **递增趋于 ∞**，中止判据 μₖP(x⁽ᵏ⁾) < ε；等式、不等式约束都能用。例：min x₁²+x₂² s.t. x₁+x₂ = 2，得 x(σ) = 2σ/(2σ+1) → (1, 1)。
**内点罚函数法（障碍函数法）**：F(x, μ) = f(x) + μB(x)，B(x) = Σ1/gᵢ(x)（倒数和）或 −Σln gᵢ(x)（负对数和），从**内部**逼近（迭代点始终严格可行），只适用于不等式约束、初始点必须在严格可行域 S₀ 内，罚因子 μₖ **递减趋于 0**，判据 μₖB(x⁽ᵏ⁾) < ε。例：min (x₁+1)³/12 + x₂ s.t. x₁ ≥ 1, x₂ ≥ 0，得 x = (1+2√μₖ, μₖ) → (1, 0)。

**易错点**：罚因子方向记"**外↑内↓**"；内点法不解等式约束；外点法的极限点要用 KKT 验证，别只写"极限就是最优"；内点障碍符号写反（墙朝下）整题崩。

### Q18 Zoutendijk 可行方向法与 Rosen 梯度投影法的思想与区别 🟡

**题**：简述可行方向法的基本思想；Zoutendijk 法与 Rosen 梯度投影法各怎么做、有什么区别？

**答**：**可行方向法总思想**（与无约束下降算法一致）：从可行点出发，在该点的**可行方向**中寻找使目标下降的方向，沿方向作一维搜索得到新可行点，迭代格式 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾；每轮解决两个问题：定**下降可行方向**、定**步长** λᵏ。
**Zoutendijk 法**：把约束按在 x⁽ᵏ⁾ 处是否起作用拆开（起作用 A₁x⁽ᵏ⁾ = b₁，不起作用 A₂x⁽ᵏ⁾ > b₂），方向归结为解一个线性规划：min ∇f(x⁽ᵏ⁾)ᵀd s.t. A₁d ≥ 0, Ed = 0, −1 ≤ dⱼ ≤ 1。d = 0 是该 LP 的可行解，故最优值 ≤ 0；最优值 **< 0** 得下降可行方向，**= 0** 则由 Farkas 定理可证 x⁽ᵏ⁾ 是 KKT 点。步长上限由不起作用约束给出 λmax，在 [0, λmax] 上一维搜索。
**Rosen 梯度投影法**：用积极约束系数矩阵 M = [A₁; E] 的行向量生成法向量子空间，把负梯度投影到它的正交补：投影矩阵 P_N(M) = I − Mᵀ(MMᵀ)⁻¹M，若 **d = −P_N(M)∇f(x) ≠ 0** 即为下降可行方向；若 d = 0，计算 w = (MMᵀ)⁻¹M∇f(x) = (uᵀ, vᵀ)ᵀ，**u ≥ 0 ⇔ x 是 KKT 点**，否则删去 u 的负分量对应行后重新投影。
**区别**：Zoutendijk 每轮解一个 LP（约束多时贵）；Rosen 只算一次投影矩阵、不解 LP，计算量小，适合线性约束。

**易错点**：方向 LP 必须带 box −1 ≤ dⱼ ≤ 1；Th12.2.2 判 KKT 的前提是投影为 0；Zoutendijk 的收敛性缺陷（算法映射 A = M∘D 不闭，Wolfe 1972 反例；Topkis-Veinott 修正把 LP 右端改为 −gᵢ(x)，保证聚点是 F-J 点）也是简答高危区。

### Q19 单纯形法的选基规则与原理 🔵 考点清单第 7 条

**题**：单纯形法每步如何选入基变量和出基变量？最优性如何判断？为什么这样选？

**答**：标准形 min z = cᵀx，s.t. Ax = b，x ≥ 0，当前基 B、基变量下标集、检验数 σⱼ = cⱼ − c_BᵀB⁻¹Aⱼ。每步四件事：① **算检验数**；② **入基**：取 σⱼ < 0 中**最负**的非基变量（σⱼ < 0 保证沿该列方向目标下降，最负下降最快）；③ **出基（比值检验）**：对主元列中 **aᵢⱼ > 0** 的行算比值 bᵢ/aᵢⱼ，取**最小比值**对应的基变量出基（最小比值保证新基点仍可行，步长 θ = 最小比值）；④ **判断最优**：所有 σⱼ ≥ 0 时当前 BFS 就是最优解。
**原理**：每次换基沿可行域的一条棱移动，非退化时 z 严格下降，而顶点（BFS）只有有限个，故有限步终止（Th3.4：相容 + 非退化 ⇒ 有限步收敛）。

**易错点**：只对 aᵢⱼ > 0 的行算比值；θ 取**最小**比值；退化时比值并列可能不下降、甚至循环（见 Q20）。

### Q20 单纯形法的退化与循环、摄动法与 Bland 规则 🟡（2026-11-22 新出练题同知识点）

**题**：什么是退化？退化为什么可能使单纯形法无限循环？有哪两种处理办法？

**答**：**退化**：基本可行解中**有基变量取 0 值**（m 个基变量至少一个为 0；与 B 满秩不矛盾，是多个约束交于同一顶点）。表上特征：比值检验出现**并列**、出基变量取 0、换基后 z **不变**。
**为什么可能循环**：Th3.4 的证明依赖"每步 z 严格下降 + 顶点有限 ⇒ 顶点不重复 ⇒ 有限步终止"；退化时出基变量取 0、步长 θ = 0，z 原地踏步，"严格下降"这一环被打断，同一顶点换一套基可以再来一遍，于是可能无限循环（Beale 例：最负 σ 规则 6 次换基回到初始基，z 恒 0）。
**两种处理**：① **摄动法**——对右端向量作小扰动 b(ε) = (ε, ε², ε³)（ε > 0 充分小），把比值并列全部打散，使问题非退化；迭代中 ε 不必代数字，按 ε 的幂次作比值比较；初始可行解由原 BFS 经列调换（基列排在左边、下标重排）得到。思想是**改数据**。② **Bland 规则**——入基在 σ < 0 的非基变量中取**下标最小**者，出基在比值并列的基变量中取**下标最小**者（课件 s084 原话："选最左边的正检验数对应的非基变量入基"，课件的"正"是其表格的符号方向；本课程 σ < 0 入基）。思想是**改选法**：放弃贪心，用确定性规则保证不循环。
**Beale 例效果**：σ₁ = −2、σ₇ = −3 时，最负规则选 x₇、Bland 选 x₁；此后最负规则 6 轮回原基（z 恒 0），Bland 6 轮终止于 x* = (3/4, 0, 0, 1, 0, 1, 0)、z* = −5/4。

**易错点**：退化 ≠ 约束冗余/矩阵奇异；两种办法的思想一句话各能概括（摄动打散并列、Bland 最小下标）；Bland 只写入基半条会漏分，出基并列规则也要写。

## F 组　第 8、9 章算法与一维搜索

### Q21 算法映射与迭代下降算法 🟡

**题**：什么是算法映射？迭代下降算法的一般格式是什么？何谓收敛、局部收敛、全局收敛？

**答**：**算法映射（Df8.1.1）**：算法 A 是空间 X 上的**点到集映射**，每个点 x ∈ X 指定一个子集 A(x) ⊂ X；给定初始点 x₁，生成点列 x⁽ᵏ⁺¹⁾ ∈ A(x⁽ᵏ⁾)。
**迭代下降算法一般格式**：给定 x⁽⁰⁾ →（i）确定可行的**下降方向** p⁽ᵏ⁾（∇f(x⁽ᵏ⁾)ᵀp⁽ᵏ⁾ < 0）；（ii）确定步长 αₖ > 0 使 f(x⁽ᵏ⁾ + αₖp⁽ᵏ⁾) < f(x⁽ᵏ⁾)；（iii）x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + αₖp⁽ᵏ⁾；（iv）检验终止准则。沿 p⁽ᵏ⁾ 求步长的过程叫**一维搜索（线性搜索）**。解集合 Ω 常取全体局部最优解、{x | f(x) ≤ b}、全体 KKT 点等；证明收敛用**下降函数** α（x ∉ Ω 时 α 严格减）配合紧性。
**收敛性**：有限步得最优解、或点列极限点是最优解 ⇒ **收敛**；当初值充分接近时才收敛 ⇒ **局部收敛**；任意初值都收敛 ⇒ **全局收敛**。
**收敛速度（Df8.2.1）**：lim ‖x⁽ᵏ⁺¹⁾ − x*‖/‖x⁽ᵏ⁾ − x*‖ = β：0 < β < 1 为**线性收敛**（β 是收敛比），β = 0 为**超线性收敛**；更一般地 lim 比值/‖x⁽ᵏ⁾ − x*‖^p = β > 0 为 **p 阶收敛**。

**易错点**：算法映射是"点到集"映射，不是点到点；证明套路是把算法写成合成映射 A = M∘D，证 M 闭（Th9.1.1）、D 连续 ⇒ A 闭，再找下降函数。

### Q22 一维搜索：单峰函数、0.618 法与 Fibonacci 法 🟡

**题**：什么是单峰函数？0.618 法和 Fibonacci 法的基本原理是什么？

**答**：**一维搜索**问题：min_{λ≥0} f(x + λd)。**单峰函数（Df9.2.1）**：[a, b] 上存在（唯一）极小点 x*，f 在 [a, x*] 严格递减、在 [x*, b] 严格递增。**Th9.2.1**：单峰函数中取两点 x⁽¹⁾ < x⁽²⁾，若 f(x⁽¹⁾) > f(x⁽²⁾) 则极小点在 [x⁽¹⁾, b]，若 f(x⁽¹⁾) ≤ f(x⁽²⁾) 则极小点在 [a, x⁽²⁾]——**一次比较砍掉一段区间**，这是所有试探法的根据。
**0.618 法（黄金分割）**：每轮取 λₖ = aₖ + 0.382(bₖ − aₖ)、μₖ = aₖ + 0.618(bₖ − aₖ)，比较函数值后舍去一段，区间每次保留 0.618 倍；**已算点可复用**，每轮只新算一个点。区间长度按 0.618ᵏ 收缩。
**Fibonacci 法**：按 Fibonacci 数列（F₀ = F₁ = 1）取点，λₖ = aₖ + F₍ₙ₋ₖ₋₁₾/F₍ₙ₋ₖ₊₁₾(bₖ − aₖ)、μₖ = aₖ + F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₾(bₖ − aₖ)；给定精度 δ，取最小 n 使 Fₙ ≥ (b₁ − a₁)/δ。
**函数逼近法**：用二次/三次插值近似 f，取近似函数的极小点；其中**一元牛顿法** x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − f′(x⁽ᵏ⁾)/f″(x⁽ᵏ⁾)，在 f 有三阶连续导数、f″(x*) ≠ 0、初点充分接近时**至少 2 阶收敛**（Th3.1）；割线法用差商代替二阶导数，只需函数值。

**易错点**：Fibonacci 取点公式分母是 **F₍ₙ₋ₖ₊₁₾**（课堂笔记曾误写 F₍ₙ₊₁₾）；0.618 法第一个试点取在 0.382 处；缩区间条件要配对（λ 函数值大舍左段、μ 大舍右段）。

### Q23 智能优化 / 运输问题 / LP 对偶

**题**：什么是智能优化？（或：运输问题、LP 对偶的一句话概念）

**答**：
- **智能优化（现代优化算法）**：面向 NP-hard 全局优化问题的随机搜索方法（GA、SA、TS、DE、蚁群等），不依赖梯度、无最优性保证，在可接受时间和精度内给出满意解。
