## 1. 局部优化与全局优化

**可直抄模板**

全局最优解是对**整个可行域** S 而言的：x* ∈ S 且对一切 x ∈ S 都有 f(x*) ≤ f(x)；局部最优解只要求**存在一个邻域**，在该邻域与可行域的交集内 f(x*) 最小（CH1-1 定义 1.1/1.2）。两者关系：**全局最优必是局部最优，局部最优未必是全局最优**；但在**凸规划**（凸目标函数 + 凸可行域）中，局部最优解就是全局最优解。算法层面：传统优化方法（最速下降、牛顿、单纯形等）基于**局部搜索**，一般只能保证收敛到局部最优解或 KKT 点；现代优化方法（遗传、模拟退火、禁忌搜索等）面向**全局优化**，用随机搜索跳出局部极小，但没有最优性保证，给出的是可接受精度内的满意解。

**易错点**
- 局部最优的定义必须写"存在邻域"，不能写成"比附近的点好"这种口语。
- "局部 = 全局"的前提是**凸规划**（目标和可行域都要凸），只说"凸函数"不完整。
- 别把"全局优化算法"说成"保证找到全局最优"——现代算法是概率意义/近似（第二册口径）。

## 2. 线性规划与非线性规划

**可直抄模板**

按**目标函数与约束函数的类型**划分：目标函数和所有约束函数都是线性（仿射）函数的优化问题是线性规划（LP）；目标或约束中**至少有一个是非线性函数**的，是非线性规划（NLP）。区别有四：① 可行域——LP 的可行域是**凸多面体**（Th2.2），NLP 的可行域一般不是凸集；② 最优解位置——LP 若有最优解，**必可在极点（基本可行解）达到**（Th2.3、Th2.4），NLP 的最优解可在可行域内部或边界任何位置，用 **KKT 条件**刻画；③ 局部与全局——LP 是凸规划，局部最优即全局最优，NLP 一般不成立；④ 算法——LP 用单纯形法、两阶段法、大 M 法，NLP 用最速下降、牛顿、共轭梯度、拟牛顿、可行方向法、罚函数法等迭代下降算法。

**易错点**
- 判别看"有没有非线性项"：x₁x₂、x₁²、sin x 都使问题成为 NLP；约束 x ≥ 0 是线性的。
- "最优解在极点"只对 **LP** 成立，且前提是"有最优解"（无界/无可行解时谈不上）。
- LP 的"线性"指目标与约束均为仿射；标准形式 min cᵀx, Ax=b, x≥0 里等式约束也是线性约束。

## 3. 对偶函数（Lagrange 对偶）【补充，讲义未展开】

> ⚠️ 先分清：这里指 **Lagrange 对偶函数**，由课程 CH7 的 Lagrange 函数自然引出；**不是第 4 章 LP 对偶理论**（那一章不考，只留一句话概念储备，见第三册 §2.3）。已核对 (7).pdf：讲义只给 L(x,w,v)=f−Σwᵢgᵢ−Σvⱼhⱼ 与 KKT，未讲对偶函数 ⇒ 本题按概念储备准备。

**可直抄模板**

对约束优化问题 min f(x)，s.t. gᵢ(x) ≥ 0，hⱼ(x) = 0，先构造 **Lagrange 函数** L(x, u, v) = f(x) − Σuᵢgᵢ(x) − Σvⱼhⱼ(x)（课程口径，uᵢ ≥ 0）。**对偶函数**定义为 θ(u, v) = inf_x L(x, u, v)，即固定乘子后对 x 取下确界。两条核心性质：① **θ 是凹函数**——因为 L 对 (u, v) 是仿射的，一族仿射函数的逐点下确界是凹的；② **弱对偶性**——当 u ≥ 0 时，对任意可行 x 有 L(x, u, v) ≤ f(x)，故 θ(u, v) ≤ f*，即对偶函数值给出原问题最优值的**下界**。对偶问题就是 max θ(u, v)，s.t. u ≥ 0；若原问题是凸规划且满足约束规格，则强对偶成立，原、对偶最优值相等，KKT 点处乘子即对偶最优解。

**易错点**
- 符号口径跟课程走：**L = f − Σug − Σvh，约束 g ≥ 0、u ≥ 0**（别写成加号或 g ≤ 0 口径，混用会翻车）。
- 对偶函数是**凹**函数（不是凸），对偶问题是**极大化**。
- inf 不一定 attain，写"下确界"比"最小值"严谨。
- 弱对偶不需要凸性；强对偶才需要凸 + 约束规格（如 Slater 条件，此名词讲义未出现，可不写）。

## 4. 凸集与凸函数的关系

**可直抄模板**

凸集是**集合**的性质：集合 C 中任意两点的连线段仍在 C 内，即 λx + (1−λ)y ∈ C（λ ∈ [0,1]）；凸函数是**函数**的性质，且定义域必须是凸集：f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y)。两者的核心桥梁是**上镜图**：f 是凸函数 **当且仅当** 其上镜图 epi f = {(x, t) | f(x) ≤ t} 是凸集。其次，凸函数的**水平集** {x | f(x) ≤ α} 都是凸集，但反过来不成立（水平集全凸只说明拟凸，不能推出凸函数）。运算性质：凸集之交仍是凸集；凸函数的非负加权和仍是凸函数。优化意义：凸集上凸函数的**局部极小点就是全局极小点**；目标凸 + 可行域凸才是凸规划，此时 KKT 点即全局最优解（Th7.2.10）。

**易错点**
- 上镜图是**充要**条件，水平集凸只是**必要**条件——这是最常考的辨析点。
- 凸函数定义里"定义域为凸集"不能漏，否则 λx+(1−λ)y 可能不在定义域内。
- 可行域凸 ≠ 凸规划：目标不凸时仍可能有多个局部极小。
- 判别凸函数的三条路线（定义 / 一阶 f(y) ≥ f(x)+∇f(x)ᵀ(y−x) / 二阶 Hessian 半正定）见第三册 §2.3 与复习课题 2，此处不重复。

## 5. 现代优化算法与传统优化算法（浓缩版）

> 完整 500 字可直抄模板（GA 为例，含流程框图、差别 5 条、联系 4 条、换 SA/TS/DE 替换句）在 **第二册**，本题直接背那份。此处给 100 字骨架防忘。

**骨架**

传统优化算法：基于**局部搜索**、要求目标**至少一阶可微**、**确定性**迭代，收敛性有理论保证，但一般只得局部最优（凸规划除外）。现代优化算法（GA/SA/TS/DE 等）：面向 **NP-hard 全局优化**的**随机搜索**，不依赖梯度、能跳出局部极小，但**无最优性保证**，给出可接受精度内的**满意解**。联系：都是迭代改进；可混合使用（现代算法全局探索 + 传统算法局部求精）；现代算法常内嵌局部搜索。答题口径按 CH1-2 PPT，"确定全局最优解"要补"概率意义上/近似"。

## 考前自查（5 句话）

1. 全局必局部、局部未必全局；凸规划里两者合一。
2. LP 全线性、最优在极点、局部即全局；NLP 有非线性、KKT 刻画、一般多局部极小。
3. 对偶函数 θ(u,v)=inf_x L，凹函数，u≥0 时 θ≤f*（弱对偶给下界）。
4. 上镜图凸 ⇔ 函数凸（充要）；水平集凸只是必要。
5. 传统 = 局部 + 可微 + 确定性；现代 = 全局 + 随机 + 满意解。
