## 1\. 公式卡（8 分钟）

**最优性条件**

* 无约束：一阶必要 ∇f(x\*)=0；二阶必要 H 半正定；**二阶充分 H 正定**；凸函数 ∇f=0 充要。
* 下降方向 ∇f(x\*)ᵀd < 0；可行方向：∃δ>0，∀λ∈(0,δ) 有 x+λd 可行。
* F-J：w₀∇f − Σwᵢ∇gᵢ − Σvⱼ∇hⱼ = 0（w₀,wᵢ ≥ 0 不全为零）。
* **KKT**：∇f − Σwᵢ∇gᵢ − Σvⱼ∇hⱼ = 0，wᵢ ≥ 0，**互补松弛 wᵢgᵢ(x)=0**。
* L = f − Σwᵢgᵢ − Σvⱼhⱼ；**∇²ₓₓL = ∇²f − Σwᵢ∇²gᵢ − Σvⱼ∇²hⱼ（减号）**。
* 正则点 + 凸规划 ⇒ **KKT 点即全局最优**。

**单纯形 / 两阶段 / 大 M**

* σⱼ = cⱼ − c\_BᵀB⁻¹Aⱼ；入基取**最负 σ**；出基 min{bᵢ/aᵢⱼ : aᵢⱼ>0}。
* 两阶段：≥ 减过剩变量 → 加人工变量 → 第一阶段 min w=Σaᵢ → **w\*=0 才转第二阶段**（w\*>0 ⇒ 无可行解）→ 删人工列、换原目标、**σ 全重算**。
* 大 M：目标加 M·Σaᵢ，M 是符号常数不进表；检验数先比 M 系数。
* 退化：比值并列 ⇒ 基变量取 0 ⇒ z 不降 ⇒ 可能循环（Beale 例 6 轮回原点）；摄动法 = b 加 ε 幂次打散并列，Bland = 入基取 σ<0 最小下标、并列出基取基变量最小下标；Th3.4 相容非退化有限步终止。

**一维搜索**

* 0.618：λ₁=a+0.382(b−a)、μ₁=a+0.618(b−a)；φ(λₖ)>φ(μₖ) 丢**左**段；旧点复用每轮只算 1 个新点。
* Fibonacci：定最小 n 使 Fₙ ≥ (b₁−a₁)/δ；λₖ=aₖ+F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎(bₖ−aₖ)、μₖ=aₖ+F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎(bₖ−aₖ)。
* 一元牛顿：x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾−f′/f″，**≥2 阶收敛**；割线法超线性。

**第 10 章**

* 最速下降 d=−∇f/‖∇f‖；收敛比 ((A−a)/(A+a))²，条件数 r=A/a 越小越快；锯齿现象。
* 牛顿 d=−∇²f⁻¹∇f，**严格二次凸函数一步到位**；阻尼=牛顿方向+一维搜索；修正 G\_k=∇²f+ε\_kI。
* 共轭 d⁽ⁱ⁾ᵀAd⁽ʲ⁾=0；FR：λ=−gᵏᵀd/(dᵀAd)、**β=‖gₖ₊₁‖²/‖gₖ‖²**、d⁽ᵏ⁺¹⁾=−gₖ₊₁+βₖd⁽ᵏ⁾；Th10.3.2 扩张子空间、Th10.3.3 二次终止。
* 拟牛顿：**p=Hq**（p 位移、q 梯度差）；Hₖ₊₁=Hₖ+ppᵀ/(pᵀq)−(Hₖq)(Hₖq)ᵀ/(qᵀHₖq)；H₁ 默认 I；H\_{n+1}=A⁻¹。

**第 12 章（只考到求方向）**

* 线性约束可行方向 ⟺ **A1d ≥ 0、Ed = 0**；方向 LP：min ∇fᵀd s.t. A1d≥0, Ed=0, **−1≤dⱼ≤1**；最优值 <0 得方向，=0 ⇒ KKT（证用 Farkas）。
* Rosen：**P\_N(M)=I−Mᵀ(MMᵀ)⁻¹M**，d=−P\_N(M)∇f ≠ 0 即下降可行方向；u≥0 ⇔ KKT。
* 非线性约束只拿 F-J（证用 Gordan）；收敛性缺陷：算法映射不闭（Wolfe 1972）。

**第 13 章**

* 外点 F=f+μP：等式罚 Σh²、不等式罚 Σ(max{0,−g})²，**μ↑∞**，判据 μP<ε；可用于等式+不等式。
* 内点 F=f+μB：B=Σ1/g 或 −Σlog g，**μ↓0**，判据 μB<ε；**只解不等式约束**、初点须严格内点。

## 3\. 六条计算大题套路（8 分钟）

**① 两阶段法**：标准化（≥ 减过剩）→ 加人工变量、第一阶段 min w=Σaᵢ → 每轮「定主元 → 主行归一 → 其余行消元 → **σ 重算**」→ 写判据句"w\*=0" → 删列换目标重算 σ → 报 **x\* 和 z\***。

**② 共轭梯度 FR**：d⁽¹⁾=−g₁ → φ′(λ)=0 求 λ → x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾+λd⁽ᵏ⁾、算 gₖ₊₁ → g=0 停 → β=‖gₖ₊₁‖²/‖gₖ‖² → d⁽ᵏ⁺¹⁾=−gₖ₊₁+βₖd⁽ᵏ⁾ → 重走。

**③ 拟牛顿 DFP**：gₖ → **d⁽ᵏ⁾=−Hₖgₖ**（不是 −gₖ）→ φ′(λ)=0 → x⁽ᵏ⁺¹⁾、gₖ₊₁ → g=0 停 → p、q 代入 DFP 校正 → 重走。

**④ KKT + 二阶**：代入定活动集 I（≤ 先翻 ≥）→ 解 ∇f=Σuᵢ∇gᵢ，**uᵢ<0 直接答"不是"** → 充分性三选一（定义法 A / 切锥放缩 B / 临界锥+Hessian C）→ 抄结论句。**KKT 过了≠就是极小点**。

**⑤ Zoutendijk / Rosen**：标准化 → **先判起不起作用**再写 A1 或 M → 列方向 LP（含 |dⱼ|≤1）或算投影 → 验 ∇fᵀd<0 → 答"非 KKT，方向 d"。**别跳过 LP 直接取 −∇f**。

**⑥ 罚函数（四问型）**：构造 F → ∂F/∂x=0 解闭式 x(μ)（负根舍去）→ 取极限（外 μ→∞ / 内 μ→0）报 x\*、f\* → 对 x\* 验 KKT。

## 4\. 简答五组 + 优缺点（5 分钟）

* **局部 vs 全局**：定义（局部必须写"存在邻域"）→ 全局必局部 → **凸规划（目标凸+可行域凸）才合一** → 传统只到局部/KKT，现代随机全局无保证。
* **LP vs NLP**：判据=有无非线性项；四区别=可行域凸多面体 / 最优在极点（Th2.3）/ 局部=全局 / 算法不同。
* **对偶函数**：θ(u,v)=inf\_x L；**θ 凹**；u≥0 时 θ≤f\*（弱对偶下界）；凸+约束规格 ⇒ 强对偶。
* **凸集 vs 凸函数**：定义 → **上镜图凸 ⇔ f 凸（充要）**；水平集凸只必要（拟凸）→ 凸集上凸函数局部=全局。
* **现代 vs 传统**：差别 5（局部确定性 vs 全局随机 / 至少一阶可微 vs 只需函数值 / 有最优性保证 vs 无 / 凸小规模 vs NP-hard / 代价）+ **联系 4**（迭代骨架同源 / 共用凸性-KKT-罚函数 / 可融合 memetic-MultiStart / 跳出局部机制同源）。**口径：概率意义/近似满意解**。
* **优缺点**：最速下降=简单省存储但锯齿、线性收敛；牛顿=二阶收敛、正定二次一步到位但贵（Hessian+解方程组）且娇气（可能不正定、局部收敛）；药方=阻尼/修正保方向，拟牛顿/共轭省二阶。
* **Farkas 画图**：画 O → 两条生成向量张成锥 C(A) → b 在锥内（非负组合）/ 锥外（过 O 的分离超平面，y 与 a₁a₂ 钝角、与 b 锐角）→ 二择一。
* **凸集定义验证**（复习课题1，x₂≥|x₁| 型）：任取两点、λ∈[0,1]，两步放缩 λ|a₁|+(1−λ)|b₁| ≥ |λa₁+(1−λ)b₁| ⇒ 凸组合仍在 S；第二步三角不等式正是凸性来源。
* **凸函数判别**（复习课题2）：Hessian 半正定最快；零特征值 ⇒ **凸但非严格凸**；保凸运算：和、非负组合仍凸。
* **概念储备**（判断题一句话）：智能优化 = NP-hard 随机搜索给满意解；运输 = 产销平衡 LP、表上作业法；LP 对偶 = 影子价格（第 4 章不考）。
