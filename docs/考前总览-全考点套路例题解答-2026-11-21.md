# 二、简答题 10 题（可直抄模板浓缩版）

完整版在 `简答与开放题-题目与答案-2026-11-17.md`，这里每题给骨架和易错点。

### Q1 局部最优 vs 全局最优

全局最优：对**整个可行域** S 一切 x 有 f(x\*) ≤ f(x)。局部最优：存在邻域 N(x\*)，在 N(x\*)∩S 内最小。关系：全局必局部，局部未必全局。**凸规划**（目标凸 + 可行域凸）里局部=全局。

易错：定义要写"存在邻域"；"局部=全局"前提是两者都凸。

### Q2 LP vs NLP

按目标与约束有无非线性划分。四条区别：① LP 可行域是凸多面体；② LP 有最优解必在极点（Th2.3）；③ LP 是凸规划，局部=全局；④ 算法：单纯形/两阶段/大 M vs KKT 迭代下降算法。

易错：x₁x₂、x₁²、sin x 都算非线性；x≥0 是线性约束。

### Q3 对偶函数（Lagrange 口径）

L(x,u,v) = f(x) − Σuᵢgᵢ(x) − Σvⱼhⱼ(x)，u≥0。对偶函数 θ(u,v) = inf_x L(x,u,v)。性质：① θ 是**凹**函数（仿射函数族的逐点下确界）；② u≥0 时 θ(u,v) ≤ f\*（弱对偶，给下界）。对偶问题 = max θ，s.t. u≥0；凸规划 + 约束规格才有强对偶。

易错：θ 凹、对偶问题是极大化；弱对偶不需要凸性。

### Q4 凸集 vs 凸函数

凸集：任意两点连线段仍在集合内。凸函数：定义域为凸集 + f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)。桥梁是**上镜图**：epi f 凸 ⇔ f 凸（**充要**）；水平集全凸只是必要（拟凸），不能反推。

易错：充要 vs 必要这条辨析最常考；定义域为凸集不能漏。

### Q5 现代 vs 传统优化算法

差别 5 条：搜索性质（局部确定性 vs 全局随机）；函数要求（至少一阶可微 vs 只需函数值）；最优性保证（KKT/收敛定理 vs 无保证、概率意义）；适用问题（凸/光滑小规模 vs NP-hard）；计算代价（单次快 vs 大量评价）。联系 4 条：同一迭代骨架 x_{k+1}=x_k+λₖdᵏ；共用凸性/下降方向/KKT/罚函数理论；互补融合（GA 全局探索 + 传统法精修）；跳出局部最优机制同源（摄动/Bland ↔ 概率接受劣解/禁忌表）。

易错：说"确定全局最优解"必须补"概率意义上"；联系 4 条开放题必须写。

### Q6 用定义验证凸集（复习课题1，S = {x₂ ≥ |x₁|}）

任取两点、任取 λ∈[0,1]，写凸组合的分量；用 a₂ ≥ |a₁|、b₂ ≥ |b₁| 推

x₂ = λa₂+(1−λ)b₂ ≥ λ|a₁|+(1−λ)|b₁| ≥ |λa₁+(1−λ)b₁| = |x₁|，

故凸组合仍在 S。第二步的 |λa₁+(1−λ)b₁| ≤ λ|a₁|+(1−λ)|b₁| 正是凸性的来源，别只写等号。

### Q7 凸函数判别（复习课题2）

f = x₁²−2x₁x₂+x₂²+x₁+x₂：∇²f = [[2,−2],[−2,2]]，特征值 0 与 4 均非负 ⇒ 半正定 ⇒ **凸但非严格凸**（有零特征值）。保凸运算：f₁+f₂ 仍凸，证明 = 两个定义式相加；升级为非负线性组合仍凸。

易错：半正定要说明"凸但非严格凸"；三路线（定义/一阶/Hessian）考场用 Hessian 最快。

### Q8 Farkas 定理几何表示 + 画图

二择一：(i) ∃x，Ax=b，x≥0；(ii) ∃y，Aᵀy≤0，bᵀy>0。几何：C(A) = cone{a₁,…,aₙ}。b 在锥内 ⇒ (i)；b 在锥外 ⇒ 凸集分离定理给过原点超平面，法向 y 使 aᵢᵀy ≤ 0（Aᵀy≤0）且 bᵀy>0 ⇒ (ii)。

30 秒画图：原点 O → 两条生成向量涂阴影成锥 → b 在阴影内标非负组合 / 在阴影外画分离直线（法向指向 b），标钝角（aᵢᵀy≤0）与锐角（bᵀy>0）。

易错：分离超平面**过原点**（C(A) 是锥）；两种情况都要会画。

### Q9 最速下降 vs 牛顿方向 + 优缺点

方向：d = −∇f vs d = −H⁻¹∇f。最速下降优点：只需梯度、计算量小、局部下降最快；缺点：收敛慢、锯齿现象、线性收敛、不利用曲率。牛顿法优点：二阶收敛、正定二次函数一步到位、无锯齿；缺点：每步算 Hessian + 解方程组（O(n³) 贵）、Hessian 可能非正定/奇异、局部收敛、要求二阶可微。补救：非正定 → 阻尼牛顿/修正牛顿（Gₖ）；算 Hessian 贵 → 拟牛顿（DFP/BFGS）/共轭梯度；远处不稳 → 线搜索。

速记：两大毛病"贵"和"娇气"，两条药方"阻尼/修正保方向，拟牛顿/共轭省二阶"。

### Q10 概念储备

智能优化：面向 NP-hard 的随机搜索（GA/SA/TS/DE），不依赖梯度、无最优性保证，给满意解。运输问题：产销平衡下最小化总运费的特殊 LP，表上作业法（整章不考）。LP 对偶：原问题约束对应影子价格，强对偶时最优值相等（第 4 章不考）。

# 三、计算题 11 类（套路 + 例题 + 解答）

## 1. 两阶段法 🔴（20 分档，"多写点会捞"）

**套路**：

1. 标准化：≥ 减**过剩变量**（系数 −1），= 直接用，bᵢ ≥ 0；
2. 阶段一：每个等式加**人工变量** aᵢ，辅助 LP **min w = Σaᵢ**，以人工变量为初始基迭代；
3. 过渡判据：w\* = 0 ⇒ 得原问题 BFS，进阶段二；w\* > 0 ⇒ **无可行解**，停；
4. 阶段二：删人工变量列、目标换回原 min z、**全部检验数重算**，继续迭代到 σ ≥ 0，报 x\* 和 z\*。

**换表四步速记**：定主元（最负 σ 列 × 最小比值行）→ 主行 ÷ 主元 → 其余行消元 → σ 行重算（c_B 变了必须重算）。

**例题（复习课题6）**：min z = x₁−x₂，s.t. −x₁+2x₂+x₃ ≤ 2；−4x₁+4x₂−x₃ = 4；x₁−x₃ = 0；x ≥ 0。

| 轮 | 基 | b 列 | 最负 σ | 入 / 出 |
|---|---|---|---|---|
| P1-0 | x₄,a₁,a₂ | (2,4,0)，w=4 | σ₂=−4 | x₂ 入；比值 1,1 并列，**人工优先** a₁ 出 |
| P1-1 | x₄,x₂,a₂ | (0,1,0) | σ₁=−1 | x₁ 入；比值 0,0 并列，a₂ 出 |
| P1-2 | x₄,x₂,x₁ | (0,1,0) | 全 0 ⇒ **w\*=0** | 过渡 ✓ |
| P2-0 | x₄,x₂,x₁ | (0,1,0)，z=−1 | σ₃=−1/4 | x₃ 入；x₄ 行 0/(5/2) 唯一有效比值，x₄ 出 |
| P2-1 | x₃,x₂,x₁ | (0,1,0) | σ=(0,0,0,1/10) ≥ 0 | **最优** |

**答案：x\* = (0,1,0)ᵀ，z\* = −1。**

易错：阶段一费用是 1 不是 M；w=0 这句判据必须写；阶段二禁止人工变量入基；比值只对**正**系数行取。

## 2. 单纯形法（纯表）🔵

**套路**：全 ≤ 且 b≥0 ⇒ 加松弛变量直接起步。min 选**最负** σⱼ = cⱼ−zⱼ 入基，σ 全 ≥ 0 才最优；比值检验只对正元素行取 min。

**例题（复习课题4）**：min z = 3x₁−5x₂−2x₃−x₄，s.t. x₁+x₂+x₃ ≤ 4；4x₁−x₂+x₃+2x₄ ≤ 6；−x₁+x₂+2x₃+3x₄ ≤ 12；x ≥ 0。

| 轮 | 基 | b 列 | 最负 σ | 入 / 出 |
|---|---|---|---|---|
| 0 | s₁,s₂,s₃ | (4,6,12) | σ₂=−5 | x₂ 入，s₁ 出（θ=4） |
| 1 | x₂,s₂,s₃ | (4,10,8)，z=−20 | σ₄=−1 | x₄ 入，s₃ 出（θ=8/3） |
| 2 | x₂,s₂,x₄ | (4,14/3,8/3)，z=−68/3 | σ=(22/3,0,10/3,0,14/3,0,1/3) ≥ 0 | **最优** |

**答案：x\* = (0,4,0,8/3)ᵀ，z\* = −68/3。**

易错：表 1 的 s₂ 行是 **加** 1×x₂ 行（x₂ 列系数 −1）；σ 行是 cⱼ−zⱼ（min 口径）。

## 3. 大 M 法 🔵

**套路**：不分阶段。≤ 加松弛、= 加**人工变量（费用 +M）**，一张表做到底。含 M 检验数比大小**只看 M 的系数**：M 系数为负的（如 1−3M）比普通负数（如 −1）更优先入基；M 系数相同时才比常数项。最优表里人工变量必须已出基。

**例题（复习课题5）**：min z = −3x₁+x₂+x₃，s.t. x₁−2x₂+x₃ ≤ 11；−4x₁+x₂+2x₃−x₄ = 3；−2x₁+x₃ = 1；x ≥ 0。

| 轮 | 基 | b 列 | 最负 σ | 入 / 出 |
|---|---|---|---|---|
| 0 | s₁,a₁,a₂ | (11,3,1)，z=4M | σ₃=1−3M | x₃ 入，a₂ 出（θ=1） |
| 1 | s₁,a₁,x₃ | (10,1,1)，z=1+M | σ₂=1−M（比 −1 更负） | x₂ 入；s₁ 行系数 −2 跳过，a₁ 出 |
| 2 | s₁,x₂,x₃ | (12,1,1)，z=2 | σ₁=−1 | x₁ 入，s₁ 出（θ=4） |
| 3 | x₁,x₂,x₃ | (4,1,9)，z=−2 | M 系数全 ≥0 且常数全 ≥0 | **最优** |

**答案：x\* = (4,1,9,0)ᵀ，z\* = −2。**

易错：人工变量费用 +M 不是 0；σ₁ 列在表 0 是 −3+6M；松弛变量只加给 ≤ 约束。11-19 练习题的三个坑：人工变量禁入基、剩余变量可以进基、先比 M 系数再比常数。

## 4. FR 共轭梯度法 🔴

**套路**：

1. 算 gₖ = ∇f(x⁽ᵏ⁾)，**第一轮 d⁽¹⁾ = −g₁**（没有旧方向）；
2. 步长：φ(λ) = f(x+λd) 求导令 φ′(λ) = 0；二次函数可用捷径 λₖ = −gᵀd/(dᵀAd)（**分母是 dᵀAd**）；
3. x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾+λₖd⁽ᵏ⁾，算 gₖ₊₁；gₖ₊₁ = 0 停；
4. βₖ = ‖gₖ₊₁‖²/‖gₖ‖²（FR 公式 10.3.24）；
5. d⁽ᵏ⁺¹⁾ = −gₖ₊₁ + βₖd⁽ᵏ⁾，循环。

**例题（复习课题9）**：min f = ½x₁²+x₂²，x⁽¹⁾ = (4,4)ᵀ。A = diag(1,2)，∇f = (x₁, 2x₂)ᵀ。

| 步 | 结果 |
|---|---|
| g¹ / d¹ | (4,8)ᵀ / (−4,−8)ᵀ |
| λ₁ = (4²+8²)/(4²·1+8²·2) | 80/160 = **5/9** |
| x⁽²⁾ | (16/9, −4/9)ᵀ |
| g² | (16/9, −8/9)ᵀ |
| β₁ = ‖g²‖²/‖g¹‖² = (320/81)/80 | **4/81** |
| d² = −g²+β₁d¹ | (−160/81, 40/81)ᵀ |
| λ₂ = (320/81)/[(160/81)²+(40/81)²·2] | **9/10** |
| x⁽³⁾ | **(0,0)ᵀ**，g³=0 停，f\*=0 |

加分验证：d¹ᵀAd² = 0（共轭）；g²ᵀd¹ = 0（精确线搜索的必然结果）；2 步 = n，Th10.3.3 二次终止。

易错：β 用 FR 公式别用 PRP；第一步 d¹=−g¹ 是规定；步长分母 dᵀ**A**d 别写成 dᵀd。

## 5. DFP 拟牛顿法 🔴

**套路**：

1. 算 gₖ，方向 **d⁽ᵏ⁾ = −Hₖgₖ**（H 近似 Hessian 的**逆**，不是 −Hₖ⁻¹g）；
2. 步长同上（φ′=0 或 λ=−gᵀd/(dᵀAd)）；
3. 新点、新梯度；g=0 停；
4. p = x_{k+1}−xₖ，q = g_{k+1}−gₖ，DFP 校正：
   Hₖ₊₁ = Hₖ + ppᵀ/(pᵀq) − (Hₖq)(Hₖq)ᵀ/(qᵀHₖq)
5. 循环，**两个分母都别漏**。

**例题（复习课题10 / 讲义练习题2）**：min f = x₁²+3x₂²，x⁽¹⁾ = (1,−1)ᵀ，H₁ = [[2,1],[1,1]]。A = diag(2,6)。

| 步 | 结果 |
|---|---|
| g¹ / d¹ = −H₁g¹ | (2,−6)ᵀ / (2,4)ᵀ |
| λ₁ = 20/(8+96) | **5/26** |
| x⁽²⁾ | (18/13, −3/13)ᵀ |
| g² | (36/13, −18/13)ᵀ |
| p / q | (5/13,10/13)ᵀ / (10/13,60/13)ᵀ |
| pᵀq / H₁q / qᵀH₁q | 50/13 / (80/13,70/13)ᵀ / 5000/169 |
| H₂ | [[493/650, −14/325],[−14/325, 113/650]] |
| d² = −H₂g² | (−54/25, 9/25)ᵀ |
| λ₂ | **25/39** |
| x⁽³⁾ | **(0,0)ᵀ**，g³=0 停，f\*=0 |

加分验证：H₂q = p（拟牛顿条件成立）；d¹ᵀAd² = 0（共轭 ⇒ 一步到极小，Th10.4.2）；若再校正一次 H₃ = A⁻¹ = diag(1/2,1/6)。

易错：方向是 −Hₖg；p、q 别写反（写反了 p=Hq 不成立）；本题 H₁ 给了就用给的非单位阵，第一步方向 = (2,4)ᵀ 别丢负号。

## 6. KKT + 局部极小点验证 🟡（KKT 必考）

**套路**：

1. 统一约束为 gᵢ(x) ≥ 0、hⱼ = 0 形式（≤ 先翻向）；
2. 列 Lagrange 函数 L = f − Σuᵢgᵢ − Σvⱼhⱼ（**减号**）；
3. 写 KKT 五件套：∂L/∂x = 0；gᵢ ≥ 0；uᵢ ≥ 0；h = 0；uᵢgᵢ = 0（互补松弛）；
4. 按"起作用/不起作用"**分情况**解方程组：不起作用 ⇒ u=0；解出 u < 0 的分支**舍去**；
5. 二阶充分条件：临界锥 C = 切锥中 ∇fᵀd = 0 的方向；验证 dᵀ∇²ₓₓL d > 0 对一切非零 d∈C 成立，其中 **∇²ₓₓL = ∇²f − Σu∇²g − Σv∇²h**。

**例题（复习课题7）**：min f = x₁²−x₂−3x₃，s.t. g₁ = −x₁−x₂−x₃ ≥ 0，h = x₁²+2x₂−x₃ = 0。

- KKT：∂L/∂x₁ = 2x₁+u₁−2vx₁ = 0；∂L/∂x₂ = −1+u₁−2v = 0；∂L/∂x₃ = −3+u₁+v = 0。
- 情形 A（g₁ 起作用）：后两式解出 u₁ = 1+2v 与 u₁ = 3−v ⇒ v = 2/3，u₁ = 7/3 > 0 ✓；代入第一式得 x₁ = −7/2；联立 h=0、g₁=0 解出 x₂ = −35/12，x₃ = 77/12。
- 情形 B（u₁=0）：−1−2v=0 与 −3+v=0 矛盾，无解。
- 二阶：临界锥由 dg₁=0、dh=0 得 d = d₁(1,2,−3)ᵀ；∇²ₓₓL = diag(2,0,0) − (2/3)diag(2,0,0) = diag(2/3,0,0)；dᵀ∇²ₓₓL d = (2/3)d₁² > 0 ⇒ 严格局部极小。
- 消元复核：f 化为 (x₁²+7x₁)/3，开口向上，x₁ = −7/2 处全局最小。

**答案：x\* = (−7/2, −35/12, 77/12)ᵀ，u₁ = 7/3，v = 2/3，f\* = −49/12，为全局最小点。**

易错：约束是 g ≥ 0、L = f − ug，∂L/∂x₁ 里是 **+u₁**；二阶条件限定在临界锥上（∇²ₓₓL 本身只是半正定）；11-17 练习题的坑：弱起作用（u=0）分支别漏，u>0 但二阶不过的点要毙掉。

## 7. Zoutendijk 求可行下降方向 🟡（考到求方向为止）

**套路**：

1. 约束标准化 Ax ≥ b、Ex = e；
2. 代入当前点，**每轮重分**起作用集：A₁x = b1（起作用）、A₂x > b2；
3. 解方向 LP：min ∇fᵀd，s.t. A₁d ≥ 0，Ed = 0，**−1 ≤ dⱼ ≤ 1**（box 约束是得分点，漏了 LP 无界）；
4. ∇fᵀd = 0 ⇒ KKT 点停；< 0 ⇒ 得方向。（λmax 与完整迭代不考。）

**例题（复习课题11(1)）**：min f = x₁²+2x₂²，s.t. g₁ = x₁+x₂−1 ≥ 0，g₂ = x₂−1 ≥ 0，x⁽¹⁾ = (1,1)ᵀ。

- 判起作用：g₁ = 1 > 0 不起作用；g₂ = 0 起作用，I = {2}。
- ∇f = (2x₁,4x₂)ᵀ\|(1,1) = (2,4)ᵀ；∇g₂ = (0,1)ᵀ。
- 条件：**∇fᵀd = 2d₁+4d₂ < 0 且 ∇g₂ᵀd = d₂ > 0**，即 d₂>0 且 d₁ < −2d₂。验证例：d=(−3,1)ᵀ 满足；d=(−2,1)ᵀ 不行（∇fᵀd=0 只平不降）。

易错：起作用集**看当前点**判，别把有裕量的约束也列进去；g ≥ 0 型约束是 ∇gᵀd **> 0**，方向别写反。

## 8. Rosen 梯度投影 🟡

**套路**：

1. 起作用约束的梯度作行，拼成 M（行满秩）；
2. 投影矩阵 **P_N(M) = I − Mᵀ(MMᵀ)⁻¹M**；
3. d = −P_N(M)∇f(x)：d ≠ 0 ⇒ 就是下降可行方向（Th12.2.1），验证 Md = 0 与 ∇fᵀd < 0 收工；
4. d = 0 才走 Th12.2.2：算 w = (MMᵀ)⁻¹M∇f，u ≥ 0 ⇒ KKT 点；u 有负分量 ⇒ 删行重投影。（d=0 分支不考，但**前提口径**要会：投影非零时直接拿方向，不算乘子。）

**例题（复习课题11(2)）**：同上题，x⁽¹⁾ = (1,1)ᵀ。起作用仅 g₂，M = [0 1]（1×2，**不是 2×2**）。

P_N = I₂ − [0;1][0 1] = [[1,0],[0,0]]；d⁽¹⁾ = −P_N(2,4)ᵀ = **(−2,0)ᵀ**。

验证：Md = 0 ✓；∇fᵀd = −4 < 0 ✓。(1,1) 不是 KKT 点（∇f=(2,4)ᵀ ≠ Mᵀw 型），与最优解在 (0,1) 一致。

易错：M 只收起作用约束；投影后**必须验证** Md=0 与下降性再写结论；有约束抄串的梯度不可能是不对称的分量式，抄完自查一遍。

## 9. 罚函数法完整求解 🟡

**套路（外点）**：

1. 构造 F(x,μ) = f(x) + μΣ(max{0,−gᵢ})² + μΣhⱼ²，等式约束直接平方项；
2. 解 ∂F/∂x = 0 得闭式解 x(μ)；
3. μ→∞ 取极限得候选 x\*；**必须回代 KKT 验证**（这是判据，不是"极限即最优"）；
4. μ 取递增数列（SUMT），判据 μP(x⁽ᵏ⁾) < ε。

**套路（内点）**：只适用不等式约束；F = f − μΣln gᵢ（负对数）或 f + μΣ1/gᵢ（倒数和）；μ 递减趋 0；判据 μB(x⁽ᵏ⁾) < ε。

**例题 A（外点，复习课题11(3)）**：min f = x₁²+2x₂²，s.t. g₁ = x₁+x₂−1 ≥ 0，g₂ = x₂−1 ≥ 0。

F = x₁²+2x₂² + μ[(1−x₁−x₂)² + (1−x₂)²]。驻点方程解出 x₁(μ) = 2μ/(μ²+4μ+2)，x₂(μ) = μ(μ+2)/(μ²+4μ+2)。μ=1 时 (2/7,3/7)（**在可行域外，正常**）；μ→∞ 时 → **(0,1)ᵀ**，f→2。直接判定：固定 x₂≥1 时 x₁=0 最优，再对 x₂ 取最小得 x\*=(0,1)ᵀ，z\*=2。两者一致。

**例题 B（内点，11-20 练习题）**：min f = x₁²+2x₂²，s.t. x₁+x₂ ≥ 2。

F = x₁²+2x₂² − μ·ln(x₁+x₂−2)（**减号**，墙朝上）。驻点方程：

2x₁ − μ/(x₁+x₂−2) = 0；4x₂ − μ/(x₁+x₂−2) = 0。

两式相减 2x₁ = 4x₂ ⇒ x₁ = 2x₂；代回解出 x₂ = (2+√(4+3μ))/6（负根不可行，**舍去**）。

x(μ) = ((2+√(4+3μ))/3, (2+√(4+3μ))/6)；μ→0⁺ 极限 x\* = **(4/3, 2/3)ᵀ**，g₁=0 起作用；KKT：∇f = u∇g ⇒ u\* = 8/3 > 0，f\* = 8/3。f 是凸函数、可行域凸 ⇒ 充分性成立。μ↓ 与外点 μ↑ **方向相反**。

易错：障碍项符号写反（+μln g 墙朝下）；别先把 μ=0 代入驻点方程（出假根 x₂=0）；极限点必须 KKT 验证；外点解在域外是正常现象。

## 10. 一维搜索 0.618 / Fibonacci 🟡

**0.618 套路**：λₖ = aₖ+0.382(bₖ−aₖ)（左点）、μₖ = aₖ+0.618(bₖ−aₖ)（右点）。φ(λₖ) ≤ φ(μₖ) ⇒ 丢右段 [μₖ,bₖ]，旧点 λₖ 留作新右点，只新算 λₖ₊₁；φ(λₖ) > φ(μₖ) ⇒ 丢左段 [aₖ,λₖ]，旧点 μₖ 留作新左点。每轮只算 1 个新函数值。终区间 = (b₁−a₁)·rⁿ⁻¹，r = 0.618。

**Fibonacci 套路**：定 n：最小 n 使 **Fₙ ≥ (b₁−a₁)/δ**（F₀=F₁=1）。第 k 轮取点：

λₖ = aₖ + F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎·(bₖ−aₖ)，μₖ = aₖ + F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎·(bₖ−aₖ)。

**分母随 k 变**（不是 F₍ₙ₊₁₎，课堂笔记曾写错已修正）。速记：F 数列上取连续三个数做"左分子、右分子、公共分母"，每轮窗口左移一格；两点系数和恒为 1。末轮两点重合，用辨别常数 δ 错开再比一次。

**例题（讲义练习题2）**：min φ(x) = x²−x+2，初始区间 (−1,3)，迭代两次。定 n：Fₙ ≥ 4/0.08 = 50 ⇒ F₉=55，**n=9**。

| 轮 | λₖ | μₖ | 比较 | 新区间 |
|---|---|---|---|---|
| 1 | −1+(21/55)·4 = **29/55** | −1+(34/55)·4 = **81/55** | φ(λ₁)=1.75 < φ(μ₁)=2.70 ⇒ 丢右段 | [−1, 81/55]，长 136/55 |
| 2 | **−3/55**（新算） | **29/55**（旧点 λ₁ 复用） | φ(λ₂)=2.06 > φ(μ₂)=1.75 ⇒ 丢左段 | **[−3/55, 81/55]** |

自检：两点到端点等距（b−λ = μ−a）；系数和 = 1（21/55+34/55=1 ✓；13/34+21/34=1 ✓）。

**答案：终区间 [−3/55, 81/55]，长 84/55 ≈ 1.527（缩为初始的 21/55）**。若做满 9 次，终区间 4/55 ≈ 0.073 ≤ 0.08 兑现定 n 承诺；同次数下 0.618 法终区间 4×0.618⁸ ≈ 0.085 > 0.08 不达标 ⇒ Fibonacci 更优。

易错：φ(λₖ) > φ(μₖ) 丢的是**左**端；0.382 = 1−0.618，λ 恒左点 μ 恒右点；取点公式分母 F₍ₙ₋ₖ₊₁₎；缩率推导钩子：等距 + 旧点复用 ⇒ 区间长满足 Lₖ = Lₖ₊₁+Lₖ₊₂（倒着长的 Fibonacci）。

## 11. 最速下降 / 牛顿方向计算 🟡

**套路**：∇f 代点得梯度；最速下降 d = −∇f；牛顿方向解 Hd = −∇f（或 d = −H⁻¹∇f）。正定二次函数牛顿 λ=1 一步到位。

**例题（复习课题8）**：min f = 2x₁²+x₂²，x⁽¹⁾ = (1,1)ᵀ。∇f = (4x₁,2x₂)ᵀ\|(1,1) = (4,2)ᵀ；H = diag(4,2) 正定。

最速下降方向 d = **(−4,−2)ᵀ**；牛顿方向 Hd = −(4,2)ᵀ ⇒ d = **(−1,−1)ᵀ**。

验证：x⁽¹⁾+(−1,−1) = (0,0) 正是极小点（一步到位）；最速下降走 λ=5/18 只到 (−1/9,4/9)，还需多步，锯齿明显。优缺点见简答 Q9。

# 四、开放题 2 题（10 分）

### 开放 1：介绍一种现代优化算法 + 与传统对比联系

以 GA 为例，500 字结构：**是什么**（编码染色体、适应度、种群随机全局搜索）→ **流程**（编码 → 初始种群 → 适应度评价 → 选择（轮盘赌/锦标赛）→ 交叉 → 变异 → 新一代，循环；带约束用罚函数）→ **差别 5 条**（同简答 Q5）→ **联系 4 条**（同 Q5）→ **收尾句**：现代算法以牺牲收敛精度和理论保证为代价，换 NP-hard 问题的全局搜索能力。

可换 SA（Metropolis 准则概率接受劣解、温度递减）/TS（禁忌表）/DE/ACS，替换句在第二册。

### 开放 2：凸/非凸优化算法对比 + 全局优化原理

凸优化算法两种：最速下降法、阻尼牛顿法（或共轭梯度、DFP、单纯形法，任选二）。非凸算法两种：GA、SA（或 TS/DE/ACS）。对比表 5 行：最优性（局部=全局 vs 无保证）、依赖信息（梯度/Hessian vs 只用函数值）、搜索方式（单点确定性 vs 种群随机）、输出（精确最优 vs 满意解）、适用问题（凸 vs NP-hard）。

相似之处 4 条：**框架同源**（x_{k+1}=x_k+λₖdᵏ 与"选择-交叉-变异"同为候选解生成机制）、目标一致、共同两大组件（新解产生 + 接受准则）、可互相结合（memetic = GA + 最速下降）。全局优化原理：种群并行 + 交叉重组 + 变异扰动 ⇒ 不易卡局部最优；深层原因是 NP-hard 在有限时间内严格求全局最优既不可能也不现实（PPT p12 口径）。

易错：相似处别写"完全不同"。
