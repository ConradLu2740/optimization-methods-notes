## 一、简答题

| 知识点 | 优先级 | 答题要点 / 易错点 |
|---|---|---|
| 局部优化 vs 全局优化 | 🟡 | 邻域内最小 vs 全可行域最小；全局必局部；**凸规划**里两者合一（目标+可行域都要凸） |
| 线性规划 vs 非线性规划 | 🟡 | 四条区别：可行域（凸多面体）/ 最优解位置（极点 Th2.3）/ 局部=全局（LP 是凸规划）/ 算法（单纯形 vs KKT 迭代） |
| 对偶函数 | 🟡 | **按 Lagrange 对偶写**：θ(u,v)=inf_x L；θ 是**凹**函数；u≥0 时 θ≤f\*（弱对偶给下界）。【补充】讲义未展开 |
| 凸集与凸函数关系 | 🟡 | 上镜图 epi f 凸 **⇔** f 凸（充要）；水平集凸只是必要（只说明拟凸）；定义域须为凸集 |
| 现代 vs 传统优化算法 | 🟡 | 传统=局部搜索+至少一阶可微+确定性；现代=NP-hard 全局+随机+满意解（无最优性保证，"概率意义/近似"） |
| 凸集定义验证 / 凸函数判别 | 🟡 | 复习课题1–2；凸函数三路线：定义 / 一阶 / Hessian 半正定（Th2.16、2.16\*、2.17） |
| Farkas 定理几何表示 + 画图 | 🔵 | 考点清单第1条 + 必考.md 点名"画图"；锥内/锥外两种情况 + 过原点分离超平面 |
| 优缺点类 | 🟡 | 最速下降 vs 牛顿方向（复习课题8）、共轭梯度特点 6 条、拟牛顿条件 p=Hq、两阶段法思想、罚函数思想、Zoutendijk vs Rosen 区别 |
| 多面体表示定理 / 极点与 BFS 关系 | 🔵 | 考点清单第2、5条；极点集 ≡ BFS 集（Th2.4） |
| 概念储备 | ⚪ | 第4章 LP 对偶一句话、第5章运输一句话、智能优化概念（考点清单第9条） |

## 二、计算大题

| 知识点 | 优先级 | 深度口径 / 易错点 |
|---|---|---|
| **两阶段法** | 🔴 | 点名"肯定要考"、20 分"多写点会捞"；P1 三轮 + P2 两轮五张表全流程；σ 精确分数 |
| **共轭梯度法（FR）** | 🔴 | 点名必考；λₖ=−gᵀᵏdᵏ/(dᵏᵀAdᵏ)(10.3.17)、βₖ=‖gₖ₊₁‖²/‖gₖ‖²(10.3.24)；两步到 (0,0) 型 |
| **拟牛顿法（DFP）** | 🔴 | 点名必考；拟牛顿条件 p=Hq、秩2校正、H₁=I、Th10.4.1 正定性、二次终止 |
| 单纯形法 / 大M法 | 🔵 | 考点清单"1–2 必考"；选基规则、退化情形（Bland 规则） |
| KKT + 局部极小点验证 | 🟡 | KKT 必考；二阶充分条件走**临界锥**（∇²ₓₓL=∇²f−Σu∇²g−Σv∇²h，符号别写反） |
| Zoutendijk 求可行下降方向 | 🟡 | 线性约束 A₁d≥0、E d=0 + ∇fᵀd<0 归结为 LP；**考到求方向为止** |
| Rosen 梯度投影求方向 | 🟡 | d=−P_N(M)∇f；Th12.2.2 前提是投影为 0 才判乘子 u≥0；u 有负分量删行重投影 |
| 惩罚函数法完整求解 | 🟡 | 外点 F=f+μP、(max{0,−gᵢ})² 罚项、闭式解 → 极限；内点倒数和/负对数和 |
| 一维搜索 0.618 / Fibonacci | 🟡 | 取点公式下标易错（笔记已修正：分母 Fₙ₋ₖ₊₁）；缩率推导 |
| 最速下降 / 牛顿方向计算 | 🟡 | 复习课题8；阻尼牛顿、修正牛顿（Hessian 非正定 → 修正矩阵 Gₖ） |
