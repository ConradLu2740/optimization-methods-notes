## 二、简答题（知识点 + 例题 + 答案 + 套路）

### S1 局部最优解与全局最优解 🟡

**知识点**：全局 = 对整个可行域 S 有 f(x\*) ≤ f(x)；局部 = 存在邻域 N(x\*)，在 N(x\*)∩S 内最小（Df1.1/1.2）；全局必局部；凸规划（目标凸 + 可行域凸）中二者合一；传统方法只保证局部/KKT，现代方法随机全局但无最优性保证。

**例题**：给出局部最优解与全局最优解的定义，说明两者关系；什么条件下局部最优就是全局最优？

**参考答案**：全局最优解是对整个可行域 S 而言的，x\* ∈ S 且对一切 x ∈ S 都有 f(x\*) ≤ f(x)；局部最优解只要求存在一个邻域 N(x\*)，使在该邻域与可行域的交集内 f(x\*) 最小。关系：全局最优必是局部最优，局部最优未必是全局最优（可行域内可能存在多个局部极小）。但在凸规划（目标函数为凸函数 + 可行域为凸集）中，局部最优解就是全局最优解。算法层面：传统优化方法基于局部搜索，一般只能保证收敛到局部最优解或 KKT 点；现代优化方法面向全局优化，用随机搜索跳出局部极小，但无最优性保证，给出的是可接受精度内的满意解。

**套路**：定义 → 关系 → 充分条件（凸规划）→ 算法视角，四段各 1–2 句。
**易错**：定义漏"存在邻域"；条件只写"凸函数"不写"可行域凸"。

### S2 线性规划与非线性规划 🟡

**知识点**：按目标与约束是否全线性划分；四条区别 —— ① 可行域（凸多面体 Th2.2 vs 一般非凸）② 最优解位置（极点 Th2.3/Th2.4 vs 任意位置、KKT 刻画）③ 局部=全局（LP 是凸规划）④ 算法（单纯形/两阶段/大M vs 下降迭代类）。

**例题**：什么是线性规划？什么是非线性规划？它们的区别有哪些？

**参考答案**：目标函数和所有约束函数都是线性（仿射）函数的是 LP；目标或约束中至少有一个非线性（x₁x₂、x₁²、sin x 都算）的是 NLP。区别：① 可行域——LP 是凸多面体（线性约束的交，Th2.2），NLP 一般不是凸集；② 最优解位置——LP 若有最优解必可在极点达到（Th2.3、Th2.4），NLP 最优解可在内部或边界任意位置，用 KKT 刻画；③ 局部与全局——LP 是凸规划，局部最优即全局最优，NLP 一般不成立；④ 算法——LP 用单纯形法、两阶段法、大 M 法，NLP 用最速下降、牛顿、共轭梯度、拟牛顿、可行方向法、罚函数法等。

**套路**：分类判据一句 → 四条对比 → 收尾"LP 是 NLP 的特例"。
**易错**："最优解在极点"前提是"有最优解"；x ≥ 0 是线性约束。

### S3 对偶函数 🟡【补充储备】

**知识点**：θ(u,v) = inf\_x L(x,u,v)，L = f − Σuᵢgᵢ − Σvⱼhⱼ（uᵢ ≥ 0）；θ 是凹函数（一族仿射函数的逐点下确界）；u ≥ 0 时 θ ≤ f\*（弱对偶给下界）；对偶问题 = max θ s.t. u ≥ 0；凸规划 + 约束规格 ⇒ 强对偶，KKT 点乘子即对偶最优解。

**例题**：什么是对偶函数？它有哪些性质？

**参考答案**：先构造 Lagrange 函数 L(x,u,v) = f(x) − Σuᵢgᵢ(x) − Σvⱼhⱼ(x)（uᵢ ≥ 0），对偶函数定义为固定乘子后对 x 取下确界 θ(u,v) = inf\_x L(x,u,v)。性质：① θ 是凹函数——L 对 (u,v) 是仿射的，一族仿射函数的逐点下确界是凹的；② 弱对偶性——u ≥ 0 时对任意可行 x 有 L ≤ f(x)，故 θ(u,v) ≤ f\*，给出原问题最优值的下界；对偶问题即 max θ(u,v) s.t. u ≥ 0；若原问题是凸规划且满足约束规格，强对偶成立，原、对偶最优值相等，KKT 点处乘子即对偶最优解。

**套路**：定义 → 凹性理由 → 弱对偶 → 强对偶条件 → KKT 联系。
**易错**：写成凸函数/极小化；inf 写"下确界"更严谨；弱对偶不需凸性，强对偶才需要。

### S4 凸集与凸函数的关系 🟡

**知识点**：凸集 C：λx+(1−λ)y ∈ C；凸函数 f（定义域须凸）：f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)；上镜图 epi f 凸 ⇔ f 凸（充要）；水平集凸只是必要（拟凸）；凸集之交仍凸、凸函数非负加权和仍凸；凸集上凸函数局部极小 = 全局极小。

**例题 A（用定义验证凸集）**：验证 S = {(x₁, x₂) | x₂ ≥ |x₁|} 是凸集。

**参考答案**：任取 x⁽¹⁾=(a₁,a₂)、x⁽²⁾=(b₁,b₂) ∈ S，λ∈\[0,1]，令 x = λx⁽¹⁾+(1−λ)x⁽²⁾，则
x₂ = λa₂+(1−λ)b₂ ≥ λ|a₁|+(1−λ)|b₁| ≥ |λa₁+(1−λ)b₁| = |x₁|
（第二步用绝对值函数的凸性 |λa+(1−λ)b| ≤ λ|a|+(1−λ)|b|。）故 x ∈ S，S 为凸集。∎
几何意义：S 是 |x₁| 的上镜图，|x₁| 是凸函数，凸函数的上镜图必为凸集。

**例题 B（凸函数判别 + 凸性保持）**：判断 f(x₁,x₂) = x₁² − 2x₁x₂ + x₂² + x₁ + x₂ 是否为凸函数；并证明两凸函数之和仍为凸函数。

**参考答案**：(1) 是凸函数，但不是严格凸函数。Hessian 法最快：∇f = (2x₁−2x₂+1, −2x₁+2x₂+1)，∇²f = \[\[2,−2],\[−2,2]]，特征值 0 与 4 均非负 ⇒ 半正定 ⇒ f 凸；因存在零特征值，非严格凸。（备选：f = (x₁−x₂)² + x₁ + x₂，平方项半正定 + 线性项既凸又凹。）
(2) 证明：任取 x, y 与 λ∈\[0,1]，由定义 f₁(λx+(1−λ)y) ≤ λf₁(x)+(1−λ)f₁(y)、f₂ 同理，两式相加即得 (f₁+f₂)(λx+(1−λ)y) ≤ λ(f₁+f₂)(x)+(1−λ)(f₁+f₂)(y)，故 f₁+f₂ 为凸函数。∎

**套路**：判别三路线按条件选 —— 无可微条件用定义、一阶可微用一阶判别 f(y) ≥ f(x)+∇f(x)ᵀ(y−x)、二阶可微用 Hessian 半正定（最快）；"证明类"一律回到定义；Th2.16 / 2.16\* / 2.17 即这三条。

**易错**：上镜图凸是充要、水平集凸只是必要（最常考辨析）；凸函数定义不能漏"定义域为凸集"；可行域凸 ≠ 凸规划。

### S5 Farkas 定理的几何表示（必考第 1 条，要画图）🔵

**知识点**：定理 2.11：Ax ≤ 0、cᵀx > 0 有解 ⟺ Aᵀy = c、y ≥ 0 无解；置换定理 2.11′：c ∈ cone(A)；经典择一形式：(i) ∃x, Ax=b, x≥0 ⟺ (ii) ∃y, Aᵀy≤0, bᵀy>0，有且仅一个成立；Gordan 定理 2.12：Ax < 0 有解 ⟺ 不存在非零 y ≥ 0 使 Aᵀy = 0；证明走凸集分离定理 Th2.7 / 推论 2.2。

**例题**：从几何角度绘图解释 Farkas 定理。

**参考答案**：记 A 的列向量为 a₁,…,aₙ，锥 C(A) = {Ax : x ≥ 0} = cone{a₁,…,aₙ}（二维下即两向量张成的楔形）。

* 情形 1（b 在锥内）：b ∈ C(A)，b 可表成列向量的非负组合，(i) 成立；
* 情形 2（b 在锥外）：由凸集分离定理，存在过原点的超平面把 b 与 C(A) 严格分离。设法向量为 y，则 y 与 C(A) 中每个向量内积 ≤ 0，即 aᵢᵀy ≤ 0 ⇒ Aᵀy ≤ 0；b 在法向所指一侧 ⇒ bᵀy > 0，(ii) 成立。
两情形互斥（同时成立则 bᵀy = xᵀAᵀy ≤ 0，矛盾），故二择一。

**套路（30 秒画图）**：① 画原点 O → ② 从 O 画两条生成向量 a₁、a₂，夹角涂阴影为 C(A) → ③ b 在阴影内：标 b = α₁a₁+α₂a₂（α ≥ 0）→ ④ b 在阴影外：过 O 画分离直线，法向 y 箭头指向 b，标 y 与 a₁、a₂ 夹角钝角（Aᵀy ≤ 0）、与 b 夹角锐角（bᵀy > 0）。

**易错**：分离超平面必须过原点（C(A) 是锥）；两种情形都要会画；"有且仅有一个"要写出来。

### S6 现代优化算法与传统优化算法 🟡（开放题同用）

**知识点**：差别 5 条（搜索性质 / 函数要求 / 最优性保证 / 适用问题 / 计算代价）+ 联系 4 条（迭代骨架同源 / 共用理论 / 互补融合 / 跳出局部机制同源）。口径（CH1-2 PPT）：传统 = 局部搜索 + 至少一阶可微 + 确定性；现代 = 面向 NP-hard 的全局随机搜索，无最优性保证，给可接受精度内满意解。

**例题**：现代优化算法与传统优化算法有什么区别和联系？

**参考答案（差别 5 条 + 联系 4 条骨架）**：
差别：① 搜索性质——传统本质是局部搜索，依赖初值、沿下降方向确定性迭代；现代（GA/SA/TS/DE）是全局随机搜索，种群/温度驱动，同一初值不同随机数结果不同。② 函数要求——传统要求目标至少一阶连续可微，常需梯度甚至 Hessian；现代只需目标值/适应度可计算，不要求可导，可处理不可微、离散、含噪问题。③ 最优性保证——传统有 KKT、F-J 与收敛性定理；现代无最优性证明，只在概率意义上收敛到全局最优附近。④ 适用问题——传统适合凸或光滑小规模问题，对 NP-hard 无能为力；现代面向 NP-hard 的全局优化与组合优化。⑤ 计算代价——传统单次迭代快、精度高；现代需大量函数评价、参数敏感。
联系：① 同一问题模型、同一迭代骨架（产生候选解 → 评价 → 更新 → 停机；传统每步也写成 x\_{k+1}=x\_k+λₖdᵏ）；② 共用同一套最优化理论（凸性、下降方向、KKT/F-J、罚函数法——GA/SA 处理约束用的就是罚函数法）；③ 互补融合（现代全局探索 + 传统局部精修：memetic 算法、Multi-Start）；④ 跳出局部最优的机制同源（单纯形摄动/Bland 规则 ↔ SA 概率接受劣解、TS 禁忌表）。

**套路**：差别按"搜索 / 可微性 / 保证 / 适用 / 代价"五维各一句；联系四条必须写全（开放题得分点）。
**易错**：不能说"保证找到全局最优"；联系别写"完全不同"。

### S7 优缺点类 🟡

**例题**：比较最速下降方向与牛顿下降方向；两种方法各有什么优缺点？牛顿法的缺点如何解决？

**参考答案**：方向：最速下降 d = −∇f（函数下降最快的方向，单位化 d=−∇f/‖∇f‖）；牛顿方向 d = −H⁻¹∇f（解 Hd = −∇f，是椭球范数意义下的最速下降）。
最速下降法：优点——概念简单，每步只需算梯度，计算量与存储小，不需要 Hessian，每步局部下降最快；缺点——收敛慢，靠近极小点出现"锯齿形"（zig-zag），相邻两步方向近似正交；线性收敛，收敛比依赖 Hessian 条件数；只有一阶信息不利用曲率。
牛顿法：优点——利用二阶信息，极小点附近二阶（二次）收敛；对正定二次函数理论上一步到达极小点；无锯齿现象。缺点——每步要算 Hessian 并解线性方程组，n 大时 O(n³) 昂贵；Hessian 可能非正定甚至奇异，方向可能不是下降方向；只有局部收敛性，初值远时可能发散；要求二阶可微。
补救（配表写）：Hessian 非正定/奇异 → 阻尼牛顿法（牛顿方向 + 一维搜索保证下降）或修正牛顿法（修正为 Gₖ 正定）；算 Hessian 太贵 → 拟牛顿法（DFP/BFGS 用梯度差近似）或共轭梯度法（只用梯度、避免锯齿）；远处不稳 → 线搜索限制步长；要求二阶可微 → 改一阶方法。

**套路**：两条方向公式 → 各 2 优点 2 缺点 → 补救配小表（毛病 → 药方）。
**速记**：牛顿法两大毛病"贵"与"娇气"；两条药方：阻尼/修正保方向，拟牛顿/共轭省二阶计算。

### S8 一句话储备（防概念小题）⚪

|问|一句话答案|
|-|-|
|智能优化是什么|面向 NP-hard 全局优化问题的随机搜索方法（GA、SA、TS、DE、蚁群），不依赖梯度、无最优性保证，在可接受时间和精度内给出满意解|
|运输问题|一类特殊 LP——把供应地物资运到需求地，产销平衡约束下最小化总运费；表上作业法三步：求初始解（西北角/最小元素法）→ 最优性检验（闭回路/位势法）→ 沿闭回路调整运量|
|LP 对偶|每个 LP 都伴随对偶问题（原 min ⇔ 对偶 max）；弱对偶：对偶可行目标值 ≤ 原可行目标值；强对偶：原问题有最优解则对偶也有且目标值相等；最优处互补松弛|
|多面体表示定理|有界多面体 = 它的极点的凸组合；无界多面体 = 极点凸组合 + 极方向非负组合|
|为什么 LP 最优解在极点|可行域是凸集（Th2.2）；最优解不在极点则可沿可行方向继续改进；由多面体表示定理任一点可表为极点凸组合，目标线性 ⇒ 最优值在某个极点达到（Th2.3）|
|基本可行解与极点关系|极点集 ≡ BFS 集（Th2.4）；求初始 BFS 就是找一个极点，两阶段法第一阶段即此用|
|单纯形法原理|从某 BFS 出发，用检验数判断是否最优；否则按最小比值规则换基得相邻 BFS，目标值严格下降；相容非退化时有限步终止（Th3.4）|
|什么是可行方向法|从可行点出发，在可行方向中找使目标下降的方向，沿方向一维搜索得新可行点，迭代至 KKT 点|
|罚函数法基本思想|构造辅助函数把约束问题化为无约束问题；外点法从外部逼近、罚因子趋于无穷；内点法从内部逼近、罚因子趋于 0|
|共轭梯度法为什么快|沿 n 个 A 共轭方向一维搜索，子空间扩张到整个 n 维空间（Th10.3.2），不超过 n 步终止；且不用 Hessian，存储小|
|拟牛顿法思想|用 f 与一阶导数信息构造 Hessian 逆的近似（满足割线方程 p=Hq），不必显式形成 Hessian|
|收敛速度分类|线性（0<β<1）、超线（β=0）、次线性（β=1）、p 阶收敛|
|一维搜索的闭性|f 连续、d 非零，则由 min f(x+λd) 定义的算法映射 M 在 (x,d) 处是闭的（Th9.1.1），是证算法收敛的标配工具|

## 三、计算大题（知识点 + 例题 + 完整答案 + 套路）

### C1 两阶段法 🔴（20 分档）

**知识点**：≥ 约束减过剩变量（系数 −1）→ 加人工变量凑单位阵 → 第一阶段 min w = Σaᵢ → w\*=0 才转第二阶段（w\*>0 ⇒ 原问题无可行解）→ 删人工列、换原目标、检验数全部重算继续迭代。σⱼ = cⱼ − c\_BᵀB⁻¹Aⱼ；入基取最负 σ（min 口径）；出基 min{bᵢ/aᵢⱼ : aᵢⱼ>0}；人工变量 ≠ 松弛变量（松弛费用 0 可留基，人工必须离基/为 0）。

**例题**（CH3 s042）：min z = 5x₁ + 21x₃，s.t. x₁−x₂+6x₃ ≥ 2；x₁+x₂+2x₃ ≥ 1；x ≥ 0。

**标准化**：x₁−x₂+6x₃−x₄ = 2、x₁+x₂+2x₃−x₅ = 1。

**答案（五张表轨迹）**：

|轮|基|基解|关键检验数|入基/出基|
|-|-|-|-|-|
|P1-1|(a₁,a₂)|(2,1)|σ₃=−8 最负|x₃ 入，a₁ 出（θ=1/3）|
|P1-2|(x₃,a₂)|(1/3,1/3)|σ₂=−4/3 最负（σ₁=−2/3、σ₄=−1/3）|x₂ 入，a₂ 出（θ=1/4）|
|P1-3|(x₃,x₂)|(3/8,1/4)|全 0 ⇒ w\*=0|过渡 ✓|
|P2-1|(x₃,x₂)|(3/8,1/4)|σ₁=−1/4 最负（σ₄=σ₅=21/8）|x₁ 入，x₂ 出（θ=1/2）|
|P2-2|(x₃,x₁)|(1/4,1/2)|σ=(0, 1/2, 0, 11/4, 9/4) ≥ 0|最优|

*结论：x = (1/2, 0, 1/4, 0, 0)ᵀ，z* = 5(1/2)+21(1/4) = 31/4\*\*（两约束同时取等；三维顶点枚举独立复核）。

**答题套路**：

1. 标准化（≥ 减过剩、bᵢ<0 先乘 −1）；
2. 加人工变量，写第一阶段目标 min w = Σaᵢ，以 (a₁,…,aₘ) 为初始基；
3. 列表迭代，每轮四步：定主元 → 主行归一（÷p，含 b 列）→ 其余行消元（行 i ← 行 i − 该列元素×新主行）→ σ 行重算（c\_B 随基变必须重算）；
4. 写过渡判据句"第一阶段最优表中人工变量全部离基且 w\*=0，得原问题一个 BFS"；
5. 删人工列、换原目标、重算全部 σ，继续到 σ 全 ≥ 0；
6. 报 x\* 和 z\*（必须报 z\*）。

**易错**：过剩变量写成加；σ 沿用上一行；w\*>0 结论写成无界（应为无可行解）；不写判据句；漏报 z\*；比值检验只看入基列正元素。

### C2 大 M 法 🔵

**知识点**：人工变量费用设 +M（符号常数，不进数值表），min z = 原费用 + M·Σaᵢ，一张表到底；检验数先比 M 系数再比常数；两阶段法是它的数值安全版。

**例题**（CH3 s060）：max z = 5x₁+2x₂+3x₃−x₄，s.t. x₁+2x₂+3x₃=15；2x₁+x₂+5x₃=20；x₁+2x₂+4x₃+x₄=26；x ≥ 0。

**答案**：化为 min z′ = −5x₁−2x₂−3x₃+x₄ + M(x₅+x₆)（x₅、x₆ 为前两个等式的人工变量）；最优解 (25/3, 10/3, 0, 11)，max z = 112/3。

**套路**：同单纯形，只多一步"目标加 M·人工变量"；max 先化 min；报解时确认 M 项已离基。

### C3 共轭梯度法 FR 🔴

**知识点**：共轭方向 d⁽ⁱ⁾ᵀAd⁽ʲ⁾ = 0（i≠j）；Th10.3.1 共轭向量组线性无关；Th10.3.2 扩张子空间定理（沿 k 个共轭方向一维搜索得线性流形上唯一极小，k=n 即全局最优）；FR 公式 λᵏ = −gᵏᵀd⁽ᵏ⁾/(d⁽ᵏ⁾ᵀAd⁽ᵏ⁾)(10.3.17)、βᵏ = ‖gₖ₊₁‖²/‖gₖ‖²(10.3.24)、d⁽ᵏ⁺¹⁾ = −gₖ₊₁ + βᵏd⁽ᵏ⁾(10.3.18)；Th10.3.3 二次终止（n 维正定二次函数至多 n 步）；β 两种写法等价（10.3.19 与 10.3.24），答 FR 写梯度式。

**例题**（(10-2).pdf p22，例10.3.2）：min f = x₁² + 2x₂²，x⁽¹⁾ = (5,5)ᵀ。

**答案**：

|步|结果|
|-|-|
|g₁ = ∇f(x⁽¹⁾)|(10, 20)ᵀ|
|d⁽¹⁾ = −g₁|(−10, −20)ᵀ|
|φ(λ) = (5−10λ)² + 2(5−20λ)²，φ′(λ)=0|λ₁ = 5/18|
|x⁽²⁾ = x⁽¹⁾+λ₁d⁽¹⁾|(20/9, −5/9)ᵀ|
|g₂|(40/9, −20/9)ᵀ|
|β₁ = ‖g₂‖²/‖g₁‖²|4/81|
|d⁽²⁾ = −g₂ + β₁d⁽¹⁾|(100/81)(−4, 1)ᵀ|
|φ′(λ) = 0|λ₂ = 9/20|
|x⁽³⁾，g₃ = 0 ⇒ 终止|(0, 0)ᵀ，f\* = 0，两步终止|

验证：g₂ᵀg₁ = 0（相邻梯度正交）；d⁽¹⁾ᵀAd⁽²⁾ = 0（共轭，A = diag(1,2)）；2 步 = n，符合 Th10.3.3。

**答题套路**：① 求 ∇f，d⁽¹⁾ = −g₁（第一轮没有旧方向，就是最速下降）→ ② 代入 x+λd 得 φ(λ)，令 φ′(λ)=0 解 λₖ（二次函数可用捷径 λ=−gᵀd/(dᵀAd)）→ ③ x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾+λd⁽ᵏ⁾，算 gₖ₊₁ → ④ gₖ₊₁=0 ⇒ 终止 → ⑤ βₖ = ‖gₖ₊₁‖²/‖gₖ‖² → ⑥ d⁽ᵏ⁺¹⁾ = −gₖ₊₁+βₖd⁽ᵏ⁾ → ⑦ 下一轮与第一轮完全相同。

**易错**：初始方向不用 −∇f；β 用错式子；忘记报 f\*。

### C4 拟牛顿法 DFP 🔴

**知识点**：拟牛顿条件（割线方程）p = Hq，p = x⁽ᵏ⁺¹⁾−x⁽ᵏ⁾、q = gₖ₊₁−gₖ；DFP 秩 2 校正：

&#x20;   Hₖ₊₁ = Hₖ + ppᵀ/(pᵀq) − (Hₖq)(Hₖq)ᵀ/(qᵀHₖq)


H₁ 默认 I（题目给了就用给的）；Th10.4.1 Hᵢ 对称正定；Th10.4.2 共轭性 + 二次终止，推论 H\_{n+1} = A⁻¹；BFGS(10.4.32/10.4.35，经 Sherman-Morrison)、Broyden 簇(10.4.36–38)。

**例题**（(10-2).pdf p56，练习题2）：min f = x₁² + 3x₂²，x⁽¹⁾ = (1,−1)ᵀ，H₁ = \[2 1; 1 1]。

**答案**：

1. g = (2x₁, 6x₂)ᵀ ⇒ g₁ = (2, −6)ᵀ；
2. d⁽¹⁾ = −H₁g₁ = (2, 4)ᵀ（不是 −g₁）；
3. φ(λ) = (1+2λ)² + 3(4λ−1)²，φ′(λ) = 104λ − 20 = 0 ⇒ λ₁ = 5/26；
4. x⁽²⁾ = (18/13, −3/13)ᵀ；g₂ = (36/13, −18/13)ᵀ；
5. p⁽¹⁾ = (5/13, 10/13)ᵀ；q⁽¹⁾ = (10/13, 60/13)ᵀ；pᵀq = 50/13；H₁q = (80/13, 70/13)ᵀ；qᵀH₁q = 5000/169；
6. H₂ = H₁ + ppᵀ/(pᵀq) − (H₁q)(H₁q)ᵀ/(qᵀH₁q) = (1/650)\[\[493, −28], \[−28, 113]]；
7. d⁽²⁾ = −H₂g₂ = (−54/25, 9/25)ᵀ；φ′(λ) = (6318λ − 4050)/625 = 0 ⇒ λ₂ = 25/39；

### C5 KKT + 局部极小点验证 🔴（KKT 必考）

**知识点**：L = f − Σuᵢgᵢ − Σvⱼhⱼ；KKT：∇f − Σuᵢ∇gᵢ − Σvⱼ∇hⱼ = 0，uᵢ ≥ 0，互补松弛 uᵢgᵢ(x)=0；正则点 + 凸规划 ⇒ KKT 即全局最优（Th7.2.10）；二阶：∇²ₓₓL = ∇²f − Σuᵢ∇²gᵢ − Σvⱼ∇²hⱼ（减号！）在临界锥上正定；F-J（Th7.2.8）允许 w₀=0，KKT 要求 w₀>0；无约束：一阶必要 ∇f=0、二阶必要 H 半正定、二阶充分 H 正定、凸函数 ∇f=0 充要。

**例题 A**（(7).pdf p32）：min (x₁−2)²+x₂²，s.t. x₁−x₂² ≥ 0，−x₁+x₂ ≥ 0；问 x⁽¹⁾=(0,0)、x⁽²⁾=(1,1) 是否为 K-T 点。
**答案**：(0,0) 处解得 w₁ = −4 < 0 ⇒ 不是 KKT 点；(1,1) 处 w₁ = 0、w₂ = 2 ⇒ 是 KKT 点（w₁=0 是"弱起作用"陷阱：约束不起作用时乘子为 0 仍满足 KKT）。

**例题 B**（验证局部极小点）：min f = 4x₁ − 3x₂，s.t. c₁ = 4−x₁−x₂ ≥ 0，c₂ = −7−x₂ ≤ 0，c₃ = −(x₁−3)²+x₂+1 ≥ 0；验证 x\* = (1,3)ᵀ 是否为局部极小点。

**答案**：

|步|结果|
|-|-|
|代入约束|c₁=0（活动）/ c₂=−10（不活动）/ c₃=0（活动），I = {1,3}|
|≥0 统一形式|g₁=4−x₁−x₂、g₂=7+x₂、g₃=−(x₁−3)²+x₂+1|
|∇f / ∇g₁ / ∇g₃（x\* 处）|(4,−3)ᵀ / (−1,−1)ᵀ / (4,1)ᵀ|
|KKT：4 = −u₁+4u₃，−3 = −u₁+u₃|u₁ = 16/3、u₃ = 7/3，均 > 0 ⇒ KKT 点|
|∇²ₓₓL = −u₃∇²g₃|diag(14/3, 0) ⪰ 0（奇异，单看它不能下结论）|
|切锥 T|d₂ ≤ −d₁ 且 d₂ ≥ −4d₁（开口朝右的尖角）|
|临界锥：4d₁−3d₂=0 ⇒ d = t(3,4)ᵀ；−7t≥0 ⇒ t≤0；16t≥0 ⇒ t≥0|t = 0，C = {0} ⇒ 二阶充分条件成立|
|路线 A（定义法）|两约束相容 ⇒ (x₁−1)(x₁−4) ≤ 0 ⇒ x₁ ≥ 1；x₂ 系数 −3<0 用上界：f ≥ 4x₁−3(4−x₁) = 7x₁−12 ≥ −5 = f(x\*)，等号仅 x\* 成立|
|结论|x\* = (1,3)ᵀ 是严格局部极小点（且唯一全局极小），u\* = (16/3, 0, 7/3)ᵀ|

**答题套路（四步；KKT 失败 ⇒ 答"不是"，直接收工）**：

1. 可行性与活动约束：代入每条约束，取等的为活动集 I；≤ 约束先翻成 ≥ 形式再取梯度；
2. 一阶必要（KKT）：解 ∇f = Σ\_{i∈I} uᵢ∇gᵢ（uᵢ ≥ 0，不活动约束 uᵢ=0 自动满足互补松弛）；解出某个 uᵢ < 0 ⇒ x\* 不是局部极小点，答题结束；
3. 充分性（二阶）三选一：

   * 路线 A 定义法（首选，纯代数）：① 活动约束联立推出自变量被夹的范围；② f 中系数为负的变量用约束上界放缩消元（系数为正用下界）；③ 代入范围得 f(x) ≥ … ≥ f(x\*)；④ 写明等号只在 x\* 成立；
   * 路线 B 切锥放缩：切锥不等式整理成 d 的分量关系，把 ∇fᵀd 放缩出正下界 ⇒ 所有可行方向一阶都在涨；
   * 路线 C 临界锥 + Hessian（题目点名"用最优性条件验证"时用）：① 切锥 T = {d : ∇gᵢᵀd ≥ 0, i∈I}；② 令 ∇fᵀd = 0 解出候选方向 d = t(·)ᵀ；③ 代回切锥不等式两边夹出 t = 0 ⇒ C = {0} ⇒ 二阶充分条件成立；④ 只有夹出非零 t（C 非空）时才真算 dᵀ∇²ₓₓL d > 0；
4. 结论句（任选其一直抄）：

   * 「x\* 处 ∇fᵀd ≥ 7d₁ > 0 对一切非零可行方向 d 成立，故 x\* 为严格局部极小点。」
   * 「临界锥 C = {0}，二阶充分条件成立，故 x\* 为严格局部极小点。」
   * 「对任意可行点 x ≠ x\* 有 f(x) ≥ 7x₁ − 12 > −5 = f(x\*)，故 x\* 为严格（唯一）局部极小点。」

**选路表**：f 线性 → A 或 B；活动约束梯度平行（相切）或有等式约束 → 必须 C；f 非线性、约束简单 → A；题目点名"用最优性条件验证" → C 的写法。

**易错**：KKT 过了就写"故为极小点"（KKT 只是必要条件）；∇²ₓₓL 符号写反；Hessian 半正定不能说"二阶充分条件成立"（要靠 C={0} 收口）；定义法漏相容性那步；≤ 约束方向搞反。

### C7 一维搜索：0.618 法 / Fibonacci 法 🟡

**知识点**：单峰函数（Df9.2.1）一次比较砍一段；Th9.2.1 比较规则；缩减率 τ = (bₖ₊₁−aₖ₊₁)/(bₖ−aₖ)；0.618：λ₁ = a+0.382(b−a)、μ₁ = a+0.618(b−a)，旧点复用，除首轮外每轮只算 1 个新函数值；缩率 r = (√5−1)/2 ≈ 0.618（由 r² = 1−r 解出，等距 + 旧点复用 ⟹ Lₖ = Lₖ₊₁+Lₖ₊₂）；Fibonacci：定最小 n 使 Fₙ ≥ (b₁−a₁)/δ，第 k 轮 λₖ = aₖ + F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎(bₖ−aₖ)、μₖ = aₖ + F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎(bₖ−aₖ)，末轮用辨别常数 δ 错开；函数逼近法：牛顿法（一元）x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − f′(x⁽ᵏ⁾)/f″(x⁽ᵏ⁾)，至少 2 阶收敛；割线法用差商代二阶导，超线性（阶 ≈1.618）。

**例题**（(9).pdf p21）：min f(x) = 2x² − x − 1，初始区间 \[−1,1]，精度 L ≤ 0.16。
**答案**（真实极小点 x\*=0.25）：

* 第 1 轮：λ₁ = −0.236、λ₂ = 0.236；f(λ₁)=−0.6526 > f(λ₂)=−1.1246 ⇒ 区间 \[−0.236, 1]（长 1.236）；
* 第 2 轮：复用 λ₂ 作新 λ₁，新 λ₂ = −0.236+0.618×1.236 = 0.5278；f(0.236) ≤ f(0.5278)=−0.9706 ⇒ \[−0.236, 0.5278]（长 0.764）；
* 第 3 轮：新 λ₁ = 0.0558；f(0.0558) > f(0.236) ⇒ \[0.0558, 0.5278]（长 0.472）；
* 第 4 轮：新 λ₂ = 0.3475；f(0.236) ≤ f(0.3475) ⇒ \[0.0558, 0.3475]（长 0.292）；
* 第 5 轮：新 λ₁ = 0.1672；f(0.1672) > f(0.236) ⇒ \[0.1672, 0.3475]（长 0.180）；
* 第 6 轮：新 λ₂ = 0.2786；f(0.236) ≤ f(0.2786) ⇒ \[0.1672, 0.2786]（长 0.111 ≤ 0.16，停止）；取中点 ≈ 0.223 作近似极小点。

**例题**（(9).pdf p30，Fibonacci）：min φ(x) = x² − x + 2，初始区间 (−1,3)，L ≤ 0.08，迭代两次。
**答案**：

* 定 n：b₁−a₁ = 4，Fₙ ≥ 4/0.08 = 50；F₈ = 34 < 50、F₉ = 55 ≥ 50 ⇒ n = 9；
* 第 1 次迭代：λ₁ = −1+(21/55)·4 = 29/55，μ₁ = −1+(34/55)·4 = 81/55（等距自检 b₁−λ₁ = μ₁−a₁ = 136/55 ✓）；φ(λ₁) = 5296/3025 < φ(μ₁) = 8156/3025 ⇒ 丢右段，\[a₂,b₂] = \[−1, 81/55]（长 136/55 = 4×34/55 ✓）；
* 第 2 次迭代：新算 λ₂ = −1+(13/34)(136/55) = −3/55；μ₂ 复用旧点 = 29/55 = λ₁ ✓；φ(λ₂) = 6224/3025 > φ(μ₂) ⇒ 丢左段；
* 结论：\[a₃,b₃] = \[−3/55, 81/55]，长 84/55 ≈ 1.527，缩为初始的 21/55 ≈ 38.2%（真极小点 x\* = 1/2 在区间内 ✓）。

**答题套路**：① 判单峰、写 φ(λ) → ② 按公式取两点（自检两点到端点等距、系数和为 1）→ ③ 比函数值定丢哪段（φ(λₖ) > φ(μₖ) 丢左段 \[aₖ,λₖ]）→ ④ 复用旧点、只算 1 个新点 → ⑤ 到达精度取区间中点（或较优点）。

**易错**：Fibonacci 取点分母是 F₍ₙ₋ₖ₊₁₎（随 k 变），不是 Fₙ₊₁；定 n 取最小 n、F 表从 F₀=F₁=1 数起；λ 恒为左点、μ 恒为右点；别拿 0.618 顶替 rₖ（同样 9 次计算，0.618 终区间 4×0.618⁸ ≈ 0.085 > 0.08 不达标，Fibonacci 4/55 ≈ 0.073 达标）。

### C8 最速下降 / 牛顿方向（10.1–10.2）🟡

**知识点**：最速下降 d = −∇f/‖∇f‖（Schwartz 不等式 ∇fᵀd ≥ −‖∇f‖）；收敛比 ((A−a)/(A+a))²、条件数 r = A/a 越小越快、锯齿现象（相邻梯度正交）；牛顿 d = −∇²f⁻¹∇f（椭球范数意义下的最速下降），严格二次凸函数一步到位、局部二阶收敛；阻尼牛顿 = 牛顿方向 + 一维搜索；修正牛顿 G\_k = ∇²f + ε\_kI；阻尼反例（Hessian 非正定时一维搜索得 λ₁=0，产生不了新点）。

**例题**（(10-1).pdf p36）：min f = (1/2)x₁² + (9/2)x₂²，x⁽⁰⁾ = (9,1)ᵀ。
**答案**：∇f = (x₁, 9x₂)ᵀ、∇²f = diag(1,9) ⇒ d⁽⁰⁾ = −∇²f⁻¹∇f = −(9, 9)ᵀ，x⁽¹⁾ = x⁽⁰⁾+d⁽⁰⁾ = (0,0)，一次迭代到极小点（正定二次函数）。
**套路**：算 ∇f、∇²f → d = −∇²f⁻¹∇f → x⁽¹⁾ = x⁽⁰⁾+d（纯牛顿 λ=1）→ 报 x\*、f\*；Hessian 非正定 ⇒ 转述阻尼/修正两条路。

### C9 Zoutendijk / Rosen 求可行下降方向 🟡（只考到求方向）

**知识点**：线性约束下 d 为可行方向 ⟺ A1d ≥ 0、Ed = 0（Th12.1.1，A1 起作用、A2 不起作用，每轮重分解）；方向 LP：min ∇f(x⁽ᵏ⁾)ᵀd s.t. A1d ≥ 0, Ed = 0, −1 ≤ dⱼ ≤ 1；最优值 <0 ⇒ 下降可行方向，=0 ⇒ x 为 KKT 点（Th12.1.2，证明用 Farkas 定理，令 v = p−q）；λmax = min{b̂ᵢ/d̂ᵢ : d̂ᵢ<0}（背景）；Rosen：M = (A1;E) 行满秩，P\_N(M) = I − Mᵀ(MMᵀ)⁻¹M，d = −P\_N(M)∇f ≠ 0 即下降可行方向（Th12.2.1）；Th12.2.2 前提是投影为 0 才判乘子 u ≥ 0 ⇔ KKT，u 有负分量删行重投影；非线性约束只拿到 F-J（Th12.1.4，证用 Gordan 定理）；收敛性缺陷：算法映射 A = M∘D 未必闭（Wolfe 1972 反例），Topkis-Veinott 修正（LP 右端改 −gᵢ(x)）。

**例题 A**（(12).pdf p42，Zoutendijk 三维）：min x₁²+2x₂²+3x₃²+x₁x₂−2x₁x₃+x₂x₃−4x₁−6x₂，s.t. x₁+2x₂+x₃ ≤ 4，x ≥ 0；求 x⁽⁰⁾ = 0 处的可行下降方向。
**答案**：原点处 ≤4 有裕量 4、不起作用，起作用的是 3 个非负约束 ⇒ A1 = I₃；∇f(x⁽⁰⁾) = (−4,−6,0)ᵀ；解 LP：min −4d₁−6d₂ s.t. 0 ≤ dⱼ ≤ 1 ⇒ 最优值 −10 < 0，d⁽⁰⁾ = (1,1,0)ᵀ ⇒ x⁽⁰⁾ 不是 KKT 点。

**例题 B**（(12).pdf p52，Rosen）：min x₁²+x₂²+2x₂+5，s.t. x₁−2x₂ ≥ 0，x₁ ≥ 0，x₂ ≥ 0；求 x⁽¹⁾ = (2,0)ᵀ 处的可行下降方向。
**答案**：仅 x₂ ≥ 0 起作用（x₁−2x₂ = 2 > 0 不起作用）⇒ M = (0 1)；P\_N(M) = diag(1,0)；∇f(x⁽¹⁾) = (4,2)ᵀ ⇒ d⁽⁰⁾ = −P\_N(M)∇f = (−4,0)ᵀ（∇fᵀd = −16 < 0，Md = 0 满足可行性）。

**例题 C**（(12).pdf p21–24，Zoutendijk 完整例，仅背景）：min x₁²+x₂²−2x₁−4x₂+6，s.t. −2x₁+x₂+1 ≥ 0，−x₁−x₂+2 ≥ 0，x₁,x₂ ≥ 0，初点 (0,0)ᵀ ⇒ ∇f⁽¹⁾=(−2,−4)ᵀ、A1=I、A2=\[−2 1; −1 −1]，方向 LP 得 d⁽¹⁾=(1,1)ᵀ，λmax = 1，一维搜索得 λ₁=1 ⇒ x⁽²⁾=(1,1)，最终 x\* = (1/2, 3/2)ᵀ。

**答题套路**：① 约束标准化（≤ 移项换向）→ ② 代入当前点定起作用集（先判起不起作用，原点处带裕量的约束不起作用）→ ③ Zoutendijk：写 A1/E、列方向 LP（含 |dⱼ| ≤ 1）、解 LP 得 d；Rosen：写 M、算投影得 d → ④ 验证下降性 ∇fᵀd < 0 + 可行性 → ⑤ 答"非 KKT 点，可行下降方向为 d"。

**易错**：跳过 LP 直接取 d = −∇f（一般不可行/非最优）；A1/A2 分解看错点；漏 |dⱼ| ≤ 1；∇f 下标写成别的点；M 多写不起作用的行。

### C10 惩罚函数法 🟡

**知识点**：思想 = 构造辅助函数把约束问题化为无约束问题（经济解释：总代价 = 价格 + 罚款）；外点 F = f + μP，等式罚项 Σhⱼ(x)²、不等式罚项 Σ(max{0,−gᵢ(x)})²，μ 很大且递增至 ∞，从可行域外逼近，可用于等式+不等式，判据 μₖP(x⁽ᵏ⁾) < ε；内点（障碍函数法）F = f + μB，B = Σ1/gᵢ 或 −Σlog gᵢ，μ 很小且递减至 0，从内部逼近，只适用于不等式约束且初始点必须严格内点，判据 μₖB(x⁽ᵏ⁾) < ε；引理13.1.1（F 与 f 非减、P 非增）、引理13.1.2（f(x\*) ≥ F ≥ f(x⁽ᵏ⁾)）、Th13.1.3（S\_ε 紧 + μ→∞ ⇒ 聚点最优）、Th13.2.1（内点子列极限最优）。

**例题 A**（(13).pdf p13，外点·等式）：min x₁²+x₂²，s.t. x₁+x₂−2 = 0。
**答案**：P(x) = (x₁+x₂−2)²，F = x₁²+x₂²+σ(x₁+x₂−2)²；令 ∂F/∂x₁ = 2x₁+2σ(x₁+x₂−2) = 0、∂F/∂x₂ = 0，相减得 x₁ = x₂，代回得 x₁ = x₂ = 2σ/(2σ+1) → (1,1)（σ→∞）；KKT：乘子 v = 4，f\* = 2。

**例题 B**（(13).pdf p14，外点·不等式）：min x²，s.t. g(x) = −x−1 ≥ 0（D = (−∞,−1]，x\* = −1）。
**答案**：P(x) = \[max{0,−g(x)}]² 分段，分段求导得 x(σ) = −σ/(1+σ) → −1。

**例题 C**（(13).pdf p29，内点）：min (x₁+1)³/12 + x₂，s.t. x₁−1 ≥ 0，x₂ ≥ 0。
**答案**：F = (x₁+1)³/12 + x₂ + μₖ(1/(x₁−1) + 1/x₂)；∂F/∂x₁ = (x₁+1)²/4 − μₖ/(x₁−1)² = 0、∂F/∂x₂ = 1 − μₖ/x₂² = 0 ⟹ x = (1+2√μₖ, μₖ) → (1,0)（μₖ→0）。

**例题 D**（(13).pdf p23，跨章综合）：min x₁²+x₂²，s.t. 2x₁+x₂−2 ≤ 0，x₂ ≥ 1；用最优性条件说明 (0,1) 是否为局部极小点。
**答案**：(0,1) 处 g₂ = x₂−1 = 0 起作用、g₁ = 2−2x₁−x₂ = 1 > 0 不起作用；∇f = (0,2) = 2·(0,1) ⇒ 乘子 u = 2 ≥ 0 ⇒ 是 KKT 点；又 x₂ ≥ 1 ⇒ f = x₁²+x₂² ≥ 1 = f(0,1) ⇒ 也是全局最优。

**答题套路（四问型）**：① 构造 F（写清罚项/障碍项与 μ 的位置）→ ② 对 F 求驻点（∂F/∂x = 0）解出闭式 x(μ)（障碍项符号别写反；负数根代回不可行要舍去）→ ③ 取 μ→∞（外点）/ μ→0（内点）得 x\*，报 f\* → ④ 对 x\* 验 KKT（别只写"极限即最优"）+ 凸性/Slater 证全局性。

**易错**：内外点 μ 方向相反（外↑内↓）；内点不能解等式约束；先把 μ=0 代入驻点方程会冒假根（如 x₂=0）。

## 五、Top 12 易错点（考前扫一遍）

1. ∇²ₓₓL = ∇²f − Σu∇²g − Σv∇²h，减号；
2. KKT 互补松弛 uᵢgᵢ(x) = 0 别漏；弱起作用 uᵢ = 0 仍算 KKT；
3. KKT 只是必要条件，充分性必须另证（临界锥 C={0} 或定义法）；
4. F-J 允许 w₀ = 0、KKT 要求 w₀ > 0；
5. 两阶段 w\* = 0 判据句必写；w\* > 0 ⇒ 原问题无可行解（不是无界）；
6. 第二阶段 c\_B 换了 ⇒ 检验数全部重算；比值检验只看入基列正元素；
7. FR 初始方向必须 −∇f；β 用 ‖gₖ₊₁‖²/‖gₖ‖²；
8. DFP 方向是 −Hₖgₖ 不是 −gₖ；p/q 别写反；g₃ = 0 即停；
9. Zoutendijk 方向 LP 的 |dⱼ| ≤ 1 别漏、别跳过 LP 直接取 −∇f；
10. Rosen 先判起作用约束再写 M；u 有负分量要删行重投影；
11. 内点不解等式约束、罚因子外↑内↓；极限点须 KKT 验证；
12. 简答写"全局最优"必须补"概率意义/近似"；现代算法无最优性保证。
