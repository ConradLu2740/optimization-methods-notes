## 三、必考第 1 条：Farkas 定理（补充知识2-凸分析.ppt s028–s036）

**定理 2.11（Farkas 定理）**　设 A 为 m×n 矩阵，c 为 n 维向量，则

    Ax <= 0,  c^T*x > 0 有解   <=>   A^T*y = c,  y >= 0 无解

**定理 2.11'（Farkas 置换定理）**　c 是 A 的行向量的凸锥组合，即

    c ∈ cone A   <=>   对任意满足 Ax <= 0 的 x，c^T*x <= 0

**经典择一形式**　设 A∈R^(m×n), b∈R^m，以下两个论断**有且只有一个**成立：

1. 存在 x∈R^n 使 Ax = b 且 x >= 0
2. 存在 y∈R^m 使 A^T*y >= 0 且 b^T*y < 0

**定理 2.12（Gordan 定理）**　Ax < 0 有解 <=> 不存在非零向量 y >= 0 使 A^T*y = 0

**证明路线**（PPT 已给）：凸集分离定理 Th2.7 / 推论 2.2 → Farkas（s029–s031：先证必要性 c^T*x>0 ⇒ A^T*y=c 无解，再证充分性）
