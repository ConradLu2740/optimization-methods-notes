## 1　拟牛顿法（DFP）　（2026-11-07 讨论核对）

**题目给什么**：min 目标 f、初始点 x⁽¹⁾、初始矩阵 H₁（没给时默认单位阵 I；给了就用给的）。

**通用步骤**：

1. 求**梯度函数** ∇f，代入当前点得 gₖ；
2. 搜索方向 **d⁽ᵏ⁾ = −Hₖgₖ**（负的"该步矩阵 × 梯度"，**不是 −gₖ**）；
3. 把 x⁽ᵏ⁾ + λd⁽ᵏ⁾ 代入目标得 φ(λ)，**求导令 φ′(λ) = 0** 解出步长 λₖ；
4. **x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λd⁽ᵏ⁾**，代入梯度函数得新梯度 gₖ₊₁；
5. 若 gₖ₊₁ = 0（或 ‖g‖ < ε）⇒ **终止**；否则算 p⁽ᵏ⁾ = x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾、q⁽ᵏ⁾ = gₖ₊₁ − gₖ，代入 **DFP 校正公式**得 Hₖ₊₁；
6. **下一轮与第一轮完全相同**（换 Hₖ₊₁、gₖ₊₁、x⁽ᵏ⁺¹⁾ 重走 2–5）。

**DFP 校正公式**：

    Hₖ₊₁ = Hₖ + ppᵀ/(pq) − (Hₖq)(Hₖq)/(qᵀHₖq)

**命名与术语**（考场简答用）：

- **Hₖ 叫啥**：Hessian 逆矩阵 (∇²f)⁻¹ 的**近似矩阵**，叫**拟牛顿矩阵**。它不是该点的 Hessian、也不是精确逆——是上一轮传下来、用 p 和 q 校正出来的近似；若每步真用精确逆就是牛顿法。正定二次函数校正 n 次后 H = A⁻¹ 精确成立。
- 由旧矩阵算新矩阵的公式叫**校正公式**（DFP 是秩 2 校正）。
- **为什么这么算**：新矩阵须满足**拟牛顿条件（割线方程）p = Hq**；DFP 是满足它且保持对称正定的构造法。
- **H₁ 默认 I**：那样第一步就是负梯度方向。
- **终止看 g = 0**：g₃ = 0 就停，H₃ 不用算。
- 拟牛顿法思想一句话：用 f 与一阶导数信息构造 Hessian 逆的近似（满足 p = Hq），不必显式形成 Hessian。

**已验证例题**（练习题2，(10-2).pdf p56；完整手推在第一册）：

min f = x₁² + 3x₂²，x⁽¹⁾ = (1, −1)ᵀ，H₁ = [2 1; 1 1]

| 步 | 结果 |
|---|---|
| g₁ = ∇f(x⁽¹⁾) | (2, −6)ᵀ |
| d⁽¹⁾ = −H₁g₁ | (2, 4)ᵀ |
| φ(λ) = (1+2λ)² + 3(4λ−1)²，φ′ = 104λ − 20 = 0 | λ₁ = 5/26 |
| x⁽²⁾ | (18/13, −3/13)ᵀ |
| g₂ | (36/13, −18/13)ᵀ |
| p⁽¹⁾ / q⁽¹⁾ | (5/13, 10/13)ᵀ / (10/13, 60/13)ᵀ |
| pᵀq / H₁q / qᵀH₁q | 50/13 / (80/13, 70/13)ᵀ / 5000/169 |
| H₂ | (1/650)[493 −28; −28 113] |
| d⁽²⁾ = −H₂g₂ | (−54/25, 9/25)ᵀ |
| φ′(λ) = (6318λ − 4050)/625 = 0 | λ₂ = 25/39 |
| x⁽³⁾，g₃ = 0 ⇒ 终止 | (0, 0)ᵀ，f* = 0 |

验证：d⁽¹⁾ᵀAd⁽²⁾ = 0（共轭）；再校正一次 H₃ = diag(1/2, 1/6) = A⁻¹。

## 2　共轭梯度法（FR）　（2026-11-07 讨论核对）

**题目给什么**：min 目标 f、初始点 x⁽¹⁾。（**没有矩阵要传**，一切从梯度出发；DFP 要给 H₁，FR 不用。）

**通用步骤**：

1. 求**梯度函数** ∇f，代入当前点得 gₖ；令 **d⁽¹⁾ = −g₁**（第一轮没有旧方向，就是最速下降）；
2. 把 x⁽ᵏ⁾ + λd⁽ᵏ⁾ 代入目标得 φ(λ)，**求导令 φ′(λ) = 0** 解出步长 λₖ；
3. **x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λₖd⁽ᵏ⁾**，代入梯度函数得新梯度 gₖ₊₁；
4. 若 gₖ₊₁ = 0 ⇒ **终止**（n 维正定二次函数最多 n 步到位，Th10.3.3 二次终止）；
5. 算 **βₖ = ‖gₖ₊₁‖² / ‖gₖ‖²**（FR 公式，Th10.3.4 / 10.3.24）；
6. **d⁽ᵏ⁺¹⁾ = −gₖ₊₁ + βₖd⁽ᵏ⁾**（新方向 = 负的新梯度 + β × 旧方向）；
7. **下一轮与第一轮完全相同**（换新点、新梯度、新方向重走 2–4）。

**FR 公式**：

    βₖ = ‖gₖ₊₁‖² / ‖gₖ‖²
    d⁽ᵏ⁺¹⁾ = −gₖ₊₁ + βₖ d⁽ᵏ⁾

**附：二次函数步长捷径**（只对二次函数成立，讲义 10.3.17）：λₖ = −gₖᵀd⁽ᵏ⁾ / (d⁽ᵏ⁾ᵀAd⁽ᵏ⁾)，其中 A 是 f = ½xᵀAx 的矩阵；与 φ′(λ) = 0 同结果，省一步展开。

**命名与术语**（考场简答用）：

- **共轭方向**：方向组满足 d⁽ⁱ⁾ᵀAd⁽ʲ⁾ = 0（i ≠ j）称**对 A 共轭**；A = I 时退化为正交。共轭向量组线性无关（Th10.3.1）。
- **d⁽ᵏ⁾ 的构成**：−gₖ（当前最速下降）+ βₖd⁽ᵏ⁻¹⁾（历史信息）。沿 k 个共轭方向各做一维搜索，在张成的线性流形上得唯一极小（扩张子空间定理 Th10.3.2）。
- **βₖ 两种写法等价**：‖gₖ₊₁‖²/‖gₖ‖²（10.3.24，只用梯度）与 d⁽ᵏ⁾ᵀAgₖ₊₁/(d⁽ᵏ⁾ᵀAd⁽ᵏ⁾)（10.3.19）；答 FR 就写前者。
- **二次终止（Th10.3.3）**：n 维正定二次函数 + 精确线搜索，FR 至多 n 步到全局极小；练习题 2 步 = n = 2。
- **第一步 = 最速下降**：没有旧方向可用，d⁽¹⁾ = −g₁。
- **对比拟牛顿**：共轭梯度**不存矩阵**，只留当前梯度与上一方向两三个向量；一般函数配一维搜索用，久不收敛可**重启**（令 d = −g 重来）。

**已验证例题**（练习题1，(10-2).pdf p25；与讲义例10.3.2（min x₁²+2x₂²，初点 (5,5)ᵀ）同型）：

min f = ½x₁² + x₂²，x⁽¹⁾ = (4, 4)ᵀ

| 步 | 结果 |
|---|---|
| g₁ = ∇f(x⁽¹⁾) | (4, 8)ᵀ |
| d⁽¹⁾ = −g₁ | (−4, −8)ᵀ |
| φ(λ) = ½(4−4λ)² + (4−8λ)²，φ′ = 144λ − 80 = 0 | λ₁ = 5/9 |
| x⁽²⁾ | (16/9, −4/9)ᵀ |
| g₂ | (16/9, −8/9)ᵀ |
| β₁ = ‖g₂‖²/‖g₁‖² = (320/81)/80 | 4/81 |
| d⁽²⁾ = −g₂ + β₁d⁽¹⁾ | (−160/81, 40/81)ᵀ |
| φ′(λ) = (3200λ − 2880)/729 = 0 | λ₂ = 9/10 |
| x⁽³⁾，g₃ = 0 ⇒ 终止 | (0, 0)ᵀ，f* = 0 |

验证：g₂ᵀg₁ = 0（相邻梯度正交）；d⁽¹⁾ᵀAd⁽²⁾ = 0（共轭，A = diag(1, 2)）；2 步 = n，符合 Th10.3.3。

## 3　牛顿法（切线法）　（2026-11-07 讨论核对）

**题目给什么**：min 单变量目标 f(x)、初始点 x⁽⁰⁾、迭代次数（或收敛判据）。
（单变量情形 = 一维搜索"函数逼近法"里对 φ′(λ) = 0 求根的牛顿法，也是第 10 章 10.2 牛顿法的 n = 1 特例。）

**通用步骤**：

1. 求 **f′(x)、f″(x)**（一阶 + 二阶导都要）；
2. 代入当前点 x⁽ᵏ⁾ 得 f′(x⁽ᵏ⁾)、f″(x⁽ᵏ⁾)；
3. **x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − f′(x⁽ᵏ⁾)/f″(x⁽ᵏ⁾)**（方向 d = −f′/f″，步长 λ = 1，纯牛顿不带一维搜索）；
4. 重复步骤 2–3 到指定次数，或 |f′(x⁽ᵏ⁾)| < ε 停。

**命名与术语**（考场简答用）：

- **来历**：在 x⁽ᵏ⁾ 处二阶 Taylor 展开取极小 ⇒ 迭代式；等价地，对 f′(x) = 0 用**切线法**求根，所以也叫**切线法**。本质是解 f′(x) = 0（一维搜索语境 = 解 φ′(λ) = 0）。
- **收敛**：局部**二阶收敛**（Th10.2.1），起步点要离根近；用到二阶导，每步比最速下降快、比割线法费信息。
- **危险点**：f″(x⁽ᵏ⁾) = 0 除零，发散；
- **f″ 非正定/为负 ⇒ 修正牛顿法**（构造正定修正矩阵 Gₖ 再迭代，10.2.3）；**加一维搜索 ⇒ 阻尼牛顿法**（牛顿方向 + φ′(λ)=0 定步长）。
- **求 f′ = 0 的根不辨极大小**：收敛到的驻点可能是极大点，要代 f″ 判性质。

**已验证例题**（2026-11-07 手稿题；数值经精确分数 + Python 复验）：

min f = 3x³ − 4x²，x⁽⁰⁾ = −1.2，迭代 2 次。f′ = 9x² − 8x，f″ = 18x − 8

| 步 | 结果 |
|---|---|
| x⁽⁰⁾ = −1.2 处 f′、f″ | 22.56、−29.6 |
| x⁽¹⁾ = x⁽⁰⁾ − f′/f″ = −1.2 + 22.56/29.6 | −81/185 ≈ −0.437838 |
| x⁽¹⁾ 处 f′、f″ | 5.22802、−15.88108 |
| x⁽²⁾ = x⁽¹⁾ − f′/f″ | −59049/543530 ≈ −0.108640 |

**陷阱（本例必看）**：f′ = x(9x−8) = 0 的驻点是 **x = 0**（f″ = −8，**极大点**）与 **x = 8/9**（f″ = 8，极小点，f* ≈ −1.0535）。从 −1.2 出发迭代会**收敛到 x = 0 这个极大点**（f′ 求根不辨极大小，且此处全程 f″ < 0）；f = 3x³ − 4x² 在 ℝ 上**无下界**（x→−∞ 时 f→−∞），全局 min 不存在。考题只要"迭代 2 次"就报表内数；若追问收敛性，答"收敛到 x = 0，是极大点，不是极小点 8/9"。

## 4　割线法　（2026-11-07 讨论核对）

**题目给什么**：min 单变量目标 f(x)、**两个**初始点 x⁽¹⁾、x⁽²⁾、迭代次数（或收敛判据）。
（一维搜索"函数逼近法"里对 φ′(λ) = 0 求根的割线法；牛顿法的低配版——**不用二阶导**。）

**通用步骤**：

1. 求 **f′(x)**（只要一阶导）；
2. 代入**最近两个已知点** x⁽ᵏ⁾、x⁽ᵏ⁻¹⁾ 得 f′(x⁽ᵏ⁾)、f′(x⁽ᵏ⁻¹⁾)；
3. **x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − f′(x⁽ᵏ⁾) · (x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾) / (f′(x⁽ᵏ⁾) − f′(x⁽ᵏ⁻¹⁾))**；
4. 丢掉最老的点，用最新两点 (x⁽ᵏ⁾, x⁽ᵏ⁺¹⁾) 重走 2–3，到指定次数或 |f′| < ε。

**命名与术语**（考场简答用）：

- **来历**：把牛顿法迭代式里的 f″(x⁽ᵏ⁾) 换成 f′ 的**两点差商（割线斜率）** (f′(x⁽ᵏ⁾) − f′(x⁽ᵏ⁻¹⁾))/(x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾)，即对 f′(x) = 0 作**割线法**求根；省一次二阶导，代价是要两个起点。
- **收敛**：**超线性**，收敛阶 ≈ 1.618（介于线性与牛顿二阶之间）。
- **易错点（本例手稿同款）**：f′ 的下标必须是**两个已知点**（(2) 与 (1)），**不能写待求的 (3)**——x⁽³⁾ 还没算出来，f′ 在它处无值可代。
- 与牛顿法相同：求 f′ = 0 **不辨极大小**，收敛点性质要代 f″ 判。

**已验证例题**（同上题，x⁽¹⁾ = −1.2、x⁽²⁾ = −0.8，迭代 2 次；数值经精确分数 + Python 复验）：

| 步 | 结果 |
|---|---|
| x⁽¹⁾ = −1.2、x⁽²⁾ = −0.8 处 f′ | 22.56、12.16 |
| x⁽³⁾ = x⁽²⁾ − f′(x⁽²⁾)(x⁽²⁾−x⁽¹⁾)/(f′(x⁽²⁾)−f′(x⁽¹⁾)) = −0.8 − 12.16×0.4/(−10.4) | −108/325 ≈ −0.332308 |
| x⁽³⁾ 处 f′ | 3.65232 |
| x⁽⁴⁾ = x⁽³⁾ − f′(x⁽³⁾)(x⁽³⁾−x⁽²⁾)/(f′(x⁽³⁾)−f′(x⁽²⁾)) | ≈ −0.131529 |

陷阱同牛顿法条目：两条序列从左侧都收敛到 **x = 0（极大点）**，真正极小点是 8/9。

## 5　验证局部极小点（约束优化：KKT + 二阶充分条件）　（2026-11-07 讨论）

**题目给什么**：min f(x)、若干约束（≥0 / ≤0 混着给）、待验证点 x\*，问 x\* **是否为**局部极小点。

**通用步骤**（总四步；KKT 失败 ⇒ 答"不是"，直接收工）：

1. **可行性与活动约束**：把 x\* 代入每条约束；取等号（= 0）的是**活动约束**，得活动集 I。≤ 0 约束先翻成 ≥ 0 形式再记（如 −7−x₂ ≤ 0 ⇒ g₂ = 7+x₂ ≥ 0）。
2. **一阶必要条件（KKT）**：算 ∇f 与活动约束的 ∇gᵢ，解 **∇f = Σ_{i∈I} uᵢ∇gᵢ**（uᵢ ≥ 0；不活动约束 uᵢ = 0，互补松弛自动满足）。**解出某个 uᵢ < 0 ⇒ x\* 不是局部极小点，答题结束**。
3. **充分性（二阶）**：KKT 通过只是"还可能是"，机械查**有没有一阶平坦的可行方向**（∇fᵀd = 0），三选一：
   - **路线 A 定义法**（首选，纯代数，零概念负担）：① 活动约束联立推出自变量被夹的范围（如 (x₁−1)(x₁−4) ≤ 0 ⇒ x₁ ≥ 1）；② f 中系数为负的变量用约束**上界**放缩消元（系数为正用下界）；③ 代入范围得 f(x) ≥ … ≥ f(x\*)；④ 写明等号只在 x\* 成立 ⇒ 严格局部极小。
   - **路线 B 切锥放缩**：切锥不等式 ∇gᵢᵀd ≥ 0 整理成 d 的分量关系，把 ∇fᵀd **放缩出正下界**（如 ≥ 7d₁ > 0）⇒ 所有可行方向一阶都在涨 ⇒ 严格局部极小。
   - **路线 C 临界锥 + Hessian**（教科书标准"二阶"，题目点名"用最优性条件验证"时用）：① 切锥 T = {d : ∇gᵢᵀd ≥ 0, i∈I}；② 令 ∇fᵀd = 0 解出候选方向 d = t(·)ᵀ；③ 代回切锥不等式**两边夹出 t = 0** ⇒ 临界锥 C = {0}；④ C 中无非零方向 ⇒ 二阶充分条件成立 ⇒ 严格局部极小。**只有夹出非零 t（C 非空）时才真算 dᵀ∇²ₓₓL d > 0**；∇²ₓₓL = −Σ_{i∈I} uᵢ∇²gᵢ（f 线性时 ∇²f = 0）。
4. **结论句**（任选其一直抄）：
   - 「x\* 处 ∇fᵀd ≥ 7d₁ > 0 对一切非零可行方向 d 成立，故 x\* 为严格局部极小点。」
   - 「临界锥 C = {0}，二阶充分条件成立，故 x\* 为严格局部极小点。」
   - 「对任意可行点 x ≠ x\* 有 f(x) ≥ 7x₁ − 12 > −5 = f(x\*)，故 x\* 为严格（唯一）局部极小点。」

**选路表**：

| 情况 | 走哪条 |
|---|---|
| f 线性 | A 或 B（两行完事） |
| 活动约束梯度**平行（相切）**或有等式约束 | 必须 C（大概率要真算 Hessian） |
| f 非线性、约束简单 | A（f 在 x\* 处 Taylor 展开后放缩） |
| 题目点名"用最优性条件验证" | C 的写法（结论用二阶充分条件术语） |

**命名与术语**（考场简答用）：

- **活动约束（起作用约束）**：在 x\* 处取等号的约束；不活动的约束乘子 uᵢ = 0。
- **KKT 只是必要条件**：不满足 ⇒ 直接"不是"；满足 ⇒ 还要证充分性，**不能直接下结论**。
- **临界锥 C** = 可行方向（切锥）中 ∇fᵀd = 0 的那一小撮——一阶判不了生死的"嫌疑人名单"。C = {0}（没嫌疑人）⇒ 一阶已全覆盖 ⇒ 严格局部极小；C 非空 ⇒ 动 Hessian 逐个验 dᵀ∇²ₓₓL d > 0。
- **二阶条件在防什么**：沿一阶平坦方向 f 可能升也可能降，二阶看曲率补刀；所有可行方向 ∇fᵀd 都严格 > 0 时二阶根本不用出场。
- **两活动约束梯度线性无关 ⇒ 交于孤立点**：可行域成尖角（如本例开口朝右的尖角），容易 ∇fᵀd > 0 全覆盖；梯度平行（相切）才会出现非零平坦方向。
- **Hessian 半正定不判生死**：∇²ₓₓL 可能奇异（如 diag(14/3, 0)），单看它不能说"二阶充分条件成立"，靠 C = {0} 收口。

## 6　一维搜索·试探法（0.618 法 / Fibonacci 法）　（2026-11-08 整理：课堂笔记 + (9).pdf 逐式核对；例题待我手写）

> 配图：`一维搜索-0.618与Fibonacci-直观图.png`（两种丢段情形 + 旧点复用几何 + 同次数下终区间对比）。

**题目给什么**：min 一元**单峰**函数 φ(λ)（= 目标 f 沿方向 d 的一维搜索函数）、初始区间 [a₁,b₁]、精度（最终区间长，讲义正文记 δ、算法框记 L）。

**0.618 法通用步骤**：

1. λ₁ = a₁ + 0.382(b₁−a₁)，μ₁ = a₁ + 0.618(b₁−a₁)；算 φ(λ₁)、φ(μ₁)；
2. 每轮比较 φ(λₖ) 与 φ(μₖ)：
   - φ(λₖ) ≤ φ(μₖ)：极小在左段，**aₖ₊₁ = aₖ、bₖ₊₁ = μₖ**；旧点 λₖ 落在新区间内留作新右点（μₖ₊₁ = λₖ），只新算 λₖ₊₁ = aₖ₊₁ + 0.382(bₖ₊₁−aₖ₊₁)；
   - φ(λₖ) > φ(μₖ)：极小在右段，**aₖ₊₁ = λₖ、bₖ₊₁ = bₖ**；旧点 μₖ 留作新左点（λₖ₊₁ = μₖ），只新算 μₖ₊₁ = aₖ₊₁ + 0.618(bₖ₊₁−aₖ₊₁)；
3. 重复到 bₖ−aₖ ≤ 精度（或指定迭代次数），取区间中点（或保留的较优点）作近似极小点。

（缩短率恒 r = (√5−1)/2 ≈ 0.618，由 r² = 1−r 解出；最终区间 rⁿ⁻¹(b₁−a₁)，线性收敛。）

**Fibonacci 法通用步骤**：

1. **定 n**：F₀=F₁=1，Fₙ₊₁=Fₙ+Fₙ₋₁；取**最小** n 使 **Fₙ ≥ (b₁−a₁)/δ**；
2. λ₁ = a₁ + F₍ₙ₋₂₎/Fₙ·(b₁−a₁)，μ₁ = a₁ + F₍ₙ₋₁₎/Fₙ·(b₁−a₁)；
3. 每轮比较缩区间（替换规则同 0.618 法）；第 k 轮取点（k=1,…,n−1）：
   **λₖ = aₖ + F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎·(bₖ−aₖ)，μₖ = aₖ + F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎·(bₖ−aₖ)**；
   旧点保留，每轮只补一个新点（下标随 k 递推）。
   （取点速记：把 F 数列写成一排，第 k 轮取**连续三个数** F₍ₙ₋ₖ₋₁₎,F₍ₙ₋ₖ₎,F₍ₙ₋ₖ₊₁₎——左、中做 λ/μ 的分子，最右做公共分母；**每轮窗口左移一格**，系数和恒为 1；rₖ = 中÷右，末轮窗口 [1,1|2] 即 r₈=1/2。）
4. 最后一步两点重合，用**辨别常数 δ** 错开（μₙ = λₙ + δ）再比一次；停止，极小点含于 [aₙ,bₙ]。

**命名与术语**（考场简答用）：

- **试探法**（0.618/Fibonacci）：只比较函数值、不用导数；**函数逼近法**（牛顿/割线/抛物线）：用导数或插值构造逼近函数求极小。
- **收缩率** τ = (bₖ₊₁−aₖ₊₁)/(bₖ−aₖ)，越小越好；0.618 法恒 r≈0.618，Fibonacci 法第 k 步为 F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎，n→∞ 时趋于 0.618。
- **缩率公式的来历（记忆钩子）**：等距 + 旧点复用两条约束 ⟹ 区间长满足 **Lₖ = Lₖ₊₁ + Lₖ₊₂**（倒着长的 Fibonacci 递推）；以"末轮两点重合、缩 1/2"为边界往回倒推 ⟹ Lₖ = F₍ₙ₋ₖ₊₁₎·c ⟹ τₖ = F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎；各轮缩率连乘相消得终区间 (1/Fₙ)(b₁−a₁)——**缩率、定 n、终区间三式同源**（(9).pdf 试探法13–15 页）。
- **Fibonacci 的"r"不用解**：讲义原话"F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎ 相当于 0.618 法中的 r"（试探法14 页）——查表直读，1−rₖ = F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎ 由递推自动给出。真正要解的只有定 n 不等式。0.618 法公式把 r→rₖ 即得 Fibonacci 法。**别拿 0.618 顶替 rₖ**：同样 9 次函数计算，0.618 法终区间 4×0.618⁸≈0.085 > 0.08 不达标，Fibonacci 4/55≈0.073 达标（练习题2 实例）。
- **Fibonacci 法是分割方法求一维极小的最优策略，0.618 法是近似最优**（(9).pdf 试探法16 页原话）。
- 除首轮外每轮只算 **1 个**新函数值（μₖ₊₁=λₖ 或 λₖ₊₁=μₖ）——两种方法共同的特点。

**易错点**：

1. Fibonacci 取点公式**分母是 F₍ₙ₋ₖ₊₁₎（随 k 变）**，不是 F₍ₙ₊₁₎（课堂笔记曾写错，已按 (9).pdf 试探法13 页修正）；
2. 定 n 用 Fₙ ≥ (b₁−a₁)/δ 取**最小** n；F 表从 F₀=F₁=1 数起；
3. φ(λₖ) > φ(μₖ) 丢的是**左端** [aₖ,λₖ]（极小只能落在 μₖ 右侧），别丢反；
4. 0.382 = 1−0.618；λₖ 恒为左点、μₖ 恒为右点（λₖ<μₖ），别写反；
5. **自检**：两点到区间端点等距（bₖ−λₖ=μₖ−aₖ）、两点系数相加 = 1（F₍ₙ₋ₖ₋₁₎+F₍ₙ₋ₖ₎=F₍ₙ₋ₖ₊₁₎ ✓）。

## 7　两阶段法 / 大 M 法　（2026-11-08：老师点名必考；例1 由 agent 代写+复验；σ 重算我已主推练会，五张表整体未合卷重走）

**题目给什么**：min LP，约束含 ≥ / =——标准化后没有现成单位列可作初始基，单纯形表起不了步，需先造一个初始基本可行解。

**通用步骤（两阶段法）**：

1. **标准化**：≥ 约束**减过剩变量**（系数 −1），= 直接用；所有 bᵢ ≥ 0（bᵢ<0 先两端乘 −1）；
2. **第一阶段**：对缺单位列的每个等式加一个**人工变量** aᵢ，构造辅助 LP：**min w = Σaᵢ**（其余变量费用全 0），以 (a₁,…,aₘ) 为初始基做单纯形迭代；
3. **过渡判据**：第一阶段迭代到最优——
   - **w\* = 0** ⟹ 人工变量全为 0 ⟹ 已得原问题一个 BFS（卷面要写这句判据）；
   - **w\* > 0** ⟹ 原问题无可行解，停；
4. **第二阶段**：删去人工变量列，目标换回原 min z，以第一阶段得到的基**重算全部检验数**继续迭代到最优，报 x*、z*。

**大 M 法一句话**：不分阶段，人工变量费用直接设 **+M**（充分大正数）：min z = 原费用 + M·Σaᵢ，一张表做到底——M 就是"罚"，逼人工变量离基。两阶段法是它的数值安全版（避开 M 舍入灾难）。二者卷面二选一出题。

**单纯形表旋转变换速记**（每次迭代 = 换表，四步，2026-11-08 补）：

1. **定主元**：入基列 k（最负 σ）与出基行 r（比值最小）交叉处为主元 p；
2. **主行归一**：主行整行 ÷ p（主元变 1，含 b 列同步除）；
3. **其余行消元**：行 i ← 行 i − (行 i 第 k 列元素) × 新主行（该列全变 0）；
4. **σ 行重算**：σ_j = c_j − c_B·(第 j 列)，**c_B 随基变化必须重算**（别沿用上一行 σ）。
自检：基变量所在列是单位向量（1 在该基行、其余 0）；基解 = b 列。

**命名与术语**（考场简答用）：

- **人工变量**：为凑初始单位阵硬加进等式的变量，无经济含义，只当"垫脚石"；**≠ 松弛变量**——松弛变量费用 0、可以留在最终基里，人工变量必须离基/为 0。
- **过剩变量**（剩余变量）：≥ 约束减掉的变量，系数 −1；把 ≥ 变等式，但也因此失去单位列。
- **过渡判据句**：第一阶段最优表中**人工变量全部离基且 w\*=0** 才进第二阶段；若有某人工变量在基中但取值 0（退化），任选其所在行一个原变量入基把它换出（该行系数全 0 时删行）。
- **第二阶段禁止人工列回基**：直接删列最干净；不删则其费用保持 M。
- **单个 ≥ 约束**可用**单个人工变量技巧**（CH3 s064–s068）：两端乘 −1 后只加一个 a。

**易错点**：

1. 过剩变量系数是 **−1**；"减过剩 + 加人工"别写成"加松弛"；
2. 比值检验只在入基列的**正元素**里取 min，负元素跳过；
3. 第一阶段结束**必须写 w\* = 0** 这句判据，再删列换目标；
4. 第二阶段 c_B 换了 ⇒ **检验数全部重算**，别沿用第一阶段的 σ 行；
5. 求 min 选**最负 σ** 入基；题目给 max 时先化 min（本课 min 口径）；
6. w\*>0 时结论是**无可行解**，不是无界。

## 8　Zoutendijk 可行方向法 / Rosen 梯度投影法　（2026-11-10：CH12 课堂已过；两题课堂完成到"求方向"，完整迭代未手练）

**题目给什么**：约束 NLP，给一个可行初点，求该点的**可行下降方向**（或作一次完整迭代：方向 + 步长 + 新点）。两种方法共同骨架 = 无约束下降算法的"方向 + 一维搜索"，迭代格式同一个：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾。

**通用步骤（Zoutendijk，线性约束）**：

1. **标准化**：约束写成 Ax ≥ b、Ex = e（≤ 约束移项换向）；
2. **定起作用约束**：代入当前点分解 A1x⁽ᵏ⁾=b1（起作用）、A2x⁽ᵏ⁾>b2（不起作用）——**每轮重分解**；
3. **解方向 LP**：min ∇f(x⁽ᵏ⁾)ᵀd s.t. A1d ≥ 0, Ed = 0, **−1 ≤ dⱼ ≤ 1**，得 d⁽ᵏ⁾；
4. **判停**：∇f(x⁽ᵏ⁾)ᵀd⁽ᵏ⁾ = 0 ⟹ x⁽ᵏ⁾ 为 KKT 点，停；否则转 5；
5. **步长上限**：b̂ = b2 − A2x⁽ᵏ⁾（**负的**）、d̂ = A2d⁽ᵏ⁾，**λmax = min{ b̂ᵢ/d̂ᵢ : d̂ᵢ < 0 }**（d̂ 全 ≥ 0 则 λmax = ∞）；
6. **一维搜索**：[0, λmax] 上 min f(x⁽ᵏ⁾+λd⁽ᵏ⁾) 得 λᵏ，x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + λᵏd⁽ᵏ⁾。

**通用步骤（Rosen 梯度投影）**：

1. **定 M**：起作用约束（A1 行 + E 行）的系数矩阵 M = (A1; E)，行满秩；
2. **投影**：P = I − Mᵀ(MMᵀ)⁻¹M，d = −P∇f(x)；
3. **分支**：d ≠ 0 ⟹ 即下降可行方向，转一维搜索；d = 0 ⟹ 算 ω = (MMᵀ)⁻¹M∇f(x) = (u; v)——**u ≥ 0 ⟹ x 为 KKT 点停**；u 有负分量 ⟹ **删该行**得 M̂ 重投影，转一维搜索；
4. **一维搜索**：同 Zoutendijk，步长受不起作用约束限制。

**速记对比**：Zoutendijk 每轮解一个 LP；Rosen 一次投影出方向、不解 LP（计算量小）。线性约束拿到的判别是 **KKT**，非线性约束（LP(12.1.31)）只拿到 **F-J**。

**命名与术语**（考场简答用）：

- **可行方向**：∃δ>0，∀λ∈(0,δ) 有 x̂+λd 可行（d ≠ 0，λ 要能连续取一小段）。
- **下降可行方向**：可行 + ∇f(x̂)ᵀd < 0。
- **λ可行集**（笔记 p3 讲法）：{① 可行方向 ②（可行）下降方向}。
- **线性化约束 LP**（非线性版）：min z s.t. ∇fᵀd − z ≤ 0，∇gᵢᵀd + z ≥ 0 (i∈I)，|dⱼ| ≤ 1——z\*<0 给方向，z\*=0 给 F-J 点。
- **投影矩阵**：P² = P 为投影矩阵；再加 PᵀP = P 才是**正交**投影。P_N(M) = I − Mᵀ(MMᵀ)⁻¹M 把向量投到 M 的零空间。

**易错点**：

1. A1/A2 分解**看当前点**，每轮重做；
2. λmax 的 b̂ 是**负**的，只对 d̂ᵢ < 0 的分量取 min；
3. 方向 LP 的 **|dⱼ| ≤ 1 不能漏**（漏了 LP 无界，且是得分点）；
4. 初点代入约束**先判起不起作用**再写 A1——原点处带裕量的约束不起作用（今天练习题 1 旧稿就错在"4 个约束全取等"）；
5. Rosen 删行后**重算投影** d̂ = −P_N(M̂)∇f(x)，不是把某个分量置零；
6. 收敛性缺陷说"**算法映射不闭 / 锯齿**"，标准答案走 Wolfe (1972) 反例 + Topkis-Veinott 修正（答题材料 §四）。
