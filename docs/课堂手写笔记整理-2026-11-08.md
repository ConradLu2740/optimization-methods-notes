## 1｜CH7 最优性条件（p3 总览 + p1 F-J/KKT/二阶）

### 1.1 三要素与凸函数判别（p3）

- 最优化 = **约束条件 + 目标函数 + 变量条件**；分线性/非线性。
- 凸函数判别：**看 Hessian 矩阵是否正定**（二阶导判别）。

**p3 右上例**：梯度分量 (2x₁−2x₂, 2x₂−2x₃−2x₁, 2x₃+3−2x₂)〔+3 由字迹推断〕
⟹ f = x₁²+x₂²+x₃²−2x₁x₂−2x₂x₃+3x₃，Hessian：

```
M = ⎡  2  −2   0 ⎤
    ⎢ −2   2  −2 ⎥
    ⎣  0  −2   2 ⎦
```

「核对」顺序主子式 D₁=2>0，D₂=4−4=0，D₃=det M=−8<0 ⟹ **M 不定 ⟹ f 非凸**。两个要点：① D₂=0 时"正定链"已断，必须继续算 D₃ 才能下结论；② 顺序主子式法只判**正定**，det<0 直接答"不定"（既非凸也非凹）。

### 1.2 无约束极值条件（p3 左中）

| 条件 | 内容 |
|---|---|
| 一阶必要 | 局部极小 + f 可微 ⟹ ∇f(x*)=0（证明用泰勒展开） |
| 二阶必要 | 再加 ∇²f(x*) **半正定** |
| 二阶充分 | ∇f(x*)=0 且 ∇²f(x*) **正定** ⟹ 严格局部极小 |
| 凸充要 | f 凸 ⟹ ∇f(x*)=0 ⟺ **全局**极小（p3 右侧"充要条件"框） |

- 下降方向：∇f(x)ᵀd<0 ⟺ 与梯度夹角 θ>90°；**负梯度 = 最快下降方向**。
- 极大点判别：① 驻点；② 用 Hessian 判（笔记"各阶海森矩阵"）。

### 1.3 有约束：F-J 与 KKT（p3 下部 + p1）

- **F-J 条件（必要条件）**：x* 局部极优 ⟹ ∇f(x*) = Σ_{i∈I} uᵢ∇gᵢ(x*)，u₀, uᵢ ≥ 0 且**不全为 0** —— 目标函数梯度可表为起作用约束梯度的线性组合。
- **拉格朗日函数**：L(x,u) = f(x) − Σᵢ uᵢgᵢ(x)。
- **KKT = F-J + u₀≠0**（笔记"比 F-J 多…〔后半不清〕"；规范说法：u₀ 可归一化为 1，即 ∇f 本人参加组合，不会被约束锥"淹没"）。
- **几何**（笔记：目标函数梯度在约束梯度锥中）：∇f 的反向落在起作用约束梯度张成的**锥**内。
- **判别流程**（笔记①②③）：① 把 x̄ 代入约束，定**起作用约束**集 I；② 解 ∇f = Σ_{i∈I} uᵢ∇gᵢ 方程组；③ 查乘子：KKT 要求 **uᵢ≥0**，F-J 只要求不全为 0。
- **正则点（p1，LICQ）**：{∇gᵢ(x̄), ∇hⱼ(x̄) | i=1..m, j=1..l} **线性无关**。
- **F-J 退化（p1）**：u₀=0（目标函数乘子为 0，拉格朗日项里 f 消失）—— 讲义例2：min −x₂ 在 (0,2)ᵀ 就是这种（11-08 讲过）。

### 1.4 二阶条件与临界锥（p1）

- **KKT 四件套**：∇L(x,u,v)=0；uᵢ≥0 (i∈I)；**uᵢ·gᵢ(x)=0（互补松弛，笔记 g(x̄)ᵀλ=0）**；可行。
- KKT + 凸 ⟹ 极小点。凸时局部=全局，答题写"**全局极小**"更满。
- **拉格朗日函数的 Hessian** ⚠️ 笔记写成 "∇²f(x̄) = Σᵢ₌₁ᵐ wᵢ∇²gᵢ(x̄) + Σⱼ₌₁ˡ vⱼ∇²hⱼ(x̄)"，两处要修：
  1. **左边应是 ∇²ₓₓL** —— 这是拉格朗日函数的 Hessian，不是 f 的；
  2. 课程口径 L = f − Σu g − Σv h，**符号是减号**：
     **∇²ₓₓL(x̄,u,v) = ∇²f(x̄) − Σᵢ uᵢ∇²gᵢ(x̄) − Σⱼ vⱼ∇²hⱼ(x̄)**
     （对照：解题步骤记录 §5 例子里 ∇²ₓₓL = −u₃∇²g₃，就是减号口径。等式约束前的符号跟 L 定义走。）
- **二阶充分（约束版）**：KKT 点 + 对**临界锥**内一切非零方向 **dᵀ∇²ₓₓL d > 0** ⟹ 严格局部极小。笔记末行 "dᵀ∇²L(x,u,v)d>0, ∀d∈G" 的 G 即临界锥。
- 「核对」与 解题步骤记录.md §5 路线 C 完全一致（临界锥 = 切锥中 ∇fᵀd=0 的"嫌疑人名单"；C={0} 时二阶条件自动成立）。
- p1 中部"二阶充分：∇f(x*)…H* 正定 ⟹ 局部极小"是无约束版（即 §1.2 表中第三行）。

## 3｜CH9 一维搜索（p5 + p4 上半）

- 迭代框架 4 条：① 方向 dᵏ；② f(xₖ+λₖdᵏ)<f(xₖ)；③ xₖ₊₁=xₖ+λₖdᵏ；④ |x*−xₖ₊₁|<ε。
- 两类方法：**试探法 / 函数逼近法**。
- **收缩率** τ=(bₖ₊₁−aₖ₊₁)/(bₖ−aₖ)，越小越好。

### 3.1 0.618 法（黄金分割）✓

- λₖ = aₖ + 0.382(bₖ−aₖ)，μₖ = aₖ + 0.618(bₖ−aₖ)。
  「核对」= (9).pdf 式(2.12)/(2.13)，**正确**。通用形式 λₖ=aₖ+(1−r)(bₖ−aₖ)、μₖ=aₖ+r(bₖ−aₖ)，r 由 r²=1−r 解出 r=(√5−1)/2≈0.618。
- 缩短率恒 r ⟹ 最终区间 rⁿ⁻¹(b₁−a₁)，线性收敛。
- **除第一次外每轮只算 1 个新试探点**：φ(λₖ)≤φ(μₖ) 时 μₖ₊₁=λₖ；φ(λₖ)>φ(μₖ) 时 λₖ₊₁=μₖ。
- 区间替换：φ(λₖ)≤φ(μₖ) ⟹ [aₖ₊₁,bₖ₊₁]=[aₖ,μₖ]；φ(λₖ)>φ(μₖ) ⟹ [aₖ₊₁,bₖ₊₁]=[λₖ,bₖ]。

### 3.2 Fibonacci 法 ⚠️ 取点公式要修

- 思想：缩短率不用 0.618，用 **Fibonacci 数**：Fₙ₊₁=Fₙ+Fₙ₋₁，F₀=F₁=1。
- **定 n**：bₙ−aₙ = (1/Fₙ)(b₁−a₁) ≤ δ ⟹ **Fₙ ≥ (b₁−a₁)/δ**，取满足的最小 n。
  「核对」笔记这条**正确**，= (9).pdf 式(1.20)。
  小提醒：讲义算法框里最终区间长记 **L**，δ 另作**辨别常数**（最后一次迭代 λₙ=μₙ₋₁、μₙ=λₙ+δ 用它把两点错开）——两个符号别混。
- **取点公式（讲义版，背这个）**，k=1,…,n−1：
  **λₖ = aₖ + F₍ₙ₋ₖ₋₁₎/F₍ₙ₋ₖ₊₁₎ · (bₖ−aₖ)，μₖ = aₖ + F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎ · (bₖ−aₖ)**
  ⚠️ 笔记写成 "F₍ₙ₋ₖ₎/F₍ₙ₊₁₎、F₍ₙ₋ₖ₊₁₎/F₍ₙ₊₁₎"——**分母应为 F₍ₙ₋ₖ₊₁₎**（随 k 变），分子比你写的差一位。
  自检口诀：**两点系数相加 = 1**（F₍ₙ₋ₖ₋₁₎+F₍ₙ₋ₖ₎=F₍ₙ₋ₖ₊₁₎ ✓）；k=1 时 λ₁=a₁+F₍ₙ₋₂₎/Fₙ(b₁−a₁)、μ₁=a₁+F₍ₙ₋₁₎/Fₙ(b₁−a₁)（讲义 Step1 原文）。
- 每步缩短率 = F₍ₙ₋ₖ₎/F₍ₙ₋ₖ₊₁₎；首轮之后同样只算 1 个新点。
- 「核对」讲义自带练习题2：min x²−x+2，初始区间 [−1,3]，迭代两次、最终区间长 ≤0.08（(9).pdf p29–30）——可当手推素材。

## 4｜CH10 使用导数的最优化方法

### 4.1 最速下降法（p4）

- 方向 **dₖ = −∇f(xₖ)**（负梯度）；"无约束优化中最简单"。
- 精确一维搜索：φ′(λₖ)=0 ⟺ f′(xₖ₊₁)=0（沿 d 的方向导数为零）⟹ 解出 λₖ 代入。
- 条件数旁注〔原文不清〕：**条件数（λmax/λmin）决定等高线椭圆的扁圆**；越接近 1（椭圆越圆）收敛越快、锯齿越轻 —— 与笔记"λ 越小收敛越快"吻合。
- **缺**：锯齿现象（相邻两步 dₖ⊥dₖ₊₁），收敛慢，可能无限迭代。
- **优**：全局收敛；计算简单。

### 4.2 牛顿法（p7）☆

- **推导**：二阶 Taylor 展开。迭代公式：**x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − [∇²f(x⁽ᵏ⁾)]⁻¹ ∇f(x⁽ᵏ⁾)**。
- 方向 dₖ = −Gₖ⁻¹gₖ（gₖ=∇f(xₖ)，Gₖ=Hessian），**步长 λₖ=1**；前提 **Gₖ 正定**。
- **缺**：① 算 Gₖ 并求逆，计算量大；② Gₖ 可能奇异/病态；③ Gₖ 不定 ⟹ 可能发散，**无全局收敛性**〔旁注 P289（教材页）〕。
- **优**：① 正定二次函数一次迭代到极小（**二次终止性**，有限步终止），收敛快；② 初始点足够靠近解时**局部二阶收敛**〔旁注不清，大意如此〕。
- **阻尼牛顿法**（讲义位置在 10.2 内，(10-1).pdf slide 43–44；笔记编号"10.3"）：针对"牛顿法不全局收敛"，**牛顿方向 + 一维搜索定步长**——min_λ f(xᵏ+λdᵏ)，令 ∂f/∂λ = 0 解出 λₖ，x⁽ᵏ⁺¹⁾=x⁽ᵏ⁾+λₖdᵏ。
- **修正牛顿法（10.2.3；笔记编号"10.4"）**：Gₖ 不正定时，**构造对称正定修正矩阵 G̃ₖ = ∇²f(xᵏ) + εₖ·I**（εₖ 把特征值垫正）。
- 「核对」流程已会（解题步骤记录 §3；n=1 特例即切线法）。

### 4.3 共轭梯度法（p6）☆"大概率考，重在算法与优缺点"

- **共轭方向**：d⁽ⁱ⁾ᵀAd⁽ʲ⁾ = 0（i≠j）。
- **扩张子空间定理（Th10.3.2）**：已搜子空间的**法向量 = 当前梯度**（gₖ₊₁ ⊥ span{d⁽¹⁾,…,d⁽ᵏ⁾}）。
- 迭代格式 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + αₖd⁽ᵏ⁾；**dₖ₊₁ = −gₖ₊₁ + βₖdₖ**（负的新梯度 + 修正项，保证共轭）。
- βₖ = dₖᵀAgₖ₊₁/(dₖᵀAdₖ)（10.3.19）—FR 法简化→ **βₖ = ‖gₖ₊₁‖²/‖gₖ‖²**（10.3.24；精确一维搜索 ⟹ 相邻梯度正交）。
- **优**（笔记）：全局收敛、计算简单；二次终止性〔笔记"二阶收敛性"〔？〕，讲义口径是"二次终止"〕；无约束问题最常用方法之一。
