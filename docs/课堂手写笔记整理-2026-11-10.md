## 1｜Zoutendijk 课堂理论（p4）

- **问题形式**：min f(x) s.t. **Ax ≥ b（线性约束）**、**Ex = e（非线性约束）**〔字迹似 Ax≥b，与讲义 (12.1.1) 一致〕。
- **按起作用性分解**：A = (A1; A2)、b = (b1; b2)，使 **A1x = b1（起作用）、A2x ≥ b2（不起作用）**。
- **下降可行方向**：∇f(x)ᵀd < 0，A1d ≥ 0，Ed = 0。
- **方向 LP**：min ∇f(x)ᵀd s.t. A1d ≥ 0，Ed = 0，**|dᵢ| ≤ 1**（i=1,…,n）。
- ∴ d ≠ 0 ⇔ … ∴ **最优点 ≤ 0**〔笔记原话；规范说法：d=0 是 LP 可行解 ⇒ 最优值 ≤ 0；最优值 <0 拿到下降方向，=0 则 x 是 KKT 点〕。
- 「核对」与 `第12章-可行方向法-答题材料.md` §二 完全一致（Th12.1.1、LP(12.1.10)、Th12.1.2）。

## 2｜CH12 理论（p3）

- **λ可行集** {① 可行方向 ②（可行）下降方向}〔① 后字迹不清，据上下文推断〕。
- **2) 线性化约束**（非线性约束版方向 LP，(12).pdf 式 12.1.31）：

      min z
      s.t.  ∇f(x)ᵀd − z ≤ 0
            ∇gᵢ(x)ᵀd + z ≥ 0 ,  i ∈ I
            |dᵢ| ≤ 1

- **缺：有锯齿**〔Zoutendijk 的缺点：相邻迭代方向近乎正交、锯齿式推进，收敛慢——答题材料 §四 Wolfe 反例的通俗版，简答题可作素材〕。
- **Rosen 梯度投影法**：**对 (−∇f(x)) 投影**（配几何草图：把负梯度投到起作用约束张成的切锥上）：

      M = ( A1 ; E )   ← 起作用约束 / 约束值
      P = I − Mᵀ(MMᵀ)⁻¹M
      ω = (MMᵀ)⁻¹M∇f(x)
      d = −P·∇f(x) ≠ 0

- 「核对」LP = 答题材料 §三（12.1.31）；Rosen 公式 = 答题材料 §五 记号 + Th12.2.1/12.2.2，逐条一致。

## 3｜练习题 1：Zoutendijk 三维题（p1，我课堂手写 + 补全）

    min x1² + 2x2² + 3x3² + x1x2 − 2x1x3 + x2x3 − 4x1 − 6x2
    s.t.  x1 + 2x2 + x3 ≤ 4
          x1 ≥ 0 ,  x2 ≥ 0 ,  x3 ≥ 0
    求 x⁽⁰⁾ = (0,0,0)ᵀ 处的可行下降方向，用 Zoutendijk 方法解

**我手写**：

- 约束整理：g1(x) = 4 − x1 − 2x2 − x3 ≥ 0；g2(x) = x1 ≥ 0；g3(x) = x2 ≥ 0；g4(x) = x3 ≥ 0
- x⁽⁰⁾ 时，**g2、g3、g4 为起作用的约束**（g1 取值 4 > 0 不起作用 ✓）
- ∇f(x) = (2x1 + x2 − 2x3 − 4, 4x2 + x1 + x3 − 6, 6x3 − 2x1 + x2)
- ∇f(x⁽⁰⁾) = **(−4, −6, 0)ᵀ**　⚠️ 笔记写的是 ∇f(x⁽¹⁾)，应为 **x⁽⁰⁾**（初点，笔误）
- 方向 LP：**min −4d1 − 6d2**（= ∇f(x⁽⁰⁾)ᵀd）s.t. 0 ≤ d1 ≤ 1，0 ≤ d2 ≤ 1，0 ≤ d3 ≤ 1

**补全（agent，2026-11-10 精确分数 Python 复验）**：

- LP 最优值 **−10**，**d⁽⁰⁾ = (1, 1, 0)ᵀ**（d3 在 [0,1] 内任意取都最优，取 0）⇒ 这就是所求可行下降方向。
- 顺带：若继续走下去，λmax = 4/3（不起作用的 x1+2x2+x3 ≤ 4 给的上限；起作用的 x≥0 因 d ≥ 0 不设限）——本题只问方向，卷面可不写。
- 「核对」= 答题材料 §二 练习题、第一册 / 考试范围与例题清单（11-10 已复核，修正旧稿"4 个约束全取等、A1 为 4×3"的错误）。
