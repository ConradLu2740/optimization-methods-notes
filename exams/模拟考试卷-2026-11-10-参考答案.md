## 一、简答题

### 1.（10 分）Farkas 定理的几何表示形式

**定理表述**（PPT 定理 2.11 原版）：设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0、cᵀx > 0 有解的充要条件是：Aᵀy = c、y ≥ 0 无解。

**等价的二择一形式**（"有且只有一个成立"）：设 A∈R^{m×n}，b∈R^m，则以下两个论断有且只有一个成立：

1. 存在 x∈R^n，使 Ax = b 且 x ≥ 0；
2. 存在 y∈R^m，使 Aᵀy ≥ 0 且 bᵀy < 0。

**几何表示**（置换定理 2.11′，画图用这个）：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥，则 c 与 S 的关系二择一：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | ∃y≥0: Aᵀy = c（系统 II 有解） | c 落在锥内；任何满足 Ax≤0 的方向 x 都与 c 成钝角/直角（cᵀx≤0），不存在 cᵀx>0 的方向 |
| c ∉ S | Ax≤0、cᵀx>0 有解（系统 I 有解） | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0（即 Ax≤0）且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

**证明骨架**：必要性用反证——若同时有 Aᵀy=c（y≥0）与 Ax̄≤0、cᵀx̄>0，则 cᵀx̄ = yᵀAx̄ ≤ 0，矛盾。充分性——S 是闭凸锥，c∉S，由严格分离定理（Th2.7）存在非零 x 使 xᵀc ≥ ε + xᵀz 对一切 z∈S 成立；取 z=0 得 xᵀc>0，取 z=Aᵀy（y≥0 任意）并由 y 分量可任意大得 xᵀAᵀ≤0，即 Ax≤0。

**意义**：Farkas 定理是凸集分离定理的应用，是判断线性系统"有无可行方向"的基本工具（也是 LP 对偶定理与 Zoutendijk 法 KKT 判别定理 Th12.1.2 的证明工具）。

> 评分点：表述的"有且只有一个"（排他）必写；图必须画成**锥**（原点出发的射线束）+ 右图**过原点**的分离超平面与法向量标注；锥对非负数乘封闭 ⇒ 分离超平面必过原点，这是会被追问的点。

### 2.（10 分）多面体表示定理与最优解在极点

**（1）多面体表示定理**：设 P = {x | Ax ≤ b} 是非空多面体，其极点（顶点）为 v₁,…,vₖ，极方向为 d₁,…,dₗ，则 x ∈ P 当且仅当

    x = Σᵢ λᵢvᵢ + Σⱼ μⱼdⱼ，其中 λᵢ ≥ 0，Σᵢ λᵢ = 1，μⱼ ≥ 0。

即多面体中任一点都可表为极点的凸组合与极方向的非负组合之和。特别地，有界多面体（多胞形）没有极方向，任一点都是极点的凸组合。

**（2）为什么最优解可在极点达到**：设 x* 是 min cᵀx（x∈P）的最优解。由表示定理 x* = Σλᵢvᵢ + Σμⱼdⱼ。因最优值有限，必有 cᵀdⱼ ≥ 0 对每个极方向成立（否则沿 dⱼ 走 x*+tdⱼ 仍可行且 cᵀx → −∞，与最优解存在矛盾）。于是

    cᵀx* = Σᵢ λᵢcᵀvᵢ + Σⱼ μⱼcᵀdⱼ ≥ Σᵢ λᵢcᵀvᵢ ≥ minᵢ{cᵀvᵢ}·Σᵢλᵢ = minᵢ{cᵀvᵢ}。

取达到 min 的极点 vₖ，则 cᵀvₖ ≤ cᵀx*；又 x* 最优，故 cᵀvₖ = cᵀx*，即**极点 vₖ 也是最优解**。

**极点与基本可行解的关系**：对标准形可行域 {x | Ax = b, x ≥ 0}，x 是极点 ⇔ x 是基本可行解（BFS）（CH2 Th2.4）。因此单纯形法只在 BFS（= 极点）之间迭代搜索。

### 3.（10 分）凸函数判别

**（1）** f(x₁,x₂) = x₁² − 2x₁x₂ + x₂² = (x₁ − x₂)²。

    ∇f = (2x₁ − 2x₂, −2x₁ + 2x₂)ᵀ，∇²f = [[2, −2], [−2, 2]]（处处常数）。

顺序主子式：2 > 0，det = 4 − 4 = 0 ⇒ ∇²f **半正定**（特征值 0 与 4），不是正定。由二阶判别法（C² 函数在 Rⁿ 上凸 ⇔ Hessian 处处半正定）⇒ **f 是凸函数，但不是严格凸**。

验证不严格：f(0,0) = f(1,1) = 0，中点 (1/2,1/2) 处 f = 0，定义不等式取等号。

（也可用性质法：f = g(Ax)，g(t) = t² 凸、A = [1 −1] 线性，凸函数与线性映射的复合仍凸。）

**（2）何时用哪种判别**：

- **定义**（f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)）：函数抽象、不可微，或要利用具体结构直接验证时；
- **性质**（非负加权和、与线性映射复合、逐点上确界等保凸运算）：函数由已知凸函数搭建而成时，最快；
- **一阶条件**（f(y) ≥ f(x) + ∇f(x)ᵀ(y−x)）：可微且梯度好处理时，也常用于证不等式；
- **二阶条件**（∇²f ⪰ 0）：二阶可微、表达式具体时最常用（本题就是）。

## 二、单纯形方法

### 4.（20 分）两阶段法

**标准化**：两个 ≥ 约束各减过剩变量 x₄、x₅（系数 −1），再加人工变量 a₁、a₂：

    x₁ + 4x₂ + 2x₃ − x₄ + a₁ = 8
    3x₁ + 2x₂ − x₅ + a₂ = 6

**第一阶段**：辅助 LP min w = a₁ + a₂（其余变量费用 0），初始基 (a₁,a₂)。

**表 P1-1**（基 (a₁,a₂)，c_B=(1,1)，w = 14）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| a₁ | 8 | 1 | **4** | 2 | −1 | 0 | 1 | 0 |
| a₂ | 6 | 3 | 2 | 0 | 0 | −1 | 0 | 1 |
| σ | | −4 | **−6** | −2 | 1 | 1 | 0 | 0 |

σ₂ = −6 最负 ⇒ x₂ 入基；比值 min{8/4, 6/2} = 2 ⇒ a₁ 出基，主元 = 4。

**变换①**：主行 ÷4；a₂ 行 − 2×新主行。

**表 P1-2**（基 (x₂,a₂)，c_B=(0,1)，w = 2）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₂ | 2 | 1/4 | 1 | 1/2 | −1/4 | 0 | 1/4 | 0 |
| a₂ | 2 | **5/2** | 0 | −1 | 1/2 | −1 | −1/2 | 1 |
| σ | | **−5/2** | 0 | 1 | −1/2 | 1 | 3/2 | 0 |

（σ 重算：σⱼ = cⱼ − 1×(a₂ 行)ⱼ。）σ₁ = −5/2 最负 ⇒ x₁ 入基；比值 min{2/(1/4), 2/(5/2)} = min{8, 4/5} = 4/5 ⇒ a₂ 出基，主元 = 5/2。

**变换②**：主行 ×2/5；x₂ 行 − (1/4)×新主行。

**表 P1-3**（基 (x₂,x₁)，c_B=(0,0)，w = 0）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₂ | 9/5 | 0 | 1 | 3/5 | −3/10 | 1/10 | 3/10 | −1/10 |
| x₁ | 4/5 | 1 | 0 | −2/5 | 1/5 | −2/5 | −1/5 | 2/5 |
| σ | | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

c_B = (0,0) ⇒ σ ≡ c，人工列 σ = 1，其余全 0。**w\* = 0 且人工变量全部离基** ⇒ 过渡判据满足，得原问题一个 BFS：x₁ = 4/5、x₂ = 9/5、x₃ = 0。进入第二阶段。

**第二阶段**：删 a₁、a₂ 两列，目标换回 min z = 3x₁ + x₂ + x₃，基不变，**检验数全部重算**（c_B = (1,3)）。

**表 P2-1**（基 (x₂,x₁)，c_B=(1,3)，z = 21/5）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|---|
| x₂ | 9/5 | 0 | 1 | 3/5 | −3/10 | 1/10 |
| x₁ | 4/5 | 1 | 0 | −2/5 | **1/5** | −2/5 |
| σ | | 0 | 0 | 8/5 | **−3/10** | 11/10 |

σ 重算示例：σ₄ = 0 − [1·(−3/10) + 3·(1/5)] = −3/10。σ₄ = −3/10 最负 ⇒ x₄ 入基；比值检验：x₂ 行系数 −3/10 < 0 跳过，x₁ 行 (4/5)/(1/5) = 4 ⇒ x₁ 出基，主元 = 1/5。

**变换③**：主行 ×5；x₂ 行 + (3/10)×新主行。

**表 P2-2**（基 (x₂,x₄)，c_B=(1,0)，z = 3）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|---|
| x₂ | 3 | 3/2 | 1 | 0 | 0 | −1/2 |
| x₄ | 4 | 5 | 0 | −2 | 1 | −2 |
| σ | | 3/2 | 0 | 1 | 0 | 1/2 |

**最优性检验**：σ = (3/2, 0, 1, 0, 1/2) ≥ 0，全部非负 ⇒ 达到最优。

**结论**：x\* = (0, 3, 0)ᵀ，**z\* = 3**（过剩变量 x₄ = 4、x₅ = 0，即第一约束松、第二约束取等：3·0+2·3 = 6 ✓，第一约束 0+12+0 = 12 ≥ 8 ✓）。

> 独立复核：可行域顶点共 4 个——(4/5, 9/5, 0) z=21/5、(2, 0, 3) z=9、(8, 0, 0) z=24、(0, 3, 0) z=3，最小值唯一，为 3。
> 评分点：标准化"减过剩加人工"；每轮 σ 重算；**w\*=0 判据句必写**；最后必须报 x\* 和 z\*。

## 三、最优性条件与使用导数的方法

### 5.（15 分）KKT 条件与局部极小验证

约束化为 gᵢ ≥ 0 口径：g₁ = 2 − x₁ − x₂ ≥ 0，g₂ = x₁ ≥ 0，g₃ = x₂ ≥ 0。L = f − u₁g₁ − u₂g₂ − u₃g₃。

**（1）KKT 条件**：

    平稳性：∇f − u₁∇g₁ − u₂∇g₂ − u₃∇g₃ = 0，即
      2(x₁ − 3) + u₁ − u₂ = 0
      2(x₂ − 3) + u₁ − u₃ = 0
    互补松弛：u₁(2 − x₁ − x₂) = 0，u₂x₁ = 0，u₃x₂ = 0
    原始可行：2 − x₁ − x₂ ≥ 0，x₁ ≥ 0，x₂ ≥ 0
    对偶可行：u₁, u₂, u₃ ≥ 0

**（2）求所有 KKT 点**（分情形）：

- 若 u₁ = 0：平稳性给 u₂ = 2(x₁−3) ≥ 0 ⇒ x₁ ≥ 3，u₃ = 2(x₂−3) ≥ 0 ⇒ x₂ ≥ 3，则 g₁ = 2−x₁−x₂ ≤ −4 < 0，不可行。无解。
- 故 u₁ > 0，互补松弛 ⇒ x₁ + x₂ = 2。
  - x₁ > 0、x₂ > 0 ⇒ u₂ = u₃ = 0 ⇒ u₁ = 6−2x₁ = 6−2x₂ ⇒ x₁ = x₂ = 1，u₁ = 4 ≥ 0 ✓。
  - x₁ = 0（则 x₂ = 2）：u₃ = 0，方程给 −6+u₁−u₂ = 0、−2+u₁ = 0 ⇒ u₁ = 2、u₂ = −4 < 0 ✗。
  - x₂ = 0（则 x₁ = 2）：对称地 u₁ = 2、u₃ = −4 < 0 ✗。

**唯一 KKT 点：x\* = (1, 1)ᵀ，乘子 u = (4, 0, 0)**。

**（3）局部极小判定**：约束均为线性，∇²ₓₓL = ∇²f = 2I **正定** ⇒ 二阶充分条件成立 ⇒ x\* 是**严格局部极小点**。进一步：f 凸（Hessian 半正定）、可行域凸（线性约束）⇒ KKT 点即**全局极小点**，f\* = (1−3)² + (1−3)² = 8。

### 6.（10 分）FR 共轭梯度法

f = 3x₁² + x₂² = ½xᵀAx，A = diag(6, 2)，∇f = (6x₁, 2x₂)ᵀ。

**第 1 步**：x⁽¹⁾ = (1,3)ᵀ，g₁ = (6,6)ᵀ，d⁽¹⁾ = −g₁ = (−6,−6)ᵀ。

    λ₁ = −g₁ᵀd⁽¹⁾ / (d⁽¹⁾ᵀAd⁽¹⁾) = 72 / 288 = 1/4
    （Ad⁽¹⁾ = (−36,−12)ᵀ，d⁽¹⁾ᵀAd⁽¹⁾ = 216+72 = 288；用 φ′(λ)=0 结果相同）

x⁽²⁾ = (1,3)ᵀ + (1/4)(−6,−6)ᵀ = **(−1/2, 3/2)ᵀ**，g₂ = (−3,3)ᵀ。

    β₁ = ‖g₂‖²/‖g₁‖² = 18/72 = 1/4
    d⁽²⁾ = −g₂ + β₁d⁽¹⁾ = (3,−3)ᵀ + (1/4)(−6,−6)ᵀ = (3/2, −9/2)ᵀ

**第 2 步**：

    g₂ᵀd⁽²⁾ = −9/2 − 27/2 = −18；Ad⁽²⁾ = (9,−9)ᵀ，d⁽²⁾ᵀAd⁽²⁾ = 27/2 + 81/2 = 54
    λ₂ = 18/54 = 1/3

x⁽³⁾ = (−1/2, 3/2)ᵀ + (1/3)(3/2, −9/2)ᵀ = **(0, 0)ᵀ**，g₃ = 0，算法终止。

n = 2，两步到达极小点——正是二次终止性（Th10.3.3）的体现。

**（2）优缺点**（各一条即可）：

- 优点：存储量小（只需存 gₖ、dₖ 两个 n 维向量，不存 n×n 矩阵），适合大规模问题；对二次函数至多 n 步终止。
- 缺点：对非二次函数共轭性易丢失，常需重启；收敛速度依赖条件数，病态问题比牛顿/拟牛顿法慢。

### 7.（10 分）DFP 拟牛顿法

f = x₁² + 3x₂²，∇f = (2x₁, 6x₂)ᵀ，A = diag(2, 6)。x⁽¹⁾ = (3,1)ᵀ，g₁ = (6,6)ᵀ，H₁ = I。

**（1）** d⁽¹⁾ = −H₁g₁ = **(−6,−6)ᵀ**。线搜索：φ(λ) = f(3−6λ, 1−6λ) = (3−6λ)² + 3(1−6λ)² = 144λ² − 72λ + 12，

    φ′(λ) = 288λ − 72 = 0 ⇒ λ₁ = 1/4。

x⁽²⁾ = (3,1)ᵀ + (1/4)(−6,−6)ᵀ = **(3/2, −1/2)ᵀ**，g₂ = (3,−3)ᵀ。

**（2）** p = x⁽²⁾ − x⁽¹⁾ = (−3/2, −3/2)ᵀ，q = g₂ − g₁ = (−3,−9)ᵀ。

    pᵀq = 9/2 + 27/2 = 18；H₁q = q，qᵀH₁q = 9 + 81 = 90。

DFP 校正：H₂ = H₁ + ppᵀ/(pᵀq) − (H₁q)(H₁q)ᵀ/(qᵀH₁q)

    ppᵀ/18 = [[1/8, 1/8], [1/8, 1/8]]，qqᵀ/90 = [[1/10, 3/10], [3/10, 9/10]]

    H₂ = I + [[1/8, 1/8], [1/8, 1/8]] − [[1/10, 3/10], [3/10, 9/10]]
       = [[41/40, −7/40], [−7/40, 9/40]]

（自检：H₂q = p，满足拟牛顿条件；H₂ 对称正定。）

**（3）** 对 n 维正定二次函数，至多 n 步迭代后 **Hₖ → A⁻¹**（Th10.4.2 推论：H_{n+1} = A⁻¹）。本题 A⁻¹ = diag(1/2, 1/6)；再走一步即有 H₃ = A⁻¹、x⁽³⁾ = (0,0)ᵀ（λ₂ = 5/12）。

### 8.（5 分）牛顿法

**（1）迭代格式**：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − [∇²f(x⁽ᵏ⁾)]⁻¹ ∇f(x⁽ᵏ⁾)。

**（2）** f = x₁² + x₂² + x₁³：∇f = (2x₁+3x₁², 2x₂)ᵀ，∇²f = [[2+6x₁, 0], [0, 2]]。

在 x⁽¹⁾ = (1,1)ᵀ：g = (5,2)ᵀ，∇²f = diag(8,2)。

    x⁽²⁾ = (1,1)ᵀ − diag(1/8, 1/2)·(5,2)ᵀ = (1 − 5/8, 1 − 1)ᵀ = (3/8, 0)ᵀ。

**（3）** 局部收敛阶为 **2（二阶/平方收敛）**。当 ∇²f(x⁽ᵏ⁾) **不正定**（不定或奇异）时，牛顿方向可能不是下降方向（甚至不存在）——补救：阻尼牛顿法（牛顿方向 + 一维搜索）或修正牛顿法（修正矩阵 Gₖ）。

## 四、约束优化方法

### 9.（10 分）Zoutendijk 可行方向法

> ⚠️ **2026-11-10 老师明确**：CH12 考到"求可行下降方向"为止 ⇒ (2)(3) 问**超范围**，考场只须做到 (1)（解方向 LP 得 d⁽¹⁾）；(2)(3) 留作学有余力的背景演练。

f = (x₁−2)² + (x₂−1)² + 1，∇f = (2(x₁−2), 2(x₂−1))ᵀ。x⁽¹⁾ = (0,0)ᵀ 处 ∇f⁽¹⁾ = (−4,−2)ᵀ。

**（1）起作用约束与方向 LP**：g₁ = −2x₁+x₂+1 = 1 > 0、g₂ = −x₁−x₂+2 = 2 > 0，均不起作用；起作用的是 x₁ ≥ 0、x₂ ≥ 0（都取等号），A₁ = I。方向 LP（规范化 |dⱼ| ≤ 1）：

    min ∇f⁽¹⁾ᵀd = −4d₁ − 2d₂
    s.t. d₁ ≥ 0，d₂ ≥ 0，−1 ≤ d₁ ≤ 1，−1 ≤ d₂ ≤ 1

目标把 d₁、d₂ 都往上推 ⇒ 最优解 **d⁽¹⁾ = (1,1)ᵀ**，最优值 −6 < 0 ⇒ 是下降可行方向（若最优值为 0 则已是 KKT 点）。

**（2）步长上限**：只需检查不起作用约束（∇gᵢᵀd < 0 的行）：

    g₁(x⁽¹⁾+λd) = 1 − λ ≥ 0 ⇒ λ ≤ 1
    g₂(x⁽¹⁾+λd) = 2 − 2λ ≥ 0 ⇒ λ ≤ 1

⇒ **λmax = 1**。

**（3）一维搜索**：φ(λ) = f(λ,λ) = (λ−2)² + (λ−1)² + 1 = 2λ² − 6λ + 6，0 ≤ λ ≤ 1。

    φ′(λ) = 4λ − 6 = 0 ⇒ λ = 3/2 > λmax ⇒ 取边界 λ₁ = 1。

**x⁽²⁾ = (0,0)ᵀ + 1·(1,1)ᵀ = (1,1)ᵀ**，f(x⁽²⁾) = 2。

> 注：x⁽²⁾ 恰为原问题最优解——此处 g₁、g₂ 都起作用，KKT 乘子 u₁ = u₂ = 2/3 ≥ 0；下一步方向 LP 最优值为 0，算法终止。

### 10.（10 分）外点罚函数法

**（1）** 等式约束 h(x) = x₁ + x₂ − 4 = 0，二次罚：

    F(x, σ) = x₁² + x₂² + σ(x₁ + x₂ − 4)²，σ > 0。

**（2）** 一阶条件：

    ∂F/∂x₁ = 2x₁ + 2σ(x₁ + x₂ − 4) = 0
    ∂F/∂x₂ = 2x₂ + 2σ(x₁ + x₂ − 4) = 0

两式相减 ⇒ x₁ = x₂；代回：2x₁ + 2σ(2x₁ − 4) = 0 ⇒ x₁(1 + 2σ) = 4σ ⇒

    x(σ) = (4σ/(2σ+1))·(1, 1)ᵀ。

∇²F = [[2+2σ, 2σ], [2σ, 2+2σ]] 特征值 2 与 2+4σ，正定 ⇒ x(σ) 是唯一全局极小点。

**（3）** lim_{σ→∞} 4σ/(2σ+1) = 2 ⇒ **x(σ) → (2, 2)ᵀ**。

验证：(2,2) 满足 x₁+x₂−4 = 0；在约束上 x₂ = 4−x₁，f = x₁² + (4−x₁)² = 2x₁² − 8x₁ + 16，在 x₁ = 2 取最小值 8，而 f(2,2) = 8 ⇒ **(2,2)ᵀ 是原问题最优解，f\* = 8**。（KKT 视角：∇f = (4,4) = v∇h，v = 4。）

## 五、开放题

### 11.（10 分）现代优化算法 vs 传统优化算法（以遗传算法 GA 为例）

> 按第二册模板 B 口径（约 500 字，可直接背）：

遗传算法（GA）是 20 世纪 80 年代初兴起的现代优化算法，模拟生物进化过程，以种群为单位在解空间进行随机全局搜索，流程为：编码 → 初始种群 → 适应度评价 → 选择 → 交叉 → 变异 → 新一代，直至终止；带约束时用罚函数处理。

与传统优化算法相比：（1）**搜索范围**：传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；GA 以种群在解空间全局采样，同初值不同随机数结果不同。（2）**函数要求**：传统算法要求目标函数至少一阶连续可微，需要梯度/Hessian；GA 只需适应度可计算，不要求可导，能处理不可微、离散、含噪问题。（3）**理论保证**：传统方法有 KKT、F-J 等最优性条件与收敛性定理，最优性可严格判定；GA 无最优性证明，只在概率意义上收敛到全局最优附近，且可能早熟收敛。（4）**适用问题**：传统方法适合凸或光滑的小规模问题，对 NP-hard 无能为力；GA 主要面向 NP-hard 的全局优化与组合优化问题。（5）**计算代价**：传统方法单次迭代快、精度高，但确定性全局方法（如分枝定界）复杂度极高、只能解小规模问题；GA 需评价大量个体，参数多而敏感。

联系在于：二者求解同一类优化问题，共用"生成候选解—评价—更新—停机"的迭代框架，共享凸性、下降方向、KKT 条件与罚函数等理论工具；且可互补融合——GA 负责全局探索、传统局部法负责精修。此外，单纯形法用摄动法跳出退化循环，与模拟退火降温、禁忌搜索禁忌表同属"跳出局部最优"的机制。

综上，现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力，是解决全局优化问题的有力工具。

> 评分点：差别 5 条 + 联系（最易漏）+ 一个具体算法机制；"概率意义上/满意解"的稳妥措辞别写成"确定求出全局最优"。
