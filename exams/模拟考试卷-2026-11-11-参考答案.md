## 一、简答题

### 1.（6 分）最速下降法 vs 牛顿法

**（1）最速下降法**：
- 优点：只需一阶梯度，不算 Hessian，每步计算量与存储量小；程序简单，对一般问题在适当线搜索下全局收敛性好。
- 缺点：相邻两次搜索方向互相正交，走"锯齿"路线；**线性收敛**，条件数大（病态）时极慢。

**（2）牛顿法**：
- 优点：**二阶（平方）收敛**，快；对正定二次函数一步即到极小点；具有仿射不变性。
- 缺点：要算 Hessian 并求逆（解线性方程组），计算量、存储量大；**局部收敛**，初值离极小点远时可能发散。

**（3）** 收敛速度：最速下降是线性收敛，牛顿是二阶收敛。当 **∇²f(x⁽ᵏ⁾) 不正定**（不定或奇异）时，牛顿方向可能不是下降方向（甚至不存在）。补救：**阻尼牛顿法**（保留牛顿方向、加一维搜索定步长）或**修正牛顿法**（Hessian 非正定时换修正矩阵 Gₖ）。

> 评分点：锯齿/线性 vs 二阶收敛必写；"Hessian 不正定"与两种补救各 1 分。

### 2.（6 分）Farkas 定理的几何表示形式

**择一表述**（PPT 定理 2.11）：设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0、cᵀx > 0 有解 ⇔ Aᵀy = c、y ≥ 0 无解。

等价的"有且只有一个成立"形式：① ∃x：Ax = b，x ≥ 0；② ∃y：Aᵀy ≥ 0，bᵀy < 0。

**几何表示**（置换定理 2.11′，画图用这个）：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥，则：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | ∃y ≥ 0：Aᵀy = c | c 落在锥内；凡满足 Ax ≤ 0 的方向 x 都与 c 成钝角/直角（cᵀx ≤ 0） |
| c ∉ S | Ax ≤ 0、cᵀx > 0 有解 | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0 且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

> 评分点："有且只有一个"（排他）必写；图画成**锥**（原点出发的射线束）+ 右图**过原点**的分离超平面并标法向量。锥对非负数乘封闭 ⇒ 分离超平面必过原点（会被追问）。证明骨架：必要性反证 cᵀx̄ = yᵀAx̄ ≤ 0 矛盾；充分性用闭凸锥严格分离（Th2.7）。

### 3.（6 分）0.618 法

**（1）基本思想**：在单峰区间 [a, b] 内对称取两个试探点，比较函数值，去掉不含极小点的一段，逐轮缩短区间直至满足精度。取点公式：

    λₖ = aₖ + 0.382(bₖ − aₖ)，μₖ = aₖ + 0.618(bₖ − aₖ)

f(λₖ) < f(μₖ) ⇒ 极小在 [aₖ, μₖ]，去右段；否则去左段 [λₖ, bₖ]。

**（2）** 每轮区间缩为原来的 **0.618** 倍。因为 0.382 = 1 − 0.618，缩区间后**保留的那个试探点恰好落在新区间的 0.618（或 0.382）位置上**，可直接复用，每轮只需新算一个点。

**（3）与 Fibonacci 法的关系**：① Fibonacci 法取点用 Fibonacci 数列之比 Fₙ₋ₖ₋₁/Fₙ₋ₖ₊₁、Fₙ₋ₖ/Fₙ₋ₖ₊₁，需**预先确定迭代次数 n**，缩短率逐轮变化；0.618 法缩短率固定，**无需预知 n**。② 当 n → ∞ 时 Fₙ₋₁/Fₙ → 0.618，故 **0.618 法是 Fibonacci 法的极限情形**（渐近缩短率相同）。

> 评分点：0.382/0.618 两个系数别写反；"复用保留点"是 0.618 的精髓；Fibonacci 取点下标以讲义为准（见 11-08 笔记修正）。

### 4.（6 分）外点法 vs 内点法（任答四点，每点 1.5 分）

| 对比项 | 外点罚函数法 | 内点罚函数法（障碍函数法） |
|---|---|---|
| 适用约束 | 等式 + 不等式均可 | **仅不等式**（且要求严格可行域非空） |
| 初始点 | 任意点（可在可行域外） | 必须是**严格可行内点**（gᵢ > 0） |
| 罚因子 | μₖ 递增 → **+∞**（SUMT） | μₖ 递减 → **0⁺**（μₖ₊₁ = βμₖ，β ∈ (0,1)） |
| 迭代点位置 | 从可行域**外**逼近边界最优解 | 始终在可行域**内**，沿中心路径逼近边界 |
| 罚项形式 | 违反量罚：Σ(max{0, −gᵢ})² + Σhⱼ² | 障碍项：−Σln gᵢ 或 Σ1/gᵢ（边界处 → ∞ 筑墙） |
| 终止判据 | μₖP(x⁽ᵏ⁾) < ε | μₖB(x⁽ᵏ⁾) < ε |

> 评分点：罚因子走向（∞ vs 0）与初始点要求是最易混的两点，必写。

### 5.（6 分）单纯形法选基与两阶段法

**（1）** 对 min 问题，检验数 σⱼ = cⱼ − zⱼ（zⱼ = c_BᵀB⁻¹aⱼ）：
- **进基**：选 σⱼ < 0 的非基变量（通常取**最负**者，目标改善最快）；
- **出基**：**最小比值规则** min{b̄ᵢ/āᵢₖ : āᵢₖ > 0}，保证迭代后仍可行（负系数行不参与比值）；
- **最优性检验**：所有 σⱼ ≥ 0 ⇒ 当前基本可行解最优。

**（2）** 当标准化后**没有现成的单位矩阵作初始基**（约束含 ≥ 或 =，找不到初始 BFS）时用两阶段法。第一阶段：加人工变量，辅助目标 **min w = Σ人工变量**。判据：**w\* = 0 且人工变量全部离基** ⇒ 得原问题一个 BFS，删人工列、换回原目标、检验数全部重算，转第二阶段；若 w\* > 0 ⇒ 原问题**无可行解**。

> 评分点：最小比值规则限定 āᵢₖ > 0；"w\*=0 判据句"与"σ 重算"是两阶段题的捞分点。

### 6.（20 分）两阶段法

**标准化**：≤ 约束加松弛变量 x₄；≥ 约束减过剩变量 x₅、加人工变量 a₁；= 约束加人工变量 a₂：

    x₁ − 2x₂ + x₃ + x₄        = 11
    −4x₁ + x₂ + 2x₃ − x₅ + a₁ = 3
    −2x₁ + x₃ + a₂            = 1

**第一阶段**：辅助 LP min w = a₁ + a₂（其余变量费用 0），初始基 (x₄, a₁, a₂)。

**表 P1-1**（基 (x₄,a₁,a₂)，c_B=(0,1,1)，w = 4）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₄ | 11 | 1 | −2 | 1 | 1 | 0 | 0 | 0 |
| a₁ | 3 | −4 | 1 | **2** | 0 | −1 | 1 | 0 |
| a₂ | 1 | −2 | 0 | 1 | 0 | 0 | 0 | 1 |
| σ | | 6 | −1 | **−3** | 0 | 1 | 0 | 0 |

（σ 重算示例：σ₁ = 0 − [0·1 + 1·(−4) + 1·(−2)] = 6；σ₃ = 0 − (0+2+1) = −3。）σ₃ = −3 最负 ⇒ x₃ 入基；比值 min{11/1, 3/2, 1/1} = 1 ⇒ a₂ 出基，主元 = 1。

**变换①**：a₂ 行即主行（主元 1）；x₄ 行 − 1×主行；a₁ 行 − 2×主行。

**表 P1-2**（基 (x₄,a₁,x₃)，c_B=(0,1,0)，w = 1）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₄ | 10 | 3 | −2 | 0 | 1 | 0 | 0 | −1 |
| a₁ | 1 | 0 | **1** | 0 | 0 | −1 | 1 | −2 |
| x₃ | 1 | −2 | 0 | 1 | 0 | 0 | 0 | 1 |
| σ | | 0 | **−1** | 0 | 0 | 1 | 0 | 3 |

σ₂ = −1 < 0 ⇒ x₂ 入基；比值：x₄ 行系数 −2 < 0 跳过，a₁ 行 1/1 = 1，x₃ 行系数 0 跳过 ⇒ a₁ 出基，主元 = 1。

**变换②**：a₁ 行即主行；x₄ 行 + 2×主行；x₃ 行不变。

**表 P1-3**（基 (x₄,x₂,x₃)，c_B=(0,0,0)，w = 0）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₄ | 12 | 3 | 0 | 0 | 1 | −2 | 2 | −5 |
| x₂ | 1 | 0 | 1 | 0 | 0 | −1 | 1 | −2 |
| x₃ | 1 | −2 | 0 | 1 | 0 | 0 | 0 | 1 |

c_B = (0,0,0) ⇒ σ ≡ c。**w\* = 0 且人工变量全部离基** ⇒ 过渡判据满足，得原问题一个 BFS：x₁ = 0、x₂ = 1、x₃ = 1。进入第二阶段。

**第二阶段**：删 a₁、a₂ 两列，目标换回 min z = −3x₁ + x₂ + x₃，基不变，**检验数全部重算**（c_B = (0,1,1)）。

**表 P2-1**（基 (x₄,x₂,x₃)，c_B=(0,1,1)，z = 2）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|---|
| x₄ | 12 | **3** | 0 | 0 | 1 | −2 |
| x₂ | 1 | 0 | 1 | 0 | 0 | −1 |
| x₃ | 1 | −2 | 0 | 1 | 0 | 0 |
| σ | | **−1** | 0 | 0 | 0 | 1 |

σ 重算示例：σ₁ = −3 − [0·3 + 1·0 + 1·(−2)] = −1；σ₅ = 0 − [0·(−2) + 1·(−1) + 1·0] = 1。σ₁ = −1 < 0 ⇒ x₁ 入基；比值：x₄ 行 12/3 = 4，x₂ 行系数 0 跳过，x₃ 行 −2 < 0 跳过 ⇒ x₄ 出基，主元 = 3。

**变换③**：主行 ÷3；x₂ 行不变；x₃ 行 + 2×新主行。

**表 P2-2**（基 (x₁,x₂,x₃)，c_B=(−3,1,1)，z = −2）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |

**最优性检验**：σ = (0, 0, 0, 1/3, 1/3) ≥ 0，全部非负 ⇒ 达到最优。

**结论**：x\* = **(4, 1, 9)ᵀ，z\* = −2**（x₄ = x₅ = 0，三个约束都取等：4−2+9 = 11 ✓，−16+1+18 = 3 ✓，−8+9 = 1 ✓）。

> 独立复核：可行域顶点共 2 个——(4,1,9) z = −2、(0,1,1) z = 2，最小值唯一，为 −2。
> 评分点：标准化"松弛/减过剩加人工"分清；每轮 σ 重算；**w\*=0 判据句必写**；最后必须报 x\* 和 z\*。

### 7.（15 分）KKT 条件与局部极小验证

约束化为 gᵢ ≥ 0 口径：g₁ = 2 − x₁ − x₂ ≥ 0，g₂ = 1 − x₁ ≥ 0，g₃ = x₁ ≥ 0，g₄ = x₂ ≥ 0。L = f − u₁g₁ − u₂g₂ − u₃g₃ − u₄g₄。

**（1）KKT 条件**：

    平稳性：∇f − Σuᵢ∇gᵢ = 0，即
      2(x₁ − 2) + u₁ + u₂ − u₃ = 0
      2(x₂ − 2) + u₁ − u₄ = 0
    互补松弛：u₁(2−x₁−x₂) = 0，u₂(1−x₁) = 0，u₃x₁ = 0，u₄x₂ = 0
    原始可行：2−x₁−x₂ ≥ 0，1−x₁ ≥ 0，x₁ ≥ 0，x₂ ≥ 0
    对偶可行：u₁, u₂, u₃, u₄ ≥ 0

**（2）验证 x\* = (1,1)ᵀ**：g₁ = 0、g₂ = 0（起作用），g₃ = 1 > 0、g₄ = 1 > 0（不起作用）⇒ 互补松弛给 u₃ = u₄ = 0。∇f(1,1) = (−2, −2)ᵀ，∇g₁ = (−1,−1)ᵀ，∇g₂ = (−1,0)ᵀ。平稳性：

    −2 + u₁ + u₂ = 0
    −2 + u₁ = 0   ⇒   u₁ = 2，u₂ = 0

u = (2, 0, 0, 0) ≥ 0，全部 KKT 条件成立 ⇒ **x\* 是 KKT 点**。（注意 g₂ 起作用但乘子 u₂ = 0——弱起作用，不影响 KKT 成立。）

**（3）** 约束均为线性，∇²ₓₓL = ∇²f = 2I **正定** ⇒ 二阶充分条件成立（临界锥上 dᵀ∇²ₓₓL d = 2‖d‖² > 0）⇒ x\* 是**严格局部极小点**。进一步：f 凸（Hessian 半正定）、可行域凸（线性约束）⇒ 凸规划，KKT 点即**全局极小点**，f\* = (1−2)² + (1−2)² = **2**。

> 评分点：g ≥ 0 口径下平稳性是 ∇f − Σu∇g = 0（符号别反）；"起作用 ⇒ 乘子未必为正"是本题陷阱；凸规划 ⇒ 全局必写理由。

### 8.（15 分）FR 共轭梯度法（讲义练习题 1 原题）

f = ½x₁² + x₂² = ½xᵀAx，A = diag(1, 2)，∇f = (x₁, 2x₂)ᵀ。

**第 1 步**：x⁽¹⁾ = (4,4)ᵀ，g₁ = (4,8)ᵀ，d⁽¹⁾ = −g₁ = **(−4,−8)ᵀ**。

    λ₁ = −g₁ᵀd⁽¹⁾ / (d⁽¹⁾ᵀAd⁽¹⁾) = 80 / 144 = 5/9
    （Ad⁽¹⁾ = (−4,−16)ᵀ，d⁽¹⁾ᵀAd⁽¹⁾ = 16+128 = 144；用 φ′(λ)=0 结果相同）

x⁽²⁾ = (4,4)ᵀ + (5/9)(−4,−8)ᵀ = **(16/9, −4/9)ᵀ**，g₂ = (16/9, −8/9)ᵀ。

    β₁ = ‖g₂‖²/‖g₁‖² = (320/81)/80 = 4/81
    d⁽²⁾ = −g₂ + β₁d⁽¹⁾ = (−16/9, 8/9)ᵀ + (4/81)(−4,−8)ᵀ = (−160/81, 40/81)ᵀ

**第 2 步**：

    g₂ᵀd⁽²⁾ = −2560/729 − 320/729 = −320/81
    Ad⁽²⁾ = (−160/81, 80/81)ᵀ，d⁽²⁾ᵀAd⁽²⁾ = 25600/6561 + 6400/6561 = 3200/729
    λ₂ = (320/81)/(3200/729) = 9/10

x⁽³⁾ = (16/9, −4/9)ᵀ + (9/10)(−160/81, 40/81)ᵀ = **(0, 0)ᵀ**，g₃ = 0，算法终止。

**（2）共轭验证**：d⁽¹⁾ᵀAd⁽²⁾ = (−4)(−160/81) + (−8)(80/81) = 640/81 − 640/81 = **0** ⇒ d⁽¹⁾、d⁽²⁾ 关于 A 共轭。n = 2 两步到达极小点——**二次终止性**（Th10.3.3：对 n 维正定二次函数至多 n 步终止）。

> 评分点：β 用梯度模平方比（FR 公式）；λ 用 −gᵀd/(dᵀAd)；最后必须报 x⁽³⁾=(0,0) 并点出二次终止性。

### 9.（15 分）DFP 拟牛顿法

f = 2x₁² + x₂²，∇f = (4x₁, 2x₂)ᵀ，A = diag(4, 2)。x⁽¹⁾ = (1,2)ᵀ，g₁ = (4,4)ᵀ，H₁ = I。

**（1）** d⁽¹⁾ = −H₁g₁ = **(−4,−4)ᵀ**。线搜索：φ(λ) = f(1−4λ, 2−4λ) = 48λ² − 32λ + 6，

    φ′(λ) = 96λ − 32 = 0 ⇒ λ₁ = 1/3。

x⁽²⁾ = (1,2)ᵀ + (1/3)(−4,−4)ᵀ = **(−1/3, 2/3)ᵀ**，g₂ = (−4/3, 4/3)ᵀ。

**（2）** p = x⁽²⁾ − x⁽¹⁾ = (−4/3, −4/3)ᵀ，q = g₂ − g₁ = (−16/3, −8/3)ᵀ。

    pᵀq = 64/9 + 32/9 = 32/3；H₁q = q，qᵀH₁q = 256/9 + 64/9 = 320/9。

DFP 校正：H₂ = H₁ + ppᵀ/(pᵀq) − (H₁q)(H₁q)ᵀ/(qᵀH₁q)

    ppᵀ/(32/3) = [[1/6, 1/6], [1/6, 1/6]]，qqᵀ/(320/9) = [[4/5, 2/5], [2/5, 1/5]]

    H₂ = I + [[1/6, 1/6], [1/6, 1/6]] − [[4/5, 2/5], [2/5, 1/5]]
       = [[11/30, −7/30], [−7/30, 29/30]]

自检：H₂q = (−4/3, −4/3)ᵀ = p ✓（拟牛顿条件/割线方程）；H₂ 对称，顺序主子式 11/30 > 0、det = (11·29−49)/900 = 270/900 > 0 ⇒ 正定。

**（3）** d⁽²⁾ = −H₂g₂ = **(4/5, −8/5)ᵀ**。线搜索：φ(λ) = f(−1/3+4λ/5, 2/3−8λ/5) = (96/25)λ² − (16/5)λ + 2/3，

    φ′(λ) = (192/25)λ − 16/5 = 0 ⇒ λ₂ = 5/12。

x⁽³⁾ = (−1/3, 2/3)ᵀ + (5/12)(4/5, −8/5)ᵀ = **(0, 0)ᵀ**，g₃ = 0，终止。

对 n 维正定二次函数，**Hₙ₊₁ = A⁻¹**（Th10.4.2 推论）。本题 **H₃ = A⁻¹ = diag(1/4, 1/2)**（脚本已验证：再作一次 DFP 校正即得）。

> 评分点：p = x 差、q = g 差别记反；两个校正项分母是 pᵀq 与 qᵀHq；Hq=p 自检是捞分点；最后报 x⁽³⁾ 与 H₃。

### 10.（15 分）Rosen 梯度投影法

f = (x₁−3)² + (x₂−1)²，∇f = (2(x₁−3), 2(x₂−1))ᵀ。约束化为 g ≥ 0：g₁ = 2−x₁−x₂，g₂ = x₁，g₃ = x₂。

**（1）起作用约束**：x⁽⁰⁾ = (1,1)ᵀ 处 g₁ = 0（**起作用**），g₂ = 1 > 0、g₃ = 1 > 0（不起作用）。

    M = ∇g₁ᵀ = (−1, −1)

**（2）投影矩阵**：MMᵀ = 2，

    P = I − Mᵀ(MMᵀ)⁻¹M = I − (1/2)[[1, 1], [1, 1]] = [[1/2, −1/2], [−1/2, 1/2]]

**（3）** ∇f(x⁽⁰⁾) = (−4, 0)ᵀ，

    d = −P∇f(x⁽⁰⁾) = −(−2, 2)ᵀ = (2, −2)ᵀ

验证：**下降性** ∇fᵀd = (−4)(2) + 0·(−2) = −8 < 0 ✓；**可行性** Md = (−1)(2) + (−1)(−2) = 0 ✓（沿起作用约束 x₁+x₂ = 2 这面"墙"滑动，不越界）。d ≠ 0 ⇒ **d = (2, −2)ᵀ 即为所求可行下降方向**。

> 按老师口径到此为止（不求 λmax、不迭代）。评分点：起作用约束判断（g₂、g₃ 有裕量不起作用）；P 的公式与计算；两个验证（∇fᵀd < 0、Md = 0）必写。M 取 (1,1)（约束 x₁+x₂ ≤ 2 的梯度）结果相同——P 与行符号无关。

## 三、开放题

### 11.（10 分）现代优化算法 vs 传统优化算法（以遗传算法 GA 为例）

> 按第二册模板口径（约 500 字，可直接背；换 SA/TS/DE 用第二册替换句清单）：

遗传算法（GA）是 20 世纪 80 年代初兴起的现代优化算法，模拟生物进化过程，以种群为单位在解空间进行随机全局搜索，流程为：编码 → 初始种群 → 适应度评价 → 选择 → 交叉 → 变异 → 新一代，直至终止；带约束时用罚函数处理。

与传统优化算法相比：（1）**搜索范围**：传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；GA 以种群在解空间全局采样，同初值不同随机数结果不同。（2）**函数要求**：传统算法要求目标函数至少一阶连续可微，需要梯度/Hessian；GA 只需适应度可计算，不要求可导，能处理不可微、离散、含噪问题。（3）**理论保证**：传统方法有 KKT、F-J 等最优性条件与收敛性定理，最优性可严格判定；GA 无最优性证明，只在概率意义上收敛到全局最优附近，且可能早熟收敛。（4）**适用问题**：传统方法适合凸或光滑的小规模问题，对 NP-hard 无能为力；GA 主要面向 NP-hard 的全局优化与组合优化问题。（5）**计算代价**：传统方法单次迭代快、精度高，但确定性全局方法（如分枝定界）复杂度极高、只能解小规模问题；GA 需评价大量个体，参数多而敏感。

联系在于：二者求解同一类优化问题，共用"生成候选解—评价—更新—停机"的迭代框架，共享凸性、下降方向、KKT 条件与罚函数等理论工具；且可互补融合——GA 负责全局探索、传统局部法负责精修。此外，单纯形法用摄动法跳出退化循环，与模拟退火降温、禁忌搜索禁忌表同属"跳出局部最优"的机制。

综上，现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力，是解决全局优化问题的有力工具。

> 评分点：差别 5 条 + 联系（最易漏）+ 一个具体算法机制；"概率意义上/满意解"的稳妥措辞别写成"确定求出全局最优"。
