## 一、简答题

### 1.（6 分）凸函数判别

**（1）** ∇f = (2x₁ − 2x₂ + 2, 8x₂ − 2x₁)ᵀ，∇²f = [[2, −2], [−2, 8]]（处处常数）。

顺序主子式：2 > 0，det = 16 − 4 = 12 > 0 ⇒ ∇²f **正定** ⇒ f 是**严格凸函数**（二阶判别法：C² 函数在 Rⁿ 上凸 ⇔ Hessian 处处半正定；正定则严格凸）。

**（2）** 定义（f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)）：函数抽象、不可微时；性质（保凸运算）：由已知凸函数搭建时最快；一阶条件（f(y) ≥ f(x)+∇f(x)ᵀ(y−x)）：可微、梯度好处理时；二阶条件（∇²f ⪰ 0）：二阶可微、表达式具体时最常用（本题就是）。

> 评分点：顺序主子式两个都要算；"正定 ⇒ 严格凸"别只写"凸"。

### 2.（6 分）共轭方向与扩张子空间定理

**（1）定义**：设 A 为 n×n 对称正定矩阵，非零向量组 d₁,…,dₖ 满足 dᵢᵀAdⱼ = 0（i ≠ j），则称它们关于 A **共轭**（A = I 时即正交）。

**（2）扩张子空间定理（Th10.3.2）**：对正定二次函数 f = ½xᵀAx + bᵀx + c，从任一点 x⁽¹⁾ 出发，依次沿 k 个关于 A 共轭的方向 d₁,…,dₖ 作精确一维搜索，则所得点 x⁽ᵏ⁺¹⁾ 是 f 在线性流形 x⁽¹⁾ + span{d₁,…,dₖ} 上的**唯一极小点**；特别地 k = n 时，x⁽ⁿ⁺¹⁾ 就是 f 在 Rⁿ 上的全局极小点。

**（3）** 由定理，n 个共轭方向张成整个 Rⁿ，故至多 n 步一维搜索即达全局极小点——**二次终止性**。且共轭向量组线性无关（Th10.3.1），n 个共轭方向必存在。

> 评分点：共轭定义里 A 对称正定、i≠j 条件；定理的"线性流形上唯一极小点"表述。

### 3.（6 分）牛顿法

**（1）迭代格式**：x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − [∇²f(x⁽ᵏ⁾)]⁻¹ ∇f(x⁽ᵏ⁾)。

**（2）局部收敛条件**（Th10.2.1）：f 二阶连续可微，∇²f(x*) 正定，初点 x⁽¹⁾ 充分接近 x*。局部收敛阶为 **2（二阶/平方收敛）**。

**（3）阻尼牛顿法**：保留牛顿方向 d⁽ᵏ⁾ = −[∇²f]⁻¹∇f，但步长不固定取 1，而是沿 d⁽ᵏ⁾ 作**一维搜索**定 λₖ。解决的问题：牛顿法步长恒 1 时初点远可能发散（不保证下降）；阻尼后每步保证 f 下降，改善全局收敛性。

> 评分点：收敛阶 2；阻尼 = 牛顿方向 + 一维搜索（区别于修正牛顿法换 Gₖ）。

### 4.（6 分）算法的一般概念（第 8 章）

**（1）** 算法映射 A 是**点到集映射**：对每点 x ∈ X 指定一个子集 A(x) ⊂ X，后继点 x⁽ᵏ⁺¹⁾ ∈ A(x⁽ᵏ⁾)（Df 8.1.1）。迭代下降算法每步两步：① 在 x⁽ᵏ⁾ 处求一个**下降（搜索）方向** p⁽ᵏ⁾；② 沿射线 x⁽ᵏ⁾+αp⁽ᵏ⁾ 作**一维搜索**定步长 αₖ，使 f(x⁽ᵏ⁺¹⁾) < f(x⁽ᵏ⁾)。

**（2）** 收敛：有限步得最优解，或点列的极限点是最优解；局部收敛：仅当初点充分接近 x* 时才收敛；全局收敛：任意初点都收敛于 x*。

**（3）** 终止准则（任两种）：‖x⁽ᵏ⁺¹⁾−x⁽ᵏ⁾‖ < ε；|f(x⁽ᵏ⁺¹⁾)−f(x⁽ᵏ⁾)| < ε；‖∇f(x⁽ᵏ⁾)‖ < ε；或上述组合。

> 评分点："点到集"是算法映射的关键（区别于点到点）；下降算法两步缺一不可。

### 5.（6 分）Farkas 定理的几何表示形式

**择一表述**（PPT 定理 2.11）：设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0、cᵀx > 0 有解 ⇔ Aᵀy = c、y ≥ 0 无解。

等价的"有且只有一个成立"形式：① ∃x：Ax = b，x ≥ 0；② ∃y：Aᵀy ≥ 0，bᵀy < 0。

**几何表示**（置换定理 2.11′）：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | ∃y ≥ 0：Aᵀy = c | c 落在锥内；凡满足 Ax ≤ 0 的方向 x 都与 c 成钝角/直角（cᵀx ≤ 0） |
| c ∉ S | Ax ≤ 0、cᵀx > 0 有解 | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0 且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

> 评分点："有且只有一个"必写；图画成锥 + 过原点的分离超平面并标法向量；锥对非负数乘封闭 ⇒ 超平面必过原点。

## 二、计算题

### 6.（20 分）两阶段法

**标准化**：两个 ≥ 约束各减过剩变量 x₃、x₄，再加人工变量 a₁、a₂：

    x₁ + 2x₂ − x₃ + a₁ = 6
    2x₁ + x₂ − x₄ + a₂ = 6

**第一阶段**：min w = a₁ + a₂，初始基 (a₁, a₂)。

**表 P1-1**（基 (a₁,a₂)，c_B=(1,1)，w = 12）

| 基 | b | x₁ | x₂ | x₃ | x₄ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|
| a₁ | 6 | 1 | 2 | −1 | 0 | 1 | 0 |
| a₂ | 6 | **2** | 1 | 0 | −1 | 0 | 1 |
| σ | | **−3** | −3 | 1 | 1 | 0 | 0 |

σ₁ = σ₂ = −3 并列最负，取 x₁ 入基；比值 min{6/1, 6/2} = 3 ⇒ a₂ 出基，主元 = 2。

**变换①**：主行 ÷2；a₁ 行 − 1×新主行。

**表 P1-2**（基 (a₁,x₁)，c_B=(1,0)，w = 3）

| 基 | b | x₁ | x₂ | x₃ | x₄ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|
| a₁ | 3 | 0 | **3/2** | −1 | 1/2 | 1 | −1/2 |
| x₁ | 3 | 1 | 1/2 | 0 | −1/2 | 0 | 1/2 |
| σ | | 0 | **−3/2** | 1 | −1/2 | 0 | 3/2 |

σ₂ = −3/2 最负 ⇒ x₂ 入基；比值 min{3/(3/2), 3/(1/2)} = min{2, 6} = 2 ⇒ a₁ 出基，主元 = 3/2。

**变换②**：主行 ×2/3；x₁ 行 − (1/2)×新主行。

**表 P1-3**（基 (x₂,x₁)，c_B=(0,0)，w = 0）

| 基 | b | x₁ | x₂ | x₃ | x₄ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|
| x₂ | 2 | 0 | 1 | −2/3 | 1/3 | 2/3 | −1/3 |
| x₁ | 2 | 1 | 0 | 1/3 | −2/3 | −1/3 | 2/3 |
| σ | | 0 | 0 | 0 | 0 | 1 | 1 |

**w\* = 0 且人工变量全部离基** ⇒ 得原问题 BFS：x₁ = 2、x₂ = 2。进入第二阶段。

**第二阶段**：删 a₁、a₂ 列，目标换回 min z = 2x₁ + 3x₂，**检验数全部重算**（c_B = (3,2)）。

**表 P2-1**（基 (x₂,x₁)，c_B=(3,2)，z = 10）

| 基 | b | x₁ | x₂ | x₃ | x₄ |
|---|---|---|---|---|---|
| x₂ | 2 | 0 | 1 | −2/3 | 1/3 |
| x₁ | 2 | 1 | 0 | 1/3 | −2/3 |
| σ | | 0 | 0 | 4/3 | 1/3 |

（σ₃ = 0 − [3·(−2/3) + 2·(1/3)] = 4/3；σ₄ = 0 − [3·(1/3) + 2·(−2/3)] = 1/3。）

**最优性检验**：σ = (0, 0, 4/3, 1/3) ≥ 0 ⇒ 第一阶段结束的基已是最优基，无需再迭代。

**结论**：x\* = **(2, 2)ᵀ，z\* = 10**（x₃ = x₄ = 0，两约束都取等：2+4 = 6 ✓，4+2 = 6 ✓）。

> 独立复核：顶点共 3 个——(2,2) z=10、(6,0) z=12、(0,6) z=18，最小值唯一为 10。
> 评分点：本题第二阶段 σ 重算后直接全非负（一步到位），仍要写"σ 重算 + 最优性检验"两句；w\*=0 判据句必写；报 x\* 和 z\*。

### 7.（15 分）最速下降法

f = x₁² + 2x₂²，∇f = (2x₁, 4x₂)ᵀ，A = diag(2, 4)。

**第 1 步**：x⁽¹⁾ = (2,1)ᵀ，g₁ = (4,4)ᵀ，d⁽¹⁾ = −g₁ = **(−4,−4)ᵀ**。

    λ₁ = −g₁ᵀd⁽¹⁾/(d⁽¹⁾ᵀAd⁽¹⁾) = 32/96 = 1/3

x⁽²⁾ = (2,1)ᵀ + (1/3)(−4,−4)ᵀ = **(2/3, −1/3)ᵀ**，g₂ = (4/3, −4/3)ᵀ。

**第 2 步**：d⁽²⁾ = −g₂ = **(−4/3, 4/3)ᵀ**。

    λ₂ = (32/9)/(96/9) = 1/3

x⁽³⁾ = (2/3,−1/3)ᵀ + (1/3)(−4/3,4/3)ᵀ = **(2/9, 1/9)ᵀ**。

**（2）** d⁽¹⁾ᵀd⁽²⁾ = (−4)(−4/3) + (−4)(4/3) = 16/3 − 16/3 = **0** ⇒ 相邻搜索方向正交（精确线搜索的必然结果：φ′(λₖ)=0 ⇒ gₖ₊₁ᵀd⁽ᵏ⁾=0）。这反映**锯齿现象**：迭代点在极小点附近来回折返；最速下降法**线性收敛**，条件数大时收敛很慢。

> 评分点：两步 λ 都是 1/3（本题 A 与初点的特殊配合）；正交验证必写；"锯齿 + 线性收敛"是结论句。

### 8.（15 分）0.618 法

f(x) = x² − 4x + 5，[a₁,b₁] = [0,3]。

**（1）第一轮**：

    λ₁ = 0 + 0.382×3 = 1.146，μ₁ = 0 + 0.618×3 = 1.854
    f(λ₁) = 1.729，f(μ₁) = 1.021

f(λ₁) > f(μ₁) ⇒ 极小在 [λ₁, b₁]，去左段 ⇒ 新区间 **[1.146, 3]**。

**（2）第二轮**：保留点 μ₁ = 1.854 成为新区间的 λ₂（复用，不重算）：

    λ₂ = 1.854，μ₂ = 1.146 + 0.618×(3 − 1.146) = 2.292
    f(λ₂) = 1.021，f(μ₂) = 1.085

f(λ₂) < f(μ₂) ⇒ 去右段 ⇒ 最终区间 **[1.146, 2.292]**，长度 **1.146**（≈ 3×0.618² = 1.1459）。

**（3）** 要求 3×0.618ⁿ ≤ 0.2 ⇒ 0.618ⁿ ≤ 1/15 ⇒ n ≥ ln(1/15)/ln(0.618) ≈ 5.63 ⇒ 至少 **6 轮**。

> 评分点：0.382/0.618 系数别反；第二轮 λ 复用第一轮 μ（只新算一个点）；轮数估算式要列出来再取整（向上）。

### 9.（15 分）内点罚函数法（讲义练习题原题）

**（1）** 约束 g(x) = x ≥ 0，严格可行域 x > 0。负对数障碍：

    F(x, μ) = (x + 1)² − μ ln x，μ > 0，x > 0。

**（2）** 一阶条件：F′(x) = 2(x + 1) − μ/x = 0 ⇒ 2x² + 2x − μ = 0 ⇒

    x(μ) = (−1 + √(1 + 2μ))/2（取正根，负根不在 x > 0 内）。

F″(x) = 2 + μ/x² > 0 ⇒ x(μ) 是唯一全局极小点。

**（3）** lim_{μ→0⁺} x(μ) = (−1 + 1)/2 = **0**。验证：在 x ≥ 0 上 f(x) = (x+1)² 单调递增，故 x\* = 0 是最优解，f\* = 1；且 x(μ) > 0 始终在可行域内（内点法特征），从内部逼近边界最优解。

> 评分点：障碍项 −μ ln x（边界处 → +∞ 筑墙）；求根取正根并说明理由；μ → 0⁺（内点法罚因子递减，别写成 ∞）。

### 10.（15 分）Zoutendijk 可行方向法

f = (x₁−2)² + (x₂−3)²，∇f = (2(x₁−2), 2(x₂−3))ᵀ。约束化 g ≥ 0：g₁ = 3−x₁−x₂，g₂ = x₁，g₃ = x₂。

**（1）起作用约束**：x⁽⁰⁾ = (0,3)ᵀ 处 g₁ = 0、g₂ = 0（**起作用**），g₃ = 3 > 0（不起作用）。∇f(x⁽⁰⁾) = (−4, 0)ᵀ。A₁ 的行：∇g₁ᵀ = (−1,−1)，∇g₂ᵀ = (1,0)。方向 LP（规范化 |dⱼ| ≤ 1）：

    min ∇fᵀd = −4d₁
    s.t.  −d₁ − d₂ ≥ 0（即 d₁ + d₂ ≤ 0）
          d₁ ≥ 0
          −1 ≤ d₁ ≤ 1，−1 ≤ d₂ ≤ 1

**（2）** 目标只含 d₁ 且系数 −4 < 0 ⇒ d₁ 取最大 1；由 d₁+d₂ ≤ 0 ⇒ d₂ ≤ −1，结合 d₂ ≥ −1 ⇒ d₂ = −1。**d⁽⁰⁾ = (1, −1)ᵀ**，LP 最优值 −4 < 0。

**（3）验证**：下降性 ∇fᵀd = (−4)(1) + 0·(−1) = −4 < 0 ✓；可行性 A₁d：−d₁−d₂ = −1+1 = 0 ≥ 0 ✓，d₁ = 1 ≥ 0 ✓（沿起作用约束 x₁+x₂ = 3 这面墙滑动）。d ≠ 0 且最优值 < 0 ⇒ **d⁽⁰⁾ = (1,−1)ᵀ 是可行下降方向**。

> 按老师口径到此为止。评分点：起作用集 {g₁,g₂}（g₃ 有裕量）；方向 LP 的约束 A₁d ≥ 0 与 |dⱼ| ≤ 1 都要写；两个验证必写。

## 三、开放题

### 11.（10 分）现代优化算法 vs 传统优化算法（以模拟退火 SA 为例）

> 按第二册模板 A 口径（约 480 字，可直接背）：

模拟退火（SA）是 20 世纪 80 年代初兴起的现代优化算法，源于固体退火原理：固体缓缓降温时粒子在每个温度达到平衡态，最终在常温达到内能最小的基态。SA 把目标函数值比拟为能量、解比拟为粒子状态，从某一初温出发，通过邻域扰动产生新解，若目标值下降则接受，否则按 Metropolis 准则以概率 exp(−Δf/T) 接受劣解，并按几何方式降温，直至温度低于终止值。

与传统优化算法相比：（1）**搜索范围**：传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；SA 通过以一定概率接受更差的解在解空间全局探索，温度高时接受劣解概率大，温度低时趋于只接受优解，从而可能跳出局部最优。（2）**函数要求**：传统算法要求目标函数至少一阶连续可微，需要梯度/Hessian；SA 只需目标值可计算，不要求可导，能处理不可微、离散、含噪问题。（3）**理论保证**：传统方法有 KKT、F-J 等最优性条件与收敛性定理，最优性可严格判定；SA 无最优性证明，只在概率意义下收敛，且收敛速度依赖降温策略。（4）**适用问题**：传统方法适合凸或光滑的小规模问题，对 NP-hard 无能为力；SA 主要面向 NP-hard 的全局优化与组合优化问题。（5）**计算代价**：传统方法单次迭代快、精度高，但确定性全局方法（如分枝定界）复杂度极高、只能解小规模问题；SA 需大量函数评价，参数（初温、降温系数）敏感。

联系在于：二者求解同一类优化问题，共用"产生候选解—评价—更新—停机"的迭代框架，共享凸性、下降方向、KKT 条件与罚函数等理论工具；且可互补融合——SA/GA 负责全局探索、传统局部法负责精修。此外，单纯形法用摄动法跳出退化循环，与 SA 的概率接受劣解、禁忌搜索的禁忌表同属跳出局部最优的机制。

综上，现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力，是解决全局优化问题的有力工具。

> 评分点：差别 5 条 + 联系（最易漏）+ SA 机制（Metropolis 准则 exp(−Δf/T)）；"概率意义上/满意解"别写成"确定求出全局最优"。
