## 一、简答题

### 1.（6 分）无约束极值条件

**（1）** 设 f 在 x* 附近可微/二次可微：
- **下降条件（Th7.1.1）**：若存在 d ≠ 0 使 ∇f(x*)ᵀd < 0，则 ∃δ > 0，对任意 λ ∈ (0, δ) 有 f(x* + λd) < f(x*)（一阶展开小步必下降）；
- **一阶必要条件**：x* 局部极小且 f 可微 ⇒ **∇f(x*) = 0**（驻点）；
- **二阶必要条件**：x* 局部极小且 f 二次可微 ⇒ ∇f(x*) = 0 且 **∇²f(x*) 半正定**；
- **二阶充分条件**：∇f(x*) = 0 且 ∇²f(x*) **正定** ⇒ x* 是（严格）局部极小点。

**（2）** f 可微凸时，x* 是全局最小点 **当且仅当 ∇f(x*) = 0**（Th7.1.5）。

> 评分点：必要/充分条件别写反（半正定是必要、正定是充分）；下降条件是“∃d 使 ∇fᵀd<0 ⇒ 可再下降”，常用来证明某点不是极小点。

### 2.（6 分）F-J 条件

**（1）Fritz John 条件（Th7.2.8）**：x* 是局部最优解，则存在**不全为零**的乘子 w₀ ≥ 0、wᵢ ≥ 0（i ∈ I，起作用不等式约束）、vⱼ ∈ R，使

    w₀∇f(x*) − Σᵢ wᵢ∇gᵢ(x*) − Σⱼ vⱼ∇hⱼ(x*) = 0

（证明路线：Th7.2.7 几何形式得不等式组无解 → 两不相交集合 → 凸集分离定理；考场写“由凸集分离定理”即可。）

**（2）** 差别就在 **w₀**：KKT 条件要求 w₀ > 0（可归一化为 1，即 ∇f = Σwᵢ∇gᵢ + Σvⱼ∇hⱼ，wᵢ ≥ 0）；F-J 允许 w₀ = 0。当 w₀ = 0 时一阶条件不含 ∇f 的信息，判不了下降方向，只能得到 F-J 点。**题目没给正则（约束规格）条件时只能得 F-J**；正则点处局部最优 ⇒ KKT 成立。

> 评分点：F-J 表述里“不全为零”和 w₀ ≥ 0 是关键词；KKT = F-J + w₀ > 0 + 正则点。

### 3.（6 分）修正牛顿法

**（1）** 牛顿方向 −[∇²f(x⁽ᵏ⁾)]⁻¹∇f 要求 Hessian 正定；当 ∇²f **不正定**（不定或奇异）时该方向可能不是下降方向、甚至不存在。修正牛顿法把 Hessian 换成一个**正定**的修正矩阵 Gₖ，迭代格式 x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − Gₖ⁻¹∇f(x⁽ᵏ⁾)。常用构造：逐次修正（H + τE，τ > 0）、对角修正（负对角元换成其模/小正数）、特征值修正（负特征元改为小正数）。条件：Gₖ 对称正定且 Gₖ − ∇²f 不太大（保证不改变“二阶信息”太多）。

**（2）** 阻尼牛顿法**只改步长**：保留牛顿方向、沿方向作一维搜索定 λₖ（解决步长取 1 可能过冲/不下降的问题）；修正牛顿法**只改方向**：把不定/奇异的 Hessian 修正为正定矩阵 Gₖ、步长仍取 1。两者可同时用（修正 + 阻尼）。

> 评分点：Gₖ 正定是必要条件；“阻尼改步长、修正改方向”各 1.5 分。

### 4.（6 分）函数逼近法（牛顿切线法与割线法）

**（1）牛顿切线法**：用 φ(λ) 在 λₖ 处的二阶 Taylor 逼近（切线/抛物线近似）求 φ′ = 0 的解：

    λₖ₊₁ = λₖ − φ′(λₖ)/φ″(λₖ)（单峰情形即 −f′(xₖ)/f″(xₖ) 的线搜索版）

中止条件：|φ′(λₖ)| ≤ ε 或区间/间距小于给定精度（需保证 λₖ₊₁ 落在搜索区间内，否则取边界/混合策略）。

**（2）割线法（伪牛顿法）**：不用二阶导数，用**差商代替二阶导数**：

    λₖ₊₁ = λₖ − φ′(λₖ)·(λₖ − λₖ₋₁) / (φ′(λₖ) − φ′(λₖ₋₁))

它复用上一步的 λₖ₋₁ 与 φ′(λₖ₋₁)，每轮只需新算一个点的导数值——与 0.618 法“复用保留点”同思路，每轮只增加一次函数/导数求值。

> 评分点：两个公式别混（切线法用 φ″，割线法用差商）；割线法“每轮只多算一个点”的理由是复用上轮信息。

### 5.（6 分）Farkas 定理的几何表示形式

**择一表述**（PPT 定理 2.11）：设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0、cᵀx > 0 有解 ⇔ Aᵀy = c、y ≥ 0 无解。

等价的“有且只有一个成立”形式：① ∃x：Ax = b，x ≥ 0；② ∃y：Aᵀy ≥ 0，bᵀy < 0。

**几何表示**（置换定理 2.11′）：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | ∃y ≥ 0：Aᵀy = c | c 落在锥内；凡满足 Ax ≤ 0 的方向 x 都与 c 成钝角/直角（cᵀx ≤ 0） |
| c ∉ S | Ax ≤ 0、cᵀx > 0 有解 | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0 且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

> 评分点：“有且只有一个”必写；图画成锥 + 过原点的分离超平面并标法向量；锥对非负数乘封闭 ⇒ 超平面必过原点。

## 二、计算题

### 6.（20 分）两阶段法

**标准化**：两个 ≥ 约束各减过剩变量 x₄、x₅，再加人工变量 a₁、a₂：

    x₁ + x₂ + x₃ − x₄ + a₁ = 6
    x₁ + x₂ + 2x₃ − x₅ + a₂ = 8

**第一阶段**：min w = a₁ + a₂，初始基 (a₁, a₂)。

**表 P1-1**（基 (a₁,a₂)，c_B=(1,1)，w = 14）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| a₁ | 6 | 1 | 1 | 1 | −1 | 0 | 1 | 0 |
| a₂ | 8 | 1 | 1 | **2** | 0 | −1 | 0 | 1 |
| σ | | −2 | −2 | **−3** | 1 | 1 | 0 | 0 |

σ₃ = −3 最负 ⇒ x₃ 入基；比值 min{6/1, 8/2} = 4 ⇒ a₂ 出基，主元 = 2。

**变换①**：主行 ÷2；a₁ 行 − 1×新主行。

**表 P1-2**（基 (a₁,x₃)，c_B=(1,0)，w = 2）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| a₁ | 2 | **1/2** | **1/2** | 0 | −1 | 1/2 | 1 | −1/2 |
| x₃ | 4 | 1/2 | 1/2 | 1 | 0 | −1/2 | 0 | 1/2 |
| σ | | **−1/2** | **−1/2** | 0 | 1 | −1/2 | 0 | 3/2 |

σ₁ = σ₂ = −1/2 并列最负，取 x₁ 入基；比值 min{2/(1/2), 4/(1/2)} = min{4, 8} = 4 ⇒ a₁ 出基，主元 = 1/2。

**变换②**：主行 ×2；x₃ 行 − (1/2)×新主行。

**表 P1-3**（基 (x₁,x₃)，c_B=(0,0)，w = 0）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ | a₁ | a₂ |
|---|---|---|---|---|---|---|---|---|
| x₁ | 4 | 1 | 1 | 0 | −2 | 1 | 2 | −1 |
| x₃ | 2 | 0 | 0 | 1 | 1 | −1 | −1 | 1 |
| σ | | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

**w\* = 0 且人工变量全部离基** ⇒ 得原问题 BFS：x₁ = 4、x₂ = 0、x₃ = 2。进入第二阶段。

**第二阶段**：删 a₁、a₂ 列，目标换回 min z = x₁ + 2x₂ + 3x₃，**检验数全部重算**（c_B = (1,3)）。

**表 P2-1**（基 (x₁,x₃)，c_B=(1,3)，z = 10）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|---|
| x₁ | 4 | 1 | 1 | 0 | −2 | 1 |
| x₃ | 2 | 0 | 0 | 1 | 1 | −1 |
| σ | | 0 | 1 | 0 | **−1** | 2 |

（σ₂ = 2 − (1·1 + 3·0) = 1；σ₄ = 0 − (1·(−2) + 3·1) = −1；σ₅ = 0 − (1·1 + 3·(−1)) = 2。）σ₄ = −1 < 0 ⇒ x₄ 入基；比值：x₁ 行系数 −2 < 0 跳过，x₃ 行 2/1 = 2 ⇒ x₃ 出基，主元 = 1。

**变换③**：x₃ 行即主行；x₁ 行 + 2×主行。

**表 P2-2**（基 (x₁,x₄)，c_B=(1,0)，z = 8）

| 基 | b | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|---|
| x₁ | 8 | 1 | 1 | 2 | 0 | −1 |
| x₄ | 2 | 0 | 0 | 1 | 1 | −1 |
| σ | | 0 | 1 | 1 | 0 | 1 |

**最优性检验**：σ = (0, 1, 1, 0, 1) ≥ 0，全部非负 ⇒ 达到最优。

**结论**：x\* = **(8, 0, 0)ᵀ，z\* = 8**（x₄ = 2、x₅ = 0：第一约束 8 ≥ 6 ✓ 松，第二约束 8 = 8 取等 ✓）。

> 独立复核：顶点共 5 个——(4,0,2) z=10、(8,0,0) z=8、(0,4,2) z=14、(0,8,0) z=16、(0,0,6) z=18，最小值唯一为 8。
> 评分点：σ 并列最负时取下标小者（Bland 思想，避免循环）；w\*=0 判据句；第二阶段 σ 重算（注意 c_B 变了）；报 x\* 和 z\*。

### 7.（15 分）修正牛顿法

f = (x₁² − 1)² + x₂²。∇f = (4x₁³ − 4x₁, 2x₂)ᵀ = (4x₁(x₁² − 1), 2x₂)ᵀ，∇²f = diag(12x₁² − 4, 2)。

**（1）** x⁽¹⁾ = (1/2, 1/2)ᵀ：

    ∇f(x⁽¹⁾) = (4·(1/2)·((1/4) − 1), 2·(1/2))ᵀ = (−3/2, 1)ᵀ
    ∇²f(x⁽¹⁾) = diag(12·(1/4) − 4, 2) = diag(−1, 2)

Hessian 第一主元 −1 < 0 ⇒ **不定** ⇒ 牛顿方向 −[∇²f]⁻¹∇f 无定义/不是下降方向，不能直接用。

**（2）** 修正矩阵 G₁ = diag(3, 6)（把负特征值 −1 修正为 +3，2 不变；G₁ 正定）：

    d⁽¹⁾ = −G₁⁻¹∇f = −(−3/2/3, 1/6)ᵀ = (1/2, −1/6)ᵀ
    x⁽²⁾ = (1/2, 1/2)ᵀ + (1/2, −1/6)ᵀ = (1, 1/3)ᵀ

**（3）验证**：∇f(x⁽¹⁾)ᵀd⁽¹⁾ = (−3/2)(1/2) + 1·(−1/6) = −3/4 − 1/6 = **−11/12 < 0** ⇒ 是下降方向。

    f(x⁽¹⁾) = ((1/4) − 1)² + 1/4 = 9/16 + 1/4 = 13/16
    f(x⁽²⁾) = (1 − 1)² + 1/9 = 1/9 < 13/16 ✓

函数值下降；且 x⁽²⁾ = (1, 1/3)ᵀ 已靠近全局最优解 (±1, 0)（f 为两个分离的“势阱”，x₁ = 1 是最优点所在坑）。

> 评分点：Hessian 不定的判断（第一主元 −1）；修正矩阵要说明“正定”；d = −G⁻¹g 不是 −H⁻¹g；两个验证（下降性 + 函数值比较）必写。

### 8.（15 分）KKT 条件（求所有 KKT 点）

约束化 g ≥ 0：g₁ = 3 − x₁ − x₂ ≥ 0，g₂ = x₁ ≥ 0，g₃ = x₂ ≥ 0。L = f − u₁g₁ − u₂g₂ − u₃g₃。

**（1）KKT 条件**：

    平稳性：∇f − Σuᵢ∇gᵢ = 0，即
      2(x₁ − 4) + u₁ − u₂ = 0
      2(x₂ − 2) + u₁ − u₃ = 0
    互补松弛：u₁(3 − x₁ − x₂) = 0，u₂x₁ = 0，u₃x₂ = 0
    原始可行：3 − x₁ − x₂ ≥ 0，x₁ ≥ 0，x₂ ≥ 0
    对偶可行：u₁, u₂, u₃ ≥ 0

**（2）分情形求所有 KKT 点**：
- **u₁ = 0**：平稳性给 u₂ = 2(x₁−4) ≥ 0 ⇒ x₁ ≥ 4，u₃ = 2(x₂−2) ≥ 0 ⇒ x₂ ≥ 2，则 g₁ = 3 − x₁ − x₂ ≤ −3 < 0，不可行。无解。
- **u₁ > 0** ⇒ 互补松弛给 x₁ + x₂ = 3：
  - x₁ > 0、x₂ > 0 ⇒ u₂ = u₃ = 0 ⇒ u₁ = 8 − 2x₁ = 4 − 2x₂ ⇒ x₁ = x₂ + 2；联立 x₁ + x₂ = 3 ⇒ **x₁ = 5/2，x₂ = 1/2，u₁ = 3** ≥ 0 ✓；
  - x₁ = 0（x₂ = 3）：方程给 −8 + u₁ − u₂ = 0、−2 + u₁ − u₃ = 0；由第二式 u₁ ≥ 2，第一式 u₂ = u₁ − 8 < 0 ✗；
  - x₂ = 0（x₁ = 3）：对称地 −2 + u₁ − u₂ = 0、−4 + u₁ − u₃ = 0 ⇒ u₁ = 2、u₃ = −2 < 0 ✗。

**唯一 KKT 点：x\* = (5/2, 1/2)ᵀ，u = (3, 0, 0)**。

**（3）** f 凸（∇²f = 2I 正定）、可行域凸（线性约束）⇒ 凸规划，KKT 点即**全局最小点**（Th7.2.10），f\* = (5/2−4)² + (1/2−2)² = 9/4 + 9/4 = **9/2**。

> 评分点：u₁ = 0 情形不可行的论证（易漏）；u₁ > 0 时 x₁+x₂=3 + 三个子情形；凸规划 ⇒ 全局必写理由（f 凸 + 可行域凸）。

### 9.（15 分）非线性约束的 Zoutendijk 可行方向法

f = (x₁−2)² + (x₂−2)²，∇f = (2(x₁−2), 2(x₂−2))ᵀ。约束化 g ≥ 0：g₁ = 4 − x₁² − x₂² ≥ 0（**非线性**），g₂ = x₁ ≥ 0，g₃ = x₂ ≥ 0。

**（1）起作用约束**：x⁽⁰⁾ = (2,0)ᵀ 处 g₁ = 4 − 4 − 0 = **0（起作用）**，g₃ = x₂ = **0（起作用）**，g₂ = x₁ = 2 > 0（不起作用）。

    ∇f(x⁽⁰⁾) = (0, −4)ᵀ
    ∇g₁ = (−2x₁, −2x₂)ᵀ = (−4, 0)ᵀ，∇g₃ = (0, 1)ᵀ

**（2）非线性约束的方向 LP**（式 12.1.31；与线性约束版“min ∇fᵀd s.t. A₁d ≥ 0”的区别：线性化后目标与约束梯度都放进 LP，用变量 z 统一“下降量”，且约束写成 ∇gᵢᵀd + z ≥ 0）：

    min z
    s.t.  ∇f(x⁽⁰⁾)ᵀd − z ≤ 0        （即 −4d₂ − z ≤ 0）
          ∇g₁ᵀd + z ≥ 0             （即 −4d₁ + z ≥ 0）
          ∇g₃ᵀd + z ≥ 0             （即 d₂ + z ≥ 0）
          |d₁| ≤ 1,  |d₂| ≤ 1

**（3）** 三个下界：z ≥ −4d₂、z ≥ 4d₁、z ≥ −d₂。令 d₂ = 1（压第一个下界）、d₁ = −1（压第二个下界）⇒ z ≥ max(−4, −4, −1) = −1，且 d = (−1, 1) 时取等。

    d⁽⁰⁾ = (−1, 1)ᵀ，LP 最优值 z* = −1 < 0

**验证**：下降性 ∇fᵀd = 0·(−1) + (−4)(1) = **−4 < 0** ✓；可行性 ∇g₁ᵀd = (−4)(−1) = **4 > 0** ✓（远离圆弧约束）、∇g₃ᵀd = **1 > 0** ✓（进入 x₂ > 0）。d ≠ 0 且 z* < 0 ⇒ **d⁽⁰⁾ = (−1, 1)ᵀ 是可行下降方向**。

> 按老师口径到此为止。评分点：起作用集 {g₁, g₃}（g₂ 有裕量）；非线性版 LP 用 z 统一三式的写法（与线性版 A₁d ≥ 0 不同，别写混）；三个验证（∇fᵀd<0、两个 ∇gᵀd>0）必写。

### 10.（15 分）外点罚函数法（不等式约束，讲义例 1 原题）

**（1）** g(x) = −x − 1 ≥ 0，违反量 = max{0, −g} = max{0, x + 1}。二次罚：

    F(x, σ) = x² + σ·(max{0, x + 1})²，σ > 0

**（2）分两段**：
- **x ≤ −1**：罚项为 0，F = x²，在 (−∞, −1] 上最小值在边界 x = −1，F(−1) = 1；
- **x > −1**：F = x² + σ(x + 1)²，F′ = 2x + 2σ(x + 1) = 0 ⇒ x(1 + σ) = −σ ⇒

      x(σ) = −σ/(1 + σ) ∈ (−1, 0)

  F″ = 2 + 2σ > 0 ⇒ 是该段唯一极小点，函数值 F(x(σ)) = σ²/(1+σ)² + σ/(1+σ)² = **σ/(1 + σ)**。

比较：σ/(1+σ) < 1 = F(−1) 对一切 σ > 0 成立 ⇒ **全局极小点 x(σ) = −σ/(1 + σ)**。

**（3）** lim_{σ→+∞} −σ/(1 + σ) = **−1**。验证：可行域为 x ≤ −1，f = x² 在 x ≤ −1 上单调递减（x 越负 f 越大），最小值在边界 x = −1，f\* = 1 ⇒ **x\* = −1 是原问题最优解**（外点法从可行域外 x(σ) > −1 一侧逼近边界最优解）。

> 评分点：不等式罚项是 (max{0, −g})² = (max{0, x+1})²，别忘平方里的符号；两段讨论 + 两段函数值比较（只解 F′=0 不够，要说明它比 x≤−1 段小）；极限与验证。

## 三、开放题

### 11.（10 分）现代优化算法 vs 传统优化算法（以遗传算法 GA 为例）

> 按第二册模板 B 口径（约 500 字，可直接背；换 SA/TS/DE 用第二册替换句清单）：

遗传算法（GA）是 20 世纪 80 年代初兴起的现代优化算法，模拟生物进化过程，以种群为单位在解空间进行随机全局搜索，流程为：编码 → 初始种群 → 适应度评价 → 选择 → 交叉 → 变异 → 新一代，直至终止；带约束时用罚函数处理。

与传统优化算法相比：（1）**搜索范围**：传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；GA 以种群在解空间全局采样，同初值不同随机数结果不同。（2）**函数要求**：传统算法要求目标函数至少一阶连续可微，需要梯度/Hessian；GA 只需适应度可计算，不要求可导，能处理不可微、离散、含噪问题。（3）**理论保证**：传统方法有 KKT、F-J 等最优性条件与收敛性定理，最优性可严格判定；GA 无最优性证明，只在概率意义上收敛到全局最优附近，且可能早熟收敛。（4）**适用问题**：传统方法适合凸或光滑的小规模问题，对 NP-hard 无能为力；GA 主要面向 NP-hard 的全局优化与组合优化问题。（5）**计算代价**：传统方法单次迭代快、精度高，但确定性全局方法（如分枝定界）复杂度极高、只能解小规模问题；GA 需评价大量个体，参数多而敏感。

联系在于：二者求解同一类优化问题，共用“生成候选解—评价—更新—停机”的迭代框架，共享凸性、下降方向、KKT 条件与罚函数等理论工具；且可互补融合——GA 负责全局探索、传统局部法负责精修。此外，单纯形法用摄动法跳出退化循环，与模拟退火降温、禁忌搜索禁忌表同属“跳出局部最优”的机制。

综上，现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力，是解决全局优化问题的有力工具。
