## 二、计算题（共 80 分）

**6.（20 分）** 用两阶段单纯形法求解下列线性规划，写出两个阶段的完整单纯形表（含最优性检验）：

    min z = x₁ + 2x₂ + 3x₃
    s.t.  x₁ + x₂ + x₃ ≥ 6
          x₁ + x₂ + 2x₃ ≥ 8
          x₁, x₂, x₃ ≥ 0

**7.（15 分）** 设 f(x) = (x₁² − 1)² + x₂²，初点 x⁽¹⁾ = (1/2, 1/2)ᵀ。
（1）（5 分）求 x⁽¹⁾ 处的梯度与 Hessian，说明为什么不能直接用牛顿方向；
（2）（6 分）取修正矩阵 G₁ = diag(3, 6)（把 Hessian 的负特征值 −1 修正为 +3），求修正牛顿方向 d⁽¹⁾ = −G₁⁻¹∇f(x⁽¹⁾) 与 x⁽²⁾；
（3）（4 分）验证 d⁽¹⁾ 是下降方向，并比较 f(x⁽¹⁾) 与 f(x⁽²⁾)。

**8.（15 分）** 对约束优化问题

    min f(x) = (x₁ − 4)² + (x₂ − 2)²
    s.t.  x₁ + x₂ ≤ 3,  x₁ ≥ 0,  x₂ ≥ 0

（1）（5 分）写出 KKT 条件（按课程口径：约束化为 gᵢ(x) ≥ 0，L = f − Σuᵢgᵢ）；
（2）（6 分）分情形求出所有 KKT 点及对应乘子；
（3）（4 分）判断所得 KKT 点是否为（全局）最小点，给出依据。

**9.（15 分）** 对问题

    min f(x) = (x₁ − 2)² + (x₂ − 2)²
    s.t.  x₁² + x₂² ≤ 4,  x₁ ≥ 0,  x₂ ≥ 0

从 x⁽⁰⁾ = (2, 0)ᵀ 出发，用 Zoutendijk 可行方向法求可行下降方向：
（1）（5 分）指出起作用约束，计算 ∇f(x⁽⁰⁾) 与起作用约束的梯度；
（2）（6 分）写出非线性约束的方向 LP（式 12.1.31，注意与线性约束版 LP 的区别）；
（3）（4 分）解 LP 得 d⁽⁰⁾，并验证其下降性与可行性。

> 按 2026-11-10 老师口径，CH12 考到“求可行下降方向”为止：本题不求 λmax、不作一维搜索、不迭代。

**10.（15 分）** 对问题 min f(x) = x²，s.t. −x − 1 ≥ 0，用外点罚函数法：
（1）（4 分）构造罚函数 F(x, σ)（二次罚，注意不等式约束的罚项写法）；
（2）（6 分）求无约束问题 min F(x, σ) 的极小点 x(σ)（分 x ≤ −1 与 x > −1 两段讨论）；
（3）（5 分）求 σ → +∞ 时 x(σ) 的极限，并验证它是原问题的最优解。
