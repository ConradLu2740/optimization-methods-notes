## 一、简答题

### 1.（6 分）Farkas 定理的几何表示形式

**择一表述**（PPT 定理 2.11）：设 A 为 m×n 矩阵，c 为 n 维向量，则

> Ax ≤ 0、cᵀx > 0 有解 ⇔ Aᵀy = c、y ≥ 0 无解。

等价的"有且只有一个成立"形式：① ∃x：Ax = b，x ≥ 0；② ∃y：Aᵀy ≥ 0，bᵀy < 0。

**几何表示**（置换定理 2.11′）：记 S = cone{a₁,…,a_m} = {Aᵀy : y ≥ 0} 为 A 的行向量生成的凸锥：

| 情形 | 代数结论 | 几何图像 |
|---|---|---|
| c ∈ S | ∃y ≥ 0：Aᵀy = c | c 落在锥内；凡满足 Ax ≤ 0 的方向 x 都与 c 成钝角/直角（cᵀx ≤ 0） |
| c ∉ S | Ax ≤ 0、cᵀx > 0 有解 | 存在**过原点**的分离超平面 H: xᵀz = 0，法向量 x 满足 aᵢᵀx ≤ 0 且 cᵀx > 0 |

![Farkas 定理的几何表示](Farkas定理-几何表示形式-图.png)

> 评分点："有且只有一个"必写；图画成锥 + 过原点的分离超平面并标法向量；锥对非负数乘封闭 ⇒ 超平面必过原点。

### 2.（6 分）极点与基本可行解

**（1）** 设 x* 是最优解。由多面体表示定理 x* = Σλᵢvᵢ + Σμⱼdⱼ（vᵢ 极点、dⱼ 极方向）。因最优值有限，必有 cᵀdⱼ ≥ 0（否则沿 dⱼ 走目标 → −∞）。于是 cᵀx* = Σλᵢcᵀvᵢ + Σμⱼcᵀdⱼ ≥ Σλᵢcᵀvᵢ ≥ minᵢ{cᵀvᵢ}。取达到 min 的极点 vₖ，则 cᵀvₖ ≤ cᵀx*；又 x* 最优，故 cᵀvₖ = cᵀx*，即**极点 vₖ 也是最优解**。

**（2）** 对标准形可行域 {x | Ax = b, x ≥ 0}，**x 是极点 ⇔ x 是基本可行解**（CH2 Th2.4）。

**（3）** 最优解既可在极点达到，而极点 = BFS，故单纯形法只需在 BFS（极点）之间迭代搜索，不必搜整个可行域。

> 评分点：极方向 cᵀdⱼ ≥ 0 的论证（易漏）；"极点 ⇔ BFS"是 Th2.4。

### 3.（6 分）拟牛顿条件

**（1）** 对 ∇f 在 x⁽ᵏ⁺¹⁾ 处作 Taylor 展开：∇f(x⁽ᵏ⁾) ≈ ∇f(x⁽ᵏ⁺¹⁾) + ∇²f(x⁽ᵏ⁺¹⁾)(x⁽ᵏ⁾ − x⁽ᵏ⁺¹⁾)。记 p = x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾、q = ∇f(x⁽ᵏ⁺¹⁾) − ∇f(x⁽ᵏ⁾)，则 q ≈ ∇²f·p，即 p ≈ (∇²f)⁻¹q。用 Hₖ₊₁ 近似 (∇²f)⁻¹，要求 **Hₖ₊₁q = p**（拟牛顿条件/割线方程）——只用梯度差与位移差，不必算 Hessian。

**（2）** 优点：不算 Hessian、不求逆（每步只作秩 2 校正），计算量存储量小；保持 Hₖ 正定从而方向必下降；对二次函数有二次终止性，一般函数超线性收敛。

**（3）** DFP 保持正定的条件：**pᵀq > 0**（精确线搜索下自动满足，因 pᵀq = λdᵀ(∇²f)d > 0）。

> 评分点：Taylor 展开推出 q ≈ Ap 是"由来"的核心；pᵀq > 0 别写成 pᵀq ≠ 0。

### 4.（6 分）罚函数法思想

**（1）** 基本思想：构造辅助函数 F = f + μP（P 为违反约束的罚项），把约束问题化为一系列**无约束**问题求解，令罚因子按某方向变化使极小点逼近原问题最优解。经济解释：**总代价 = 价格（目标 f）+ 罚款（违反约束的代价 μP）**。

**（2）** 外点法迭代点可在可行域外；若 μ 不够大，"违反约束省下的目标值"可能超过罚款，极小点就停在可行域外。只有 μ → +∞，违反约束的代价才压倒一切，迫使违反量 → 0、极小点从外部逼近边界最优解。

**（3）** 缺点：μ 很大时 F 的 Hessian **病态**（条件数随 μ 增大），无约束子问题数值求解困难；迭代点不可行（对必须全程可行的实际问题不适用）。

> 评分点：经济解释"价格+罚款"；μ→∞ 的"罚款压倒收益"论证；病态是外点法核心缺点。

### 5.（6 分）退化与循环

**（1）** 退化基本可行解：BFS 中**有基变量取值为 0**（即多于 n−m 个约束在该点取等，极点处"过度确定"）。

**（2）** 退化时最小比值可能为 0，换基后目标值不变（原地踏步），可能出现**循环**——基序列周而复始，单纯形法永不终止。

**（3）** 两种避免方法：**摄动法**（把 b 微扰为 b+ε 使退化消失，再令 ε→0）；**Bland 规则**（进基、出基都选下标最小者，可证避免循环）。

> 评分点：退化 = 基变量为 0；循环 = 不终止；摄动法/Bland 规则各 1 分。

## 二、计算题

### 6.（20 分）两阶段法

**标准化**：= 约束加人工变量 a₁；≥ 约束减过剩变量 x₃、加人工变量 a₂：

    x₁ + x₂ + a₁ = 3
    x₁ − x₂ − x₃ + a₂ = 1

**第一阶段**：min w = a₁ + a₂，初始基 (a₁, a₂)。

**表 P1-1**（基 (a₁,a₂)，c_B=(1,1)，w = 4）

| 基 | b | x₁ | x₂ | x₃ | a₁ | a₂ |
|---|---|---|---|---|---|---|
| a₁ | 3 | 1 | 1 | 0 | 1 | 0 |
| a₂ | 1 | **1** | −1 | −1 | 0 | 1 |
| σ | | **−2** | 0 | 1 | 0 | 0 |

σ₁ = −2 最负 ⇒ x₁ 入基；比值 min{3/1, 1/1} = 1 ⇒ a₂ 出基，主元 = 1。

**变换①**：a₂ 行即主行；a₁ 行 − 1×主行。

**表 P1-2**（基 (a₁,x₁)，c_B=(1,0)，w = 2）

| 基 | b | x₁ | x₂ | x₃ | a₁ | a₂ |
|---|---|---|---|---|---|---|
| a₁ | 2 | 0 | **2** | 1 | 1 | −1 |
| x₁ | 1 | 1 | −1 | −1 | 0 | 1 |
| σ | | 0 | **−2** | −1 | 0 | 2 |

σ₂ = −2 最负 ⇒ x₂ 入基；比值：a₁ 行 2/2 = 1，x₁ 行系数 −1 < 0 跳过 ⇒ a₁ 出基，主元 = 2。

**变换②**：主行 ÷2；x₁ 行 + 1×新主行。

**表 P1-3**（基 (x₂,x₁)，c_B=(0,0)，w = 0）

| 基 | b | x₁ | x₂ | x₃ | a₁ | a₂ |
|---|---|---|---|---|---|---|
| x₂ | 1 | 0 | 1 | 1/2 | 1/2 | −1/2 |
| x₁ | 2 | 1 | 0 | −1/2 | 1/2 | 1/2 |
| σ | | 0 | 0 | 0 | 1 | 1 |

**w\* = 0 且人工变量全部离基** ⇒ 得原问题 BFS：x₁ = 2、x₂ = 1。进入第二阶段。

**第二阶段**：删 a₁、a₂ 列，目标换回 min z = 2x₁ + x₂，**检验数全部重算**（c_B = (1,2)）。

**表 P2-1**（基 (x₂,x₁)，c_B=(1,2)，z = 5）

| 基 | b | x₁ | x₂ | x₃ |
|---|---|---|---|---|
| x₂ | 1 | 0 | 1 | 1/2 |
| x₁ | 2 | 1 | 0 | −1/2 |
| σ | | 0 | 0 | 1/2 |

（σ₃ = 0 − [1·(1/2) + 2·(−1/2)] = 1/2。）

**最优性检验**：σ = (0, 0, 1/2) ≥ 0 ⇒ 已最优，无需再迭代。

**结论**：x\* = **(2, 1)ᵀ，z\* = 5**（x₃ = 0：x₁+x₂ = 3 ✓，x₁−x₂ = 1 ≥ 1 取等 ✓）。

> 独立复核：顶点共 2 个——(2,1) z=5、(3,0) z=6，最小值唯一为 5。
> 评分点：= 约束直接加人工（无松弛）；w\*=0 判据句；σ 重算；报 x\* 和 z\*。

### 7.（15 分）牛顿法 vs 最速下降法

f = 2x₁² + x₂² − 4x₁ + 2，∇f = (4x₁−4, 2x₂)ᵀ，∇²f = diag(4, 2)（常数正定）。x⁽¹⁾ = (2,1)ᵀ，g₁ = (4,2)ᵀ，f(x⁽¹⁾) = 3。

**（1）牛顿法**：d = −[∇²f]⁻¹g₁ = −diag(1/4, 1/2)(4,2)ᵀ = **(−1,−1)ᵀ**。

    x⁽²⁾ = (2,1)ᵀ + (−1,−1)ᵀ = (1, 0)ᵀ

验证：∇f(1,0) = (0,0)ᵀ，∇²f 正定 ⇒ x⁽²⁾ = (1,0)ᵀ 是**全局极小点**，f\* = 0。（正定二次函数牛顿一步终止。）

**（2）最速下降法**：d = −g₁ = (−4,−2)ᵀ。φ(λ) = f(2−4λ, 1−2λ) = 36λ² − 20λ + 3，

    φ′(λ) = 72λ − 20 = 0 ⇒ λ₁ = 5/18

x⁽²⁾ = (2,1)ᵀ + (5/18)(−4,−2)ᵀ = **(8/9, 4/9)ᵀ**，f = 2/9（未到最优）。

**（3）** 同一初点：牛顿一步到最优（f: 3→0），最速下降一步只到 f = 2/9。原因：牛顿法利用二阶信息（Hessian），对正定二次函数一步终止、一般函数**二阶收敛**；最速下降只用一阶梯度，**线性收敛**且走锯齿路线，慢得多。

> 评分点：牛顿方向是 −H⁻¹g（不是 −g）；最速下降 λ 用 φ′=0；对比结论落到"二阶 vs 线性收敛"。

### 8.（15 分）FR 共轭梯度法

f = x₁² + 2x₂² = ½xᵀAx，A = diag(2, 4)，∇f = (2x₁, 4x₂)ᵀ。

**第 1 步**：x⁽¹⁾ = (2,2)ᵀ，g₁ = (4,8)ᵀ，d⁽¹⁾ = −g₁ = **(−4,−8)ᵀ**。

    λ₁ = −g₁ᵀd⁽¹⁾/(d⁽¹⁾ᵀAd⁽¹⁾) = 80/288 = 5/18

x⁽²⁾ = (2,2)ᵀ + (5/18)(−4,−8)ᵀ = **(8/9, −2/9)ᵀ**，g₂ = (16/9, −8/9)ᵀ。

    β₁ = ‖g₂‖²/‖g₁‖² = (320/81)/80 = 4/81
    d⁽²⁾ = −g₂ + β₁d⁽¹⁾ = (−160/81, 40/81)ᵀ

**第 2 步**：

    g₂ᵀd⁽²⁾ = −320/81；d⁽²⁾ᵀAd⁽²⁾ = 6400/729
    λ₂ = (320/81)/(6400/729) = 9/20

x⁽³⁾ = (8/9,−2/9)ᵀ + (9/20)(−160/81,40/81)ᵀ = **(0, 0)ᵀ**，g₃ = 0，终止。

**（2）共轭验证**：Ad⁽²⁾ = (−320/81, 160/81)ᵀ，d⁽¹⁾ᵀAd⁽²⁾ = (−4)(−320/81) + (−8)(160/81) = 1280/81 − 1280/81 = **0** ⇒ 共轭。n = 2 两步到极小点——**二次终止性**（Th10.3.3）。

> 评分点：β 用梯度模平方比；λ 用 −gᵀd/(dᵀAd)；报 x⁽³⁾=(0,0) 并点出二次终止性。

### 9.（15 分）DFP 拟牛顿法

f = 3x₁² + x₂²，∇f = (6x₁, 2x₂)ᵀ，A = diag(6, 2)。x⁽¹⁾ = (1,3)ᵀ，g₁ = (6,6)ᵀ，H₁ = I。

**（1）** d⁽¹⁾ = −H₁g₁ = **(−6,−6)ᵀ**。φ(λ) = f(1−6λ, 3−6λ) = 144λ² − 72λ + 12，

    φ′(λ) = 288λ − 72 = 0 ⇒ λ₁ = 1/4。

x⁽²⁾ = (1,3)ᵀ + (1/4)(−6,−6)ᵀ = **(−1/2, 3/2)ᵀ**，g₂ = (−3,3)ᵀ。

**（2）** p = x⁽²⁾ − x⁽¹⁾ = (−3/2, −3/2)ᵀ，q = g₂ − g₁ = (−9, −3)ᵀ。

    pᵀq = 27/2 + 9/2 = 18；H₁q = q，qᵀH₁q = 81 + 9 = 90。

DFP 校正：H₂ = H₁ + ppᵀ/(pᵀq) − (H₁q)(H₁q)ᵀ/(qᵀH₁q)

    ppᵀ/18 = [[1/8, 1/8], [1/8, 1/8]]，qqᵀ/90 = [[9/10, 3/10], [3/10, 1/10]]

    H₂ = I + [[1/8, 1/8], [1/8, 1/8]] − [[9/10, 3/10], [3/10, 1/10]]
       = [[9/40, −7/40], [−7/40, 41/40]]

自检：H₂q = (−3/2, −3/2)ᵀ = p ✓（拟牛顿条件）；H₂ 对称，顺序主子式 9/40 > 0、det = (9·41−49)/1600 = 320/1600 > 0 ⇒ 正定。

**（3）** d⁽²⁾ = −H₂g₂ = **(6/5, −18/5)ᵀ**。φ(λ) = f(−1/2+6λ/5, 3/2−18λ/5)，

    φ′(λ) = 0 ⇒ λ₂ = 5/12。

x⁽³⁾ = (−1/2,3/2)ᵀ + (5/12)(6/5,−18/5)ᵀ = **(0, 0)ᵀ**，g₃ = 0，终止。

对 n 维正定二次函数 **Hₙ₊₁ = A⁻¹**（Th10.4.2 推论）。本题 **H₃ = A⁻¹ = diag(1/6, 1/2)**（脚本已验证）。

> 评分点：p = x 差、q = g 差；两校正项分母 pᵀq 与 qᵀHq；Hq=p 自检；报 x⁽³⁾ 与 H₃。

### 10.（15 分）KKT 条件（非线性约束）

约束化 g ≥ 0：g(x) = 1 − x₁² − x₂² ≥ 0。L = f − ug。

**（1）KKT 条件**：

    平稳性：∇f − u∇g = 0，即
      2(x₁ − 2) + 2ux₁ = 0
      2x₂ + 2ux₂ = 0
    互补松弛：u(1 − x₁² − x₂²) = 0
    原始可行：x₁² + x₂² ≤ 1
    对偶可行：u ≥ 0

**（2）验证 x\* = (1,0)ᵀ**：g(1,0) = 0（起作用）。∇f(1,0) = (−2, 0)ᵀ，∇g(1,0) = (−2, 0)ᵀ。平稳性：−2 + 2u = 0 ⇒ **u = 1** ≥ 0；第二式 0 = 0 ✓。互补松弛 u·0 = 0 ✓。全部 KKT 条件成立 ⇒ x\* 是 KKT 点。

**（3）** 约束非线性，∇²ₓₓL = ∇²f − u∇²g。∇²f = 2I，∇²g = −2I，故

    ∇²ₓₓL = 2I − 1·(−2I) = 4I（正定）

二阶充分条件成立 ⇒ x\* 是**严格局部极小点**。进一步：f 凸（∇²f = 2I ⪰ 0），g 凹（∇²g = −2I ⪯ 0）⇒ 可行域 {g ≥ 0} 是凸集（单位圆盘）⇒ 凸规划，KKT 点即**全局极小点**，f\* = (1−2)² + 0 = **1**。

> 独立复核：在边界 x₁²+x₂² = 1 上 f = x₁²+x₂²−4x₁+4 = 5−4x₁ ≥ 1，x₁ = 1 时取等 ⇒ (1,0) 全局最优。
> 评分点：**∇²ₓₓL = ∇²f − u∇²g**（约束非线性时 ≠ ∇²f，符号别反——11-08 笔记修正点）；凸规划 ⇒ 全局要写"可行域凸"的理由（g 凹）。

## 三、开放题

### 11.（10 分）现代优化算法 vs 传统优化算法（以遗传算法 GA 为例）

> 按第二册模板 B 口径（约 500 字，可直接背；换 SA/TS/DE 用第二册替换句清单）：

遗传算法（GA）是 20 世纪 80 年代初兴起的现代优化算法，模拟生物进化过程，以种群为单位在解空间进行随机全局搜索，流程为：编码 → 初始种群 → 适应度评价 → 选择 → 交叉 → 变异 → 新一代，直至终止；带约束时用罚函数处理。

与传统优化算法相比：（1）**搜索范围**：传统算法本质上是局部搜索，依赖初值、沿下降方向迭代且是确定性的；GA 以种群在解空间全局采样，同初值不同随机数结果不同。（2）**函数要求**：传统算法要求目标函数至少一阶连续可微，需要梯度/Hessian；GA 只需适应度可计算，不要求可导，能处理不可微、离散、含噪问题。（3）**理论保证**：传统方法有 KKT、F-J 等最优性条件与收敛性定理，最优性可严格判定；GA 无最优性证明，只在概率意义上收敛到全局最优附近，且可能早熟收敛。（4）**适用问题**：传统方法适合凸或光滑的小规模问题，对 NP-hard 无能为力；GA 主要面向 NP-hard 的全局优化与组合优化问题。（5）**计算代价**：传统方法单次迭代快、精度高，但确定性全局方法（如分枝定界）复杂度极高、只能解小规模问题；GA 需评价大量个体，参数多而敏感。

联系在于：二者求解同一类优化问题，共用"生成候选解—评价—更新—停机"的迭代框架，共享凸性、下降方向、KKT 条件与罚函数等理论工具；且可互补融合——GA 负责全局探索、传统局部法负责精修。此外，单纯形法用摄动法跳出退化循环，与模拟退火降温、禁忌搜索禁忌表同属"跳出局部最优"的机制。

综上，现代优化算法以牺牲收敛精度和理论保证为代价，换取对 NP-hard 问题的全局搜索能力，是解决全局优化问题的有力工具。

> 评分点：差别 5 条 + 联系（最易漏）+ 一个具体算法机制；"概率意义上/满意解"别写成"确定求出全局最优"。
