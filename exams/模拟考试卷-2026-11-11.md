## 一、简答题（每题 6 分，共 30 分）

**1.（6 分）** 比较最速下降法与牛顿法。
（1）（2 分）最速下降法的优点、缺点各一条；
（2）（2 分）牛顿法的优点、缺点各一条；
（3）（2 分）两者收敛速度有何差异？牛顿方向在什么情形下可能不是下降方向？如何补救？

**2.（6 分）** 叙述 Farkas 定理的几何表示形式（含"二者有且只有一个成立"的择一表述），并画出两种情况的示意图。

**3.（6 分）** 关于一维搜索的 0.618 法：
（1）（3 分）基本思想与两个试探点的取点公式（写出 λₖ、μₖ 的表达式）；
（2）（1 分）每轮迭代后区间缩短为原来的多少倍？为什么每轮只需新算一个试探点？
（3）（2 分）0.618 法与 Fibonacci 法的关系（两点）。

**4.（6 分）** 简述外点罚函数法与内点罚函数法（障碍函数法）的区别（至少四点）。

**5.（6 分）** 关于单纯形法：
（1）（3 分）进基变量、出基变量各按什么规则选取？最优性检验的准则是什么？
（2）（3 分）什么情况下要用两阶段法？第一阶段的目标函数是什么？转入第二阶段的判据是什么？

## 二、计算题（共 80 分）

**6.（20 分）** 用两阶段单纯形法求解下列线性规划，写出两个阶段的完整单纯形表（含最优性检验）：

    min z = −3x₁ + x₂ + x₃
    s.t.  x₁ − 2x₂ + x₃ ≤ 11
          −4x₁ + x₂ + 2x₃ ≥ 3
          −2x₁ + x₃ = 1
          x₁, x₂, x₃ ≥ 0

**7.（15 分）** 对约束优化问题

    min f(x) = (x₁ − 2)² + (x₂ − 2)²
    s.t.  x₁ + x₂ ≤ 2,  x₁ ≤ 1,  x₁ ≥ 0,  x₂ ≥ 0

（1）（5 分）写出 KKT 条件（按课程口径：约束化为 gᵢ(x) ≥ 0，L = f − Σuᵢgᵢ）；
（2）（5 分）验证 x* = (1, 1)ᵀ 是 KKT 点，并求出对应乘子；
（3）（5 分）用二阶充分条件判断 x* 是否为局部极小点；它是否为全局极小点？说明理由。

**8.（15 分）** 设 f(x) = ½x₁² + x₂²，初点 x⁽¹⁾ = (4, 4)ᵀ。
（1）（12 分）用 Fletcher–Reeves 共轭梯度法（精确线搜索）求 x⁽²⁾ 与 x⁽³⁾，写出每步的 d⁽ᵏ⁾、λₖ、βₖ；
（2）（3 分）验证 d⁽¹⁾ 与 d⁽²⁾ 关于 A 共轭（A 为 f 的 Hessian），并说明本题体现的共轭梯度法性质。

**9.（15 分）** 设 f(x) = 2x₁² + x₂²，初点 x⁽¹⁾ = (1, 2)ᵀ，H₁ = I。用 DFP 拟牛顿法（精确线搜索）：
（1）（4 分）求 d⁽¹⁾、λ₁、x⁽²⁾；
（2）（6 分）用 DFP 校正公式求 H₂（写出 p、q 与两个校正项），并自检是否满足拟牛顿条件；
（3）（5 分）求 d⁽²⁾、λ₂、x⁽³⁾；对 n 维正定二次函数，Hₙ₊₁ 等于什么？本题的 H₃ 是多少？

**10.（15 分）** 对问题

    min f(x) = (x₁ − 3)² + (x₂ − 1)²
    s.t.  x₁ + x₂ ≤ 2,  x₁ ≥ 0,  x₂ ≥ 0

从 x⁽⁰⁾ = (1, 1)ᵀ 出发，用 Rosen 梯度投影法求可行下降方向：
（1）（5 分）指出起作用约束，写出矩阵 M；
（2）（5 分）求投影矩阵 P = I − Mᵀ(MMᵀ)⁻¹M；
（3）（5 分）求 d = −P∇f(x⁽⁰⁾)，并验证其下降性与可行性。

> 按 2026-11-10 老师口径，CH12 考到"求可行下降方向"为止：本题**不求 λmax、不作一维搜索、不迭代**。
