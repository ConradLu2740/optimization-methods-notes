## 题面

用 **0.618 法** 求解一维搜索问题：

```
min  φ(λ) = (λ − 2.5)² + 1        初始区间 [a₁, b₁] = [0, 4]
```

（φ 为单峰函数，解析极小点 λ* = 2.5、φ* = 1 仅用于第 (3) 问比误差，做题时不许用）

1. 写出 0.618 法的取点公式与缩区间规则（λ₁ = a₁ + 0.382(b₁−a₁)、μ₁ = a₁ + 0.618(b₁−a₁)，小数保留三位）；
2. 完成**前 4 轮**迭代，每轮给出：区间 [aₖ, bₖ]、两个取点及函数值、舍去方向、新区间；**注意旧点复用，不要重复算函数值**；
3. 报 4 轮后的最终区间、区间长度、近似极小点（两种口径都报：区间中点 / 较优保留点），并与解析解比误差；
4. 若把精度要求改为最终区间长度 ≤ 0.5：0.618 法至少还要几轮（用缩率 rᵏ(b₁−a₁) ≤ δ 估）？同精度下用 Fibonacci 法定 n 是多少（F₀ = F₁ = 1，查表）？

|---|---|---|---|---|---|
| 1 | [0, 4] | 1.528（1.944784） | 2.472（1.000784） | 左段 | [1.528, 4] |
| 2 | [1.528, 4] | 2.472（1.000784，复用） | 3.055696（1.308798） | 右段 | [1.528, 3.055696] |
| 3 | [1.528, 3.055696] | 2.11158（1.15087） | 2.472（1.000784，复用） | 左段 | [2.11158, 3.055696] |
| 4 | [2.11158, 3.055696] | 2.472（1.000784，复用） | 2.695044（1.038042） | 右段 | [2.11158, 2.695044] |

- 终区间长 0.583464 = 4 × 0.618⁴；含真极小 2.5 ✓
- 近似极小点：中点 2.403312（误差 0.096688）；较优保留点 λ₄ = 2.472（误差 0.028，φ = 1.000784）
- 第 (4) 问：0.618 法 4 × 0.618⁴ = 0.583 > 0.5、4 × 0.618⁵ = 0.361 ≤ 0.5 ⇒ 至少 **5 轮**（与 (3) 的 0.583 自洽）；
  Fibonacci：需 Fₙ ≥ 4/0.5 = 8，F₅ = 8 ⇒ **n = 5**，终区间 ≤ 4/8 = 0.5。

## 预埋坑

① 缩区间方向判反（φ(λₖ) ≤ φ(μₖ) 是舍**右**段、bₖ₊₁ = μₖ，不是 aₖ₊₁ = μₖ）；
② 旧点复用搞错：舍右段后 μₖ₊₁ = λₖ（旧左点变新右点），只新算一个点；舍左段后 λₖ₊₁ = μₖ，只新算 μₖ₊₁；
③ 新取点要放在**新区间**里算（aₖ₊₁ + r(bₖ₊₁−aₖ₊₁)），用旧 aₖ 算会整段跑偏；
④ 0.382 = 1 − 0.618，λ/μ 左右写反；
⑤ 报结果漏报"区间长度"或只报一种近似极小点口径；
⑥ 第 (4) 问把 0.618 的轮数与 Fibonacci 的 n 混为一谈（轮数 = 缩减次数，n 是取点次数口径）。
