## 参考答案（先自己写完再看）

### (1) 退化的定义与表上特征

**定义**：基本可行解中若有**取零值的基变量**，称它为退化的 BFS（m 个基变量里至少一个是 0；非基变量本来就取 0，不算）。退化与系数矩阵 B 满秩不矛盾——几何上是**多个约束交于同一顶点**，顶点被"超定"地表示。

**单纯形表上的特征**（三点）：

- 比值检验 min{bᵢ/āᵢⱼ : āᵢⱼ > 0} 出现**并列**（多行同时取到最小比值）；
- 按规则选中的出基变量，其取值为 **0**；
- 换基步长 θ = 0，换基后**目标函数值 z 不变**——只是同一顶点换了一组基来表示。

### (2) 为什么"非退化"假设不可少

Th3.4 的证明骨架：**每次迭代 z 严格下降**，而可行域的顶点（BFS）只有**有限个**，z 严格下降就不可能两次到达同一顶点，故有限步终止。

退化时这条链断在第一步：出基变量取 0 ⇒ 步长 θ = 0 ⇒ **z 不下降（原地踏步）**。"z 严格下降 ⇒ 顶点不重复"的保障失效，同一顶点可以换一套基再来一遍，于是**可能无限循环**（Beale 例：按"最负 σ + 并列取最上行"规则，6 次换基回到初始基 (x₁, x₂, x₃)，z 恒等于 0）。

答题时两个角度都要点到：**比值检验**（并列是退化的表上信号）和**目标函数值**（θ = 0 使 z 不变，破坏有限步终止的论证）。

### (3) 两种处理办法

**(a) 摄动法**（课件 s075–s083）：对右端向量作小扰动 b(ε) = (ε, ε², ε³)（ε > 0 充分小，各分量取 ε 的不同幂次），把比值检验里的并列**全部打散**，使摄动问题非退化；迭代中 ε 不必代具体数字，按 ε 的幂次作比值比较即可；初始可行解由原问题的 BFS 经**列调换**（基列排在非基列左边、下标重排）得到；解出摄动问题即可确定原问题的最优解。思想：**改数据**。

**(b) Bland 规则**（课件 s084，原话："在单纯形表中选**最左边的正检验数**对应的非基变量入基"）：入基在满足条件的非基变量中取**下标最小**者；配套出基规则是比值并列时取**基变量下标最小**者。思想：**改选法**——放弃"检验数最负"的贪心，用确定性的最小下标规则，Bland 证明了不会循环。

⚠️ 符号口径：课件 s084 写"正检验数"，是课件表格的符号方向（对 min 问题取了反向检验数）；本课程材料与 `scripts/demo_beale.py` 用 σⱼ = cⱼ − c_BᵀB⁻¹Aⱼ、**σⱼ < 0 入基**。考场按自己卷子的表头走，别把方向说反。

### (4) Beale 例应用

**入基选择**：最负 σ 规则 ⇒ **x₇**（σ₇ = −3 比 σ₁ = −2 更负）；Bland 规则 ⇒ **x₁**（负检验数中下标最小）。

**两条路线的结局**（`scripts/demo_beale.py` 精确复跑）：

| 轮 | 最负 σ 路线 | Bland 路线 |
|---|---|---|
| 0–2 | x₄ → x₅ → x₆ | x₄ → x₅ → x₆（与前 3 轮完全相同） |
| 3 | **x₇**（最负） | **x₁**（下标最小）← 第一次分岔 |
| 4 | x₁ | x₂（此时 σ₂ = −1、σ₄ = −5/4，仍取下标小的） |
| 5 | x₂ | x₄ |
| 6 | 回到初始基 (x₁,x₂,x₃)，**死循环**，z 恒 0 | σ 全 ≥ 0，**最优** x* = (3/4, 0, 0, 1, 0, 1, 0)，**z* = −5/4** |

结论：Bland 牺牲"每步检验数最负"的贪心速度，换取全局不循环；摄动法则保持贪心判据、从数据上消灭并列。两条路都通向最优解 x* = (3/4, 0, 0, 1, 0, 1, 0)、z* = −5/4，只是一个要绕 6 轮死循环、一个 6 轮直达。

## 预埋坑（考场易错点）

1. **把退化理解成"约束冗余/系数矩阵奇异"**——退化与 B 满秩不矛盾，纯粹是基变量取 0（多个约束交于同一顶点）。
2. 第 (2) 问只写"z 可能不下降"，不写"**顶点有限 + z 严格下降 ⇒ 不重复顶点**"这个闭环；或不提比值并列这个表上信号。
3. **把"选最左边（下标最小）的检验数入基"挂到摄动法名下**——课件 s084 明确归 Bland 规则；摄动法的标志是 b(ε) 加 ε 幂次。（第一册 §3.3 旧稿有此错，本文件已按课件实抽更正。）
4. Bland 只写入基半条，**漏"出基并列取基变量下标最小"**。
5. 第 (4) 问符号口径混淆：本课程 σ < 0 入基；若照课件 s084"正检验数"的字面，会把入基方向说反。
6. 第 (3) 问只写两个名字不写思想（摄动 = 打散并列、改数据；Bland = 最小下标、改选法）。
